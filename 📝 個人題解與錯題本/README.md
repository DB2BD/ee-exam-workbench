## 📄 建立新題解步驟
1. 複製 [`TEMPLATE_題解與錯題筆記範本.md`](./TEMPLATE_題解與錯題筆記範本.md)。
2. 將檔案命名為：`<年份>年_<考科>_<題號>_<主題>.md`（例如：`114年_電路學_第一題_節點電壓法.md`）。
3. 填入 YAML Frontmatter 中的 `考點`、`難易度` 與 `掌握狀態`。
4. 在 [📊 備考進度儀表板.md](../📊%20備考進度儀表板.md) 中即可自動同步追蹤！
