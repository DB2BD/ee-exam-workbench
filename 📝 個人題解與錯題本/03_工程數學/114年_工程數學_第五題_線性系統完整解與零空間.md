## 📌 題目在問什麼？（原題呈現）

題目給我們一個矩陣 $\mathbf{A}$ 和一個向量 $\mathbf{b}$：
$$\mathbf{A} = \begin{bmatrix} 0 & -1 & 0 & 1 \\ 0 & 1 & -1 & 0 \end{bmatrix}, \quad \mathbf{b} = \begin{bmatrix} 0 \\ 1 \end{bmatrix}$$

要我們求兩件事：
1. **第 (一) 小題（20 分）**：求 $\mathbf{A}\mathbf{x} = \mathbf{b}$ 的「完整解（Complete Solution）」。
2. **第 (二) 小題（10 分）**：求矩陣 $\mathbf{A}$ 的「零空間（Null Space）$N(\mathbf{A})$」。

---

## 💡 白話文破題：這題到底在考什麼？

別被「矩陣」嚇到了！這題本質上就是**國中學過的「解聯立方程式」**：

我們假設要求的答案是 4 個未知數 $\mathbf{x} = \begin{bmatrix} x_1 \\ x_2 \\ x_3 \\ x_4 \end{bmatrix}$。

題目寫成矩陣相乘 $\mathbf{A}\mathbf{x} = \mathbf{b}$，其實翻譯成白話文就是兩條方程式：
- **第 1 式（第 1 列相乘）**：$0\cdot x_1 - 1\cdot x_2 + 0\cdot x_3 + 1\cdot x_4 = 0 \implies \mathbf{-x_2 + x_4 = 0}$
- **第 2 式（第 2 列相乘）**：$0\cdot x_1 + 1\cdot x_2 - 1\cdot x_3 + 0\cdot x_4 = 1 \implies \mathbf{x_2 - x_3 = 1}$

> **核心邏輯**：
> 未知數有 **4 個**（$x_1, x_2, x_3, x_4$），但條件只有 **2 條**！
> 方程式不夠用，所以答案不會是唯一的數字，一定會有可以「自由隨便代數字」的變數（稱為**自由變數**）。

---

## ✏️ 手把手帶你一步一步算

### 🔹 第 (一) 小題：求完整解（20 分）

我們把這兩條方程式移項整理一下：
1. 由第 1 式：$-x_2 + x_4 = 0 \implies \mathbf{x_2 = x_4}$
2. 由第 2 式：$x_2 - x_3 = 1 \implies \mathbf{x_3 = x_2 - 1 = x_4 - 1}$
3. 那 $x_1$ 呢？
   👉 **$x_1$ 從頭到尾根本沒在方程式裡出現過！** 這代表 $x_1$ 愛等於多少就等於多少，完全不受限制！

#### 步驟：設定自由變數
因為 $x_1$ 和 $x_4$ 可以隨便代數字，我們給它們兩個參數代號：
- 令 **$x_1 = c_1$**（$c_1$ 可以是任何實數）
- 令 **$x_4 = c_2$**（$c_2$ 可以是任何實數）

那麼 4 個未知數立刻全部解出來了：
- $x_1 = c_1$
- $x_2 = c_2$ （因為 $x_2 = x_4$）
- $x_3 = c_2 - 1$ （因為 $x_3 = x_4 - 1$）
- $x_4 = c_2$

#### 寫成直立的向量形式：
$$\mathbf{x} = \begin{bmatrix} x_1 \\ x_2 \\ x_3 \\ x_4 \end{bmatrix} = \begin{bmatrix} c_1 \\ c_2 \\ -1 + c_2 \\ c_2 \end{bmatrix}$$

#### 拆成「純常數」+「$c_1$ 項」+「$c_2$ 項」：
$$\mathbf{x} = \underbrace{\begin{bmatrix} 0 \\ 0 \\ -1 \\ 0 \end{bmatrix}}_{\text{特解} \mathbf{x}_p \text{ (純數字)}} + c_1 \underbrace{\begin{bmatrix} 1 \\ 0 \\ 0 \\ 0 \end{bmatrix}}_{\mathbf{v}_1} + c_2 \underbrace{\begin{bmatrix} 0 \\ 1 \\ 1 \\ 1 \end{bmatrix}}_{\mathbf{v}_2}$$

🎉 **第 (一) 小題答案就完成了！**

---

### 🔹 第 (二) 小題：求零空間 $N(\mathbf{A})$（10 分）

> **什麼是零空間（Null Space）？**
> 零空間的定義就是：**「如果把等號右邊的答案改成 0（即 $\mathbf{A}\mathbf{x} = \mathbf{0}$），解出來的向量是什麼？」**

既然等號右邊變成 $0$ 了，剛剛算出來的純數字特解 $\begin{bmatrix} 0 \\ 0 \\ -1 \\ 0 \end{bmatrix}$ 就會消失（變成 $0$），只會剩下帶有參數 $c_1$ 和 $c_2$ 的那兩組方向向量：

$$N(\mathbf{A}) = \text{span}\left\{ \begin{bmatrix} 1 \\ 0 \\ 0 \\ 0 \end{bmatrix}, \begin{bmatrix} 0 \\ 1 \\ 1 \\ 1 \end{bmatrix} \right\}$$

也就是說，$N(\mathbf{A})$ 是由這兩個向量所張成的二維空間！

---

## 🎯 考場上只要這樣寫（滿分作答範本）

在考卷上作答時，只要簡潔俐落地寫下以下 4 行即可拿滿 30 分：

```markdown
解：
(一)
設 x = [x1, x2, x3, x4]^T。
由 Ax = b 展開可得聯立方程：
  -x2 + x4 = 0  ==>  x2 = x4
   x2 - x3 = 1  ==>  x3 = x4 - 1
選取 x1, x4 為自由變數，令 x1 = c1, x4 = c2 (c1, c2 為任意實數)。
則完整解為：
  x = [0, 0, -1, 0]^T + c1 * [1, 0, 0, 0]^T + c2 * [0, 1, 1, 1]^T  (c1, c2 in R)

(二)
矩陣 A 之零空間 N(A) 為滿足 Ax = 0 之所有解集合。
令右端項 b = [0, 0]^T，得通解為 c1 * [1, 0, 0, 0]^T + c2 * [0, 1, 1, 1]^T。
故零空間為：
  N(A) = span{ [1, 0, 0, 0]^T, [0, 1, 1, 1]^T}
  維度 dim(N(A)) = 2
```

## ⚠️ 考場最容易粗心的地方

1. **以為 $x_1 = 0$（致命陷阱！）**
   - 矩陣第 1 行是 $\begin{bmatrix} 0 \\ 0 \end{bmatrix}$，代表 $x_1$ 完全沒被任何條件限制，所以 $x_1$ 是自由變數（可以是任何數字 $c_1$），**絕對不能寫 $x_1 = 0$**，否則整題直接被扣一半分數！
2. **忘記寫 $c_1, c_2 \in \mathbb{R}$**
   - 完整解一定要宣告 $c_1, c_2$ 為任意實數常數。
