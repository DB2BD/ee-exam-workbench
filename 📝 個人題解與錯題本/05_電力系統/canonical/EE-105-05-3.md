## 三、同步發電機中性點經電抗接地單線接地故障（20 分）

### 📌 題目與已知條件
![[105年_電力系統_第3題_同步機接地單線圖.png|750]]
*圖：105年電力系統第三題 同步機接地單線圖*

- 發電機：$100\text{ MVA}, 20\text{ kV}, X_1'' = X_2'' = 0.20\text{ pu}, X_0 = 0.08\text{ pu}$。
- 中性點接地電抗：$X_n = 0.32\ \Omega$。

**試求**：$a$ 相單線接地故障（SLG）次暫態故障電流實際值（$\text{kA}$）。（20 分）

---

### ✏️ 步驟式詳細數學推導
1. **基準阻抗與標么化**：
   $$Z_{base} = \frac{(20\text{ kV})^2}{100\text{ MVA}} = 4.0\ \Omega \implies X_{n,pu} = \frac{0.32}{4.0} = 0.08\text{ pu}$$
2. **單線接地序阻抗串聯**：
   $$I_{a1} = \frac{1.0}{j(0.20 + 0.20 + 0.08 + 3\times 0.08)} = \frac{1.0}{j0.72} = -j1.3889\text{ pu}$$
   $$I_f = 3 I_{a1} = \mathbf{-j4.1667\text{ pu}}$$
3. **實體電流**：
   $$I_{base} = \frac{100\times 10^6}{\sqrt{3}\times 20\times 10^3} = 2886.75\text{ A} \implies I_{f,actual} = 4.1667 \times 2.88675\text{ kA} = \mathbf{12.028\text{ kA}}$$

---

### 🎯 第三題 滿分關鍵與結論
- **標么故障電流**：$I_f = \mathbf{4.167\text{ pu}}$
- **實體故障電流**：$I_f = \mathbf{12.03\text{ kA}}$
