# TDD Skill (by Matt Pocock)

Enforces strict **Test-Driven Development** (TDD) discipline.

## 🔴 🟢 🔵 Protocol

1. **🔴 Red Phase**: Write the minimal failing test first that demonstrates the missing feature or bug. Run it to confirm it fails for the expected reason.
2. **🟢 Green Phase**: Write the simplest, cleanest implementation code necessary to make the test pass. Run tests to confirm green.
3. **🔵 Refactor Phase**: Clean up formatting, extract reusable helpers, eliminate duplication while keeping all tests passing.
4. **Never skip writing tests first.**
