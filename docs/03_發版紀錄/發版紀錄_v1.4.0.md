- 工程數學 12 則起手式的字面 `\n`、4 份 Markdown 的外洩 `$`／`\frac` 修正。
- 新增常設閘門 `scripts/audit_math_render.cjs`＋`tests/test_math_render.py`：以 App 實際渲染流程檢查 1485 個欄位，要求 0 個 KaTeX 錯誤、0 個外洩指令。

### 2. 詳解補足與兩位小數

- 新增 `scripts/audit_solution_depth.py`（報告 `reports/題解深度稽核_2026-10-14.md`）：逐子題檢查觀念句、代入式、中間結果與篇幅。
- 264 題改寫：每個子題依「觀念一句 → 符號公式 → 代入 → 中間結果 → 答案」寫出；需要時補一句等效電路、相量圖或參考方向的畫法。稽核後只剩 1 題標記（EE-108-03-3，答案為精確分式，屬稽核誤判）。
- 計算所得數字一律顯示到小數點後第二位（規範見 `AGENT-SOLVE.md`「三之一」）：完整精度計算、只在顯示時四捨五入；整數與題給數據照原樣；兩位小數誤差超過 0.5% 時改用 SI 字首或科學記號；題幹指定位數時以題幹為準（EE-113-06-2 取 0.9803）。
- 答案數值、稽核狀態與 323 支驗算腳本皆未改；無疑似答案問題。順帶更正數處中間值的舊顯示錯誤（例：串接四捨五入造成的 48.62→48.61、213.66→213.62，失分點自相矛盾的 0.610%→1.06%）。
- 165 處測試字串只因四捨五入更新（逐條列於 `.agents/results/V140-DEPTH/*.json` 的 `test_string_updates`）；其他斷言語意未改。
