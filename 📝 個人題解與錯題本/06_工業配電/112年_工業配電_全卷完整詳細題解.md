## 一、系統接地與設備接地之方法與目的（20 分）

### 📌 題目與已知條件
* **(一)** 試述系統接地（System Grounding）與設備接地（Equipment Grounding）之方法與目的。（10 分）
* **(二)** 請繪圖說明這兩種接地之實務施作法。（10 分）

---

### 💡 核心考點與破題關鍵
1. **系統接地（System Grounding）**：
   - **定義**：將電力系統之中性點（Neutral Point）直接或經由阻抗連接於大地。
   - **目的**：穩定系統對地電位、限制異常突波電壓、提供接地故障電流回路使保護電驛（51N）快速動作。
   - **常見方式**：固態接地（Solid Grounding）、低電阻接地（Low-Resistance）、高電阻接地（High-Resistance）、不接地。
2. **設備接地（Equipment Grounding）**：
   - **定義**：將電氣設備之非帶電金屬外殼、導線管、配電盤箱體連接至接地極。
   - **目的**：防止絕緣劣化外殼漏電造成人員感電危險（降低接觸電壓 Touch Voltage）、提供低阻抗故障路徑使過電流斷路器跳脫。

---

### 🎯 第一題 滿分關鍵與結論
- **完整區分系統接地（保護電力系統）與設備接地（保護人身安全）之核心功能與接線圖**。

## 二、負載特性分析與變壓器容量計算（20 分）

### 📌 題目與已知條件
工廠配電系統如圖一所示，主變壓器下設變壓器 A 與變壓器 B，各自供應設備 1~4。各設備容量、功率因數、需量因數（$f_D$）、負載因數（$f_L$）、設備間參差因數（$f_{div}$）與變壓器間參差因數如表所示。
試求：
* **(一)** 變壓器 A 供應之最高需量（$\text{kW}$）。（5 分）
* **(二)** 變壓器 B 供應之最高需量（$\text{kW}$）。（5 分）
* **(三)** 主變壓器供應之總最高需量（$\text{kW}$）。（5 分）
* **(四)** 工廠全日總耗電量（$\text{kWh}$）。（5 分）

---

### 💡 核心考點與破題關鍵
1. **設備個別最高需量**：$P_{max,i} = S_i \times \text{PF}_i \times f_{D,i}$
2. **群組綜合最高需量**：$P_{group} = \frac{\sum P_{max,i}}{f_{div}}$
3. **全日用電量**：$E_i = P_{max,i} \times f_{L,i} \times 24\text{ h}$

---

### ✏️ 步驟式詳細數學推導
1. **變壓器 A 負載計算**：
   - 設備 1：$P_{max,1} = 300 \times 0.95 \times 0.80 = 228\text{ kW}$
   - 設備 2：$P_{max,2} = 250 \times 0.85 \times 0.60 = 127.5\text{ kW}$
   - 變壓器 A 最高需量（參差因數 $1.2$）：
     $$\mathbf{P_{max,A} = \frac{228 + 127.5}{1.2} = \frac{355.5}{1.2} = 296.25\text{ kW}}$$
2. **變壓器 B 負載計算**：
   - 設備 3：$P_{max,3} = 500 \times 0.80 \times 0.50 = 200\text{ kW}$
   - 設備 4：$P_{max,4} = 250 \times 0.70 \times 0.70 = 122.5\text{ kW}$
   - 變壓器 B 最高需量（參差因數 $1.4$）：
     $$\mathbf{P_{max,B} = \frac{200 + 122.5}{1.4} = \frac{322.5}{1.4} = 230.36\text{ kW}}$$
3. **主變壓器總最高需量**：
   - 變壓器間參差因數為 $1.15$：
     $$\mathbf{P_{max,main} = \frac{P_{max,A} + P_{max,B}}{1.15} = \frac{296.25 + 230.36}{1.15} = \frac{526.61}{1.15} = 457.92\text{ kW}}$$
4. **計算工廠全日總用電量（kWh）**：
   - $E_1 = 228 \times 0.70 \times 24 = 3830.4\text{ kWh}$
   - $E_2 = 127.5 \times 0.60 \times 24 = 1836.0\text{ kWh}$
   - $E_3 = 200 \times 0.40 \times 24 = 1920.0\text{ kWh}$
   - $E_4 = 122.5 \times 0.50 \times 24 = 1470.0\text{ kWh}$
   $$\mathbf{E_{total} = 3830.4 + 1836.0 + 1920.0 + 1470.0 = 9056.4\text{ kWh}}$$

---

### 🎯 第二題 滿分關鍵與結論
- **變壓器 A 最高需量**：$P_{max,A} = \mathbf{296.25\text{ kW}}$
- **變壓器 B 最高需量**：$P_{max,B} = \mathbf{230.36\text{ kW}}$
- **主變壓器總最高需量**：$P_{max,main} = \mathbf{457.92\text{ kW}}$
- **全日總耗電量**：$E_{total} = \mathbf{9056.4\text{ kWh}}$

## 三、MVA 法求解放射狀系統各點三相短路容量（20 分）

### 📌 題目與已知條件
放射狀系統如圖二，電源短路容量 $S_{sc,sys} = 200\text{ MVA}$（$11.4\text{ kV}$）。主變 $1000\text{ kVA}, 11.4\text{ kV} / 380\text{ V}, Z = 10\%$。電纜線阻抗 $R+jX = 0.0722\ \Omega$（於 $380\text{ V}$ 側）。
試以 MVA 法求 $F_1, F_2, F_3$ 發生三相短路時斷路器之對稱啟斷電流值。

---

### 💡 核心考點與破題關鍵
1. **MVA 法元件短路容量定義**：
   - 變壓器 MVA 容量：$S_{sc,Tr} = \frac{S_{Tr}}{Z_{pu}} = \frac{1\text{ MVA}}{0.10} = 10\text{ MVA}$
   - 電纜 MVA 容量：$S_{sc,cable} = \frac{V_L^2}{Z_{cable}} = \frac{(0.38)^2}{0.0722} = \frac{0.1444}{0.0722} = 2.0\text{ MVA}$
2. **串聯 MVA 綜合法**：$\frac{1}{S_{sc,total}} = \sum \frac{1}{S_{sc,i}}$。
3. **短路電流計算**：$I_{sc} = \frac{S_{sc}}{\sqrt{3} V_L}$。

---

### ✏️ 步驟式詳細數學推導
1. **故障點 $F_1$（$11.4\text{ kV}$ 匯流排）**：
   - $S_{sc,F1} = S_{sc,sys} = \mathbf{200\text{ MVA}}$
   - 短路電流：
     $$\mathbf{I_{sc,F1} = \frac{200 \times 10^6}{\sqrt{3} \times 11.4 \times 10^3} = 10127.3\text{ A} = 10.13\text{ kA}}$$
2. **故障點 $F_2$（變壓器二次側 $380\text{ V}$ 匯流排）**：
   - 電源與變壓器串聯：
     $$\frac{1}{S_{sc,F2}} = \frac{1}{200} + \frac{1}{10} = 0.005 + 0.10 = 0.105 \implies \mathbf{S_{sc,F2} = \frac{1}{0.105} = 9.524\text{ MVA}}$$
   - 短路電流：
     $$\mathbf{I_{sc,F2} = \frac{9.524 \times 10^6}{\sqrt{3} \times 380} = 14470.2\text{ A} = 14.47\text{ kA}}$$
3. **故障點 $F_3$（電纜末端負載側）**：
   - 串聯電纜：
     $$\frac{1}{S_{sc,F3}} = \frac{1}{9.524} + \frac{1}{2.0} = 0.105 + 0.50 = 0.605 \implies \mathbf{S_{sc,F3} = \frac{1}{0.605} = 1.653\text{ MVA}}$$
   - 短路電流：
     $$\mathbf{I_{sc,F3} = \frac{1.653 \times 10^6}{\sqrt{3} \times 380} = 2511.4\text{ A} = 2.51\text{ kA}}$$

---

### 🎯 第三題 滿分關鍵與結論
- **$F_1$ 啟斷容量與電流**：$S_{sc} = \mathbf{200\text{ MVA}}, \quad I_{sc} = \mathbf{10.13\text{ kA}}$
- **$F_2$ 啟斷容量與電流**：$S_{sc} = \mathbf{9.52\text{ MVA}}, \quad I_{sc} = \mathbf{14.47\text{ kA}}$
- **$F_3$ 啟斷容量與電流**：$S_{sc} = \mathbf{1.65\text{ MVA}}, \quad I_{sc} = \mathbf{2.51\text{ kA}}$

## 四、過電流電驛（CO Relay）動作時間與曲線參數求解（20 分）

### 📌 題目與已知條件
由 $11.4\text{ kV}$ 受電，系統短路容量 $500\text{ MVA}$，變壓器 $750\text{ kVA}, 11.4\text{ kV} / 380\text{ V}, Z\% = 5.7\%$。
* **(一)** 求二次側 F 點之三相對稱故障電流（A）。（8 分）
* **(二)** 反時限電驛動作公式為 $T_s = \frac{k \times 80}{(I/I_s)^2 - 1} \times 0.808$。若始動電流 $I_s = 135\% I_{FLC}$，要求短路時電驛在 $0.3\text{ 秒}$ 動作，求參數 $k$。（12 分）

---

### 💡 核心考點與破題關鍵
1. **短路電流計算**：
   - $S_{sc,Tr} = \frac{0.75}{0.057} = 13.158\text{ MVA}$
   - $S_{sc,total} = 500 \parallel 13.158 = 12.82\text{ MVA}$
   - $I_{sc} = \frac{12.82 \times 10^6}{\sqrt{3} \times 380} = 19480\text{ A}$（二次側）或換算至一次側。

---

### ✏️ 步驟式詳細數學推導
1. **(一) 計算對稱短路電流**：
   - 變壓器一次側額定電流：$I_{FLC,1} = \frac{750}{\sqrt{3} \times 11.4} = 37.98\text{ A}$。
   - 一次側短路電流：$I_{sc,1} = \frac{12.82 \times 10^6}{\sqrt{3} \times 11.4 \times 10^3} = \mathbf{649.33\text{ A}}$。
2. **(二) 求解曲線參數 $k$**：
   - 始動電流：$I_s = 1.35 \times 37.98 = 51.27\text{ A}$。
   - 電流倍數比：$\frac{I}{I_s} = \frac{649.33}{51.27} = 12.665$。
   - 代入公式解 $k$：
     $$0.3 = \frac{k \times 80}{(12.665)^2 - 1} \times 0.808 = \frac{k \times 64.64}{160.40 - 1} = \frac{64.64 k}{159.40} = 0.4055 k$$
     $$\mathbf{k = \frac{0.3}{0.4055} = 0.74}$$

---

### 🎯 第四題 滿分關鍵與結論
- **一次側對稱故障電流**：$I_{sc} = \mathbf{649.33\text{ A}}$（二次側為 **$19.48\text{ kA}$**）
- **曲線選擇參數**：$k = \mathbf{0.74}$
