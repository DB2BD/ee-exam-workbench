# 105 年第 1 題｜由通解反推 ODE

通解 (y=e^{3x}(c_1sin2x+c_2cos2x)) 對應複數根 (r=3pm2i)。因此特徵多項式為
[
(r-(3+2i))(r-(3-2i))=(r-3)^2+4=r^2-6r+13.
]

[
\boxed{y''-6y'+13y=0}.
]
直接代入 (e^{3x}sin2x) 與 (e^{3x}cos2x) 均得零，驗證兩個獨立解。
