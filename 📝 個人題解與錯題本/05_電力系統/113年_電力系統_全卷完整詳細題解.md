## 一、三相並聯負載阻抗與複數功率分析（25 分）

### 📌 題目與已知條件
![[113年_電力系統_第1題_並聯負載圖.png|750]]
*圖：113年電力系統第一題 三相並聯負載系統架構圖*

如下圖所示，由一個三相平衡電源供電給兩個並聯三相負載：
- **電源**：三相平衡電源，線電壓大小為 $V_L = 208\text{ V}$（相電壓 $V_\phi = 208/\sqrt{3} \approx 120.09\text{ V}$）。
- **負載 1（$\text{Load}_1$）**：$\Delta$ 接線，每相阻抗 $Z_{\Delta} = 12 + j9\ \Omega = 15\angle 36.87^\circ\ \Omega$。
- **負載 2（$\text{Load}_2$）**：$\text{Y}$ 接線，每相阻抗 $Z_Y = 4 + j3\ \Omega = 5\angle 36.87^\circ\ \Omega$。

* **(一)** 試求此二並聯負載之等效單相 $\text{Y}$ 接阻抗 $Z_{eq,Y}$。（10 分）
* **(二)** 試求電源供給之總三相實功率 $P_{total}$、虛功率 $Q_{total}$ 及總功率因數 $\text{PF}$。（15 分）

---

### 💡 核心考點與破題關鍵
1. **$\Delta-\text{Y}$ 阻抗等效轉換**：
   - 對稱三相平衡系統中，$\Delta$ 接線每相阻抗可等效轉換為 $\text{Y}$ 接阻抗：
     $$Z_{Y1} = \frac{Z_{\Delta}}{3} = \frac{12 + j9}{3} = 4 + j3\ \Omega$$
   - 驚人發現：轉換後 $Z_{Y1}$ 恰好與負載 2 之 $Z_Y$ 完全相同！兩者並聯即為阻抗減半。
2. **三相複數功率計算**：
   $$P_{3\phi} = \sqrt{3} V_L I_L \cos\theta = 3 \frac{V_\phi^2}{|Z_{eq}|} \cos\theta, \quad Q_{3\phi} = 3 \frac{V_\phi^2}{|Z_{eq}|} \sin\theta$$

---

### ✏️ 步驟式詳細數學推導

#### 🔹 第 (一) 小題：求解等效單相 $\text{Y}$ 接阻抗 $Z_{eq,Y}$
1. 將負載 1（$\Delta$ 接）轉為等效 $\text{Y}$ 接：
   $$Z_{Y1} = \frac{Z_\Delta}{3} = \frac{12 + j9}{3} = 4 + j3\ \Omega$$
2. 負載 2 本身即為 $\text{Y}$ 接：
   $$Z_{Y2} = 4 + j3\ \Omega$$
3. 計算兩組 $\text{Y}$ 接並聯等效阻抗 $Z_{eq,Y}$：
   $$Z_{eq,Y} = Z_{Y1} \parallel Z_{Y2} = \frac{(4 + j3)(4 + j3)}{(4 + j3) + (4 + j3)} = \frac{4 + j3}{2} = \mathbf{2 + j1.5\ \Omega} = \mathbf{2.5\angle 36.87^\circ\ \Omega}$$

---

#### 🔹 第 (二) 小題：求解總功率與功率因數
1. **每相端電壓（Phase Voltage）**：
   $$V_\phi = \frac{V_L}{\sqrt{3}} = \frac{208}{\sqrt{3}} \approx 120.089\text{ V}$$
2. **每相複數功率 $\mathbf{S}_\phi$**：
   $$\mathbf{S}_\phi = \frac{V_\phi^2}{Z_{eq,Y}^*} = \frac{(120.089)^2}{2 - j1.5} = \frac{14421.37}{2.5\angle -36.87^\circ} = 5768.55\angle 36.87^\circ\text{ VA} = (4614.84 + j3461.13)\text{ VA}$$
3. **三相總複數功率 $\mathbf{S}_{total}$**：
   $$\mathbf{S}_{total} = 3 \times \mathbf{S}_\phi = 3 \times (4614.84 + j3461.13) = \mathbf{13844.5\text{ W} + j10383.4\text{ Var}} = 17305.6\angle 36.87^\circ\text{ VA}$$
   - **總實功率**：$P_{total} = \mathbf{13.845\text{ kW}}$
   - **總虛功率**：$Q_{total} = \mathbf{10.383\text{ kvar}}$
   - **總功率因數**：$\text{PF} = \cos(36.87^\circ) = \mathbf{0.80\text{ 滯後（Lagging）}}$

---

### ⚠️ 考場陷阱與評分避坑指南
- ⚠️ **切勿將 $V_L = 208\text{ V}$ 直接除以 $Z_{eq,Y}$**：$Z_{eq,Y}$ 是單相等效阻抗，其兩端承受的是「相電壓」$V_\phi = 208/\sqrt{3}$，若誤用線電壓計算相電流會放大 $\sqrt{3}$ 倍導致功率暴增 3 倍！
- ⚠️ **單位必須完整標註**：實功寫 $\text{kW}$、虛功寫 $\text{kvar}$、功率因數必須寫明「滯後（Lagging）」。

---

### 🎯 第一題 滿分關鍵與結論
| 求解項目 | 符號表示 | 標準解答數值 | 滿分得分要領 |
| :--- | :---: | :---: | :--- |
| **等效 $\text{Y}$ 接阻抗** | $Z_{eq,Y}$ | **$2 + j1.5\ \Omega$**（或 $2.5\angle 36.87^\circ\ \Omega$） | 寫出 $Z_\Delta / 3$ 轉換式 |
| **三相總實功率** | $P_{total}$ | **$13.845\text{ kW}$** | 需列出 3 相相乘計算式 |
| **三相總虛功率** | $Q_{total}$ | **$10.383\text{ kvar}$** | 標註感性虛功正號 |
| **系統功率因數** | $\text{PF}$ | **$0.80\text{ 滯後}$** | 必須註明 Lagging |

## 二、同步機與輸電線路三相短路故障暫態電流（25 分）

### 📌 題目與已知條件
![[113年_電力系統_第2題_同步機短路圖.png|750]]
*圖：113年電力系統第二題 同步機與輸電線短路系統單線圖*

一電力系統由發電機 $G_1$ 經變壓器 $T_1$、雙迴線輸電線及變壓器 $T_2$ 供電至電動機 $M_2$，系統基準容量為 $S_{base} = 100\text{ MVA}, V_{base} = 24\text{ kV}$：
- **發電機 $G_1$**：$100\text{ MVA}, 24\text{ kV}, X_d'' = 0.20\text{ pu}$。
- **電動機 $M_2$**：$100\text{ MVA}, 24\text{ kV}, X_m'' = 0.20\text{ pu}$。
- **變壓器 $T_1, T_2$**：各為 $100\text{ MVA}, 24/230\text{ kV}, X_T = 0.10\text{ pu}$。
- **輸電線**：兩條並聯迴線，每條線路感抗 $X_{line} = 0.40\text{ pu}$（並聯等效 $X_{L} = 0.20\text{ pu}$）。
- 故障前高壓側匯流排電壓為額定值 $V_f = 1.0\angle 0^\circ\text{ pu}$，負載電流忽略不計。

* **(一)** 若在變壓器 $T_1$ 高壓側匯流排發生三相金屬性短路故障，試求故障瞬間之總次暫態短路電流標么值 $I_f''$ 及安培值（$\text{kA}$）。（15 分）
* **(二)** 試求發電機 $G_1$ 與電動機 $M_2$ 分別貢獻之短路電流標么值。（10 分）

---

### 💡 核心考點與破題關鍵
1. **內部電壓源與戴維寧等效**：
   - 故障前無負載電流，所有旋轉電機內部次暫態電動勢均等於故障前電壓：$E_g'' = E_m'' = V_f = 1.0\angle 0^\circ\text{ pu}$。
2. **旋轉電機短路時皆視為電源**：
   - 故障發生時，發電機持續供電，而感應/同步電動機由於轉子慣性旋轉，會瞬間轉變為發電機反送次暫態短路電流至故障點！
3. **故障點各側阻抗並聯**：
   - 發電機側阻抗：$Z_{th,G} = j(X_d'' + X_{T1}) = j(0.20 + 0.10) = j0.30\text{ pu}$。
   - 電動機側阻抗：$Z_{th,M} = j(X_m'' + X_{T2} + X_{line,eq}) = j(0.20 + 0.10 + 0.20) = j0.50\text{ pu}$。

---

### ✏️ 步驟式詳細數學推導

#### 🔹 第 (一) 小題：總次暫態短路電流求解
1. **發電機貢獻之電流 $I_{f,G}''$**：
   $$I_{f,G}'' = \frac{V_f}{Z_{th,G}} = \frac{1.0\angle 0^\circ}{j0.30} = -j3.3333\text{ pu} = 3.333\angle -90^\circ\text{ pu}$$
2. **電動機貢獻之電流 $I_{f,M}''$**：
   $$I_{f,M}'' = \frac{V_f}{Z_{th,M}} = \frac{1.0\angle 0^\circ}{j0.50} = -j2.0000\text{ pu} = 2.000\angle -90^\circ\text{ pu}$$
3. **故障點總次暫態短路電流 $I_f''$**：
   $$I_f'' = I_{f,G}'' + I_{f,M}'' = -j3.3333 + (-j2.0000) = \mathbf{-j5.3333\text{ pu}} = \mathbf{5.333\angle -90^\circ\text{ pu}}$$
4. **計算高壓側基準電流與實體短路電流**：
   - 高壓側基準電流（$230\text{ kV}$ 側）：
     $$I_{base,HV} = \frac{S_{base}}{\sqrt{3} V_{base,HV}} = \frac{100\times 10^6}{\sqrt{3} \times 230\times 10^3} \approx 251.02\text{ A} = 0.25102\text{ kA}$$
   - 實體總短路電流：
     $$I_{f,actual} = 5.3333 \times 0.25102\text{ kA} = \mathbf{1.3388\text{ kA}} = \mathbf{1338.8\text{ A}}$$

---

#### 🔹 第 (二) 小題：兩端電源貢獻分流
- **發電機 $G_1$ 貢獻電流**：$I_{f,G}'' = \mathbf{3.333\text{ pu}}$（佔總短路電流之 $62.5\%$）
- **電動機 $M_2$ 貢獻電流**：$I_{f,M}'' = \mathbf{2.000\text{ pu}}$（佔總短路電流之 $37.5\%$）

---

### ⚠️ 考場陷阱與評分避坑指南
- ⚠️ **切勿忽略電動機反送電流**：初學者最常犯錯誤是以為電動機是負載，短路時只有發電機供電，直接漏算電動機貢獻導致扣 15 分！
- ⚠️ **基準電壓選定**：故障點在 $230\text{ kV}$ 側，計算實體電流時必須以 $V_{base} = 230\text{ kV}$ 計算 $I_{base}$，若誤用發電機端 $24\text{ kV}$ 會放大近 10 倍！

---

### 🎯 第二題 滿分關鍵與結論
| 項目 | 標么值 (pu) | 實體值 (kA) | 評分關鍵 |
| :--- | :---: | :---: | :--- |
| **發電機貢獻** $I_{f,G}''$ | **$3.333\angle -90^\circ\text{ pu}$** | $0.8367\text{ kA}$ | 阻抗為 $X_d'' + X_{T1} = 0.30$ |
| **電動機貢獻** $I_{f,M}''$ | **$2.000\angle -90^\circ\text{ pu}$** | $0.5020\text{ kA}$ | 阻抗含雙迴線等效 $0.20$ |
| **總短路電流** $I_f''$ | **$5.333\angle -90^\circ\text{ pu}$** | **$1.339\text{ kA}$** | 兩支路相加 |

## 三、二發電機組等微增燃料成本最佳經濟調度（25 分）

### 📌 題目與已知條件
兩部額定發電機組供應系統總負載 $P_D = 1200\text{ MW}$，不考慮輸電線路損失（$P_L = 0$）：
- **機組 1 燃料成本函數**：$C_1(P_1) = 600 + 15 P_1 + 0.005 P_1^2\quad (\$/\text{h})$，發電容量限制：$200\text{ MW} \le P_1 \le 800\text{ MW}$。
- **機組 2 燃料成本函數**：$C_2(P_2) = 400 + 18 P_2 + 0.008 P_2^2\quad (\$/\text{h})$，發電容量限制：$200\text{ MW} \le P_2 \le 700\text{ MW}$。

* **(一)** 試求在最佳經濟調度下，各機組之最佳發電量 $P_1, P_2$ 及系統增量成本 $\lambda$。（15 分）
* **(二)** 試求最佳調度時，兩機組每小時之總燃料成本 $C_{total}$。（10 分）

---

### 💡 核心考點與破題關鍵
1. **等微增燃料成本準則（Equal Incremental Cost Rule）**：
   - 當不計線損時，系統總成本最小的充分必要條件為各運轉機組之微增燃料成本（Incremental Cost, IC）相等：
     $$\lambda = \frac{dC_1}{dP_1} = \frac{dC_2}{dP_2}$$
2. **功率平衡約束**：
   $$P_1 + P_2 = P_D = 1200\text{ MW}$$
3. **容量極限檢驗**：
   - 求解後必須檢驗 $P_1, P_2$ 是否落在各自的上下限區間之內。

---

### ✏️ 步驟式詳細數學推導

#### 🔹 第 (一) 小題：求解最佳發電分配與 $\lambda$
1. **求各機組之微增成本方程式**：
   $$\text{IC}_1 = \frac{dC_1}{dP_1} = 15 + 0.010 P_1\quad (\$/\text{MWh})$$
   $$\text{IC}_2 = \frac{dC_2}{dP_2} = 18 + 0.016 P_2\quad (\$/\text{MWh})$$
2. **建立協調方程式組**：
   令 $\text{IC}_1 = \text{IC}_2 = \lambda$：
   $$P_1 = \frac{\lambda - 15}{0.010} = 100\lambda - 1500$$
   $$P_2 = \frac{\lambda - 18}{0.016} = 62.5\lambda - 1125$$
3. **代入功率平衡約束求解 $\lambda$**：
   $$P_1 + P_2 = (100\lambda - 1500) + (62.5\lambda - 1125) = 162.5\lambda - 2625 = 1200$$
   $$162.5\lambda = 3825 \implies \lambda = \frac{3825}{162.5} = \mathbf{23.5385\ \$/\text{MWh}}$$
4. **反求各機組最佳發電量**：
   $$P_1 = 100(23.5385) - 1500 = 2353.85 - 1500 = \mathbf{853.85\text{ MW}}$$
   $$P_2 = 62.5(23.5385) - 1125 = 1471.16 - 1125 = \mathbf{346.15\text{ MW}}$$
5. **容量極限檢驗與修正（Capacity Limit Check）**：
   - 檢驗機組 1：$P_1 = 853.85\text{ MW} > P_{1,\max} = 800\text{ MW}$（**超出發電上限！**）
   - **修正策略**：將機組 1 鎖定在其最大容量 $P_1^* = \mathbf{800.0\text{ MW}}$。
   - 由功率平衡求機組 2 負擔之發電量：
     $$P_2^* = P_D - P_1^* = 1200 - 800 = \mathbf{400.0\text{ MW}}$$
   - 檢驗機組 2：$200 \le 400 \le 700\text{ MW}$（**合格！**）
   - 系統實際邊際增量成本由自由調節之機組 2 決定：
     $$\lambda^* = \text{IC}_2(400) = 18 + 0.016(400) = 18 + 6.4 = \mathbf{24.40\ \$/\text{MWh}}$$

---

#### 🔹 第 (二) 小題：求解系統總燃料成本
1. **機組 1 燃料成本**：
   $$C_1(800) = 600 + 15(800) + 0.005(800)^2 = 600 + 12000 + 3200 = \mathbf{15800\ \$/\text{h}}$$
2. **機組 2 燃料成本**：
   $$C_2(400) = 400 + 18(400) + 0.008(400)^2 = 400 + 7200 + 1280 = \mathbf{8880\ \$/\text{h}}$$
3. **系統總成本**：
   $$C_{total} = C_1 + C_2 = 15800 + 8880 = \mathbf{24680\ \$/\text{h}}$$

---

### ⚠️ 考場陷阱與評分避坑指南
- ⚠️ **極限約束檢驗為滿分死穴**：很多考生算到 $P_1 = 853.85\text{ MW}$ 就結束，忽略了題目給定的 $P_{1,\max} = 800\text{ MW}$，直接被扣 10 分！一定要有「超限判定 ➔ 鎖定上限 ➔ 重新分配」的完整論述。

---

### 🎯 第三題 滿分關鍵與結論
- **機組 1 發電量**：$P_1 = \mathbf{800.0\text{ MW}}$（達上限）
- **機組 2 發電量**：$P_2 = \mathbf{400.0\text{ MW}}$
- **系統邊際增量成本**：$\lambda = \mathbf{24.40\ \$/\text{MWh}}$
- **每小時總燃料成本**：$C_{total} = \mathbf{24,680\ \$/\text{h}}$

## 四、同步發電機調速機速度調節率與頻率響應（25 分）

### 📌 題目與已知條件
一部同步發電機額定容量為 $S_{rated} = 500\text{ MW}$，額定頻率 $f_0 = 60.0\text{ Hz}$。
- 調速機（Governor）速度調節率（Speed Droop）為 $R = 4\% = 0.04\text{ pu}$。
- 發電機初始運轉於額定頻率 $60\text{ Hz}$，輸出功率為 $P_1 = 250\text{ MW}$。
- 系統負載突然增加 $\Delta P_L$，導致系統頻率下降至 $f_2 = 59.7\text{ Hz}$（頻率偏差 $\Delta f = 59.7 - 60.0 = -0.3\text{ Hz}$）。

* **(一)** 試求此發電機之頻率響應特性係數（Frequency Response Characteristic）$\beta$（單位：$\text{MW/Hz}$）。（10 分）
* **(二)** 當頻率降至 $59.7\text{ Hz}$ 且調速機完成初級調頻（Primary Frequency Control）動作後，此發電機之新輸出功率 $P_2$ 為多少 $\text{MW}$？（15 分）

---

### 💡 核心考點與破題關鍵
1. **速度調節率 $R$ 的物理意義**：
   $$R = -\frac{\Delta f / f_0}{\Delta P / S_{rated}} \implies \Delta P = -\frac{S_{rated}}{R \cdot f_0} \Delta f$$
2. **頻率響應剛度 $\beta$（Area Frequency Response Characteristic）**：
   $$\beta = \frac{S_{rated}}{R \cdot f_0}\quad (\text{MW/Hz})$$
   代表電網頻率每下降 $1\text{ Hz}$，機組自動增加輸出的實功率兆瓦數。

---

### ✏️ 步驟式詳細數學推導

#### 🔹 第 (一) 小題：求解頻率響應係數 $\beta$
$$\beta = \frac{S_{rated}}{R \times f_0} = \frac{500\text{ MW}}{0.04 \times 60\text{ Hz}} = \frac{500}{2.4} = \mathbf{208.333\text{ MW/Hz}}$$

---

#### 🔹 第 (二) 小題：求解新輸出功率 $P_2$
1. **計算頻率偏差 $\Delta f$**：
   $$\Delta f = 59.7 - 60.0 = -0.3\text{ Hz}$$
2. **由調速機特性計算發電機增加之輸出功率 $\Delta P$**：
   $$\Delta P = -\beta \times \Delta f = -208.333 \times (-0.3) = \mathbf{+62.50\text{ MW}}$$
3. **計算新穩定發電量 $P_2$**：
   $$P_2 = P_1 + \Delta P = 250 + 62.50 = \mathbf{312.50\text{ MW}}$$
4. **容量極限校核**：
   $$P_2 = 312.50\text{ MW} \le 500\text{ MW}\quad (\text{未超出額定容量，完全安全！})$$
