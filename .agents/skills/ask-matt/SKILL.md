# Ask Matt Skill (by Matt Pocock)

Acts as an intelligent **workflow navigator and skill recommendation engine**.

## 🎯 Skill Routing Guide

- **Starting a new feature/concept from scratch?** ➔ `/grill-me`
- **Starting work in an existing codebase/vault?** ➔ `/grill-with-docs`
- **Finished a discussion and need a formal spec?** ➔ `/to-spec`
- **Have a spec and need to break it into small tasks?** ➔ `/to-tickets`
- **Ready to write code/推導?** ➔ `/tdd`
- **Finished writing and need a strict quality review?** ➔ `/code-review`
- **Confused by a mathematical or theoretical explanation?** ➔ `/wait-what`
