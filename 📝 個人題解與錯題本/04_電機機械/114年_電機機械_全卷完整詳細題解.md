## 一、簡化兩極電機氣隙磁路與線圈電感（20 分）

### 📌 題目與已知條件
如圖 1 所示之簡化兩極電機結構，其磁路參數規格如下：
- 氣隙個數：2 個氣隙，每一氣隙長度 $l_g = 2\text{ mm} = 2 \times 10^{-3}\text{ m}$
- 磁極面截面積：$A_g = 400\text{ cm}^2 = 400 \times 10^{-4}\text{ m}^2 = 0.04\text{ m}^2$
- 線圈匝數：$N = 400\text{ 匝}$，線圈電流：$I = 4\text{ A}$
- 鐵心導磁係數 $\mu_c  \to \infty$（鐵心磁阻忽略不計），空氣導磁率 $\mu_0 = 4\pi \times 10^{-7}\text{ H/m}$
- 忽略漏磁通與氣隙邊緣效應（Fringing effect）。

* **(一)** 畫出其對應的等效磁路並求氣隙中之磁通密度 $B_g$ 為何？（10 分）
* **(二)** 求線圈之電感值 $L$ 為何？（10 分）

---

### 💡 核心考點與破題關鍵
1. **安培環路定律與磁路歐姆定律**：
   $$\mathcal{F} = N I = \Phi \mathcal{R}_{total} = H_g (2 l_g)$$
   因鐵心磁阻 $\mathcal{R}_c \approx 0$，總磁阻為兩個對稱氣隙串聯：
   $$\mathcal{R}_{total} = 2 \mathcal{R}_g = 2 \left( \frac{l_g}{\mu_0 A_g} \right) = \frac{2 l_g}{\mu_0 A_g}$$
2. **磁通密度 $B_g$**：
   $$B_g = \mu_0 H_g = \mu_0 \left( \frac{N I}{2 l_g} \right) = \frac{\Phi}{A_g}$$
3. **線圈電感 $L$**：
   $$L = \frac{N \Phi}{I} = \frac{N^2}{\mathcal{R}_{total}} = \frac{N^2 \mu_0 A_g}{2 l_g}$$

---

### ✏️ 步驟式詳細數學推導

#### 🔹 第 (一) 小題：畫出等效磁路並求氣隙磁通密度 $B_g$
1. **等效磁路圖說明**：
   - 磁動勢源 $\mathcal{F} = N I = 400 \times 4 = 1600\text{ A}\cdot\text{t}$。
   - 串聯兩個氣隙磁阻 $\mathcal{R}_{g1} = \mathcal{R}_{g2} = \mathcal{R}_g$。
   - 總磁阻 $\mathcal{R}_{total} = 2 \mathcal{R}_g$。
2. **計算總磁阻 $\mathcal{R}_{total}$**：
   $$\mathcal{R}_g = \frac{l_g}{\mu_0 A_g} = \frac{2 \times 10^{-3}}{(4\pi \times 10^{-7}) \times 0.04} \approx 3.9789 \times 10^4\text{ A}\cdot\text{t/Wb}$$
   $$\mathcal{R}_{total} = 2 \mathcal{R}_g = \frac{4 \times 10^{-3}}{(4\pi \times 10^{-7}) \times 0.04} = \frac{10^5}{\pi} \approx 7.9577 \times 10^4\text{ A}\cdot\text{t/Wb}$$
3. **計算氣隙磁通量 $\Phi$ 與磁通密度 $B_g$**：
   $$\Phi = \frac{\mathcal{F}}{\mathcal{R}_{total}} = \frac{1600}{7.9577 \times 10^4} = 0.020106\text{ Wb} = 20.106\text{ mWb}$$
   $$\mathbf{B_g = \frac{\Phi}{A_g} = \frac{0.020106}{0.04} = \frac{\mu_0 N I}{2 l_g} = 0.16\pi \approx \mathbf{0.5027\text{ T}}}$$

---

#### 🔹 第 (二) 小題：求線圈之電感值 $L$
$$L = \frac{N^2}{\mathcal{R}_{total}} = \frac{400^2}{7.9577 \times 10^4} = \frac{160000 \times \pi}{10^5} = 1.6\pi \approx \mathbf{5.0265\text{ H} \approx 5.027\text{ H}}$$
（若以單線圈交鏈計算 $L = \frac{N \Phi}{I} = \frac{400 \times 0.020106}{4} = \mathbf{2.0106\text{ H}}$）

> 🧮 **E-MORE fx-127 實戰按鍵**：
> - `4` `×` `π` `EXP` `7` `+/-` `×` `400` `×` `4` `÷` `0.004` `=` ➔ 得到 **`0.50265`**（磁通密度 $B_g = 0.5027\text{ T}$）。

---

### 🎯 第一題 滿分關鍵與結論
- **氣隙磁通密度**：$B_g = \mathbf{0.5027\text{ T}}$
- **線圈電感值**：$L = \mathbf{2.0106\text{ H}}$（$\Phi = 0.0201\text{ Wb}$）

## 二、單相變壓器分接頭阻抗匹配與最大功率轉移（20 分）

### 📌 題目與已知條件
- 電源端：一次側連接 $V_s = 110\sqrt{2}\text{ V}$，內部阻抗 $Z_s = j1\ \Omega$。
- 二次側：接等效電阻負載 $R_L$，變動範圍 $1\ \Omega \le R_L \le 4\ \Omega$。
- 變壓器匝數比 $a = N_1 / N_2$ 可透過二次側分接頭調整。

* **(一)** 當負載電阻為 $R_L = 2.5\ \Omega$ 時，變壓器匝數比 $a$ 應調整為何？（10 分）
* **(二)** 根據問題 (一)，負載兩端的電壓 $V_o$ 應調整為何？（10 分）

---

### ✏️ 步驟式詳細數學推導
1. **最大功率轉移條件**：
   $$R_L' = a^2 R_L = |Z_s| = \sqrt{0^2 + 1^2} = 1.0\ \Omega$$
   $$a^2 \times 2.5 = 1.0 \implies a^2 = 0.40 \implies \mathbf{a = \sqrt{0.40} = \mathbf{0.6325}}$$
2. **負載電壓計算**：
   $$V_1 = V_s \frac{R_L'}{|R_L' + jX_s|} = 110\sqrt{2} \times \frac{1.0}{\sqrt{1^2 + 1^2}} = 110\text{ V}$$
   $$V_o = \frac{V_1}{a} = \frac{110}{\sqrt{0.40}} = 110 \times \sqrt{2.5} = \mathbf{173.93\text{ V}}$$

---

### 🎯 第二題 滿分關鍵與結論
- **(一) 最佳匝數比**：$a = \mathbf{0.6325}$
- **(二) 負載端電壓**：$V_o = \mathbf{173.93\text{ V}}$

## 三、單相感應電動機二相旋轉磁場與轉向控制（20 分）

### 📌 題目與已知條件
- 主繞組 $i_M(t) = I_m \cos(\omega t)$，輔助繞組 $i_A(t) = I_m \sin(\omega t)$，空間夾角 $90^\circ$。

* **(一)** 畫出在 $t = t_1, t_3, t_5, t_7$ 時兩繞組產生的合成磁通大小與相位，並說明旋轉磁場之轉向？（10 分）
* **(二)** 證明任意對調輔助繞組接線，旋轉磁場會反轉。（10 分）

---

### ✏️ 步驟式詳細數學推導
1. **合成磁通推導**：
   $$\vec{\Phi}_{total}(t) = (\Phi_m \cos\omega t) \hat{a}_x + (\Phi_m \sin\omega t) \hat{a}_y = \Phi_m ngle(\omega t)$$
   - $t_1 (\omega t = 0^\circ) \implies \Phi_m ngle 0^\circ$
   - $t_3 (\omega t = 90^\circ) \implies \Phi_m ngle 90^\circ$
   - $t_5 (\omega t = 180^\circ) \implies \Phi_m ngle 180^\circ$
   - $t_7 (\omega t = 270^\circ) \implies \Phi_m ngle 270^\circ$
   👉 **轉向為逆時針（CCW）等速旋轉**，大小恆為 $\Phi_m$。
2. **反接證明**：
   $$i_A'(t) = -i_A(t) \implies \vec{\Phi}_{total}'(t) = (\Phi_m \cos\omega t) \hat{a}_x - (\Phi_m \sin\omega t) \hat{a}_y = \Phi_m ngle(-\omega t)$$
   相角隨時間遞減，轉向變為**順時針（CW）旋轉**，證明反轉。

---

### 🎯 第三題 滿分關鍵與結論
- **合成磁通幅值**：恆為 $\mathbf{\Phi_m}$
- **初始旋轉方向**：$\mathbf{逆時針（CCW）}$
- **反接後旋轉方向**：$\mathbf{順時針（CW）}$

## 四、三相同步發電機內生電壓與原動機轉矩（20 分）

### 📌 題目與已知條件
- 額定：三相 $\text{Y}$ 接、4 極、$60\text{ Hz}$、$1000\text{ kVA}$、$3.2\text{ kV}$、$\text{PF} = 0.9\text{ 落後}$。
- 參數：$R_a = 0.1\ \Omega/\text{相}, X_s = 2.0\ \Omega/\text{相}$。鐵損 $15\text{ kW}$，摩擦風阻損 $14\text{ kW}$。

* **(一)** 求每相內生電壓 $E_f$ 與功率角 $\delta$？（10 分）
* **(二)** 求原動機輸入機械轉矩 $T_{in}$？（10 分）

---

### ✏️ 步驟式詳細數學推導
1. **內生電壓相量**：
   $$V_\phi = \frac{3200}{\sqrt{3}} = 1847.52\text{ V}, \quad I_a = \frac{1000\times 10^3}{\sqrt{3}\times 3200} = 180.422ngle -25.84^\circ\text{ A}$$
   $$\mathbf{E}_f = 1847.52 + 180.422ngle -25.84^\circ \times (0.1 + j2.0) = 2021.04 + j316.90\text{ V}$$
   $$|\mathbf{E}_f| = \mathbf{2045.73\text{ V/相}}, \quad \mathbf{\delta = 8.91^\circ}$$
2. **原動機轉矩**：
   $$P_{out} = 1000 \times 0.9 = 900\text{ kW}, \quad P_{cu} = 3 \times (180.422)^2 \times 0.1 = 9.77\text{ kW}$$
   $$P_{in} = 900 + 9.77 + 15 + 14 = 938.77\text{ kW}$$
   $$\omega_m = \frac{2\pi \times 1800}{60} = 60\pi \approx 188.50\text{ rad/s}$$
   $$\mathbf{T_{in} = \frac{938770}{188.4956} = \mathbf{4980.33\text{ N}\cdot\text{m}}}$$

---

### 🎯 第四題 滿分關鍵與結論
- **內生電壓與功角**：$E_f = \mathbf{2045.73\text{ V/相}}, \delta = \mathbf{8.91^\circ}$
- **原動機轉矩**：$T_{in} = \mathbf{4980.33\text{ N}\cdot\text{m}}$

## 五、四極磁阻電動機瞬時轉矩與平均轉矩推導（20 分）

### 📌 題目與已知條件
- 磁阻：$\mathcal{R}(\theta) = \mathcal{R}_0 - \mathcal{R}_1 \cos(4\theta)$，$\mathcal{R}_0 = 2\times 10^5, \mathcal{R}_1 = 10^5$。$\theta = \omega_m t + \delta$。
- 線圈 $N = 50\text{ 匝}$，電壓 $v(t) = 110\sqrt{2}\sin(\omega t), f = 60\text{ Hz}$。

* **(一)** 推導瞬時轉矩 $T(t)$。（10 分）
* **(二)** 求產生平均轉矩之轉速 $\omega_m$ 與平均轉矩 $T_{avg}$。（10 分）

---

### ✏️ 步驟式詳細數學推導
1. **磁通推導**：
   $$\Phi(t) = \frac{1}{N}\int v(t) dt = -\frac{110\sqrt{2}}{50 \times 120\pi} \cos(\omega t) = -\Phi_{max}\cos(\omega t) \quad (\Phi_{max} = 8.253\times 10^{-3}\text{ Wb})$$
2. **瞬時轉矩**：
   $$T(t) = -\frac{1}{2}\Phi^2 \frac{d\mathcal{R}}{d\theta} = -\frac{1}{2}[-\Phi_{max}\cos\omega t]^2 [4\mathcal{R}_1 \sin 4\theta]$$
   $$\mathbf{T(t) = -2\mathcal{R}_1 \Phi_{max}^2 \cos^2(\omega t) \sin(4\omega_m t + 4\delta)}$$
3. **同步運轉與平均轉矩**：
   展開 $\cos^2(\omega t) = \frac{1+\cos 2\omega t}{2}$，當 $4\omega_m = 2\omega \implies \mathbf{\omega_m = \omega/2 = 60\pi\text{ rad/s} = 1800\text{ rpm}}$。
   $$\mathbf{T_{avg} = -\frac{1}{2}\mathcal{R}_1 \Phi_{max}^2 \sin(4\delta) = -3.406 \sin(4\delta)\text{ N}\cdot\text{m}}$$

---

> [!WARNING]
> ⚠️ **電機機械 核心防坑與閱卷踩雷提醒**：
> 1. **變壓器阻抗折合**：低壓側折合至高壓側乘以變比平方 $a^2$；自耦變壓器共用繞組電流為高低壓側電流之差值。
> 2. **感應機最大轉矩**：最大轉矩 $T_{max}$ 與轉子電阻 $R_2$ 無關，但產生最大轉矩之轉差率 $s_{max}$ 與 $R_2$ 成正比。
> 3. **同步機相量計算**：同步電動機 $\mathbf{E}_f = \mathbf{V}_\phi - \mathbf{I}_a \mathbf{Z}_s$；同步發電機 $\mathbf{E}_f = \mathbf{V}_\phi + \mathbf{I}_a \mathbf{Z}_s$。

---


### 🎯 第五題 滿分關鍵與結論
- **瞬時轉矩**：$T(t) = -2\mathcal{R}_1 \Phi_{max}^2 \cos^2(\omega t) \sin(4\omega_m t + 4\delta)$
- **同步角轉速**：$\omega_m = 60\pi\text{ rad/s} = \mathbf{1800\text{ rpm}}$
- **最大平均轉矩**：$T_{avg,max} = \mathbf{3.406\text{ N}\cdot\text{m}}$
