## 三、三相感應電動機無載與堵轉試驗（20 分）

### 📌 題目與已知條件
一部三相、$\text{Y}$ 接、線電壓 $220\text{ V}, 60\text{ Hz}, 6$ 極感應電動機：
- **直流電阻試驗**：兩端子間電阻 $R_{dc} = 0.40\ \Omega$（每相定子電阻 $R_1 = \frac{R_{dc}}{2} = 0.20\ \Omega$）。
- **無載試驗（$60\text{ Hz}$）**：$V_{nl} = 220\text{ V}, I_{nl} = 6.0\text{ A}, P_{nl} = 400\text{ W}$。
- **堵轉試驗（$15\text{ Hz}$）**：$V_{bl} = 25\text{ V}, I_{bl} = 30.0\text{ A}, P_{bl} = 900\text{ W}$。

* **(一)** 計算定子每相電阻 $R_1$ 與轉子等效電阻 $R_2'$。（10 分）
* **(二)** 計算在 $60\text{ Hz}$ 下之定子漏抗 $X_1$、轉子漏抗 $X_2'$（設 $X_1 = X_2'$）與激磁電抗 $X_m$。（10 分）

---

### ✏️ 步驟式詳細數學推導
1. **堵轉試驗求電阻與漏抗**：
   $$R_{eq} = \frac{P_{bl}}{3 I_{bl}^2} = \frac{900}{3 \times 30^2} = \frac{900}{2700} = \mathbf{0.3333\ \Omega}$$
   $$\mathbf{R_2' = R_{eq} - R_1 = 0.3333 - 0.20 = \mathbf{0.1333\ \Omega}}$$
   $$Z_{bl} = \frac{V_{bl}/\sqrt{3}}{I_{bl}} = \frac{25/\sqrt{3}}{30} = \frac{14.434}{30} = 0.4811\ \Omega$$
   在 $15\text{ Hz}$ 下之總漏抗：
   $$X_{eq,15Hz} = \sqrt{Z_{bl}^2 - R_{eq}^2} = \sqrt{0.4811^2 - 0.3333^2} = \sqrt{0.2315 - 0.1111} = 0.3470\ \Omega$$
   換算至 $60\text{ Hz}$ 額定頻率：
   $$X_{eq,60Hz} = 0.3470 \times \left( \frac{60}{15} \right) = \mathbf{1.388\ \Omega}$$
   $$\mathbf{X_1 = X_2' = \frac{X_{eq,60Hz}}{2} = \mathbf{0.694\ \Omega/\text{相}}}$$
2. **無載試驗求激磁電抗 $X_m$**：
   $$Z_{nl} = \frac{V_{nl}/\sqrt{3}}{I_{nl}} = \frac{220/\sqrt{3}}{6.0} = \frac{127.02}{6.0} = 21.17\ \Omega$$
   $$X_{nl} \approx Z_{nl} = 21.17\ \Omega$$
   $$\mathbf{X_m = X_{nl} - X_1 = 21.17 - 0.694 = \mathbf{20.476\ \Omega/\text{相}}}$$

---

### 🎯 第三題 滿分關鍵與結論
- **電阻參數**：$R_1 = \mathbf{0.20\ \Omega}, R_2' = \mathbf{0.1333\ \Omega}$
- **電抗參數**：$X_1 = X_2' = \mathbf{0.694\ \Omega}, X_m = \mathbf{20.48\ \Omega}$
