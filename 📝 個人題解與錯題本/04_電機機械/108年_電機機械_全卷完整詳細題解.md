## 一、480/120V 自耦變壓器容量與功率拆解（20 分）

### 📌 題目與已知條件
- 雙繞組變壓器額定：$480\text{ V} / 120\text{ V}, 5\text{ kVA}, 60\text{ Hz}$。
- 改接為 $480\text{ V}$ 輸入、$600\text{ V}$ 輸出之升壓自耦變壓器。

* **(一)** 求此自耦變壓器之額定容量 $S_{auto}$。（10 分）
* **(二)** 分析滿載時電氣直接傳導功率 $S_{cond}$ 與磁場感應功率 $S_{ind}$。（10 分）

---

### ✏️ 步驟式詳細數學推導
1. **額定電流與自耦容量**：
   - 串聯繞組（$120\text{ V}$ 繞組）額定電流：$I_{series} = \frac{5000\text{ VA}}{120\text{ V}} = \mathbf{41.67\text{ A}}$。
   - 輸出端電壓 $V_H = 480 + 120 = 600\text{ V}$。
   - **自耦變壓器額定容量**：
     $$\mathbf{S_{auto} = 600\text{ V} \times 41.67\text{ A} = \mathbf{25000\text{ VA} = 25.0\text{ kVA}}}$$
2. **傳導與感應功率**：
   - **磁場感應功率**：$\mathbf{S_{ind} = S_{two-wdg} = \mathbf{5.0\text{ kVA}}}$
   - **電氣傳導功率**：$\mathbf{S_{cond} = S_{auto} - S_{ind} = 25.0 - 5.0 = \mathbf{20.0\text{ kVA}}}$

---

### 🎯 第一題 滿分關鍵與結論
- **自耦變壓器容量**：$S_{auto} = \mathbf{25.0\text{ kVA}}$（提升 5 倍）
- **感應功率**：$S_{ind} = \mathbf{5.0\text{ kVA}}$，**傳導功率**：$S_{cond} = \mathbf{20.0\text{ kVA}}$

## 二、他激直流電動機弱磁調速（20 分）

### 📌 題目與已知條件
- 額定：$25\text{ kW}, 125\text{ V}, 1200\text{ rpm}$ 他激直流電動機，$R_a = 0.05\ \Omega$。
- 負載轉矩固定為額定轉矩。欲將轉速提昇至 $1500\text{ rpm}$。

* **(一)** 額定滿載運轉時之反電動勢 $E_{a1}$ 與電樞電流 $I_{a1}$。（10 分）
* **(二)** 採用弱磁調速提昇至 $1500\text{ rpm}$，求此時磁通比 $\Phi_2 / \Phi_1$ 與新電樞電流 $I_{a2}$。（10 分）

---

### ✏️ 步驟式詳細數學推導
1. **額定狀態**：
   $$I_{a1} = \frac{25000}{125} = \mathbf{200.0\text{ A}}$$
   $$E_{a1} = 125 - (200 \times 0.05) = \mathbf{115.0\text{ V}}$$
2. **弱磁至 $1500\text{ rpm}$**：
   因 $T \propto \Phi I_a$ 且轉矩固定 $\implies \Phi_2 I_{a2} = \Phi_1 I_{a1} \implies I_{a2} = I_{a1} \frac{\Phi_1}{\Phi_2}$。
   反電動勢關係：$E_{a2} = 125 - I_{a2} R_a = E_{a1} \left( \frac{\Phi_2}{\Phi_1} \right)\left( \frac{1500}{1200} \right) = 115 \times 1.25 \times \left( \frac{\Phi_2}{\Phi_1} \right) = 143.75 \left( \frac{\Phi_2}{\Phi_1} \right)$。
   令 $x = \frac{\Phi_2}{\Phi_1}$：
   $$125 - \left( \frac{200}{x} \right) \times 0.05 = 143.75 x \implies 125 - \frac{10}{x} = 143.75 x$$
   143. $75 x^2 - 125 x + 10 = 0$
   解一元二次方程式：
   $$x = \frac{125 \pm \sqrt{125^2 - 4 \times 143.75 \times 10}}{2 \times 143.75} = \frac{125 \pm \sqrt{15625 - 5750}}{287.5} = \frac{125 \pm 99.373}{287.5}$$
   取合理弱磁解 $x = \frac{125 - 99.373}{287.5} \approx \mathbf{0.7804}$（即 $\mathbf{\Phi_2 = 78.04\% \Phi_1}$）。
   新電樞電流：
   $$\mathbf{I_{a2} = \frac{200}{0.7804} \approx \mathbf{256.28\text{ A}}}$$

---

### 🎯 第二題 滿分關鍵與結論
- **額定反電動勢**：$E_{a1} = \mathbf{115.0\text{ V}}$
- **弱磁磁通比**：$\frac{\Phi_2}{\Phi_1} = \mathbf{0.7804\ (78.04\%)}$
- **新電樞電流**：$I_{a2} = \mathbf{256.28\text{ A}}$

## 三、三相感應電動機無載與堵轉試驗（20 分）

### 📌 題目與已知條件
一部三相、$\text{Y}$ 接、線電壓 $220\text{ V}, 60\text{ Hz}, 6$ 極感應電動機：
- **直流電阻試驗**：兩端子間電阻 $R_{dc} = 0.40\ \Omega$（每相定子電阻 $R_1 = \frac{R_{dc}}{2} = 0.20\ \Omega$）。
- **無載試驗（$60\text{ Hz}$）**：$V_{nl} = 220\text{ V}, I_{nl} = 6.0\text{ A}, P_{nl} = 400\text{ W}$。
- **堵轉試驗（$15\text{ Hz}$）**：$V_{bl} = 25\text{ V}, I_{bl} = 30.0\text{ A}, P_{bl} = 900\text{ W}$。

* **(一)** 計算定子每相電阻 $R_1$ 與轉子等效電阻 $R_2'$。（10 分）
* **(二)** 計算在 $60\text{ Hz}$ 下之定子漏抗 $X_1$、轉子漏抗 $X_2'$（設 $X_1 = X_2'$）與激磁電抗 $X_m$。（10 分）

---

### ✏️ 步驟式詳細數學推導
1. **堵轉試驗求電阻與漏抗**：
   $$R_{eq} = \frac{P_{bl}}{3 I_{bl}^2} = \frac{900}{3 \times 30^2} = \frac{900}{2700} = \mathbf{0.3333\ \Omega}$$
   $$\mathbf{R_2' = R_{eq} - R_1 = 0.3333 - 0.20 = \mathbf{0.1333\ \Omega}}$$
   $$Z_{bl} = \frac{V_{bl}/\sqrt{3}}{I_{bl}} = \frac{25/\sqrt{3}}{30} = \frac{14.434}{30} = 0.4811\ \Omega$$
   在 $15\text{ Hz}$ 下之總漏抗：
   $$X_{eq,15Hz} = \sqrt{Z_{bl}^2 - R_{eq}^2} = \sqrt{0.4811^2 - 0.3333^2} = \sqrt{0.2315 - 0.1111} = 0.3470\ \Omega$$
   換算至 $60\text{ Hz}$ 額定頻率：
   $$X_{eq,60Hz} = 0.3470 \times \left( \frac{60}{15} \right) = \mathbf{1.388\ \Omega}$$
   $$\mathbf{X_1 = X_2' = \frac{X_{eq,60Hz}}{2} = \mathbf{0.694\ \Omega/\text{相}}}$$
2. **無載試驗求激磁電抗 $X_m$**：
   $$Z_{nl} = \frac{V_{nl}/\sqrt{3}}{I_{nl}} = \frac{220/\sqrt{3}}{6.0} = \frac{127.02}{6.0} = 21.17\ \Omega$$
   $$X_{nl} \approx Z_{nl} = 21.17\ \Omega$$
   $$\mathbf{X_m = X_{nl} - X_1 = 21.17 - 0.694 = \mathbf{20.476\ \Omega/\text{相}}}$$

---

### 🎯 第三題 滿分關鍵與結論
- **電阻參數**：$R_1 = \mathbf{0.20\ \Omega}, R_2' = \mathbf{0.1333\ \Omega}$
- **電抗參數**：$X_1 = X_2' = \mathbf{0.694\ \Omega}, X_m = \mathbf{20.48\ \Omega}$

## 四、同步發電機並聯無限匯流排與功角（20 分）

### 📌 題目與已知條件
- 額定：三相 $2300\text{ V}, 1500\text{ kW}, 60\text{ Hz}, 30$ 極圓型轉子同步發電機，同步電抗 $X_s = 2.0\ \Omega/\text{相}$，電樞電阻忽略。
- 連接於 $2300\text{ V}$ 無限匯流排，供應 $1200\text{ kW}$ 實功率，功率因數 $\text{PF} = 0.8\text{ 落後}$。

* **(一)** 計算每相激磁電壓 $E_f$ 與功率角 $\delta$。（10 分）
* **(二)** 若原動機輸入功率維持不變（實功 $1200\text{ kW}$ 固定），調整激磁電流使功率因數變為 $1.0$，求新激磁電壓 $E_f'$ 與新功角 $\delta'$。（10 分）

---

### ✏️ 步驟式詳細數學推導
1. **初始狀態（$\text{PF} = 0.8$ 落後）**：
   $$V_\phi = \frac{2300}{\sqrt{3}} \approx 1327.91\text{ V}$$
   $$I_a = \frac{1200 \times 10^3}{\sqrt{3} \times 2300 \times 0.8} = 376.53\angle -36.87^\circ\text{ A} = (301.22 - j225.92)\text{ A}$$
   $$\mathbf{E}_f = 1327.91 + j2.0(301.22 - j225.92) = (1327.91 + 451.84) + j602.44 = 1779.75 + j602.44\text{ V}$$
$$|\mathbf{E}_f| = \sqrt{1779.75^2 + 602.44^2} = \mathbf{1878.96\text{ V/相}}$$
   $$\mathbf{\delta = \tan^{-1}\left( \frac{602.44}{1779.75} \right) = \mathbf{18.70^\circ}}$$
2. **調整至單位功因（$\text{PF} = 1.0$）**：
   $$I_a' = \frac{1200 \times 10^3}{\sqrt{3} \times 2300 \times 1.0} = 301.22\angle 0^\circ\text{ A}$$
   $$\mathbf{E}_f' = V_\phi + j X_s I_a' = 1327.91 + j(2.0 \times 301.22) = 1327.91 + j602.44\text{ V}$$
   $$|\mathbf{E}_f'| = \sqrt{1327.91^2 + 602.44^2} = \sqrt{1763345 + 362934} = \sqrt{2126279} = \mathbf{1458.18\text{ V/相}}$$
   $$\mathbf{\delta' = \tan^{-1}\left( \frac{602.44}{1327.91} \right) = \mathbf{24.40^\circ}}$$

---

### 🎯 第四題 滿分關鍵與結論
- **初始狀態**：$E_f = \mathbf{1878.96\text{ V/相}}, \delta = \mathbf{18.70^\circ}$
- **$\text{PF}=1.0$ 狀態**：$E_f' = \mathbf{1458.18\text{ V/相}}, \delta' = \mathbf{24.40^\circ}$

## 五、磁路基礎物理四大核心問答（20 分）

* **(一) 安培環路定律（Ampere's Circuital Law）的物理意義？（5 分）**
  - 沿任意閉合路徑之磁場強度線積分等於通過該迴路所圍面積之淨電流：$\oint \vec{H} \cdot d\vec{l} = \sum I_{enc} = \mathcal{F}$。
* **(二) 磁阻 $\mathcal{R}$ 的定義與幾何關係式？（5 分）**
  - $\mathcal{R} = \frac{l}{\mu A}$，與磁路長度成正比、與截面積及導磁係數成反比。
* **(三) 氣隙對磁路特性之影響？（5 分）**
  - 氣隙導磁率極低，佔據整個磁路絕大部分磁阻，能有效**防止鐵心磁飽和、線性化磁化曲線並儲存大部分磁場能量**。
* **(四) 鐵心磁滯損（Hysteresis Loss）與渦流損（Eddy Current Loss）之成因與降低方法？（5 分）**
  - **磁滯損**：磁疇反覆轉向摩擦耗能，與磁滯迴線面積成正比；採用**高導磁矽鋼片**降低。
  - **渦流損**：交變磁通感應環形電流於鐵心產生 $I^2 R$ 損耗；採用**薄片相互絕緣之疊片鐵心（Lamination）**大幅提升電阻。
