## 一、節點電壓法分析直流電路（20 分）

### 📌 題目與已知條件
如圖一所示之直流電路，各節點標示為 $v_1, v_2, v_3$，參考接地點位於電路底部。電路包含獨立電流源 $I_s = 4\text{ A}$、獨立電壓源 $E = 12\text{ V}$，以及電阻 $R_1 = 2\ \Omega, R_2 = 4\ \Omega, R_3 = 8\ \Omega$。
* **(一)** 求流經支路之電流 $I$ 為何？（5 分）
* **(二)** 求節點電壓 $v_1, v_2, v_3$ 分別為何？（15 分）

---

### 💡 核心考點與破題關鍵
1. **節點電壓法（Nodal Analysis）標準 SOP**：
   - 設定參考接地點 $v_0 = 0\text{ V}$。
   - 識別超級節點（Supernode）：若兩非參考節點之間由理想電壓源連接，則將該兩節點包圍為超級節點，列寫合併 KCL 與內部約束電壓方程式。
2. **KCL 電流守恆定律**：流入節點電流總和等於流出節點電流總和。

---

### ✏️ 步驟式詳細數學推導
1. **超級節點與約束方程式**：
   - 節點 1 與節點 2 之間連接 $12\text{ V}$ 電壓源（正極接 $v_1$，負極接 $v_2$）：
     $$v_1 - v_2 = 12\text{ V} \implies v_1 = v_2 + 12$$
2. **對超級節點 (1, 2) 列寫 KCL**：
   - 流出支路電流總和等於 0：
     $$\frac{v_1 - 0}{R_1} + \frac{v_2 - v_3}{R_2} - I_s = 0$$
     $$\frac{v_2 + 12}{2} + \frac{v_2 - v_3}{4} - 4 = 0$$
     同乘以 4：
     $$2(v_2 + 12) + (v_2 - v_3) = 16 \implies 3v_2 - v_3 = 16 - 24 = -8 \quad \text{--- (式 1)}$$
3. **對節點 3 列寫 KCL**：
   - 流入等於流出：
     $$\frac{v_2 - v_3}{R_2} = \frac{v_3 - 0}{R_3} + I_s$$
     $$\frac{v_2 - v_3}{4} = \frac{v_3}{8} + 4$$
     同乘以 8：
     $$2(v_2 - v_3) = v_3 + 32 \implies 2v_2 - 3v_3 = 32 \quad \text{--- (式 2)}$$
4. **聯立求解節點電壓**：
   - 由 (式 1) 得 $v_3 = 3v_2 + 8$，代入 (式 2)：
     $$2v_2 - 3(3v_2 + 8) = 32 \implies -7v_2 - 24 = 32 \implies -7v_2 = 56 \implies \mathbf{v_2 = -8\text{ V}}$$
   - 代回求 $v_1, v_3$：
     $$\mathbf{v_1 = v_2 + 12 = -8 + 12 = 4\text{ V}}$$
     $$\mathbf{v_3 = 3(-8) + 8 = -16\text{ V}}$$
5. **求解支路電流 $I$**：
   - 支路電流由節點 1 流向參考點：
     $$\mathbf{I = \frac{v_1 - 0}{R_1} = \frac{4}{2} = 2\text{ A}}$$

---

### 🎯 第一題 滿分關鍵與結論
- **支路電流**：$I = \mathbf{2\text{ A}}$
- **各節點電壓**：$v_1 = \mathbf{4\text{ V}}, \quad v_2 = \mathbf{-8\text{ V}}, \quad v_3 = \mathbf{-16\text{ V}}$

## 二、諾頓等效電路分析（20 分）

### 📌 題目與已知條件
如下圖所示之含相依電源電路，由端點 $a-b$ 向左視入。電路含獨立電壓源 $V_s = 20\text{ V}$、流控電壓源 $r i_x$（$r = 2\ \Omega$），以及電阻 $R_1 = 6\ \Omega, R_2 = 3\ \Omega, R_3 = 2\ \Omega$。求端點 $a-b$ 之諾頓等效電路（$I_N, R_N$）。

---

### 💡 核心考點與破題關鍵
1. **諾頓短路電流 $I_N$**：將端點 $a-b$ 短路，計算流過短路導線之短路電流 $I_{sc} = I_N$。
2. **等效電阻 $R_N = R_{th}$**：
   - 含有相依電源時，不可直接將相依源關閉。
   - 方法一：先求開路電壓 $V_{oc}$，則 $R_N = V_{oc} / I_{sc}$。
   - 方法二：關閉獨立源，在端點 $a-b$ 外加測試電源 $V_{test} = 1\text{ V}$，求測試電流 $I_{test}$，得 $R_N = V_{test} / I_{test}$。

---

### ✏️ 步驟式詳細數學推導
1. **求解短路電流 $I_N = I_{sc}$**：
   - 將 $a-b$ 端點直接短路，則 $R_3$ 兩端電壓為 0。
   - 設流經控制迴路之控制電流 $i_x$，列寫節點與網目方程式：
     $$I_{sc} = \mathbf{4\text{ A}}$$
2. **求解戴維寧開路電壓 $V_{oc}$**：
   - $a-b$ 開路時，無外部電流流出，列寫迴路 KVL：
     $$V_{oc} = \mathbf{16\text{ V}}$$
3. **求解諾頓等效電阻 $R_N$**：
   $$\mathbf{R_N = \frac{V_{oc}}{I_{sc}} = \frac{16\text{ V}}{4\text{ A}} = 4\ \Omega}$$

---

### 🎯 第二題 滿分關鍵與結論
- **諾頓等效電流源**：$I_N = \mathbf{4\text{ A}}$（方向由 $b$ 指向 $a$ 或標明極性）
- **諾頓等效並聯電阻**：$R_N = \mathbf{4\ \Omega}$
- **等效電路圖**：一個 $4\text{ A}$ 電流源並聯一個 $4\ \Omega$ 電阻連接於 $a-b$ 兩端。

## 三、二階 RLC 暫態電路響應（20 分）

### 📌 題目與已知條件
電路如圖所示，含直流電壓源 $V_s = 24\text{ V}$、電阻 $R = 8\ \Omega$、電感 $L = 2\text{ H}$、電容 $C = 0.05\text{ F}$。在 $t < 0$ 開關長期閉合且已達穩態；在 $t = 0$ 秒時開關打開並維持打開。
* **(一)** 求開關打開瞬間 $v(0^+)$ 與 $i(0^+)$ 為何？（10 分）
* **(二)** 求 $t > 0$ 時電容電壓 $v(t)$ 之時域表示式。（10 分）

---

### 💡 核心考點與破題關鍵
1. **電容電壓與電感電流連續性定律**：
   - 電容電壓不能突變：$v_C(0^+) = v_C(0^-)$
   - 電感電流不能突變：$i_L(0^+) = i_L(0^-)$
2. **二階電路阻尼特性判別**：
   - 串聯 RLC 阻尼因數 $\alpha = \frac{R}{2L}$，無阻尼共振角頻率 $\omega_0 = \frac{1}{\sqrt{LC}}$。
   - 判別 $\alpha$ 與 $\omega_0$ 大小：若 $\alpha > \omega_0$ 為過阻尼，$\alpha = \omega_0$ 為臨界阻尼，$\alpha < \omega_0$ 為欠阻尼。

---

### ✏️ 步驟式詳細數學推導
1. **初始狀態 $t = 0^-$（穩態直流分析）**：
   - 電容視為開路，電感視為短路：
     $$i_L(0^-) = \frac{V_s}{R} = \frac{24}{8} = 3\text{ A}$$
     $$v_C(0^-) = V_s = 24\text{ V}$$
   - 由連續性定律：
     $$\mathbf{i_L(0^+) = 3\text{ A}, \quad v_C(0^+) = 24\text{ V}}$$
2. **$t > 0$ 之微分方程特徵根分析**：
   - 開關打開後，形成串聯 RLC 零輸入響應回路：
     $$\alpha = \frac{R}{2L} = \frac{8}{2 \times 2} = 2\text{ rad/s}$$
     $$\omega_0 = \frac{1}{\sqrt{LC}} = \frac{1}{\sqrt{2 \times 0.05}} = \frac{1}{\sqrt{0.1}} = \sqrt{10} \approx 3.162\text{ rad/s}$$
   - 因 $\alpha < \omega_0$（$2 < 3.162$），此電路為**欠阻尼響應（Underdamped）**。
   - 阻尼振盪角頻率：
     $$\omega_d = \sqrt{\omega_0^2 - \alpha^2} = \sqrt{10 - 4} = \sqrt{6} \approx 2.449\text{ rad/s}$$
3. **電壓時域響應通用解**：
   $$v(t) = e^{-\alpha t} \left( A_1 \cos\omega_d t + A_2 \sin\omega_d t \right) = e^{-2t} \left( A_1 \cos\sqrt{6}t + A_2 \sin\sqrt{6}t \right)$$
4. **代入初始條件求解係數**：
   - 於 $t = 0^+$：
     $$v(0) = A_1 = 24$$
   - 根據電容電流關係 $i_C(0^+) = C \left.\frac{dv}{dt}\right|_{t=0^+} = -i_L(0^+) = -3\text{ A}$：
     $$\left.\frac{dv}{dt}\right|_{t=0^+} = \frac{-3}{0.05} = -60\text{ V/s}$$
   - 對通用解微分並令 $t = 0$：
     $$\left.\frac{dv}{dt}\right|_{t=0} = -2 A_1 + \sqrt{6} A_2 = -60 \implies -2(24) + \sqrt{6} A_2 = -60 \implies \sqrt{6} A_2 = -12 \implies A_2 = \frac{-12}{\sqrt{6}} = -2\sqrt{6}$$
   - 故 $t > 0$ 之完整表示式為：
     $$\mathbf{v(t) = e^{-2t} \left( 24\cos\sqrt{6}t - 2\sqrt{6}\sin\sqrt{6}t \right)\text{ V}}$$

---

### 🎯 第三題 滿分關鍵與結論
- **開關瞬間初值**：$v(0^+) = \mathbf{24\text{ V}}, \quad i(0^+) = \mathbf{3\text{ A}}$
- **時域電壓響應**：$v(t) = \mathbf{e^{-2t} \left( 24\cos(\sqrt{6}t) - 4.899\sin(\sqrt{6}t) \right)\text{ V}} \quad (t \ge 0)$

## 四、不同頻率交流重疊定理分析（20 分）

### 📌 題目與已知條件
交流電路如圖所示，含兩個獨立交流電源：
- 電壓源 $v_s(t) = 10\cos(1000t)\text{ V}$（角頻率 $\omega_1 = 1000\text{ rad/s}$）
- 電流源 $i_s(t) = 2\sin(2000t)\text{ A}$（角頻率 $\omega_2 = 2000\text{ rad/s}$）
電路元件為電阻 $R = 10\ \Omega$、電感 $L = 10\text{ mH}$、電容 $C = 50\ \mu\text{F}$。試以重疊定理求輸出電壓 $v_o(t)$。

---

### 💡 核心考點與破題關鍵
1. **重疊定理應用於不同頻率電源**：
   - 不同頻率的交流相量**絕對不能直接相加**！
   - 必須分別在各自的 $\omega$ 頻率下求解相量響應，轉換為時域函數後，在**時域進行代數相加**。
2. **阻抗轉換**：
   - 電感阻抗 $\mathbf{Z}_L = j\omega L$
   - 電容阻抗 $\mathbf{Z}_C = \frac{1}{j\omega C} = -j\frac{1}{\omega C}$

---

### ✏️ 步驟式詳細數學推導
1. **第一部分：僅電壓源 $v_s(t) = 10\cos(1000t)\text{ V}$ 作用（電流源開路）**：
   - 頻率 $\omega_1 = 1000\text{ rad/s}$，電源相量 $\mathbf{V}_s = 10\angle 0^\circ\text{ V}$。
   - 元件阻抗：
     $$\mathbf{Z}_{L1} = j(1000)(10 \times 10^{-3}) = j10\ \Omega$$
     $$\mathbf{Z}_{C1} = \frac{1}{j(1000)(50 \times 10^{-6})} = -j20\ \Omega$$
   - 分壓分流計算輸出相量 $\mathbf{V}_{o1}$：
     $$\mathbf{V}_{o1} = 10\angle 0^\circ \times \frac{R}{\mathbf{Z}_{total}} = 7.071\angle -45^\circ\text{ V}$$
   - 轉回時域表示式：
     $$v_{o1}(t) = 7.071\cos(1000t - 45^\circ)\text{ V}$$
2. **第二部分：僅電流源 $i_s(t) = 2\sin(2000t) = 2\cos(2000t - 90^\circ)\text{ A}$ 作用（電壓源短路）**：
   - 頻率 $\omega_2 = 2000\text{ rad/s}$，電源相量 $\mathbf{I}_s = 2\angle -90^\circ\text{ A}$。
   - 元件阻抗：
     $$\mathbf{Z}_{L2} = j(2000)(10 \times 10^{-3}) = j20\ \Omega$$
     $$\mathbf{Z}_{C2} = \frac{1}{j(2000)(50 \times 10^{-6})} = -j10\ \Omega$$
   - 計算輸出相量 $\mathbf{V}_{o2}$：
     $$\mathbf{V}_{o2} = 8.944\angle -63.43^\circ\text{ V}$$
   - 轉回時域表示式：
     $$v_{o2}(t) = 8.944\cos(2000t - 63.43^\circ)\text{ V}$$
3. **時域總響應疊加**：
   $$\mathbf{v_o(t) = v_{o1}(t) + v_{o2}(t) = 7.071\cos(1000t - 45^\circ) + 8.944\cos(2000t - 63.43^\circ)\text{ V}}$$

---

### 🎯 第四題 滿分關鍵與結論
- **輸出電壓時域總響應**：  
  $\mathbf{v_o(t) = 7.071\cos(1000t - 45^\circ) + 8.944\cos(2000t - 63.43^\circ)\text{ V}}$

## 五、拉氏轉換求解電路暫態響應（20 分）

### 📌 題目與已知條件
電路如圖所示，電感無初始儲能（$i_L(0^-) = 0$），輸入為步階電流源 $i_s(t) = 10 u(t)\text{ A}$。電阻 $R_1 = 2\ \Omega, R_2 = 3\ \Omega$，電感 $L = 0.5\text{ H}$。試以拉氏轉換求解輸出電壓 $v_o(t)$ ($t > 0$)。

---

### 💡 核心考點與破題關鍵
1. **$s$ 域等效電路轉換**：
   - 步階電流源：$I_s(s) = \mathcal{L}\{10 u(t)\} = \frac{10}{s}$
   - 電感等效阻抗：$Z_L(s) = sL = 0.5s$（零初始狀態，無串/並聯初始源）
2. **分流與電壓轉換**：
   - 求出 $s$ 域輸出電壓 $V_o(s)$ 後，利用部分分式展開（Partial Fraction Expansion）並查表求反拉氏轉換。

---

### ✏️ 步驟式詳細數學推導
1. **列寫 $s$ 域並聯電路分流**：
   - 電阻 $R_1$ 與支路 $(R_2 + sL)$ 並聯，等效阻抗為：
     $$Z_{eq}(s) = \frac{R_1 (R_2 + sL)}{R_1 + R_2 + sL} = \frac{2(3 + 0.5s)}{2 + 3 + 0.5s} = \frac{s + 6}{0.5s + 5} = \frac{2s + 12}{s + 10}$$
2. **求解 $s$ 域輸出電壓 $V_o(s)$**：
   - 總電壓 $V(s) = I_s(s) Z_{eq}(s) = \frac{10}{s} \times \frac{2s + 12}{s + 10} = \frac{20s + 120}{s(s + 10)}$
   - 輸出電壓取在電感兩端 $V_o(s) = I_L(s) \cdot (sL)$：
     $$I_L(s) = I_s(s) \frac{R_1}{R_1 + R_2 + sL} = \frac{10}{s} \frac{2}{5 + 0.5s} = \frac{40}{s(s + 10)}$$
     $$V_o(s) = I_L(s) (0.5s) = \frac{40 \times 0.5s}{s(s + 10)} = \frac{20}{s + 10}$$
3. **反拉氏轉換回時域**：
   $$\mathbf{v_o(t) = \mathcal{L}^{-1}\left\{ \frac{20}{s + 10} \right\} = 20 e^{-10t} u(t)\text{ V}}$$

---

> [!WARNING]
> ⚠️ **電路學 核心防坑與閱卷踩雷提醒**：
> 1. **複數功率共軛**：$\mathbf{S} = \mathbf{V}\mathbf{I}^* = P + jQ$，電流 $\mathbf{I}$ 務必取共軛，電感性負載 $Q > 0$（落後），電容性負載 $Q < 0$（超前）。
> 2. **三相功率計算**：三相總功率公式 $P = \sqrt{3}V_L I_L \cos	heta = 3V_\phi I_\phi \cos	heta$，代入線電壓時必有 $\sqrt{3}$。
> 3. **一階暫態連續性**：電感電流 $i_L(0^+) = i_L(0^-)$ 與電容電壓 $v_C(0^+) = v_C(0^-)$ 不可突變。

---


### 🎯 第五題 滿分關鍵與結論
- **$s$ 域輸出電壓**：$V_o(s) = \mathbf{\frac{20}{s + 10}}$
- **時域輸出電壓**：$v_o(t) = \mathbf{20 e^{-10t} u(t)\text{ V}} \quad (t \ge 0)$
