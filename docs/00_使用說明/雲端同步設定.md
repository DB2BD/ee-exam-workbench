# 雲端同步設定

手機與電腦各自做題時，可以用 GitHub 的「秘密 Gist」當雲端，讓兩邊的進度自動合併。不需要再下載 .json 檔來回傳送。

## 一、建立權杖（每台裝置貼一次）

1. 登入 GitHub，開啟 <https://github.com/settings/tokens>。
2. 二選一：
   - **Fine-grained token（建議）**：選 Generate new token，Account permissions 裡把 **Gists** 設為 Read and write，其他一律不開。
   - **Classic token**：選 Generate new token (classic)，只勾選 **gist**，其他權限都不要勾。
3. Expiration（到期日）依自己的習慣設定，建立後複製權杖。權杖只會顯示一次。
4. 在工作台開啟「備份／還原」，找到「雲端同步」，把權杖貼進欄位，按「連線」。
5. 第二台裝置貼**同一個權杖**即可：程式會依固定的描述找到第一台建立的 Gist，不會另外建立。

## 二、之後怎麼運作

- 開啟工作台時，先下載雲端進度並**合併**到本機。
- 存結果卡、完成今日任務、複習評分後，約 30 秒內會把合併後的進度上傳。
- 離線或上傳失敗時，進度留在本機，之後開啟工作台或網路恢復時會自動再試。
- 備份視窗會顯示「上次同步」時間；也可以按「立即同步」。
- 每次合併前，會自動在本機拍一份「同步前」快照，可在「自動快照」還原。
- 「中斷連線」只會刪除這台裝置保存的權杖，雲端那份不會被刪除，**也不會撤銷權杖**（見下方安全說明）。

合併規則：結果卡依編號聯集、已完成任務聯集、SM-2 複習取較新一次。做題進度、重點收藏、回想紀錄、手動章節標籤與每日練習完成紀錄，會以「上次同步後本機有改動（含刪除）」為準，這台裝置的新改動不會被雲端的舊值蓋掉。模考計時是各裝置自己的狀態，不會被雲端蓋掉。

還原快照或以「取代」匯入備份後（已連線時），下一次同步會直接用本機資料覆寫雲端，不再合併。若雲端檔案格式損壞，按「立即同步」會詢問是否用本機進度覆寫雲端。

重複的 Gist（同描述）只在「尚未合併過、或自上次合併後有變動」時才會併入，避免已刪除的資料在每次開啟後又被併回來。已知限制：帳號內 Gist 超過 100 個時，各裝置只會查詢前 10 頁並取到的「最早」那份，在極少數情況下可能不一致。

## 三、隱私與安全

- 秘密 Gist 不會出現在你的 GitHub 個人頁或搜尋結果，但**知道網址的人都能讀取**。同步的內容只有做題進度與作答紀錄，不含權杖。
- **權杖等同密碼**：不要分享、不要貼到聊天或截圖。權杖只存在這台瀏覽器的本機儲存空間，不會寫進備份檔或快照，也不會上傳。
- 公用電腦或不再使用的裝置，請先按「中斷連線」，並到 <https://github.com/settings/tokens> 撤銷該權杖：「中斷連線」只刪除本機保存的權杖，**不會**在 GitHub 端撤銷。
- 權杖遺失或外洩時，隨時可到 <https://github.com/settings/tokens> 撤銷，再建立新的重新連線。
- **秘密 Gist 會保留修訂歷史**：舊版本仍可透過 Gist 網址讀取。想徹底移除舊進度，要到 GitHub 的 Gist 頁面刪除整個 Gist（只改內容不會清掉歷史）。
- **同源風險**：`db2bd.github.io` 底下所有 GitHub Pages 網站共用同一個瀏覽器儲存空間，同一網域下任何一個頁面的程式都能讀到這裡保存的權杖。請使用只開 **Gists** 權限的 fine-grained token，並設定較短的到期日（例如 30～90 天），到期後重新建立即可。
