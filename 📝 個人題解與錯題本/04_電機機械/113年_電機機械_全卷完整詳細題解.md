## 一、單相變壓器實體磁路與等效電感模型（20 分）

### 📌 題目與已知條件
一單相變壓器，一次側/二次側電壓、電流、匝數、漏磁通分別為 $V_1/V_2, I_1/I_2, N_1/N_2, \phi_{l1}/\phi_{l2}$，鐵心主磁通為 $\phi_M$，鐵心的磁阻為 $\mathcal{R}_M$，一次側/二次側漏磁阻分別為 $\mathcal{R}_{l1}/\mathcal{R}_{l2}$。
* **(一)** 繪出此變壓器的磁路（含磁動勢、磁阻、磁通）。（10 分）
* **(二)** 考量線圈銅損、鐵損後，畫出變壓器的等效電路，並列出等效電路中的各電感公式（以匝數及磁阻來表示）。（10 分）

---

### 💡 核心考點與破題關鍵
1. **變壓器磁路架構**：
   - 一次側磁動勢 $\mathcal{F}_1 = N_1 I_1$，二次側磁動勢 $\mathcal{F}_2 = N_2 I_2$。
   - 總磁通分為鐵心主磁路互感磁通 $\phi_M$ 與兩側漏磁通 $\phi_{l1}, \phi_{l2}$。
2. **電感定義公式（$L = \frac{N^2}{\mathcal{R}}$）**：
   - 激磁電感（主電感）：$L_M = \frac{N_1^2}{\mathcal{R}_M}$
   - 一次側漏電感：$L_{l1} = \frac{N_1^2}{\mathcal{R}_{l1}}$
   - 二次側漏電感：$L_{l2} = \frac{N_2^2}{\mathcal{R}_{l2}}$

---

### ✏️ 步驟式詳細數學推導

#### 🔹 (一) 變壓器磁路模型繪製
* **磁路節點與支路分析**：
  - 一次側磁動勢源 $\mathcal{F}_1 = N_1 I_1$ 驅動總磁通 $\Phi_1 = \phi_{l1} + \phi_M$。
  - 一次側漏磁迴路：$\phi_{l1} = \frac{\mathcal{F}_1}{\mathcal{R}_{l1}}$
  - 主鐵心磁迴路：$\phi_M = \frac{\mathcal{F}_1 - \mathcal{F}_2}{\mathcal{R}_M} = \frac{N_1 I_1 - N_2 I_2}{\mathcal{R}_M}$
  - 二次側漏磁迴路：$\phi_{l2} = \frac{\mathcal{F}_2}{\mathcal{R}_{l2}}$
* **磁路圖**：
  ```
  + ───[ F1 = N1 I1 ]───┬───[ RM (主鐵心磁阻) ]───┬───[ F2 = N2 I2 (反向) ]─── -
                        │                         │
                 [ Rl1 (一次漏磁阻) ]       [ Rl2 (二次漏磁阻) ]
                        │                         │
  - ────────────────────┴─────────────────────────┴─────────────────────────── +
  ```

#### 🔹 (二) 考慮銅損與鐵損之等效電路與各電感公式
* **完整等效電路結構（參照一次側）**：
  - $R_1, R_2'$：一次側與二次側繞組電阻（代表銅損）。
  - $R_c$：鐵損激磁電阻（代表渦流與磁滯損）。
  - $L_{l1}, L_{l2}'$：一次側與二次側漏電感。
  - $L_M$：激磁互感主電感。
* **各電感公式（以匝數 $N$ 及磁阻 $\mathcal{R}$ 表示）**：
  1. **一次側漏電感（Primary Leakage Inductance）**：
     $$\mathbf{L_{l1} = \frac{N_1^2}{\mathcal{R}_{l1}}}$$
  2. **二次側漏電感（Secondary Leakage Inductance）**：
     $$\mathbf{L_{l2} = \frac{N_2^2}{\mathcal{R}_{l2}} \quad \left(\text{參照至一次側為 } L_{l2}' = a^2 L_{l2} = \frac{N_1^2}{\mathcal{R}_{l2}}\right)}$$
  3. **激磁互感電感（Magnetizing Inductance）**：
     $$\mathbf{L_M = \frac{N_1^2}{\mathcal{R}_M}}$$

---

### 🎯 第一題 滿分關鍵與結論
* **各電感公式**：$L_{l1} = \mathbf{\frac{N_1^2}{\mathcal{R}_{l1}}}, \quad L_{l2} = \mathbf{\frac{N_2^2}{\mathcal{R}_{l2}}}, \quad L_M = \mathbf{\frac{N_1^2}{\mathcal{R}_M}}$

## 二、600 kVA 同步發電機標么阻抗、銅損與轉矩（20 分）

### 📌 題目與已知條件
一台 $600\text{ kVA}、1800\text{ rpm}、4.2\text{ kV}、60\text{ Hz}、3\phi$、效率 $\eta = 0.9$ 的同步發電機，在 $0.9\text{ 滯後}$（落後）功率因數下提供額定電流。每相同步阻抗為 $\mathbf{Z}_s = 2 + j20\ \Omega$。
* **試求**：
  1. 發電機之極數 $P$。
  2. 以額定容量和電壓為基準之同步阻抗標么值 $Z_{s,pu}$。
  3. 定子銅損耗 $P_{cu}$。
  4. 所產生的電機轉矩 $T_{dev}$。（20 分）

---

### 💡 核心考點與破題關鍵
1. **極數與同步轉速**：$P = \frac{120 f}{n_s}$。
2. **阻抗基準值**：$Z_{base} = \frac{V_{base,LL}^2}{S_{base,3\phi}}$。
3. **額定電流與銅損**：$I_{rated} = \frac{S_{rated}}{\sqrt{3} V_{LL}}, \ P_{cu} = 3 I_{rated}^2 R_a$。
4. **電機轉矩**：$T_{dev} = \frac{P_{dev}}{\omega_s} = \frac{P_{out} + P_{cu}}{\omega_s}$。

---

### ✏️ 步驟式詳細數學推導
1. **(1) 計算極數 $P$**：
   $$\mathbf{P = \frac{120 \times f}{n_s} = \frac{120 \times 60}{1800} = \mathbf{4\text{ 極}}}$$
2. **(2) 計算同步阻抗標么值**：
   - 阻抗基準值：
     $$Z_{base} = \frac{(4.2\text{ kV})^2}{600\text{ kVA}} = \frac{4200^2}{600000} = \mathbf{29.40\ \Omega}$$
   - 同步阻抗標么值：
     $$\mathbf{Z_{s,pu} = \frac{2 + j20\ \Omega}{29.40\ \Omega} = \mathbf{0.06803 + j0.68027\text{ pu}} \quad (|Z_{s,pu}| = \mathbf{0.6837\text{ pu}})}$$
3. **(3) 計算定子銅損耗 $P_{cu}$**：
   - 額定線電流：
     $$I_{rated} = \frac{600000\text{ VA}}{\sqrt{3} \times 4200\text{ V}} = \mathbf{82.4786\text{ A}}$$
   - 三相定子銅損（$R_a = 2\ \Omega$）：
     $$\mathbf{P_{cu} = 3 \times I_{rated}^2 \times R_a = 3 \times (82.4786\text{ A})^2 \times 2\ \Omega = \mathbf{40816.3\text{ W} = 40.82\text{ kW}}}$$
4. **(4) 計算產生的電機轉矩 $T_{dev}$**：
   - 同步機械角速度：
     $$\omega_s = \frac{2\pi \times 1800}{60} = 60\pi \approx \mathbf{188.496\text{ rad/s}}$$
   - 額定輸出實功率（$\text{PF} = 0.9$）：
     $$P_{out} = S_{rated} \times \text{PF} = 600\text{ kVA} \times 0.9 = 540\text{ kW}$$
   - 電磁內生總功率：
     $$P_{dev} = P_{out} + P_{cu} = 540000\text{ W} + 40816.3\text{ W} = \mathbf{580816.3\text{ W} = 580.82\text{ kW}}$$
   - 電機電磁轉矩：
     $$\mathbf{T_{dev} = \frac{P_{dev}}{\omega_s} = \frac{580816.3\text{ W}}{188.496\text{ rad/s}} = \mathbf{3081.33\text{ N}\cdot\text{m}}}$$
   - *(若求原動機輸入總轉矩：$T_{in} = \frac{P_{in}}{\omega_s} = \frac{540\text{ kW}/0.9}{188.496} = \frac{600000}{188.496} = \mathbf{3183.10\text{ N}\cdot\text{m}}$)*

---

### 🎯 第二題 滿分關鍵與結論
* **極數**：$P = \mathbf{4\text{ 極}}$
* **同步阻抗標么值**：$\mathbf{Z_{s,pu} = 0.0680 + j0.6803\text{ pu}}$（$|Z_s| = \mathbf{0.6837\text{ pu}}$）
* **定子銅損**：$P_{cu} = \mathbf{40.82\text{ kW}}$
* **電機轉矩**：$T_{dev} = \mathbf{3081.33\text{ N}\cdot\text{m}}$

## 三、串激直流電動機場電阻並聯調速與效率（20 分）

### 📌 題目與已知條件
一 $300\text{ V}、60\text{ A}、1800\text{ rpm}$ 串激直流馬達，串聯的電樞和場電阻均為 $0.10\ \Omega$（$R_a = 0.10\ \Omega, R_f = 0.10\ \Omega$）。
* 當 $0.10\ \Omega$ 電阻並聯於場繞組時，馬達的扭矩增加了一倍（$T_2 = 2 T_1$）。
* 假設可以忽略電樞反應和旋轉損失。

**試求**：馬達之電樞電流 $I_{a2}$、轉速 $n_2$ 及效率 $\eta_2$。（20 分）

---

### 💡 核心考點與破題關鍵
1. **串激馬達轉矩正比於磁通與電樞電流乘積**：
   $$T = K \Phi I_a = K' I_f I_a$$
   - 原始狀態：$I_{f1} = I_{a1} = 60\text{ A} \implies T_1 = K' (60)^2 = 3600 K'$。
2. **場繞組並聯分流電阻後**：
   - 場電阻 $R_f = 0.10\ \Omega$ 與分流電阻 $R_{sh} = 0.10\ \Omega$ 並聯，等效場電阻 $R_{f,eq} = 0.10 \parallel 0.10 = 0.05\ \Omega$。
   - 由分流定律，流過場繞組電流 $I_{f2} = 0.5 I_{a2}$。
   - 新轉矩：$T_2 = K' I_{f2} I_{a2} = K' (0.5 I_{a2}) I_{a2} = 0.5 K' I_{a2}^2$。
   - 已知 $T_2 = 2 T_1 \implies 0.5 I_{a2}^2 = 2 \times 3600 = 7200 \implies I_{a2}^2 = 14400 \implies I_{a2} = 120\text{ A}$！
3. **轉速與反電動勢比例關係**：
   $$\frac{n_2}{n_1} = \frac{E_{a2}}{E_{a1}} \times \frac{\Phi_1}{\Phi_2} = \frac{E_{a2}}{E_{a1}} \times \frac{I_{f1}}{I_{f2}}$$

---

### ✏️ 步驟式詳細數學推導
1. **計算原始反電動勢 $E_{a1}$**：
   $$E_{a1} = V_t - I_{a1} (R_a + R_f) = 300 - 60 \times (0.10 + 0.10) = 300 - 12 = \mathbf{288\text{ V}}$$
2. **求解新電樞電流 $I_{a2}$**：
   - 由轉矩加倍條件：
     $$T_2 = 2 T_1 \implies 0.5 K' I_{a2}^2 = 2 K' (60)^2 = 7200 K'$$
     $$\mathbf{I_{a2} = \sqrt{14400} = \mathbf{120\text{ A}}}$$
   - 新磁場電流：$I_{f2} = 0.5 \times 120\text{ A} = \mathbf{60\text{ A}}$（恰好與原磁場電流相等 $\Phi_2 = \Phi_1$！）。
3. **計算新反電動勢 $E_{a2}$ 與轉速 $n_2$**：
   - 新迴路總電阻：$R_{total} = R_a + (R_f \parallel R_{sh}) = 0.10 + 0.05 = \mathbf{0.15\ \Omega}$。
   - 新反電動勢：
     $$\mathbf{E_{a2} = V_t - I_{a2} R_{total} = 300 - 120 \times 0.15 = 300 - 18 = \mathbf{282\text{ V}}}$$
   - 因 $I_{f2} = I_{f1} = 60\text{ A} \implies \Phi_2 = \Phi_1$，轉速與反電動勢直接成正比：
     $$\mathbf{n_2 = n_1 \times \frac{E_{a2}}{E_{a1}} = 1800 \times \frac{282\text{ V}}{288\text{ V}} = \mathbf{1762.5\text{ rpm}}}$$
4. **計算馬達效率 $\eta_2$**：
   - 輸出機械功率（忽略旋轉損失時等於內生電磁功率）：
     $$P_{out2} = E_{a2} I_{a2} = 282\text{ V} \times 120\text{ A} = \mathbf{33840\text{ W}}$$
   - 輸入電功率：
     $$P_{in2} = V_t I_{a2} = 300\text{ V} \times 120\text{ A} = \mathbf{36000\text{ W}}$$
   - 新效率：
     $$\mathbf{\eta_2 = \frac{P_{out2}}{P_{in2}} \times 100\% = \frac{33840}{36000} \times 100\% = \mathbf{94.00\%}}$$

---

### 🎯 第三題 滿分關鍵與結論
* **電樞電流**：$I_{a2} = \mathbf{120\text{ A}}$
* **運轉轉速**：$n_2 = \mathbf{1762.5\text{ rpm}}$
* **運轉效率**：$\eta_2 = \mathbf{94.0\%}$

## 四、三相感應馬達等效電路、轉矩與滑差率分析（20 分）

### 📌 題目與已知條件
一部 $220\text{ V}、60\text{ Hz}、1120\text{ rpm}$ 三相感應馬達，每相等效電路參數如下：
* 定子阻抗：$R_1 + jX_1 = 0.1 + j0.25\ \Omega$。
* 激磁分路：鐵損電阻 $R_c = 60\ \Omega$，激磁電抗 $X_m = 15\ \Omega$。
* 轉子阻抗：$jX_2 = j0.35\ \Omega, \ \frac{R_2}{s} = \frac{0.2}{s}\ \Omega$。
* 同步轉速 $n_s = 1200\text{ rpm}$（6 極），滿載轉差率 $s_{fl} = \frac{1200 - 1120}{1200} = \frac{80}{1200} = \frac{1}{15} \approx 0.06667$。

**試求**：在忽略旋轉損失及激磁阻抗情況下，計算：
1. 啟動電流 $I_{start}$。
2. 滿載電流 $I_{fl}$、功率因數 $\text{PF}$、扭矩 $T$ 及效率 $\eta$。
3. 最大扭矩時之滑差率 $s_{max}$ 及電流 $I_{smax}$。
4. 將激磁阻抗考慮在內之啟動電流 $I_{start,m}$。（20 分）

---

### 💡 核心考點與破題關鍵
1. **輸入相電壓**：$V_1 = \frac{220}{\sqrt{3}} \approx 127.017\text{ V}$。
2. **忽略激磁分路時等效總阻抗**：
   $$Z_{in} = (R_1 + \frac{R_2}{s}) + j(X_1 + X_2) = (0.1 + \frac{0.2}{s}) + j0.60\ \Omega$$
3. **最大轉矩轉差率**：
   $$s_{max} = \frac{R_2}{\sqrt{R_1^2 + (X_1 + X_2)^2}} = \frac{0.2}{\sqrt{0.1^2 + 0.6^2}} = \frac{0.2}{0.6083} \approx 0.3288$$

---

### ✏️ 步驟式詳細數學推導

#### 🔹 (1) 忽略激磁阻抗之啟動電流（$s = 1$）
* 啟動總阻抗：
  $$Z_{start} = (0.1 + 0.2) + j(0.25 + 0.35) = 0.3 + j0.6\ \Omega \implies |Z_{start}| = \sqrt{0.3^2 + 0.6^2} = \sqrt{0.45} = \mathbf{0.67082\ \Omega}$$
* 啟動電流：
  $$\mathbf{I_{start} = \frac{127.017\text{ V}}{0.67082\ \Omega} = \mathbf{189.35\text{ A}}}$$

#### 🔹 (2) 滿載運轉特性（$s = \frac{1}{15} \implies \frac{R_2}{s} = 3.0\ \Omega$）
* 滿載總阻抗：
  $$Z_{fl} = (0.1 + 3.0) + j0.60 = 3.1 + j0.6\ \Omega \implies |Z_{fl}| = \sqrt{3.1^2 + 0.6^2} = \sqrt{9.97} = \mathbf{3.15753\ \Omega}$$
* 滿載電流：
  $$\mathbf{I_{fl} = \frac{127.017\text{ V}}{3.15753\ \Omega} = \mathbf{40.23\text{ A}}}$$
* 滿載功率因數：
  $$\mathbf{\text{PF} = \frac{3.1}{3.15753} = \mathbf{0.9818\text{ 落後}}}$$
* 滿載電磁轉矩（$\omega_s = \frac{2\pi \times 1200}{60} = 125.664\text{ rad/s}$）：
  $$\mathbf{T = \frac{3 I_{fl}^2 (R_2/s)}{\omega_s} = \frac{3 \times (40.227)^2 \times 3.0}{125.664} = \frac{14563.8}{125.664} = \mathbf{115.89\text{ N}\cdot\text{m}}}$$
* 滿載效率（機械輸出 $P_{mech} = 3 I_{fl}^2 \times 0.2 \frac{1-s}{s} = 13592.9\text{ W}$，電氣輸入 $P_{in} = 3 I_{fl}^2 \times 3.1 = 15049.3\text{ W}$）：
  $$\mathbf{\eta = \frac{13592.9}{15049.3} \times 100\% = \mathbf{90.32\%}}$$

#### 🔹 (3) 最大扭矩之滑差率與電流
* 最大轉矩轉差率：
  $$\mathbf{s_{max} = \frac{0.2}{\sqrt{0.1^2 + 0.6^2}} = \frac{0.2}{0.60828} = \mathbf{0.3288\ (32.88\%)}}$$
* 最大轉矩時總阻抗與電流：
  $$\frac{R_2}{s_{max}} = \frac{0.2}{0.3288} = 0.6083\ \Omega \implies Z_{smax} = (0.1 + 0.6083) + j0.60 = 0.7083 + j0.60\ \Omega$$
  $$|Z_{smax}| = \sqrt{0.7083^2 + 0.60^2} = \sqrt{0.5017 + 0.36} = \mathbf{0.92827\ \Omega}$$
  $$\mathbf{I_{smax} = \frac{127.017\text{ V}}{0.92827\ \Omega} = \mathbf{136.83\text{ A}}}$$

#### 🔹 (4) 考慮激磁阻抗之啟動電流
* 激磁並聯阻抗：
  $$Z_m = R_c \parallel jX_m = \frac{60 \times j15}{60 + j15} = \frac{j900}{60 + j15} = 3.5294 + j14.1176\ \Omega$$
* 轉子靜止阻抗 $Z_2 = 0.2 + j0.35\ \Omega$ 與 $Z_m$ 並聯：
  $$Z_p = \frac{Z_2 \times Z_m}{Z_2 + Z_m} = \mathbf{0.1948 + j0.3418\ \Omega}$$
* 總啟動阻抗：
  $$Z_{total,m} = (0.1 + j0.25) + (0.1948 + j0.3418) = 0.2948 + j0.5918\ \Omega \implies |Z_{total,m}| = \mathbf{0.66122\ \Omega}$$
* 考慮激磁阻抗後之啟動電流：
  $$\mathbf{I_{start,m} = \frac{127.017\text{ V}}{0.66122\ \Omega} = \mathbf{192.10\text{ A}}}$$

---

### 🎯 第四題 滿分關鍵與結論
* **(1) 啟動電流**：$I_{start} = \mathbf{189.35\text{ A}}$
* **(2) 滿載運轉**：$I_{fl} = \mathbf{40.23\text{ A}}, \ \text{PF} = \mathbf{0.9818\text{ 落後}}, \ T = \mathbf{115.89\text{ N}\cdot\text{m}}, \ \eta = \mathbf{90.32\%}$
* **(3) 最大轉矩點**：$s_{max} = \mathbf{0.3288}, \ I_{smax} = \mathbf{136.83\text{ A}}$
* **(4) 含激磁分路啟動電流**：$I_{start,m} = \mathbf{192.10\text{ A}}$

## 五、電容啟動單相感應馬達啟動電容與轉矩比較（20 分）

### 📌 題目與已知條件
一部 $240\text{ V}、60\text{ Hz}、4\text{ 極}$ 電容啟動單相感應馬達，在轉子靜止下：
* 主繞組輸入阻抗：$\mathbf{Z}_m = 3.5 + j6.2\ \Omega$。
* 輔助繞組輸入阻抗：$\mathbf{Z}_a = 7.2 + j4.8\ \Omega$。

**試求**：
* **(一)** 於靜止狀態下，求使主繞組電流 $\mathbf{I}_m$ 與輔助繞組電流 $\mathbf{I}_a$ 產生 $90^\circ$ 相角差的啟動電容大小 $C$（$\mu\text{F}$）。（10 分）
* **(二)** 比較有啟動電容及無啟動電容二者之啟動扭力倍率。（10 分）

---

### 💡 核心考點與破題關鍵
1. **主繞組電流相角**：
   $$\mathbf{Z}_m = 3.5 + j6.2\ \Omega \implies \theta_m = \tan^{-1}\left(\frac{6.2}{3.5}\right) \approx 60.55^\circ \implies \mathbf{I}_m \text{ 落後端電壓 } 60.55^\circ$$
2. **正交 $90^\circ$ 條件**：
   - 為使 $\mathbf{I}_a$ 領先 $\mathbf{I}_m$ 達 $90^\circ，\mathbf{I}_a$ 必須**超前**端電壓 $\theta_a' = 90^\circ - 60.55^\circ = 29.45^\circ$。
   - 串聯電容後輔助繞組阻抗：$\mathbf{Z}_a' = 7.2 + j(4.8 - X_c)$。
   - 阻抗角必須為 $-29.45^\circ \implies \frac{4.8 - X_c}{7.2} = -\tan(29.45^\circ) = -0.5646$。
3. **單相感應電動機啟動轉矩公式**：
   $$T_{start} \propto |\mathbf{I}_m| |\mathbf{I}_a| \sin\alpha \quad (\alpha = \text{兩繞組電流相角差})$$

---

### ✏️ 步驟式詳細數學推導

#### 🔹 (一) 求解啟動電容 $C$
1. 主繞組阻抗大小與相角：
   $$|\mathbf{Z}_m| = \sqrt{3.5^2 + 6.2^2} = \sqrt{12.25 + 38.44} = \mathbf{7.1197\ \Omega}$$
   $$\theta_m = \tan^{-1}\left(\frac{6.2}{3.5}\right) = \mathbf{60.552^\circ}$$
2. 輔助繞組所需阻抗角：
   $$\theta_a' = -(90^\circ - 60.552^\circ) = \mathbf{-29.448^\circ}$$
   $$\tan(-29.448^\circ) = \frac{4.8 - X_c}{7.2} \implies -0.5646 = \frac{4.8 - X_c}{7.2}$$
   4. $8 - X_c = -0.5646 \times 7.2 = -4.0651\ \Omega \implies \mathbf{X_c = 4.8 + 4.0651 = \mathbf{8.8651\ \Omega}}$
3. 計算電容量 $C$：
   $$\mathbf{C = \frac{1}{\omega X_c} = \frac{1}{2\pi \times 60 \times 8.8651} = \frac{1}{3342.1} = \mathbf{2.992 \times 10^{-4}\text{ F} = \mathbf{299.2\ \mu\text{F}}}}$$

#### 🔹 (二) 比較有、無啟動電容之啟動扭力
1. **無電容時（No Capacitor）**：
   - 輔助繞組阻抗：$|\mathbf{Z}_a| = \sqrt{7.2^2 + 4.8^2} = \mathbf{8.6533\ \Omega}, \ \theta_a = \tan^{-1}\left(\frac{4.8}{7.2}\right) = \mathbf{33.690^\circ}$
   - 電流相角差：$\alpha = \theta_m - \theta_a = 60.552^\circ - 33.690^\circ = \mathbf{26.862^\circ}$
   - 電流大小：$I_m = \frac{240}{7.1197} = 33.709\text{ A}, \ I_a = \frac{240}{8.6533} = 27.735\text{ A}$
   - 轉矩指標：
     $$T_{start,noC} \propto I_m I_a \sin(26.862^\circ) = (33.709) \times (27.735) \times \sin(26.862^\circ) = 934.92 \times 0.45185 = \mathbf{422.45}$$
2. **串聯啟動電容時（With Capacitor）**：
   - 新輔助繞組阻抗：$|\mathbf{Z}_a'| = \sqrt{7.2^2 + (-4.0651)^2} = \sqrt{51.84 + 16.525} = \mathbf{8.2683\ \Omega}$
   - 新輔助電流：$I_a' = \frac{240}{8.2683} = \mathbf{29.026\text{ A}}$
   - 電流相角差：$\alpha' = \mathbf{90.00^\circ} \implies \sin(90^\circ) = 1.0$
   - 新轉矩指標：
     $$T_{start,withC} \propto I_m I_a' \sin(90^\circ) = (33.709) \times (29.026) \times 1.0 = \mathbf{978.44}$$
3. **扭力提升倍率**：
   $$\mathbf{\frac{T_{start,withC}}{T_{start,noC}} = \frac{978.44}{422.45} = \mathbf{2.316\text{ 倍}} \quad (\text{增長率為 } \mathbf{+131.6\%})}$$

> 1. **變壓器阻抗折合**：低壓側折合至高壓側乘以變比平方 $a^2$；自耦變壓器共用繞組電流為高低壓側電流之差值。

> 3. **同步機相量計算**：同步電動機 $\mathbf{E}_f = \mathbf{V}_\phi - \mathbf{I}_a \mathbf{Z}_s$；同步發電機 $\mathbf{E}_f = \mathbf{V}_\phi + \mathbf{I}_a \mathbf{Z}_s$。
