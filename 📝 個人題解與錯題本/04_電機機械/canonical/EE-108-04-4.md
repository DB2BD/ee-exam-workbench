## 四、同步發電機並聯無限匯流排與功角（20 分）

### 📌 題目與已知條件
- 額定：三相 $2300\text{ V}, 1500\text{ kW}, 60\text{ Hz}, 30$ 極圓型轉子同步發電機，同步電抗 $X_s = 2.0\ \Omega/\text{相}$，電樞電阻忽略。
- 連接於 $2300\text{ V}$ 無限匯流排，供應 $1200\text{ kW}$ 實功率，功率因數 $\text{PF} = 0.8\text{ 落後}$。

* **(一)** 計算每相激磁電壓 $E_f$ 與功率角 $\delta$。（10 分）
* **(二)** 若原動機輸入功率維持不變（實功 $1200\text{ kW}$ 固定），調整激磁電流使功率因數變為 $1.0$，求新激磁電壓 $E_f'$ 與新功角 $\delta'$。（10 分）

---

### ✏️ 步驟式詳細數學推導
1. **初始狀態（$\text{PF} = 0.8$ 落後）**：
   $$V_\phi = \frac{2300}{\sqrt{3}} \approx 1327.91\text{ V}$$
   $$I_a = \frac{1200 \times 10^3}{\sqrt{3} \times 2300 \times 0.8} = 376.53ngle -36.87^\circ\text{ A} = (301.22 - j225.92)\text{ A}$$
   $$\mathbf{E}_f = 1327.91 + j2.0(301.22 - j225.92) = (1327.91 + 451.84) + j602.44 = 1779.75 + j602.44\text{ V}$$
$$|\mathbf{E}_f| = \sqrt{1779.75^2 + 602.44^2} = \mathbf{1878.96\text{ V/相}}$$
   $$\mathbf{\delta = \tan^{-1}\left( \frac{602.44}{1779.75} \right) = \mathbf{18.70^\circ}}$$
2. **調整至單位功因（$\text{PF} = 1.0$）**：
   $$I_a' = \frac{1200 \times 10^3}{\sqrt{3} \times 2300 \times 1.0} = 301.22ngle 0^\circ\text{ A}$$
   $$\mathbf{E}_f' = V_\phi + j X_s I_a' = 1327.91 + j(2.0 \times 301.22) = 1327.91 + j602.44\text{ V}$$
   \(|\mathbf{E}_f'| = \sqrt{1327.91^2 + 602.44^2} = \sqrt{1763345 + 362934} = \sqrt{2126279} = \mathbf{1458.18\text{ V/相}}\)
   $$\mathbf{\delta' = \tan^{-1}\left( \frac{602.44}{1327.91} \right) = \mathbf{24.40^\circ}}$$

---

### 🎯 第四題 滿分關鍵與結論
- **初始狀態**：$E_f = \mathbf{1878.96\text{ V/相}}, \delta = \mathbf{18.70^\circ}$
- **$\text{PF}=1.0$ 狀態**：$E_f' = \mathbf{1458.18\text{ V/相}}, \delta' = \mathbf{24.40^\circ}$

---

> [!WARNING]
> ⚠️ **電機機械 核心防坑與閱卷踩雷提醒**：
> 1. **變壓器阻抗折合**：低壓側折合至高壓側乘以變比平方 $a^2$；自耦變壓器共用繞組電流為高低壓側電流之差值。
> 2. **感應機最大轉矩**：最大轉矩 $T_{max}$ 與轉子電阻 $R_2$ 無關，但產生最大轉矩之轉差率 $s_{max}$ 與 $R_2$ 成正比。
> 3. **同步機相量計算**：同步電動機 $\mathbf{E}_f = \mathbf{V}_\phi - \mathbf{I}_a \mathbf{Z}_s$；同步發電機 $\mathbf{E}_f = \mathbf{V}_\phi + \mathbf{I}_a \mathbf{Z}_s$。
