## 110 年

#### 一、 正交矩陣與 Gram-Schmidt 正交化：將向量空間之基底 $\mathbf{v}_1 = (1, 1, 0)^T, \mathbf{v}_2 = (1, 0, 1)^T, \mathbf{v}_3 = (0, 1, 1)^T$ 透過葛蘭－史密特正交化程序轉換為標準正交基底。（20 分）

#### 二、 波動方程（Wave Equation）達朗貝爾解：求解無邊界一維弦波方程 $\frac{\partial^2 u}{\partial t^2} = c^2 \frac{\partial^2 u}{\partial x^2}$，初始位移 $u(x, 0) = \frac{1}{1+x^2}$，初始速度 $\frac{\partial u}{\partial t}(x, 0) = 0$。（20 分）

#### 三、 泰勒級數與勞倫級數（Laurent Series）：求複變函數 $f(z) = \frac{1}{(z-1)(z-2)}$ 在以下各區域之級數展開式：(一) $|z| < 1$；(二) $1 < |z| < 2$；(三) $|z| > 2$。（20 分）

#### 四、 高階變係數 Euler-Cauchy 方程：求解歐拉－柯西常微分方程 $x^2 y'' - 3x y' + 4y = x^2 \ln x, x > 0$。（20 分）

#### 五、 雙重積分與極座標變換：計算積分 $\iint_R \exp(-(x^2+y^2)) dx dy$，其中區域 $R = \{(x, y) \mid x \ge 0, y \ge 0\}$，並證明高斯積分 $\int_{-\infty}^\infty e^{-x^2} dx = \sqrt{\pi}$。（20 分）
