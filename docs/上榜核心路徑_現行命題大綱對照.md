## 核心路徑刻意未宣稱覆蓋的官方領域

下列領域仍在官方大綱內。它們不是新增的 24 時段，也不要求另行回填；目前由 114 年完整計時演練與 108 年零重疊盲測負責暴露缺口，再依 [59 題錯因修復索引](./上榜錯因修復索引_114-108.md) 處理最早失分位置。

| 科目 | 12 核心章節以外仍須保留警覺的官方領域 |
| --- | --- |
| 電路學 | 直流定理、一階電路、三相電路、頻率響應、拉氏／傅利葉轉換、雙埠網路 |
| 電子學 | BJT／FET、運算放大器、類比放大與回授、數位電路、SCR／IGBT、整流器、變頻器與諧振轉換 |
| 工程數學 | 常／偏微分方程、線性代數、特徵值、保角映射、傅利葉級數、向量分析 |
| 電機機械 | 磁路與能量轉換、變壓器、感應機、特殊電機及電動機控制 |
| 電力系統 | 輸電線模型、故障與保護、經濟調度、負載頻率控制、無效功率與電壓控制 |
| 工業配電 | 負載與設備、電壓降、電動機起動、保護協調、照明與系統設計、功因、閃爍與接地 |

## 使用規則

1. 12 核心章節仍照既定順序完成，不因大綱很廣而回到隨機刷 323 題。
2. 完整年度卷遇到非核心領域時，仍先用 [六科考場得分骨架](./上榜考場得分骨架_六科.md) 留下可得分的定義與起手式。
3. 只修復實際在整卷中暴露的最早失分點，不先擴張成新的大綱整理工程。
4. 官方備註明示命題大綱只是範圍例示，仍可命擬相關綜合題；因此本對照只證明核心章節未過期，不證明未列題型不會出現。
