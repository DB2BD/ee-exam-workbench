# 電機工程技師歷屆試題工作庫

民國 104～114 年電機工程技師考試六科歷屆試題、官方原卷對照、逐題詳解與離線練習工作台。

- 線上版：<https://db2bd.github.io/ee-exam-workbench/>
- 目前版本：**v1.3.5**（2026-10-06），變更內容見 [發版紀錄](./docs/03_發版紀錄/發版紀錄_v1.3.5.md)。

## 1. 概述

本工作庫收錄考選部公布之 104～114 年電機工程技師六科試題（66 份官方試卷、323 題），以及 110～114 年公務人員高考三級電機類同級題 161 題。每題保留：

- 官方試卷 PDF 與題目裁切圖（可追溯到頁碼）；
- 逐題詳解：已知與所求、標準作答、公式推導、數值回代與驗算；
- 驗證狀態與考點分類。

詳解以官方題幹為準，不以參考書答案反推題目；題幹缺條件或資料互相矛盾時，詳解保留條件式解答並標註待覆核，不把推測寫成唯一答案。

### 工作台

工作台是單一靜態網頁，不需要伺服器或帳號，進度只存在使用者自己的瀏覽器（可匯出備份）。

| 分頁 | 功能 |
| :--- | :--- |
| 今天 | 依日程與進度排出當日任務；落後時自動刪減次要任務，模考卷不刪；平日模考可拆成兩天完成 |
| 模考 | 整卷 120 分鐘模考、核對與修復，結果以 100／50／0 計分 |
| 成績 | 六科估計分數與目標線（合計 380 分，及格線 360 分），列出失分最多的章節 |
| 更多 | 題庫瀏覽、考前速查手冊、備份與還原 |

隨機練習提供五種選題方式：依目標分配、各科輪流、補強（模考錯題優先）、全部隨機、只練單科。做題時可依序揭露四段提示（章節 → 起手式 → 公式與陷阱 → 完整推導），作答結果以 ○／△／× 與錯因代碼記錄。

### 預設備考順序

這套順序不等待自評、不要求把分數或錯因回填到專案，也不先猜個人強弱：

1. 照 [逐日開工表](./docs/01_備考計畫/逐日開工表_115年.md) 執行，日期區段與刪減規則見 [倒數節奏](./docs/01_備考計畫/倒數節奏_115年電機技師.md)。
2. 依序完成 [24 個核心時段](./docs/01_備考計畫/預設24時段_核心題路徑.md)，建立高覆蓋章節的母題、同型題與變式題。
3. 以隨機練習「各科輪流」做弱題分析（原六科 12 題混合橋接已退休，[清單](./docs/01_備考計畫/混合橋接_六科12題.md) 僅供查閱）。
4. 完成 [114 年六科計時模考](./docs/01_備考計畫/被動模考_114年六科執行包.md)，每科 120 分鐘採 [5＋90＋17＋8 得分節奏](./docs/02_考場策略/考場120分鐘得分節奏.md)，再做 30 分鐘核對與 30 分鐘修復。
5. 完成 [108 年六科被動複測](./docs/01_備考計畫/被動複測_108年六科執行包.md)，檢查方法能否移轉到未練過的試卷。
6. 失分題查 [59 題錯因修復索引](./docs/02_考場策略/錯因修復索引_114-108.md)；卡在第一步時先看 [起手式急救卡](./docs/02_考場策略/起手式急救卡_114-108.md)。

歷屆覆蓋只決定練習優先順序，不代表未來命中率；公式、單位、方向與結論以題號級 `verified` 詳解為準。

## 4. 資料範圍與驗證

| 資料集 | 規模 | 說明 |
| :--- | :---: | :--- |
| 技師題庫 | 104～114 年、6 科、323 題 | 申論題、官方原卷對照與逐題詳解 |
| 技師題解稽核 | 323 題 | 283 題 `verified`、10 題 `reference_book_verified`、30 題待人工覆核（截至 2026-10-04，依 `data/` 稽核檔） |
| 高考三級同級題 | 110～114 年、161 題 | 101 道申論題、60 道工程數學測驗題；23 份官方試卷已下載、2 份未公布 |

驗證狀態：

- `verified`：依官方題圖與題幹推導，並完成獨立回代或交叉檢核。
- `reference_book_verified`：已與參考書交叉核對，但不等於官方公布答案；來源衝突時詳解保留各分支並說明原因。
- `needs_manual_review`：題幹缺參數、圖形需估讀或官方資料互相矛盾；保留條件式計算，不升級為唯一答案。

驗證報告：[題解稽核](./reports/pe-solution-audit-2026-08-30.md) · [人工覆核索引](./reports/manual-review-index.md)

## 5. 建置與測試

```bash
pip install -r requirements.txt
python3 scripts/build_workbench.py        # 由 src/ 與資料檔建置 index.html
python3 scripts/run_all_tests.py          # 單元測試與 323 支獨立驗算腳本
python3 scripts/check_html_js_syntax.py

npm run check:fast                        # 開發迴圈：建置＋語法＋測試（平行）
npm run check:fast -- -k pacing           # 只跑名稱含 pacing 的測試
npm run check                             # 完整閘門（生成器、建置、測試、語法、連結、圖片）
npm run stage                             # 另外組出 _site（qa:browser 需要）
```

推送到 `main` 後，GitHub Actions 會先建置並跑完整測試，再以 `scripts/stage_pages_artifact.py` 組出發布內容並部署到 GitHub Pages。`dashboard-data.js`、`solutions-bundle.js` 等為生成檔，請修改來源與編譯腳本，不要直接編輯。
