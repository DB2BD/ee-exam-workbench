# 107 年第 3 題｜圓錐閉曲面通量

依官方 crop，(mathbf F=4xz,mathbf i+xyz^2,mathbf j+3y,mathbf k)，閉曲面為 (x^2+y^2=z^2, 0\le z\le2)。散度
[
\nabla\cdot\mathbf F=4z+xz^2.
]
圓錐體積區域可寫成 (0\le z\le2, 0\le r\le z)。由對稱性 (xz^2) 的體積積分為零，因此
[
\iint_S\mathbf F\cdot\mathbf n,dA
=\iiint_V4z,dV
=\int_0^2\int_0^{2\pi}\int_0^z4z,r,dr,d\theta,dz
=\boxed{16\pi}.
]
