# 雲端同步設定

手機與電腦各自做題時，可以用 GitHub 的「秘密 Gist」當雲端，讓兩邊的進度自動合併。不需要再下載 .json 檔來回傳送。

## 一、建立權杖（每台裝置貼一次）

1. 登入 GitHub，開啟 <https://github.com/settings/tokens>。
2. 二選一：
   - **Fine-grained token（建議）**：選 Generate new token，Account permissions 裡把 **Gists** 設為 Read and write，其他一律不開。
   - **Classic token**：選 Generate new token (classic)，只勾選 **gist**，其他權限都不要勾。
3. Expiration（到期日）依自己的習慣設定，建立後複製權杖。權杖只會顯示一次。
4. 在工作台開啟「備份／還原」，找到「雲端同步」，把權杖貼進欄位，按「連線」。
5. 第二台裝置貼**同一個權杖**即可：程式會依固定的描述找到第一台建立的 Gist，不會另外建立。

## 二、之後怎麼運作

- 開啟工作台時，先下載雲端進度並**合併**到本機。
- 存結果卡、完成今日任務、複習評分後，約 30 秒內會把合併後的進度上傳。
- 離線或上傳失敗時，進度留在本機，之後開啟工作台或網路恢復時會自動再試。
- 備份視窗會顯示「上次同步」時間；也可以按「立即同步」。
- 每次合併前，會自動在本機拍一份「同步前」快照，可在「自動快照」還原。
- 「中斷連線」只會刪除這台裝置保存的權杖，雲端那份不會被刪除。

合併規則沿用「合併還原」：結果卡依編號聯集、已完成任務聯集、SM-2 複習取較新一次。模考計時是各裝置自己的狀態，不會被雲端蓋掉。

## 三、隱私與安全

- 秘密 Gist 不會出現在你的 GitHub 個人頁或搜尋結果，但**知道網址的人都能讀取**。同步的內容只有做題進度與作答紀錄，不含權杖。
- **權杖等同密碼**：不要分享、不要貼到聊天或截圖。權杖只存在這台瀏覽器的本機儲存空間，不會寫進備份檔或快照，也不會上傳。
- 公用電腦或不再使用的裝置，請先按「中斷連線」。
- 權杖遺失或外洩時，隨時可到 <https://github.com/settings/tokens> 撤銷，再建立新的重新連線。
- 想徹底刪除雲端那份，到 GitHub 的 Gist 頁面自行刪除即可。
