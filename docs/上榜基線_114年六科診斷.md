# 電機工程技師上榜基線｜114 年六科診斷

> 目的：提供可選的個人診斷與分數留存。它不是開始練習的前置條件；預設請直接使用 [114 年六科被動模考執行包](./上榜被動模考_114年六科執行包.md)，不需回填本頁。

## 為什麼先做 114 年

- 114 年是目前題庫中最新的完整技師年度，六科官方試卷皆已收錄。
- 六科共 29 題；依 `dashboard-data.js` 目前資料，29 題的題解狀態皆為 `verified`。
- 每科以官方完整 120 分鐘作答，能同時暴露知識缺口、書寫得分能力與時間分配問題。

「題解已驗證」只表示現有推導通過專案的題級查核，不等於官方公布閱卷標準。自評分數是個人診斷資料，不宣稱等同正式考試成績。

## 作答規則

每科使用一個獨立時段，不必連續六天完成。

1. 開始前只開官方試卷；關閉完整題解、搜尋、筆記與 AI。
2. 設定 120 分鐘倒數，使用正式考試允許的計算器與書寫工具。
3. 每一題先寫題號與開始時間。卡住超過 8 分鐘時，先寫出已知條件、可用公式及下一步，再移往下一題。
4. 時間到立即停筆，標出空白題、猜測題與未完成步驟；不要先補答案。
5. 保留原始作答，再開完整題解逐題核對；只有想保存數字時才填寫本文件。
6. 每題只記一個「主要失分原因」；若有多個錯誤，選最早讓解題偏離的那一個。

## 保守自評方式

沒有官方逐步配分表時，不硬湊單一精確分數。每一小題記錄兩個界線：

- **確定得分**：只計算你能在答案紙上指出完整證據的部分，例如正確圖形、必要公式、代入、單位與結論。
- **可能得分上限**：再納入方法正確但算術失誤、最後一步未完成，或閱卷者可能給予的部分分。不能說明得分理由的內容不列入。

每科基線以「確定得分～可能得分上限」表示。後續規劃優先採確定得分，避免高估目前程度。

### 單題核對表

每完成一科，複製下表到該科下方；題目數以原卷為準。

| 題號／小題 | 配分 | 完成狀態 | 確定得分 | 可能上限 | 主要失分代碼 | 可補回分數 | 下一個動作 |
| --- | ---: | --- | ---: | ---: | --- | ---: | --- |
|  |  | 完成／部分／空白 |  |  |  |  |  |

主要失分代碼：

- `R`：題型辨識錯誤
- `S`：知道題型，但起手式寫不出來
- `F`：公式、定理或適用條件錯誤
- `C`：計算、代數或數值操作錯誤
- `K`：觀念混淆，無法解釋物理或數學意義
- `U`：單位、正負號、方向、相序或有效位數錯誤
- `T`：時間分配造成未完成

「可補回分數」只填透過針對性練習有把握改善的分數，不把完全陌生、需要長期補課的題目全部算入。

優先級依下列順序判斷：

1. 短期可補回分數高，而且錯因集中在 `S/F/C/U/T`。
2. 歷屆重複出現、可由一題母題帶動多題的章節。
3. 已接近完成但因書寫、單位或時間丟分的題目。
4. 完全陌生且只出現一次的高成本題，暫不自動列為第一優先。

## 若選擇填寫，可得到的輸出

基線完成的證據不是「看完六份詳解」，而是具備以下資料：

- 六科各一份保留原貌的限時作答。
- 六科確定得分與可能得分上限。
- 每科空白配分、主要失分代碼及可補回分數。
- 第一批核心母題候選及其選題理由。
- 下一週可執行的科目與題目順序。

個人化調整可在上述資料齊全後進行，但預設題序不等待這些資料。未回填時，照 [固定上榜路徑](./上榜預設24時段_核心題路徑.md) 完成 24 個核心時段，再依本頁六科順序做 114 年整卷。
