## 三、感應電動機戴維寧等效與轉矩計算（20 分）

### 📌 題目與已知條件
一部三相、4 極、$60\text{ Hz}$、$\text{Y}$ 接感應電動機，額定 $380\text{ V}, 1755\text{ rpm}$。
定子側單相戴維寧等效參數：$V_{TH} = 210\text{ V}, Z_{TH} = (0.2 + j4.0)\ \Omega$，轉子等效阻抗 $Z_R = \left(\frac{0.8}{s} + j4.0 \right)\ \Omega$。

* **(一)** 計算轉差率 $s = 5\%$ 時之轉子轉速 $n$ 與感應轉矩 $T_{ind}$。（10 分）
* **(二)** 計算產生最大轉矩時之轉差率 $s_{max}$ 與最大電磁轉矩 $T_{max}$。（10 分）

---

### ✏️ 步驟式詳細數學推導
1. **$s = 0.05$ 時之轉速與轉矩**：
   $$n_s = \frac{120 \times 60}{4} = 1800\text{ rpm} \implies \mathbf{n} = (1 - 0.05) \times 1800  = \mathbf{1710\text{ rpm}}$$
   $$\omega_s = \frac{2\pi \times 1800}{60} = 188.50\text{ rad/s}$$
   轉子支路電阻：$\frac{R_2'}{s} = \frac{0.8}{0.05} = 16.0\ \Omega$。
   總迴路阻抗：$Z_{tot} = (0.2 + 16.0) + j(4.0 + 4.0) = 16.2 + j8.0\ \Omega \implies |Z_{tot}| = \sqrt{16.2^2 + 8.0^2} = 18.068\ \Omega$。
轉子電流：$I_2' = \frac{V_{TH}}{|Z_{tot}|} = \frac{210}{18.068} = 11.623\text{ A}$。
   $$\mathbf{T_{ind} = \frac{3 (I_2')^2 (R_2'/s)}{\omega_s} = \frac{3 \times (11.623)^2 \times 16.0}{188.50} = \frac{6484.5}{188.50} = \mathbf{34.40\text{ N}\cdot\text{m}}}$$
2. **最大轉矩特性**：
   $$\mathbf{s_{max} = \frac{R_2'}{\sqrt{R_{TH}^2 + (X_{TH} + X_2')^2}} = \frac{0.8}{\sqrt{0.2^2 + (4.0 + 4.0)^2}} = \frac{0.8}{\sqrt{0.04 + 64}} = \frac{0.8}{8.0025} \approx \mathbf{0.100\ (10.0\%)}}$$
   $$\mathbf{T_{max} = \frac{3 V_{TH}^2}{2\omega_s [R_{TH} + \sqrt{R_{TH}^2 + (X_{TH} + X_2')^2}]} = \frac{3 \times 210^2}{2 \times 188.50 \times (0.2 + 8.0025)} = \frac{132300}{377 \times 8.2025} = \mathbf{42.78\text{ N}\cdot\text{m}}}$$

---

### 🎯 第三題 滿分關鍵與結論
- **$s=5\%$ 轉速與轉矩**：$n = \mathbf{1710\text{ rpm}}, T_{ind} = \mathbf{34.40\text{ N}\cdot\text{m}}$
- **最大轉矩與轉差**：$s_{max} = \mathbf{10.0\%}, T_{max} = \mathbf{42.78\text{ N}\cdot\text{m}}$
