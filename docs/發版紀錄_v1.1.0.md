# 發版紀錄 v1.1.0

日期：2026-10-04

## 本版內容

本版收錄 `v1.0.7` 之後的全部提交：PE 323 題題目裁切與題幹全面校正、題解全面改寫為精簡且可重算的 `lean-v1` 版型，以及考前 6 週的考生端功能精簡與增補。

### 題目與題幹

- 323 張官方題目裁切圖重產：遮除試卷表頭、頁尾與「請接背面」，邊界對齊題間空白；兩輪視覺稽核全數通過。
- 323 題題幹逐題對照官方裁切圖修正（85 題 major、170 題 minor）；移除編譯器中的手寫題幹覆寫。

### 題解精確化（Wave 1～4）

- 323 份 canonical 題解全數改為 `lean-v1` 四段式：已知與所求／考場標準作答／驗算／失分點，必要時加「條件與疑義」。
- 每題新增獨立驗算腳本 `verification/pe/<QID>.py`（共 323 支），由題目已知量從第一原理重算並 `assert` 每個框選答案。
- 流程：Worker 盲解與改寫 → 不同子 agent 盲審 → 主 session 閘門；答案更正逐批經使用者同意。
- 答案更正 56 題（各波報告 `reports/題解精確化_wave-*.md`）；工作台以 ⚠ 標示並列出「答案已更正、而你做過的題」。
- 題幹條件不足或有歧義者改列 `needs_manual_review`，並列各讀法答案；條件題安全作答卡 30 張。

### 考生端

- 「一鍵開始今天」：依 52 天逐日開工表顯示下一個任務；閉卷階段只顯示題目與倒數計時，停筆後才出現核對入口；可設定紙本已完成的進度。
- 首頁只保留「今天的任務」與「到期複習」兩個主要入口，其餘練習方式收合；人工覆核標注移出考生介面。
- 移除無實證依據的上榜預測（PPI）。
- 奪榜本與 120 分鐘模考計時器的配速統一為官方節奏文件的 5＋90＋17＋8 分鐘。
- 新增六科失分點速查卡（`docs/上榜失分點速查卡_六科.md`，奪榜本第伍節可列印），每條附題號並經逐條對照題解審查。
- README 入口精簡為 3 列，其餘移至附錄；路徑文件改為 `lean-v1` 敘述。
- 修正四段蓋牌揭露按鈕全部無法點選：數值盲測區的按鈕被算入揭露順序，導致 ① 被視為第 2 段而停用；改為只計算四個揭露按鈕，並補回歸測試。

### 其他（`v1.0.7` 後、本分支前已在 `main` 的提交）

- 問題驅動 Obsidian 知識圖譜整合、被動備考路徑、題解稽核與同步、GK 來源索引強化、Pages 建置依賴。
