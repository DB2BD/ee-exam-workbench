# 108 年第 1 題｜電容式比壓器比壓式

## 官方題目（逐題裁切）

電容式比壓器用於高壓系統的電壓偵測，圖一為其等效電路，試推導比壓式。

官方題圖保留於 \`source_crop\`；圖中上端施加 \(V_1\)，下端接地，\(C_1\) 與 \(C_2\) 為串接的電容分壓器，中點經補償電抗器 \(L\) 串接負載 \(Z_B\) 接地，輸出 \(V_2\) 跨在 \(Z_B\) 兩端。

## 節點與阻抗定義

令 \(V_a\) 為 \(C_1,C_2,L\) 的共接點，\(V_2\) 為負載上端電壓。定義
\[
Z_1=\frac{1}{sC_1},\qquad
Z_2=\frac{1}{sC_2},\qquad
Z_L=sL.
\]
由官方拓樸，從 \(V_a\) 到地有兩個並聯支路：
\[
Z_2,\qquad Z_L+Z_B.
\]
因此
\[
Z_p=Z_2\parallel(Z_L+Z_B)
=\frac{Z_2(Z_L+Z_B)}{Z_2+Z_L+Z_B}.
\]

## 比壓式推導

中點電壓是 \(Z_1\) 與 \(Z_p\) 的分壓：
\[
V_a=V_1\frac{Z_p}{Z_1+Z_p}.
\]
負載 \(Z_B\) 是 \(Z_L+Z_B\) 支路的一部分，故
\[
V_2=V_a\frac{Z_B}{Z_L+Z_B}.
\]
合併並約去 \(Z_L+Z_B\)：
\[
\boxed{
\frac{V_2}{V_1}
=\frac{Z_2Z_B}
{Z_1Z_2+(Z_1+Z_2)(Z_L+Z_B)}
}.
\]

代入 \(Z_1,Z_2,Z_L\) 並乘上 \(s^2C_1C_2\)，得到直接以元件值表示的比壓式：
\[
\boxed{
\frac{V_2(s)}{V_1(s)}
=\frac{sC_1Z_B}
{1+s(C_1+C_2)Z_B+s^2L(C_1+C_2)}
}.
\]

若負載是電阻 \(Z_B=R_B\)，則
\[
\boxed{
H(s)=\frac{V_2}{V_1}
=\frac{sC_1R_B}
{1+s(C_1+C_2)R_B+s^2L(C_1+C_2)}
}.
\]

對工頻相量 \(s=j\omega\)：
\[
\boxed{
\frac{\widetilde V_2}{\widetilde V_1}
=\frac{j\omega C_1Z_B}
{1+j\omega(C_1+C_2)Z_B-\omega^2L(C_1+C_2)}
}.
\]
若 \(Z_B=R_B\)，此式同時保留負載造成的幅值與相角誤差。

## 無負載與補償條件檢查

在負載趨近開路 \(Z_B\to\infty\) 且補償電抗支路電流趨近零時，
\[
\lim_{Z_B\to\infty}\frac{V_2}{V_1}
=\frac{C_1}{C_1+C_2},
\]
這正是理想電容串聯分壓比。

由分母的二階項，若以理想電壓源固定輸入、並希望補償電抗器與中點看到的等效電容產生工頻諧振，對本官方等效圖的節點模型其無負載近似諧振條件為
\[
\boxed{
\omega_0^2L(C_1+C_2)=1
}
\qquad\Longleftrightarrow\qquad
\boxed{
L=\frac{1}{\omega_0^2(C_1+C_2)}
}.
\]
實際有負載時 \(Z_B\) 仍出現在分母的一階項，會造成阻尼、幅值誤差與相角誤差；因此不能在有負載時直接把輸出比壓寫成只含 \(C_1/(C_1+C_2)\) 的常數。

## 節點方程回代

以節點分析直接驗證：
\[
\frac{V_a-V_1}{Z_1}+\frac{V_a}{Z_2}
+\frac{V_a}{Z_L+Z_B}=0,
\]
\[
V_2=V_a\frac{Z_B}{Z_L+Z_B}.
\]
第一式解得
\[
V_a=V_1\frac{Z_2(Z_L+Z_B)}
{Z_1Z_2+(Z_1+Z_2)(Z_L+Z_B)},
\]
再代入第二式即回到上方 \(V_2/V_1\)，故拓樸、端點定義與比壓式一致。

## 審查備註

年度解答只寫出無負載電容分壓
\[
\frac{C_1}{C_1+C_2}
\]
並額外引入官方裁切圖未出現的中間變壓器匝數比 \(N_2/N_1\)，未處理圖中補償電抗器 \(L\) 與負載 \(Z_B\)。本稿依官方單題裁切圖保留 \(L,Z_B\)，推導出含負載的完整比壓函數；其 \(Z_B\to\infty\) 極限才退化為單純電容分壓，並以節點方程回代確認，故標記為 \`verified\`。
