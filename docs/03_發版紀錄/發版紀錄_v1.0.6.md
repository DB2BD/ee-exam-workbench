# 發版紀錄 v1.0.6

日期：2026-09-11

## 本版內容

本版依照既有 `v1.0.x` 公開里程碑規則，收錄 `v1.0.5` 後的第二階段使用者優化、每日練習流程與可靠性修正。

### 每日練習與蓋牌提取

- 完成四段蓋牌提取流程：章節、起手式、公式／陷阱、完整推導依序揭露，並保留自評與完成紀錄邏輯。
- 每日練習改為依考科範圍建立多樣化題目組合，降低近期完成題與同型題連續重複的機率。
- 修正完成本題、進入下一題、結束本輪與詳解瀏覽之間的狀態轉移，避免只開啟詳解而無法前進。
- 將唯一的「開始四段蓋牌」入口移至「結束本輪」旁的頁首操作區，原題與詳解內容不再重複顯示蓋牌按鈕。
- 窄版畫面可正確進入蓋牌揭露視窗，並保留每題的揭露進度與閱讀位置。

### 使用者介面與維護資訊

- 隱藏不屬於考生操作流程的維護稽核欄位與內部回報細節。
- 保留原題、詳解、完整詳解與蓋牌練習的清楚分流，降低誤觸與重複入口。
- 修正每日練習標題、題數與完成狀態顯示，使目前題次與可用操作一致。

### 公式、圖片與閱讀可靠性

- 補強題目、詳解與人工覆核裁切圖的載入失敗替代提示。
- 統一詳解標題、段落、清單、表格與 KaTeX 公式的閱讀尺寸與行距。
- 補齊 KaTeX 字型資產，避免部分公式字型請求產生 404。
- 保留參考書校驗、官方來源與人工覆核的資料邊界，不將工作庫校驗狀態誤稱為官方公布答案。

## 驗證結果

- 完整測試：309 項通過。
- HTML／JavaScript 語法檢查：通過。
- PE 321 題與 GK 161 題切片、PDF 連結及題級來源檢查：482/482 通過。
- PE／GK 圖片資產稽核：缺失目標 0、錯誤引用 0。
- GitHub Pages staging：1,085 個檔案、約 190.7 MiB。
- 瀏覽器實測：頁首蓋牌入口可開啟四段揭露視窗，完成本題後可正常進入下一題。

## 版次依據

過往 `v1.0.0`～`v1.0.5` 均以公開功能、資料或文件里程碑遞增一個 `v1.0.x` 版次。本版延續該專案既有慣例，將 `v1.0.5` 後已完成並部署的累積更新標記為 `v1.0.6`；實際建置仍以 GitHub Actions 的部署 commit SHA 為執行識別。
