# 114 年電路學逐題詳解

## 一、某電路如圖一所示

### 題目辨識

本題原始題目與電路圖以 [官方原題裁切](../../../依考科分類/🏛️_國考同級參考題庫/01_電路學/images/questions/GK_114年_電路學_Q01.png) 及 [電路圖裁切](../../../依考科分類/🏛️_國考同級參考題庫/01_電路學/images/figures/GK_114年_電路學_Q01_figure-01.png) 為準。以下電流正方向完全依圖示箭頭，電壓正負完全依圖示極性。

### 建立節點方程式

以下方形底線為參考地。左側電壓源上端節點為 `12 V`；中央節點記為 `V_A`，右側節點記為 `V_B`。

依圖示定義：

* `i₂`：經 40 Ω 由左向右。
* `i₄`：經 80 Ω 由上向下。
* `i₅`：經 48 Ω 由右向左。
* `i₆`：經 32 Ω 由下向上。

中央節點套用 KCL：

```text
(V_A - 12)/40 + V_A/80 + (V_A - V_B)/48 + 0.5 = 0
```

右側節點套用 KCL：

```text
(V_B - V_A)/48 + V_B/32 = 0
```

化簡後：

```text
14 V_A - 5 V_B = -48
-2 V_A + 5 V_B = 0
```

解得：

```text
V_A = -4 V
V_B = -1.6 V
```

### 各電阻電壓與電流

依圖示極性與箭頭直接代回：

| 元件 | 電壓 | 電流 | 說明 |
| --- | ---: | ---: | --- |
| 40 Ω | `v₂ = 12 - V_A = 16 V` | `i₂ = (12 - V_A)/40 = 0.4 A` | 方向與箭頭相同 |
| 80 Ω | `v₄ = V_A = -4 V` | `i₄ = V_A/80 = -0.05 A` | 實際電流為向上 50 mA |
| 48 Ω | `v₅ = V_B - V_A = 2.4 V` | `i₅ = (V_B - V_A)/48 = 0.05 A` | 方向與箭頭相同 |
| 32 Ω | `v₆ = 0 - V_B = 1.6 V` | `i₆ = (0 - V_B)/32 = 0.05 A` | 方向與箭頭相同 |

因此答案為：

```text
v₂ = 16 V,  i₂ = 0.4 A
v₄ = -4 V, i₄ = -0.05 A  （實際向上 50 mA）
v₅ = 2.4 V, i₅ = 0.05 A
v₆ = 1.6 V, i₆ = 0.05 A
```

### 獨立驗算

1. 中央節點電流：流出中央節點的 40 Ω 支路為 `(-4-12)/40=-0.4 A`、80 Ω 支路為 `-0.05 A`、48 Ω 支路為 `(-4+1.6)/48=-0.05 A`，再加電流源 `0.5 A`，總和為 `0`。
2. 右側節點：由 B 流向 A 為 `0.05 A`，由 B 經 32 Ω 向地為 `-0.05 A`，總和為 `0`。
3. 電阻耗散功率為 `6.40 + 0.20 + 0.12 + 0.08 = 6.80 W`；電壓源與電流源供應的代數功率合計為 `-4.80 + (-2.00) = -6.80 W`，功率平衡成立。

### 常見失分點

* `i₄` 算出負值不是方程式錯誤，而是代表實際方向與圖示箭頭相反。
* `v₅` 的正端在右側，不能直接寫成 `V_A - V_B`。
* `i₆` 的箭頭向上，不能誤套用由上往下的 `V_B/32`；依箭頭應為 `(0-V_B)/32`。

## 二、電感－電阻－開關電路

### 題目辨識與開關狀態

本題原始題目與電路圖以 [官方原題裁切](../../../依考科分類/🏛️_國考同級參考題庫/01_電路學/images/questions/GK_114年_電路學_Q02.png) 及 [電路圖裁切](../../../依考科分類/🏛️_國考同級參考題庫/01_電路學/images/figures/GK_114年_電路學_Q02_figure-01.png) 為準。依圖示切換時序：`t<0` 時 10 A 電流源已接入；`t=0` 時電流源支路切離，電感保留與中間 2 Ω 電阻形成放電回路；`t=1 ms` 時右側 2 Ω 支路接入。

### （一）初始電流

`t<0` 已達直流穩態，電感視為短路，因此並聯在電感兩端的中間 2 Ω 電阻電壓為零、電阻電流為零。10 A 電流全部流經電感：

```text
i(0-) = 10 A
i(0+) = i(0-) = 10 A
```

電感電流不能瞬間改變，所以答案為 `i(0)=10 A`，方向依圖示向下。

### （二）`0<t≤1 ms`

`t=0` 後電流源切離，電感看到的等效電阻為中間的 2 Ω：

```text
Rth,1 = 2 Ω
τ₁ = L/Rth,1 = 2 mH / 2 Ω = 1 ms
i(∞)=0
```

因此：

```text
i(t) = 10 e^(-t/1ms) A,  0<t≤1ms
```

在切換瞬間前後的電流為：

```text
i(1ms-) = 10e^(-1) = 3.68 A
```

### （三）`t>1 ms`

右側 2 Ω 支路接入後，電感看到兩個 2 Ω 並聯：

```text
Rth,2 = 2 Ω || 2 Ω = 1 Ω
τ₂ = L/Rth,2 = 2 mH / 1 Ω = 2 ms
```

電感電流連續，所以 `i(1ms+)=i(1ms-)=3.68 A`。新的終值仍為零，故：

```text
i(t) = 3.68 e^(-(t-1ms)/2ms) A,  t>1ms
```

### （四）完整響應圖的關鍵點

```text
t=0       : i=10 A
t=1 ms    : i=3.68 A，無跳變
t→∞       : i→0 A
```

曲線先以 `τ₁=1 ms` 較快下降，`t=1 ms` 接入另一個 2 Ω 支路後，改以 `τ₂=2 ms` 較慢下降；電流與斜率可在切換點連接，但斜率會改變。

### 獨立驗算

對每一段使用電感自然響應 `L di/dt + Rth i=0`：第一段 `2mH·di/dt+2i=0`，得到 `τ₁=1ms`；第二段 `2mH·di/dt+1i=0`，得到 `τ₂=2ms`。兩段均符合電感電流連續條件與初始／最終值，且 `e^-1≈0.368` 與題目提示一致。

## 三、一理想變壓器電路圖如圖三所示

### 題目辨識

本題原始題目與電路圖以 [官方原題裁切](../../../依考科分類/🏛️_國考同級參考題庫/01_電路學/images/questions/GK_114年_電路學_Q03.png) 及 [電路圖裁切](../../../依考科分類/🏛️_國考同級參考題庫/01_電路學/images/figures/GK_114年_電路學_Q03_figure-01.png) 為準。圖中一次側繞組上端為點端，二次側繞組下端為點端；`V₁`、`V₂` 的正端則都在上方。

### 變壓器關係與負載電流

匝數比為 `N₁:N₂=1:2`。因為二次側的點端在下方，而 `V₂` 的正端在上方，所以：

```text
V₂ = -2 V₁
```

輸出端直接跨接 24 Ω 負載，因此：

```text
V₂ = V₀ = 48∠30° V
I₂ = V₀ / 24 = 2∠30° A
```

`I₂` 由繞組上端流出，等效為由二次側點端流入。以點端電流套用理想變壓器功率關係：

```text
V₁ I₁ + (2V₁) I₂ = 0
I₁ = -2 I₂ = 4∠(-150°) A
```

並且：

```text
V₁ = -V₂/2 = 24∠(-150°) V
```

### 一次側 KVL

一次側串聯阻抗為：

```text
Zs = 6 - j6 Ω
```

由左迴路電壓定律：

```text
VＳ = V₁ + Zs I₁
    = 24∠(-150°) + (6-j6)(4∠(-150°))
    = -53.569 - j3.215 V
```

換成極座標：

```text
VＳ = 53.67∠(-176.57°) V
```

### 獨立驗算

將 24 Ω 負載反映至一次側：

```text
ZL' = (N₁/N₂)² × 24 = (1/2)² × 24 = 6 Ω
```

因此一次側看到的負載電阻為 6 Ω，與一次側電阻串聯後可用 `I₁=V₁/6=4∠(-150°) A` 驗證。再加上 `-j6 Ω` 電抗的壓降，即得到上式的 `VＳ`；匝數比、點標記、KVL 三者一致。

## 四、OPA 非反相放大器

### 題目辨識

本題原始題目與電路圖以 [官方原題裁切](../../../依考科分類/🏛️_國考同級參考題庫/01_電路學/images/questions/GK_114年_電路學_Q04.png) 及 [電路圖裁切](../../../依考科分類/🏛️_國考同級參考題庫/01_電路學/images/figures/GK_114年_電路學_Q04_figure-01.png) 為準。假設 OPA 在線性負回授區工作，輸入端電流為零，且 `v₊=v₋`。

### 增益與電阻限制

因 `v₊=v₋=vＳ=1 V`，非反相放大器增益為：

```text
A = vₒ/vＳ = 1 + R₂/R₁
```

又 `R₁+R₂=10 kΩ`，代入 `R₂=10 kΩ-R₁`：

```text
A = 1 + (10 kΩ-R₁)/R₁ = 10 kΩ/R₁
```

輸出端電流 `iₒ` 同時供應負載電阻與回授電阻：

```text
iₒ = vₒ/RL + (vₒ-v₋)/R₂
```

令 `vₒ=A vＳ=A V`，並使用 `R₁=10 kΩ/A`、`R₂=10 kΩ(1-1/A)`，可化為：

```text
iₒ = A/50 + (A-1)/(10000(1-1/A))
    = A/50 + A/10000
    = 0.0201 A
```

輸出電流上限為 200 mA，所以：

```text
0.0201 A ≤ 0.2
A ≤ 9.950248756
```

此時輸出電壓約 `9.95 V`，小於 OPA 的正電源 `+15 V`，故真正的限制是輸出電流，而非電壓飽和。

### 最佳電阻與最大增益

取電流上限恰好成立：

```text
Amax = 2000/201 ≈ 9.95025
R₁ = 10 kΩ/Amax ≈ 1.005 kΩ
R₂ = 10 kΩ-R₁ ≈ 8.995 kΩ
```

工程上可選：

```text
R₁ ≈ 1.005 kΩ，R₂ ≈ 8.995 kΩ，Amax ≈ 9.95
```

### 獨立驗算

```text
vₒ = 9.95025 V
iL = vₒ/50 = 0.199005 A
iR₂ = (vₒ-1)/8995 ≈ 0.000995 A
iₒ = iL+iR₂ ≈ 0.200000 A
```

而 `vₒ=9.95 V<15 V`，所以線性工作條件與 200 mA 輸出上限同時成立。
