# ADR-0003: 5 大維度客觀科學難度評級體系 (5-Dimensional Scientific Difficulty Model)

* **狀態**：`已接受 (Accepted)`
* **日期**：2026-08-24
* **決策者**：系統架構團隊
* **範圍**：考題元資料評分與儀表板難度過濾器

---

## 1. 背景與脈絡 (Context)

原先題目的星級難度僅透過簡單的幾個關鍵字增減（+1 / -1），導致全站 90% 以上題目皆被判定為 3★，缺乏客觀科學鑑別度，考生無法精準進行分層刷題（例如新手想從 1★ 基礎題入門，榜首考生想專攻 4★~5★ 壓軸鑑別題）。

---

## 2. 決策方案 (Decision)

建立量化之 **5 大客觀維度加權評級模型（Multi-Dimensional Objective Evaluation Engine）**：
1. **數學與計算複雜度（Math Complexity，權重 25\%）**：區分代數、相量、二階微積分、留數定理、SVD/PDE。
2. **物理與概念抽象度（Conceptual Depth，權重 25\%）**：區分直流電阻、三相/差動、對稱分量/雙反應、PSS/FACTS/IEEE 80。
3. **多小題相依鏈（Derivation Dependency，權重 20\%）**：評估子題數量與前後小題相依深度。
4. **邊界條件與陷阱度（Boundary Constraints，權重 15\%）**：評估非零儲能、雙開關、飽和極限、相依源等陷阱。
5. **分值與時間壓力權重（Exam Score Weight，權重 15\%）**：依據題目的分值（10分、20分、30分）計算考場壓力感知。

$$\text{RawScore} = 0.25 S_M + 0.25 S_C + 0.20 S_D + 0.15 S_B + 0.15 S_W$$
- **1★ (入門基礎)**：$\text{RawScore} < 1.75$
- **2★ (常規核心)**：$1.75 \le \text{RawScore} < 2.20$
- **3★ (中等進階)**：$2.20 \le \text{RawScore} < 2.80$
- **4★ (高難挑戰)**：$2.80 \le \text{RawScore} < 3.30$
- **5★ (地獄壓軸)**：$\text{RawScore} \ge 3.30$

---

## 3. 影響與結果 (Consequences)

### 正面效益：
- 模型可套用於目前 PE 321 題與 GK 161 筆資料；實際分布以生成資料與儀表板當下的難度欄位為準，不在 ADR 中硬編一組會過期的百分比。
- 考生可在儀表板首頁依難度進行精確的靶向複習。
