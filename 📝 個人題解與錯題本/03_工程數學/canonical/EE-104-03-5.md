# 104 年第 5 題｜直線段線積分

以 (r(u)=(1-3u,1,1+2u)), (0le ule1) 參數化，故 (dx=-3du,dy=0,dz=2du)。代入
[
I=\int_C xyz\,dx-(\cos y)\,dy+xz\,dz
]
得
[
I=\int_0^1[-3(1-3u)(1+2u)+2(1-3u)(1+2u)],du
= -\int_0^1(1-3u)(1+2u),du=-\frac52.
]

[
\boxed{I=-\frac52}.
]
這裡依官方 crop 採用 (xyz,dx-(\cos y)dy+xz,dz)，與舊 dashboard 的文字不同。
