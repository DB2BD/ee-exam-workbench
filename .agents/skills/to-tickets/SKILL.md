# To Tickets Skill (by Matt Pocock)

Breaks down larger specs into sequential, atomic, and testable **Tracer-Bullet Tickets**.

## 🎯 Ticket Principles

1. **Single Context Sized**: Each ticket must be implementable and verifiable within a single conversation turn/window.
2. **Explicit Verification Steps**: Every ticket must list exact commands or test cases to verify completion.
3. **Strict Dependency Graph**: Clearly specify which tickets block or depend on other tickets.
