## 二、含相依源電路之戴維寧等效電阻求解（20 分）

### 📌 題目與已知條件
![[105年_電機工程技師_電路學_p1.png|750]]
*圖：105年電路學第二題 含流控電壓源戴維寧電阻分析（圖 2）*

> **題目陳述**：
> 「圖 2 中，試求 $A-B$ 端看進去的戴維寧等效電阻（Thevenin's resistance）$R_{th}$。（20 分）」

---

### 💡 核心考點與破題關鍵
1. **外加測試電源法（Test Source Method）**：
   - 因電路內部含相依電壓源 $2000 I_x$，且無獨立電源，必須在 $A-B$ 端外加測試電壓 $V_t$（或測試電流 $I_t$）。
   - 戴維寧等效電阻定義： $\mathbf{R_{th} = \frac{V_t}{I_t}}$。
2. **控制電流 $I_x$ 與中間節點電位關係**：
   - 設 $B$ 端為參考地（$0\text{ V}$），中間 $1\text{ k}\Omega$ 頂部電位為 $V_x$。
   - 控制電流向下： $I_x = \frac{V_x}{1\text{ k}\Omega} = \frac{V_x}{1000}$。
   - 左側相依電壓源電位： $2000 I_x = 2000 \left(\frac{V_x}{1000}\right) = \mathbf{2 V_x}$。

---

### ✏️ 步驟式詳細數學推導

```
                    ( 2kΩ )            ( 3kΩ )
           ┌─────────[ 2kΩ ]──────────────┬─────────[ 3kΩ ]─────────┐【 端點 A (電位 Vt) 】
           │                              │                         │
     ( + 2000Ix - )                    ( 1kΩ )                   ( 2kΩ )  (外加測試電源)
           │                              │ (↓ Ix)                  │      ( It 流入 )
           └──────────────────────────────┴─────────────────────────┴─────────┘
                                   【 端點 B (接地 0 V) 】
```

#### 步驟 1：對中間節點 $V_x$ 列寫 KCL
流出節點 $V_x$ 之電流總和為 0：
$$
\frac{V_x - 2V_x}{2\text{ k}\Omega} + \frac{V_x}{1\text{ k}\Omega} + \frac{V_x - V_t}{3\text{ k}\Omega} = 0
$$
同乘以 $6\text{ k}\Omega$：
$$
3(V_x - 2V_x) + 6V_x + 2(V_x - V_t) = 0
$$
$$
-3V_x + 6V_x + 2V_x - 2V_t = 0 \implies 5V_x - 2V_t = 0 \implies \mathbf{V_x = \frac{2}{5} V_t = 0.4 V_t}
$$

#### 步驟 2：對端點 $A$ 列寫 KCL 求測試電流 $I_t$
外加測試電流 $I_t$ 流入端點 $A$，分流進入 $3\text{ k}\Omega$ 與 $2\text{ k}\Omega$：
$$
I_t = \frac{V_t - V_x}{3\text{ k}\Omega} + \frac{V_t}{2\text{ k}\Omega}
$$
代入 $V_x = 0.4 V_t$：
$$
I_t = \frac{V_t - 0.4 V_t}{3000} + \frac{V_t}{2000} = \frac{0.6 V_t}{3000} + \frac{V_t}{2000} = \frac{V_t}{5000} + \frac{V_t}{2000}
$$
通分（公分母 10000）：
$$
I_t = \frac{2V_t + 5V_t}{10000} = \frac{7 V_t}{10000}
$$

#### 步驟 3：求戴維寧等效電阻 $R_{th}$
$$
\mathbf{R_{th} = \frac{V_t}{I_t} = \frac{10000}{7}\ \Omega \approx \mathbf{1428.57\ \Omega = 1.4286\text{ k}\Omega}}
$$

---

### 🎯 第二題 滿分關鍵與結論
* **戴維寧等效電阻**： $\mathbf{R_{th} = \frac{10000}{7}\ \Omega \approx 1.429\text{ k}\Omega}$
