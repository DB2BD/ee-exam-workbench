# 👶 ELI5 Skill (Explain Like I'm 5) — Claude Community Standard

Transforms opaque, math-heavy, or abstract engineering topics into **crystal-clear, intuitively intuitive mental models**.

---

## 🎯 Core Pedagogy Principles

1. **The Vivid Anchor Metaphor (核心形象錨點)**:
   - Start immediately with a physical, everyday real-world analogy (e.g. water pipes for power systems, traffic lanes for transmission, rubber bands for stability, prisms for Fourier/Symmetrical components).
2. **De-Jargonize First, Re-Introduce Precisely (先白話後精確)**:
   - Explain the *why* and *what happens* before bringing in formulas or formal Greek letters.
   - Once the intuition clicks, connect the analogy directly to the standard mathematical notation ($Z_{th}, I_f, X_d'', \delta$).
3. **Progressive Complexity Ladder (階梯式認知拆解)**:
   - Level 1: What is the fundamental problem?
   - Level 2: The intuitive mechanism (The "Aha!" moment).
   - Level 3: How engineers solve it in practice.
   - Level 4: 30-Second Exam Cheat Sheet / Formula Memory Hook.
4. **Visual ASCII / Markdown Diagrams (結構化圖解)**:
   - Always include clean ASCII flowcharts, state transitions, or sequence block diagrams.
5. **No Hand-Waving (通俗但不失嚴謹)**:
   - An ELI5 must remain mathematically and physically accurate. Never teach an oversimplification that leads to wrong answers in exam calculations.

## 📋 Response Blueprint

```markdown
### 💡 核心直覺與生活比喻 (The Anchor Metaphor)
[以最貼近生活的事物做比喻]

### 🔍 深度原理拆解 (The Mechanism)
1. 為什麼會這樣？
2. 系統如何反應？
3. 關鍵轉折點在哪裡？

### 📊 視覺化流程 / 方塊圖 (Visual Flow)
[清晰 ASCII 或 Markdown 方塊對照圖]

### 🎯 考點對照與秒殺口訣 (Takeaways & Mnemonics)
- 概念 1 ➔ 考場代碼/公式
- 概念 2 ➔ 破題口訣
```
