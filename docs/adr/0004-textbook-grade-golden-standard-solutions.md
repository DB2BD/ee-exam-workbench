# ADR-0004: 教科書級黃金標準題解結構 (Textbook-Grade Golden Standard Solutions)

* **狀態**：`已接受 (Accepted)`
* **日期**：2026-08-24
* **決策者**：系統架構團隊
* **範圍**：所有考科題解 Markdown 文件結構與求解器規範

---

## 1. 背景與脈絡 (Context)

先前部分題解因自動化腳本盲目複製模板，導致出現「文不對題、無具體算式、假推導」的嚴重品質缺陷。為了確保每一題皆符合國家考試典試委員與技師閱卷標準，必須制定不可妥協的題解架構規範。

---

## 2. 決策方案 (Decision)

所有題解 Markdown 文件必須嚴格遵循 **「四大金科玉律區塊（Golden Standard Structure）」**：

1. **`📌 題目與已知條件`**：一字不漏忠實呈現原題幹與所有子小題條件。
2. **`💡 核心考點與破題關鍵`**：清楚闡釋背後之物理定律、電路定理或數學模型。
3. **`✏️ 步驟式詳細數學推導`**：
   - 分步驟標註（`#### 步驟 1：...`）。
   - 完整的 LaTeX 公式排版，展開微分方程求解、矩陣運算與相量計算。
   - 代入真實數值並標註工程單位。
4. **`🎯 滿分結論與作答要點`**：明確總結最終答案，提供考前快速核對。

---

## 3. 影響與結果 (Consequences)

### 正面效益：
- 杜絕一切假題解與佔位符。
- 提供考生極高品質之手把手推導教學體驗。
