# 電機工程技師上榜｜114／108 年錯因修復索引

> 這是一份被動、免回填的重做索引。範圍固定為 114 年六科 29 題與 108 年六科 30 題，共 59 題；不需要把分數、錯因或日期輸入專案。

59 題的 canonical 與十二份年度彙整頁目前都已具備並同步五個得分型區塊；開啟任一入口都會看到相同的作答、得分點、推導、驗算與失分提醒。

## 使用方式

先依既有的 114 年模考／108 年複測執行包完成閉卷作答，再從下表開啟該題的 canonical 完整題解。每題的「核心動作」是依 canonical 題解與已核准 taxonomy 章節所做的固定起手式，不是對個人弱點的猜測；若答案紙已找出更早的實際失分位置，直接套用該位置的 `R／S／F／C／K／U／T` 規則即可。

若題目標為 `S` 或 `T`，先開 [15 題起手式急救卡](./上榜起手式急救卡_114-108.md)，只揭露第一個可得分動作；停筆後才開完整題解，避免為了找第一式而提前看到整題答案。

特別注意 114 年電子學第 3 題：先照官方控制波形辨認前半週開路、後半週短路；題面未給零初始電流，若要求數值波形須先明示周期穩態條件。這是該題的公式適用條件，不應照舊解把時序反過來。

章節／題型欄優先採 canonical frontmatter 的 `chapter`；canonical 未提供章節時，採 `data/knowledge/question-links.json` 的 approved taxonomy node 對應 `data/taxonomy/alias-map.json` 顯示名稱。沒有另造題型。

## 固定 R／S／F／C／K／U／T 修復規則

| 代碼 | 最早偏離位置 | 固定修復動作 |
| --- | --- | --- |
| `R` | 題型辨識錯 | 重讀題幹，只寫已知、所求、限制條件與應用章節，再閉卷重開題。 |
| `S` | 起手式寫不出 | 只看題解第一個關鍵式，立即關閉題解，自己補完後續。 |
| `F` | 公式或適用條件錯 | 先寫公式成立條件，再代入本題數值；不直接背最後答案。 |
| `C` | 代數或數值計算錯 | 從第一個錯誤等號重算，最後用另一種代入、回代或量級檢查。 |

| `U` | 單位、正負、方向或相序錯 | 在重寫答案的每個最終量旁補單位、參考方向與正負號意義。 |
