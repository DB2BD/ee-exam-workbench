# 弱章專攻｜13 輪（FOCUS-01～13）

> 學習者自評最弱的四科：電力系統、工業配電、電子學、工程數學。`FOCUS-01`–`FOCUS-13` 取代已退休的 `WEAK-01`–`WEAK-11` 隨機練習配額，改成每輪固定兩題、同章對照的專攻回合。逐日位置見 [41 天逐日開工表](./逐日開工表_115年.md)。

## 每輪 60 分鐘怎麼做

1. **看懂例題詳解（10 分鐘，開卷）**：只打開「例題」的題解，弄懂每一步為什麼這樣做，特別是第一步怎麼起手；不抄寫。
2. **蓋解重做例題（15 分鐘，閉卷）**：闔上題解，把例題自己重寫一次。
3. **同章新題（25 分鐘，閉卷，考場速度）**：做同一章的「新題」，用正式考試的節奏與六科考場得分骨架作答。
4. **核對＋一句話錯因整理（10 分鐘）**：核對新題並記錄作答結果，再只寫一句：最常錯在哪一步、下次最先要改的動作。

## 名詞與計分

- **例題**：學習者先前做錯過的題，或該章具代表性的題；可以與核心時段（`CORE-xx`）重複。
- **新題**：學習者沒有做過的題；與 `CORE-01`–`CORE-24`、`MAIN-01`–`MAIN-05` 以及其他 FOCUS 輪次的題目完全不重複。
- **只有新題的結果計入分數估計**；例題只用來學會該章的起手式，不計分。
- 114 年與 108 年的題目留給模考與盲測，FOCUS 不使用（例題與新題都不是 EE-114-／EE-108-）。
