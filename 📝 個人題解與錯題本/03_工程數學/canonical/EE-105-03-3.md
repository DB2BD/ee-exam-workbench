# 105 年第 3 題｜複變線積分

題目給 \(z(t)=t^3+it,\ 0\le t\le1\)，故
\[\operatorname{Im}z(t)=t,\qquad dz=(3t^2+i)\,dt.\]
直接依參數計算：
\[\int_C\operatorname{Im}(z)\,dz=\int_0^1t(3t^2+i)\,dt=\frac34+\frac{i}{2}.\]

因此 \[\boxed{\int_C\operatorname{Im}(z)\,dz=\frac34+\frac{i}{2}}.\]
以參數式重新積分，實部為 \(3/4\)、虛部為 \(1/2\)，與結果一致。
