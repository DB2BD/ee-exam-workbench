## 一、多網目直流電路節點分析法求解（20 分）

### 📌 題目與已知條件

> **題目陳述**：
> 「圖 1 中，試求電流 $I_o$ 值。（20 分）」

---

### 💡 核心考點與破題關鍵
1. **節點電壓法（Nodal Analysis）**：
   - 選取最下方水平導線為**參考接地點（$0\text{ V}$）**。
   - 標定三個獨立主節點：
     - **節點 1（$V_1$）**：左側 $2\text{ mA}$ 電流源頂端。
     - **節點 2（$V_2$）**：中間 $1\text{ k}\Omega$ 右端與 $2\text{ k}\Omega$（$I_o$ 所在支路）頂端。
     - **節點 3（$V_3$）**：右側 $4\text{ mA}$ 流入端與右側 $2\text{ k}\Omega$ 頂端。
2. **待求電流 $I_o$ 定義**：
   $$I_o = \frac{V_2}{2\text{ k}\Omega}$$

---

### ✏️ 步驟式詳細數學推導

```
                    ( -  6V  + )       ( 1kΩ )
           ┌──────────[ 6V 電源 ]─────────[ 1kΩ ]─────────┐
           │                                             │
      【節點 1 (V1)】     ( 1kΩ )      【節點 2 (V2)】 (→ 4mA) 【節點 3 (V3)】
           ├──────────────[ 1kΩ ]─────────────┬───────────( 4mA )───┤
           │                                 │                     │
        (↑ 2mA)                           ( 2kΩ )               ( 2kΩ )
           │                                 │ (↓ Io)              │
           └─────────────────────────────────┴─────────────────────┘
                             【 參考接地（0 V）】
```

#### 步驟 1：列寫三個主節點之 KCL 方程式
*注意：頂部支路由 $6\text{ V}$（左負右正）串聯 $1\text{ k}\Omega$，從節點 1 到節點 3 之電位上升 $6\text{ V}$，故流經頂部 $1\text{ k}\Omega$（向右進入節點 3）之電流為 $\frac{V_1 + 6 - V_3}{1\text{ k}\Omega}$。*

1. **對節點 1 列寫 KCL（流入 ＝ 流出）**：

   $$2\text{ mA} = \frac{V_1 - V_2}{1} + \frac{V_1 + 6 - V_3}{1}$$


   $$2 = 2V_1 - V_2 - V_3 + 6 \implies \mathbf{2V_1 - V_2 - V_3 = -4} \quad \text{--- (式 1)}$$

2. **對節點 2 列寫 KCL（流入 ＝ 流出）**：

   $$\frac{V_1 - V_2}{1} = \frac{V_2}{2} + 4\text{ mA}$$

   同乘以 2：

   $$2V_1 - 2V_2 = V_2 + 8 \implies \mathbf{2V_1 - 3V_2 = 8} \implies \mathbf{2V_1 = 3V_2 + 8} \quad \text{--- (式 2)}$$

3. **對節點 3 列寫 KCL（流入 ＝ 流出）**：

   $$4\text{ mA} + \frac{V_1 + 6 - V_3}{1} = \frac{V_3}{2}$$

   同乘以 2：

   $$8 + 2V_1 + 12 - 2V_3 = V_3 \implies 2V_1 - 3V_3 = -20 \implies \mathbf{3V_3 = 2V_1 + 20} \quad \text{--- (式 3)}$$


---

#### 步驟 2：聯立求解節點電壓 $V_2$
1. 將 (式 2) 的 $2V_1 = 3V_2 + 8$ 代入 (式 3)：

   $$3V_3 = (3V_2 + 8) + 20 = 3V_2 + 28 \implies \mathbf{V_3 = V_2 + \frac{28}{3}}$$

2. 將 $2V_1$ 與 $V_3$ 表為 $V_2$ 的函數代入 (式 1)：

$$(3V_2 + 8) - V_2 - \left( V_2 + \frac{28}{3} \right) = -4$$


   $$V_2 + 8 - \frac{28}{3} = -4 \implies V_2 - \frac{4}{3} = -4$$


   $$\mathbf{V_2 = -4 + \frac{4}{3} = -\frac{8}{3}\text{ V} \approx -2.6667\text{ V}}$$

   * （可求出 \(V_1 = 0\text{ V}, V_3 = \frac{20}{3}\text{ V}\)）*

---

#### 步驟 3：計算支路電流 $I_o$
$$
\mathbf{I_o = \frac{V_2}{2\text{ k}\Omega} = \frac{-\frac{8}{3}\text{ V}}{2\text{ k}\Omega} = -\frac{4}{3}\text{ mA} \approx -1.3333\text{ mA}}
$$

---

### 🎯 第一題 滿分關鍵與結論
* **支路電流**： $\mathbf{I_o = -\frac{4}{3}\text{ mA} \approx -1.333\text{ mA}}$ （負號代表實際電流方向向上）
