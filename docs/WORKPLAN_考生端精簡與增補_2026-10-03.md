## 0. 判斷基準

115 年技師考試為 2026-11-14～15，今天起剩 42 天。唯一目標是提高上榜機率，因此每項功能只問一件事：**它是否讓「打開 → 作答 → 核對 → 修正」更快、更不容易出錯？**

- 會讓人選擇、猶豫、維護兩份資料的 → 精簡。
- 能防止背錯答案、或在考場直接拿分的 → 增加。
- 只對維護者有用的 → 移出考生介面，不刪除。

## 2. 工作項目

依「考前價值 ÷ 工作量」排序。T 為截止日；超過截止日未完成的項目自動延到考後，不壓縮其他項。

### P0｜考前必做

**K1 答案更正提醒（T：Wave 3 commit 後 2 天內）**

- 新增 `data/answer-corrections.json`：由 `reports/題解精確化_wave-*.md` 的答案更正表與 `.agents/results/WAVE-*/0?.json` 中 `answer_change: corrected` 的紀錄產生，欄位 `{qid, wave, old_answer, new_answer, reason, decided_at}`。由腳本 `scripts/build_answer_corrections.py` 產出，不手寫。
- 工作台：
  - 題目卡與題解頂端加一行「⚠ 本題答案已於 2026-10-0X 更正：舊 → 新」，只顯示一行，點開才看原因。
  - 複習中心加入口「答案已更正、而我做過的題」：比對 `localStorage` 既有作答紀錄（attempt／practice／SM2 任一有紀錄即算做過），列出需重看的題目。
- 文件：`上榜逐日開工表_115年.md` 開頭加一句「做過的題若出現 ⚠，先重看該題」。
- 驗收：所有已更正 QID 都有提醒；無紀錄的瀏覽器不顯示個人清單、也不報錯；測試覆蓋 JSON 產生與畫面渲染。

## 4. 執行方式與閘門

- 時序：Wave 3 commit → K1 → K3 → K2 檢查點 → K4、K5 → Wave 4 → K6。K1／K3 與 Wave 4 不碰同一檔案，可並行。
- 分工：主 session 決定介面與資料格式；子 Agent 執行腳本與測試的重複性工作。
- 每項完成後執行 WORKPLAN_題解精確化 第 7 節閘門，加上 `scripts/qa_browser.cjs` 實際開頁檢查；每項一個本地 commit，不 push。
- 停止條件：需要刪除使用者資料、需要改動逐日開工表內容、或任何 push／發版時，先問使用者。
