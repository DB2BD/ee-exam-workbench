# 發版紀錄 v1.6.0（2026-10-20）

## 改了什麼

- **雲端同步（GitHub Gist）**：備份視窗新增「雲端同步」。貼上只有 gist 權限的權杖後，程式建立（或找回）一個秘密 Gist `ee-exam-progress.json`，手機與電腦共用同一份進度。設定步驟與隱私說明見 [雲端同步設定](../00_使用說明/雲端同步設定.md)。
- **同步流程**：下載遠端 → 同步前快照 → 以既有 `applyUserDataBackup(…, 'merge')` 合併 → 產生備份內容 → 上傳。合併前另有兩項保護：模考計時保留本機、SM-2 取較新一次。
- **觸發時機**：開啟工作台時拉取；存結果卡、完成任務、SM-2 複習評分、匯入備份後 30 秒防抖上傳；離線或失敗時保留待上傳旗標，並以退避重試或在網路恢復時重試。多分頁以 localStorage 鎖只讓一個分頁同步。
- **權杖安全**：權杖只存在 `localStorage` 鍵 `EE_EXAM_CLOUD_SYNC_V1`，不進備份檔、不進快照、不上傳（上傳前再檢查內容不含權杖）；請求不帶 cookie、不送 referrer。
- **快照**：新增「同步前」快照類型（獨立保留最近 2 份，不擠掉匯入前／還原前快照）。
- 新增模組 `src/state/cloudSync.js`、測試 `tests/test_cloud_sync.py`、`qa_browser.cjs` 雲端同步情境（模擬 GitHub API，兩台裝置各存一張結果卡，同步後兩邊都有兩張）。

## 同步安全修正

- **三向合併**：每次同步成功後，本機另存「上次同步基準」（獨立 localStorage 鍵 `EE_EXAM_CLOUD_SYNC_BASE_V1`，不進備份、快照或 Gist）。合併前，做題進度、重點收藏、回想紀錄、手動章節標籤、每日練習完成紀錄中，本機相對基準有改動（含刪除）的項目一律保留本機值，雲端舊值不再蓋掉本機。`applyUserDataBackup` 的一般匯入語意不變。
- 做題進度、收藏、回想、手動標籤、每日練習儲存時，已連線則標記待上傳。
- **強制覆寫**：已連線時還原快照或以「取代」匯入後，下一次同步直接以本機覆寫雲端，不再合併舊資料回來。
- **重複 Gist**：每次開啟後第一次同步、以及剛建立 Gist 後，會列出同描述的 Gist；有多個時改綁最早的，並把較新的內容合併進來（不刪除任何 Gist）。分頁鎖改為寫入隨機擁有者戳記、稍候重讀，仍是自己的才同步。
- **寫入競爭**：上傳後再讀一次雲端，若內容不同（別台剛寫入），多跑一輪合併（最多一輪）。
- **下載上限**：讀取前檢查 Content-Length 與檔案大小，超過 8 MB 拒絕並顯示固定訊息。
- **重試分級**：只有網路、5xx、429 持續退避重試；程式例外與合併失敗連續 3 次後停止。雲端資料格式損壞時，按「立即同步」會詢問是否用本機進度覆寫雲端。
- Gist 查詢在第一個有符合描述的頁面就停止並取最早者；有找到就不會再建立新的。

## 已知限制

- 秘密 Gist 保留修訂歷史，舊版本仍可透過網址讀取；「中斷連線」不會撤銷權杖；`db2bd.github.io` 下的網站共用同一儲存空間。對策見 [雲端同步設定](../00_使用說明/雲端同步設定.md)。
- 本機刪除會在同步時保留（不會被雲端舊值復活），但不會傳給其他裝置；其他裝置仍可能把該項目再同步回來。
- 備份內容超過 8 MB 時不上傳，雲端檔案超過 8 MB 時不讀取。
