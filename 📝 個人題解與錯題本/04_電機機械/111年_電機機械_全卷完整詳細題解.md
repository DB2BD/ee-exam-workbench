## 一、環形鐵磁電感結構與提高電感值之四種方法（16 分）

### 📌 題目與已知條件
下圖為一典型的環形電感，其環形鐵磁材料之導磁係數（permeability）為 $\mu$，外部繞線圈數為 $N$ 匝，環形平均半徑為 $r$，圓形截面半徑為 $a$。
* **試求**：請依所使用之材料以及幾何結構，提出**四種**提高該電感值的方法。（16 分）

---

### 💡 核心考點與破題關鍵
1. **環形電感數學推導**：
   - 磁路平均周長：$l_c = 2\pi r$。
   - 磁路截面積：$A = \pi a^2$。
   - 鐵心磁阻：$\mathcal{R} = \frac{l_c}{\mu A} = \frac{2\pi r}{\mu (\pi a^2)} = \frac{2r}{\mu a^2}$。
   - 線圈電感值：
     $$\mathbf{L = \frac{N^2}{\mathcal{R}} = \frac{N^2 \mu A}{l_c} = \frac{N^2 \mu (\pi a^2)}{2\pi r} = \frac{N^2 \mu a^2}{2r}}$$

---

### ✏️ 步驟式詳細推導與四種提高電感方法
根據電感公式 $L = \frac{\mu N^2 a^2}{2r}$，提高電感值之四種工程方法如下：
1. **增加線圈繞組匝數 $N$（幾何繞線結構）**：
   - 電感值 $L$ 與匝數平方成正比（$L \propto N^2$）。若將繞線匝數加倍，電感值將提高為 4 倍。
2. **選用更高導磁係數 $\mu$ 之鐵磁材料（材料特性）**：
   - 電感值 $L$ 與導磁率成正比（$L \propto \mu = \mu_r \mu_0$）。採用高導磁率材料（如矽鋼片、高導磁鐵氧體 Ferrite、超導磁合金 Permalloy 等），可大幅降低磁阻並成倍提高電感。
3. **增加鐵心截面半徑 $a$ 或截面積 $A$（幾何截面結構）**：
   - 電感值 $L$ 與截面半徑平方（即截面積 $A = \pi a^2$）成正比（$L \propto a^2$）。加粗鐵心截面積可擴大磁通容納路徑，提升電感值。
4. **縮小環形鐵心之平均半徑 $r$（幾何長度結構）**：
   - 電感值 $L$ 與平均半徑成反比（$L \propto \frac{1}{r}$）。縮小環形平均半徑 $r$ 可以縮短磁路長度 $l_c = 2\pi r$，進而降低總磁阻、提高電感值。

---

### 🎯 第一題 滿分關鍵與結論
* **電感公式**：$L = \mathbf{\frac{N^2 \mu A}{l_c} = \frac{N^2 \mu a^2}{2r}}$
* **四種方法**：(1) 增加線圈匝數 $N$、(2) 換用高導磁係數 $\mu$ 材料、(3) 增加截面半徑 $a$、(4) 縮小環形平均半徑 $r$。

## 二、四極繞線式感應馬達轉矩方程式與轉子電阻調速（25 分）

### 📌 題目與已知條件
某三相、$60\text{ Hz}$ 交流之四極繞線式（wound-rotor）感應馬達，其扭力（$T_{mech}$）與轉差率（$s$）之間的數值關係為：
$$T_{mech} = \frac{207.63 s}{s^2 + 0.0925 s + 0.0382}\text{ 牛頓}\cdot\text{米 (N}\cdot\text{m)}$$
* 同步轉速：$n_s = \frac{120 \times 60}{4} = 1800\text{ rpm}$。

**試求**：
* **(一)** 當此感應馬達帶動 $100\text{ N}\cdot\text{m}$ 負載時，其轉速為若干 rpm？（5 分）
* **(二)** 若 $R_2$ 增加為原來的兩倍，且負載保持在 $100\text{ N}\cdot\text{m}$ 大小，則轉速將如何變化？（10 分）
* **(三)** 在帶動同樣 $100\text{ N}\cdot\text{m}$ 負載的情況下，欲利用加入轉子電阻（即從原本的 $R_2$ 變為 $R_2'$），使轉速降為 $1700\text{ rpm}$，試問比值 $\frac{R_2'}{R_2}$ 應為若干？（10 分）

---

### 💡 核心考點與破題關鍵
1. **感應電動機轉矩與轉子電阻關聯**：
   $$T \propto \frac{s/R_2}{(R_{1,eq} + R_2/s)^2 + (X_{1,eq} + X_2)^2}$$
   - 在相同電磁轉矩下，轉差率與轉子電阻成正比：$\mathbf{\frac{s}{R_2} = \text{常數} \implies s \propto R_2}$。
2. **轉速與轉差率關係**：$n = n_s (1 - s) = 1800(1 - s)$。

---

### ✏️ 步驟式詳細數學推導

#### 🔹 (一) 負載轉矩 $100\text{ N}\cdot\text{m}$ 時之轉速 $n_1$
1. 建立代數方程式：
   $$\frac{207.63 s}{s^2 + 0.0925 s + 0.0382} = 100$$
   $$100 s^2 + 9.25 s + 3.82 = 207.63 s \implies 100 s^2 - 198.38 s + 3.82 = 0$$
2. 一元二次方程式求解：
   $$s = \frac{198.38 - \sqrt{198.38^2 - 4(100)(3.82)}}{200} = \frac{198.38 - \sqrt{39354.6 - 1528}}{200} = \frac{198.38 - 194.49}{200} = \mathbf{0.01945\ (1.945\%)}$$
3. 計算轉速 $n_1$：
   $$\mathbf{n_1 = 1800 \times (1 - 0.01945) = \mathbf{1765.0\text{ rpm}}}$$

#### 🔹 (二) $R_2$ 增為 2 倍時轉速之變化
1. 轉矩相同時，轉差率直接加倍：
   $$\mathbf{s_2 = 2 \times s_1 = 2 \times 0.01945 = \mathbf{0.03890\ (3.89\%)}}$$
2. 新轉速 $n_2$：
   $$\mathbf{n_2 = 1800 \times (1 - 0.03890) = \mathbf{1730.0\text{ rpm}}}$$
3. 轉速變化量：
   $$\mathbf{\Delta n = 1730.0 - 1765.0 = \mathbf{-35.0\text{ rpm}}\quad (\text{轉速下降 } 35\text{ rpm})}$$

#### 🔹 (三) 降速至 $1700\text{ rpm}$ 之轉子電阻比值 $\frac{R_2'}{R_2}$
1. 目標轉速對應之轉差率 $s_3$：
   $$s_3 = \frac{1800 - 1700}{1800} = \frac{100}{1800} = \mathbf{\frac{1}{18} \approx 0.05556\ (5.556\%)}$$
2. 由 $\frac{s_3}{R_2'} = \frac{s_1}{R_2}$：
   $$\mathbf{\frac{R_2'}{R_2} = \frac{s_3}{s_1} = \frac{0.055556}{0.019445} = \mathbf{2.857\text{ 倍}}}$$

---

### 🎯 第二題 滿分關鍵與結論
* **(一) 帶動 $100\text{ N}\cdot\text{m}$ 轉速**：$n_1 = \mathbf{1765.0\text{ rpm}}$（$s = 1.945\%$）
* **(二) $R_2$ 加倍後轉速**：$n_2 = \mathbf{1730.0\text{ rpm}}$（下降 $35.0\text{ rpm}$）
* **(三) 降速至 $1700\text{ rpm}$ 電阻比**：$\mathbf{\frac{R_2'}{R_2} = 2.857\text{ 倍}}$

## 三、複激直流發電機磁化曲線、無載端電壓與平複激設計（25 分）

### 📌 題目與已知條件
某 $20\text{ kW}、200\text{ V}、1800\text{ rpm}$ 直流發電機：
* 電樞電阻 $R_a = 0.1\ \Omega$，並激繞組電阻 $R_{fw} = 150\ \Omega$。
* 在 $1800\text{ rpm}$ 並激無載運轉下，磁化曲線如下表：

| $I_f\text{ (A)}$ | 0.0 | 0.125 | 0.25 | 0.5 | 0.625 | 0.75 | 0.875 | 1.0 | 1.25 | 1.48 |
| :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: |
| $E_a\text{ (V)}$ | 5 | 33.5 | 67 | 134 | 160 | 175 | 190 | 200 | 214 | 222 |

* 改以長分路積複激（Long-Shunt Cumulative Compound）運轉，串激繞組電阻 $R_{sr} = 0.04\ \Omega$。

**試求**：
* **(一)** 在 $1800\text{ rpm}$ 運轉且無負載情況下，此發電機輸出端電壓之最大值為多少 V？（5 分）
* **(二)** 不考慮電樞反應，當發電機為額定滿載輸出時，相當於上表磁化曲線之總激磁電流 $I_f$ 應為多少 A？（10 分）
* **(三)** 已知並激繞組匝數 $N_f = 1200\text{ 匝/每極}$，今欲使發電機之無載與滿載輸出端電壓俱為 $200\text{ V}$（平複激），求串激繞組之每極匝數 $N_s$ 應為多少？（10 分）

---

### 💡 核心考點與破題關鍵
1. **無載最高電壓**：發生在場可變電阻 $R_{fc} = 0$（總場電阻最小 $R_f = R_{fw} = 150\ \Omega$），場電阻線 $E_a = 150 I_f$ 與磁化曲線之交點。
2. **長分路滿載電樞內生電壓**：
   - 額定輸出：$P_{out} = 20\text{ kW}, V_t = 200\text{ V} \implies I_L = \frac{20000}{200} = 100\text{ A}$。
   - $E_a = V_t + I_a (R_a + R_{sr})$。
3. **平複激（Flat Compounding）磁動勢平衡方程式**：
   $$\mathcal{F}_{total} = N_f I_{f,total} = N_f I_{f,sh} + N_s I_a \implies N_s = \frac{N_f (I_{f,total} - I_{f,sh})}{I_a}$$

---

### ✏️ 步驟式詳細數學推導

#### 🔹 (一) 無載輸出端電壓最大值
1. 無載時 $I_L = 0 \implies I_a = I_f$（極小），端電壓 $V_t \approx E_a$。
2. 場可變電阻調至 $R_{fc} = 0$，場迴路總電阻 $R_f = 150\ \Omega$。
3. 場電阻線方程式：$E_a = 150 \times I_f$。
   - 檢查表格數據：當 $I_f = 1.48\text{ A}$ 時，$150 \times 1.48 = \mathbf{222\text{ V}}$，恰與磁化曲線 $E_a = 222\text{ V}$ 完全重合！
4. **最大無載端電壓**：
   $$\mathbf{V_{t,max} = \mathbf{222\text{ V}}}$$

#### 🔹 (二) 額定滿載輸出所需之總激磁電流 $I_f$
1. 滿載負載電流：$I_L = \frac{20000\text{ W}}{200\text{ V}} = 100\text{ A}$。
2. 並激場電流（$V_t = 200\text{ V}$ 下 $I_{f,sh} \approx 1.0\text{ A}$），電樞電流 $I_a = 100 + 1.0 = \mathbf{101.0\text{ A}}$。
3. 滿載反電動勢：
   $$\mathbf{E_a = V_t + I_a (R_a + R_{sr}) = 200 + 101.0 \times (0.1 + 0.04) = 200 + 101.0 \times 0.14 = \mathbf{214.14\text{ V}}}$$
4. 查表對應總激磁電流：
   - 查磁化曲線表格，當 $E_a = 214\text{ V}$ 時，對應之總激磁電流為：
     $$\mathbf{I_{f,total} = \mathbf{1.25\text{ A}}}$$

#### 🔹 (三) 平複激之串激繞組每極匝數 $N_s$
1. 無載端電壓 $V_t = 200\text{ V}$ 時：
   - 查表 $E_a = 200\text{ V}$ 對應並激電流 $I_{f,sh} = \mathbf{1.0\text{ A}}$。
2. 滿載端電壓維持 $V_t = 200\text{ V}$ 時：
   - 總磁動勢需達到產生 $E_a = 214.14\text{ V}$ 所需之磁動勢：
     $$\mathcal{F}_{total} = N_f \times I_{f,total} = 1200 \times 1.25 = \mathbf{1500\text{ A}\cdot\text{t}}$$
   - 並激繞組提供之磁動勢：
     $$\mathcal{F}_{sh} = N_f \times I_{f,sh} = 1200 \times 1.0 = \mathbf{1200\text{ A}\cdot\text{t}}$$
   - 串激繞組需提供之補償磁動勢：
     $$\mathcal{F}_{sr} = \mathcal{F}_{total} - \mathcal{F}_{sh} = 1500 - 1200 = \mathbf{300\text{ A}\cdot\text{t}}$$
3. 求解串激匝數 $N_s$：
   $$\mathbf{N_s = \frac{\mathcal{F}_{sr}}{I_a} = \frac{300\text{ A}\cdot\text{t}}{101.0\text{ A}} = \mathbf{2.97\text{ 匝/極} \approx \mathbf{3\text{ 匝/極}}}}$$

---

### 🎯 第三題 滿分關鍵與結論
* **(一) 無載最大端電壓**：$V_{t,max} = \mathbf{222\text{ V}}$
* **(二) 滿載總激磁電流**：$I_{f,total} = \mathbf{1.25\text{ A}}$（$E_a = 214.14\text{ V}$）
* **(三) 串激繞組匝數**：$N_s = \mathbf{2.97\text{ 匝/極} \approx 3\text{ 匝/極}}$

## 四、25 MVA 同步發電機電壓調整率與 OCC/SCC 激磁電流（20 分）

### 📌 題目與已知條件
某三相 $\text{Y}$ 接、額定線電壓 $11\text{ kV}、60\text{ Hz}、25\text{ MVA}$ 圓桶式轉子同步發電機：
* 每相飽和同步電抗 $X_s = 4.5\ \Omega$，忽略電樞電阻（$R_a = 0$）。
* 當場電流調整為 $I_f = 200\text{ A}$ 時，發電機以額定電壓與額定電流對 $\text{PF} = 0.85\text{ 落後}$ 負載供電。

**試求**：
* **(一)** 若場電流值不變，則發電機之電壓調整率 $\text{VR}$ 為若干？（5 分）
* **(二)** 就此發電機之開路特性（OCC）曲線來看，相對於額定電壓輸出之所需場電流大小應為若干 A？（5 分）
* **(三)** 就此發電機之短路特性（SCC）曲線來看，相對於額定電流輸出之所需場電流大小應為若干 A？（10 分）

---

### 💡 核心考點與破題關鍵
1. **相電壓與額定電流**：
   $$V_\phi = \frac{11000}{\sqrt{3}} \approx 6350.85\text{ V}, \quad I_{rated} = \frac{25 \times 10^6}{\sqrt{3} \times 11000} \approx 1312.16\text{ A}$$
2. **內生激磁電壓 $\mathbf{E}_f$**：
   $$\mathbf{E}_f = V_\phi + jX_s \mathbf{I}_a$$
3. **短路比與開路/短路激磁電流關係**：
   $$\text{SCR} = \frac{I_{f,nl}}{I_{f,sc}} = \frac{1}{X_{s,pu}} \implies I_{f,sc} = X_{s,pu} \times I_{f,nl}$$

---

### ✏️ 步驟式詳細數學推導

#### 🔹 (一) 計算電壓調整率 $\text{VR}$
1. 電樞電流相量（$\text{PF} = 0.85\text{ 落後} \implies \theta = 31.788^\circ$）：
   $$\mathbf{I}_a = 1312.16\angle -31.788^\circ = 1115.34 - j691.22\text{ A}$$
2. 激磁相量 $\mathbf{E}_f$：
   $$\mathbf{E}_f = 6350.85 + j4.5 \times (1115.34 - j691.22) = (6350.85 + 3110.49) + j5019.03$$
   $$\mathbf{E}_f = 9461.34 + j5019.03\text{ V}$$
$$|\mathbf{E}_f| = \sqrt{9461.34^2 + 5019.03^2} = \sqrt{89516965 + 25190662} = \sqrt{114707627} = \mathbf{10710.16\text{ V/相}}$$
3. 電壓調整率：
   $$\mathbf{VR = \frac{|\mathbf{E}_f| - V_\phi}{V_\phi} \times 100\% = \frac{10710.16 - 6350.85}{6350.85} \times 100\% = \frac{4359.31}{6350.85} \times 100\% = \mathbf{68.64\%}}$$

#### 🔹 (二) OCC 開路特性額定電壓所需場電流 $I_{f,nl}$
* 當 $I_f = 200\text{ A}$ 時，發電機內部開路電壓為 $|\mathbf{E}_f| = 10708.06\text{ V}$。
* 額定相電壓為 $V_\phi = 6350.85\text{ V}$：
  $$\mathbf{I_{f,nl} = 200\text{ A} \times \frac{6350.85\text{ V}}{10708.06\text{ V}} = \mathbf{118.62\text{ A}}}$$

#### 🔹 (三) SCC 短路特性額定電流所需場電流 $I_{f,sc}$
1. 計算基準阻抗與標么電抗：
   $$Z_{base} = \frac{V_{LL}^2}{S_{3\phi}} = \frac{11000^2}{25 \times 10^6} = \mathbf{4.84\ \Omega}$$
   $$X_{s,pu} = \frac{X_s}{Z_{base}} = \frac{4.5\ \Omega}{4.84\ \Omega} = \mathbf{0.92975\text{ pu}}$$
2. 由短路比定義 $X_{s,pu} = \frac{I_{f,sc}}{I_{f,nl}}$：
   $$\mathbf{I_{f,sc} = X_{s,pu} \times I_{f,nl} = 0.92975 \times 118.62\text{ A} = \mathbf{110.29\text{ A}}}$$
   * $(亦可由 $X_s I_{rated} = 4.5 \times 1312.16 = 5904.72\text{ V} \implies I_{f,sc} = 118.62 \times \frac{5904.72}{6350.85} = \mathbf{110.29\text{ A}}$)*$

## 五、工廠負載功因矯正與同步調相機參數計算（14 分）

### 📌 題目與已知條件
某工廠內部以電感性負載為主，由線電壓 $2300\text{ V}$ 之三相輸電電纜供電：
* 工廠用電量為 $P = 3000\text{ kW}$，功率因數 $\text{PF} = 0.85\text{ 落後}$。
* 選用一具同步阻抗 $X_s = 1.6\ \Omega$ 之同步機做為同步調相機（Synchronous Capacitor / Condenser），將工廠用電之功率因數矯正為 $1.0$。

**試求**：
* **(一)** 所選用之同步機額定 $\text{kVA}$ 值應為何？（4 分）
* **(二)** 工廠安裝此同步調相機之前與安裝之後，輸電電纜所需提供給工廠之線電流大小有何改變？（4 分）
* **(三)** 欲達成上述功因改善之要求，應將同步機之電樞（激磁）電壓值調整為多少？（6 分）

---

### 💡 核心考點與破題關鍵
1. **負載虛功率計算**：
   $$S_{load} = \frac{3000}{0.85} = 3529.41\text{ kVA}, \quad Q_{load} = 3000 \times \tan(\cos^{-1} 0.85) = 1859.23\text{ kVAR}$$
2. **同步調相機容量**：純提供虛功率 $\implies Q_{cond} = 1859.23\text{ kVAR} \implies S_{cond} = 1859.23\text{ kVA}$。
3. **電樞內生電壓（超激磁運轉）**：
   $$V_\phi = \frac{2300}{\sqrt{3}} \approx 1327.91\text{ V}, \quad \mathbf{E}_f = V_\phi - jX_s \mathbf{I}_{cond} = V_\phi - jX_s (+j I_{cond}) = V_\phi + X_s I_{cond}$$

---

### ✏️ 步驟式詳細數學推導

#### 🔹 (一) 同步機額定 $\text{kVA}$ 容量
1. 工廠原始虛功率：
   $$\theta = \cos^{-1}(0.85) = 31.788^\circ$$
   $$Q = P \tan\theta = 3000\text{ kW} \times \tan(31.788^\circ) = 3000 \times 0.61974 = \mathbf{1859.23\text{ kVAR}}$$
2. 同步調相機額定容量：
   $$\mathbf{S_{cond} = Q = \mathbf{1859.23\text{ kVA} \approx 1859\text{ kVA}}}$$

#### 🔹 (二) 輸電電纜線電流變化
1. **安裝前線電流**：
   $$\mathbf{I_{line,before} = \frac{S_{load}}{\sqrt{3} V_L} = \frac{3529.41 \times 10^3\text{ VA}}{\sqrt{3} \times 2300\text{ V}} = \mathbf{886.02\text{ A}}}$$
2. **安裝後線電流（$\text{PF} = 1.0$）**：
   $$\mathbf{I_{line,after} = \frac{P}{\sqrt{3} V_L} = \frac{3000 \times 10^3\text{ W}}{\sqrt{3} \times 2300\text{ V}} = \mathbf{753.12\text{ A}}}$$
3. **線電流改變量**：
   $$\mathbf{\Delta I = 753.12 - 886.02 = \mathbf{-132.90\text{ A}}\quad (\text{供電線路電流大幅降低 } \mathbf{15.0\%})}$$

#### 🔹 (三) 同步機電樞（激磁）電壓調整值
1. 同步機吸納之純超前無效電流：
   $$I_{cond} = \frac{Q_{cond}}{\sqrt{3} V_L} = \frac{1859.23 \times 10^3}{\sqrt{3} \times 2300} = \mathbf{466.75\text{ A}}$$
   $$\mathbf{I}_{cond} = 466.75\angle +90^\circ = +j 466.75\text{ A}$$
2. 每相激磁電壓 $\mathbf{E}_f$：
   $$\mathbf{E}_f = V_\phi - jX_s \mathbf{I}_{cond} = \frac{2300}{\sqrt{3}} - j(1.6\ \Omega)(+j 466.75\text{ A})$$
   $$\mathbf{E}_f = 1327.91 + (1.6 \times 466.75) = 1327.91 + 746.80 = \mathbf{2074.71\text{ V/相}}$$
3. 線間激磁電壓：
   $$\mathbf{E}_{f,LL} = \sqrt{3} \times 2074.71\text{ V} = \mathbf{3593.5\text{ V}} \approx \mathbf{3.59\text{ kV}}$$

> 3. **同步機相量計算**：同步電動機 $\mathbf{E}_f = \mathbf{V}_\phi - \mathbf{I}_a \mathbf{Z}_s$；同步發電機 $\mathbf{E}_f = \mathbf{V}_\phi + \mathbf{I}_a \mathbf{Z}_s$。
