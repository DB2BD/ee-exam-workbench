### 一、電磁鐵電磁吸力與磁場儲存能量（20 分）

#### 📌 題目與已知條件
- 線圈匝數 $N = 400\text{ 匝}$，電阻 $R = 5\ \Omega$。
- 鐵心截面為正方形，邊長 $5\text{ cm}$（截面積 $A = 25\text{ cm}^2 = 2.5 \times 10^{-3}\text{ m}^2$）。
- 兩邊氣隙長度均為 $g = 0.1\text{ cm} = 10^{-3}\text{ m}$。忽略鐵心與鐵板之磁阻。
- 平均吸力 $F = 550\text{ N}$。直流電源供電。

* **(一)** 求直流電源電壓 $V$ 為多少伏特？（10 分）
* **(二)** 求儲存在磁場中之能量 $W_f$ 為多少焦耳？（10 分）

---

#### ✏️ 步驟式詳細數學推導
1. **電磁吸力公式**（雙氣隙）：
   $$F = 2 \times \left( \frac{B_g^2 A}{2\mu_0} \right) = \frac{B_g^2 A}{\mu_0}$$
   $$B_g = \sqrt{\frac{F \mu_0}{A}} = \sqrt{\frac{550 \times (4\pi \times 10^{-7})}{2.5 \times 10^{-3}}} = \sqrt{\frac{6.9115 \times 10^{-4}}{2.5 \times 10^{-3}}} = \sqrt{0.27646} = \mathbf{0.5258\text{ T}}$$
2. **所需電流與直流電壓**：
   $$N I = H_g (2g) = \frac{B_g}{\mu_0} (2g) \implies I = \frac{B_g (2g)}{\mu_0 N} = \frac{0.5258 \times (2 \times 10^{-3})}{(4\pi \times 10^{-7}) \times 400} = \frac{1.0516 \times 10^{-3}}{5.0265 \times 10^{-4}} = \mathbf{2.0921\text{ A}}$$
   $$\mathbf{V} = I R = 2.0921 \times 5  = \mathbf{10.46\text{ V}}$$
3. **磁場儲存能量 $W_f$**：
   $$\mathbf{W_f = 2 \times \left( \frac{B_g^2}{2\mu_0} A g \right) = F \times g = 550\text{ N} \times 10^{-3}\text{ m} = \mathbf{0.55\text{ J}}}$$

---

#### 🎯 第一題 滿分關鍵與結論
- **直流電壓**：$V = \mathbf{10.46\text{ V}}$
- **磁場儲能**：$W_f = \mathbf{0.55\text{ J}}$

## 二、106 年電機機械第 2 題｜雙繞組變壓器改接自耦變壓器容量與效率

> ✅ 已依官方 2400/240 V、50 kVA 額定值與 2400→2640 V 升壓接法重算串聯、公共繞組電流、容量及滿載損耗。

### 二、雙繞組變壓器改接自耦變壓器容量與效率（20 分）

#### 📌 題目與已知條件
- 雙繞組變壓器：$2400\text{ V} / 240\text{ V}, 50\text{ kVA}, 60\text{ Hz}$，滿載 $\text{PF} = 1.0$ 下效率 $\eta = 98\%$。
- 改接為 $2400\text{ V}$ 供應 $2640\text{ V}$ 負載之自耦變壓器。

* **(一)** 求自耦變壓器之額定容量 $S_{auto}$（$\text{kVA}$）。（10 分）
* **(二)** 求自耦變壓器在滿載 $\text{PF} = 1.0$ 下之效率 $\eta_{auto}$。（10 分）

---

#### ✏️ 步驟式詳細數學推導
1. **自耦變壓器容量**：
   二次側串聯繞組（$240\text{ V}$）額定電流：$I_{series} = \frac{50000}{240} = 208.33\text{ A}$。
輸出電壓 $V_H = 2400 + 240 = 2640\text{ V}$。
   $$\mathbf{S_{auto} = 2640 \times 208.33 = \mathbf{550000\text{ VA} = 550.0\text{ kVA}}}$$
2. **效率計算**：
   雙繞組變壓器滿載損耗：
   $$P_{loss} = P_{in} - P_{out} = \frac{50}{0.98} - 50 = 51.0204 - 50 = \mathbf{1.0204\text{ kW}}$$
   自耦變壓器滿載輸出（$\text{PF} = 1.0$）：$P_{out,auto} = 550.0\text{ kW}$。
   $$\mathbf{\eta_{auto} = \frac{550}{550 + 1.0204} \times 100\% = \frac{550}{551.0204} \times 100\% = \mathbf{99.81\%}}$$

---

#### 🎯 第二題 滿分關鍵與結論
- **自耦容量**：$S_{auto} = \mathbf{550.0\text{ kVA}}$
- **自耦滿載效率**：$\eta_{auto} = \mathbf{99.81\%}$

### 三、直流並激電動機負載運轉分析（20 分）

#### 📌 題目與已知條件
- 額定 $200\text{ V}$ 直流並激電動機，$R_f = 200\ \Omega, R_a = 0.5\ \Omega$。
- 無載試驗：$n_{nl} = 1000\text{ rpm}, I_f = 1.0\text{ A}, I_{a,nl} = 4.0\text{ A}$。
- 外接負載轉矩 $T_L = 100\text{ N}\cdot\text{m}$。忽略磁飽和與電樞反應。

* **(一)** 求負載時之電樞電流 $I_a$ 為多少安培？（10 分）
* **(二)** 求負載時之轉速 $n$ 為多少轉/分？（10 分）

---

#### ✏️ 步驟式詳細數學推導
1. **反電動勢常數 $K\Phi$**：
   $$E_{a,nl} = V_t - I_{a,nl} R_a = 200 - (4.0 \times 0.5) = \mathbf{198.0\text{ V}}$$
   $$\omega_{nl} = \frac{2\pi \times 1000}{60} = \frac{100\pi}{3} \approx 104.72\text{ rad/s}$$
   $$K\Phi = \frac{E_{a,nl}}{\omega_{nl}} = \frac{198.0}{104.72} = \mathbf{1.8908\text{ V}\cdot\text{s/rad}}$$
2. **負載狀態計算**：
   由電磁轉矩公式 $T = K\Phi I_a$：
   $$\mathbf{I_a = \frac{T}{K\Phi} = \frac{100}{1.8908} = \mathbf{52.888\text{ A} \approx 52.89\text{ A}}}$$
   負載反電動勢：
   $$E_a = V_t - I_a R_a = 200 - (52.89 \times 0.5) = 200 - 26.44 = \mathbf{173.56\text{ V}}$$
   負載轉速：
   $$\omega_m = \frac{E_a}{K\Phi} = \frac{173.56}{1.8908} = 91.792\text{ rad/s}$$
   $$\mathbf{n = 91.792 \times \frac{60}{2\pi} = \mathbf{876.54\text{ rpm}}}$$

---

#### 🎯 第三題 滿分關鍵與結論
- **電樞電流**：$I_a = \mathbf{52.89\text{ A}}$
- **負載轉速**：$n = \mathbf{876.54\text{ rpm}}$

---

### 四、三相感應電動機各項損耗與總效率（20 分）

#### 📌 題目與已知條件
- 三相感應電動機：$230\text{ V}, 60\text{ Hz}, 25\text{ hp}$。
- 在 $\text{PF} = 0.866\text{ 落後}$ 下從電源吸取電流 $I_L = 60\text{ A}$。
- 各項損耗：定子銅損 $P_{cu1} = 850\text{ W}$，鐵損 $P_{core} = 450\text{ W}$，轉子銅損 $P_{cu2} = 1050\text{ W}$，旋轉機械損 $P_{rot} = 500\text{ W}$。

* **(一)** 求產生之機械輸出功率 $P_{out}$（$\text{W}$ 與 $\text{hp}$）。（10 分）
* **(二)** 求電動機之操作效率 $\eta$（$\%$）。（10 分）

---

#### ✏️ 步驟式詳細數學推導
1. **輸入總電功率**：
   $$P_{in} = \sqrt{3} V_L I_L \cos\theta = \sqrt{3} \times 230 \times 60 \times 0.866 = 398.37 \times 51.96 = \mathbf{20700\text{ W}}$$
2. **總損耗與輸出功率**：
   $$P_{loss,total} = P_{cu1} + P_{core} + P_{cu2} + P_{rot} = 850 + 450 + 1050 + 500 = \mathbf{2850\text{ W}}$$
   $$\mathbf{P_{out} = P_{in} - P_{loss,total} = 20700 - 2850 = \mathbf{17850\text{ W}}}$$
   $$\mathbf{P_{out\ (hp)} = \frac{17850}{746} = \mathbf{23.93\text{ hp}}}$$
3. **操作效率**：
   $$\mathbf{\eta = \frac{P_{out}}{P_{in}} \times 100\% = \frac{17850}{20700} \times 100\% = \mathbf{86.23\%}}$$

---

#### 🎯 第四題 滿分關鍵與結論
- **機械輸出功率**：$P_{out} = \mathbf{17850\text{ W} = 23.93\text{ hp}}$
- **總效率**：$\eta = \mathbf{86.23\%}$

---

### 五、同步發電機功率因數超前與滯後電壓調整率（20 分）

#### 📌 題目與已知條件
- 額定：$9\text{ kVA}, 208\text{ V}$、$\text{Y}$ 接三相同步發電機，$R_a = 0.1\ \Omega/\text{相}, X_s = 5.6\ \Omega/\text{相}$。

* **(一)** 滿載功率因數 $\text{PF} = 0.8\text{ 落後}$ 時之電壓調整率 $\text{VR}$。（10 分）
* **(二)** 滿載功率因數 $\text{PF} = 0.8\text{ 超前}$ 時之電壓調整率 $\text{VR}$。（10 分）

---

#### ✏️ 步驟式詳細數學推導
1. **額定相電壓與電流**：
   $$V_\phi = \frac{208}{\sqrt{3}} \approx 120.09\text{ V}, \quad I_a = \frac{9000}{\sqrt{3}\times 208} = 25.0\text{ A}$$
2. **第 (一) 小題：$\text{PF} = 0.8\text{ 落後}$**：
   $$\mathbf{I}_a = 25.0ngle -36.87^\circ = (20.0 - j15.0)\text{ A}$$
   $$\mathbf{E}_f = 120.09 + (20.0 - j15.0)(0.1 + j5.6) = 120.09 + (2.0 + 84.0) + j(112.0 - 1.5) = 206.09 + j110.50\text{ V}$$
$$|\mathbf{E}_f| = \sqrt{206.09^2 + 110.50^2} = \sqrt{42473 + 12210} = \sqrt{54683} \approx \mathbf{233.84\text{ V/相}}$$
   $$\mathbf{VR = \frac{233.84 - 120.09}{120.09} \times 100\% = \frac{113.75}{120.09} \times 100\% = \mathbf{94.72\%}}$$
3. **第 (二) 小題：$\text{PF} = 0.8\text{ 超前}$**：
   $$\mathbf{I}_a = 25.0ngle +36.87^\circ = (20.0 + j15.0)\text{ A}$$
   $$\mathbf{E}_f = 120.09 + (20.0 + j15.0)(0.1 + j5.6) = 120.09 + (2.0 - 84.0) + j(112.0 + 1.5) = 38.09 + j113.50\text{ V}$$
$$|\mathbf{E}_f| = \sqrt{38.09^2 + 113.50^2} = \sqrt{1450.8 + 12882.3} = \sqrt{14333.1} \approx \mathbf{119.72\text{ V/相}}$$
   $$\mathbf{VR = \frac{119.72 - 120.09}{120.09} \times 100\% = \frac{-0.37}{120.09} \times 100\% = \mathbf{-0.31\%}}$$

---

> [!WARNING]
> ⚠️ **電機機械 核心防坑與閱卷踩雷提醒**：
> 1. **變壓器阻抗折合**：低壓側折合至高壓側乘以變比平方 $a^2$；自耦變壓器共用繞組電流為高低壓側電流之差值。
> 2. **感應機最大轉矩**：最大轉矩 $T_{max}$ 與轉子電阻 $R_2$ 無關，但產生最大轉矩之轉差率 $s_{max}$ 與 $R_2$ 成正比。
> 3. **同步機相量計算**：同步電動機 $\mathbf{E}_f = \mathbf{V}_\phi - \mathbf{I}_a \mathbf{Z}_s$；同步發電機 $\mathbf{E}_f = \mathbf{V}_\phi + \mathbf{I}_a \mathbf{Z}_s$。

---


#### 🎯 第五題 滿分關鍵與結論
- **(一) 0.8 落後電壓調整率**：$\text{VR} = \mathbf{94.72\%}$（端電壓隨負載大幅下跌）
- **(二) 0.8 超前電壓調整率**：$\text{VR} = \mathbf{-0.31\%}$（Ferranti 磁化效應使電壓不跌反升）
