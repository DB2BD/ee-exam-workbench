# 📌 114 年 電力系統 — 第二題（單線接地故障 SLG 計算）

> **題目出處**：[[依考科分類/05_電力系統#二-如下圖所示系統]]  
> **關聯核心考點**：[[01_標么系統與對稱成分故障分析]]

---

## 💡 核心解題思維（SOP）
1. **單線接地故障（SLG）邊界條件**：
   $$I_b = 0, \quad I_c = 0, \quad V_a = I_a Z_f$$
2. **序電流特性**：正序、負序、零序電流相等：
   $$I_{a0} = I_{a1} = I_{a2} = \frac{V_f}{Z_0 + Z_1 + Z_2 + 3Z_n + 3Z_f}$$
3. **故障相總電流**：
   $$I_f = I_a = I_{a0} + I_{a1} + I_{a2} = 3 I_{a1}$$

---

## ✍️ 詳細推導過程
1. **繪製正序、負序、零序網路**並計算故障點視入之等效阻抗 $Z_1, Z_2, Z_0$。
2. 代入故障電流公式計算 $I_{a1}$ 標么值。
3. 將標么值乘上基準電流 $I_{\text{base}} = \frac{S_{\text{base}}}{\sqrt{3} V_{\text{base}}}$ 換算為實際安培數 $\text{A}$。

---

## ⚠️ 易錯重點
- 零序網路中，變壓器接線方式（Y 接接地、不接地、Δ 接）對零序通路的影響不同！
- $3Z_n$ 與 $3Z_f$ 容易漏乘係數 $3$。
