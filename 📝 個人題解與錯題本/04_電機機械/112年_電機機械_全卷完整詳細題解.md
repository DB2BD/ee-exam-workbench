## 一、鐵心電感器電感值與最大磁通量計算（20 分）

### 📌 題目與已知條件
圖一所示的電感器，鐵心的相對導磁係數 $\mu_r = 950$，磁路平均長度 $l_c = 32\text{ cm} = 0.32\text{ m}$，磁路的平均截面積 $A_c = 20\text{ cm}^2 = 20 \times 10^{-4}\text{ m}^2 = 2 \times 10^{-3}\text{ m}^2$，繞組的匝數 $N = 70\text{ 匝}$。此電感器與 $60\ \Omega$ 的電阻器串聯後，連接至 $220\text{ V}、60\text{ Hz}$ 的單相交流電源。
* **(一)** 計算此電感器的電感值。（10 分）
* **(二)** 計算鐵心中，磁通量 $\phi$ 的最大值。（10 分）

---

### 💡 核心考點與破題關鍵
1. **磁阻與電感公式**：
   $$\mathcal{R}_c = \frac{l_c}{\mu_r \mu_0 A_c}, \quad L = \frac{N^2}{\mathcal{R}_c} = \frac{N^2 \mu_r \mu_0 A_c}{l_c}$$
2. **交流串聯電路阻抗與最大電流**：
   $$X_L = \omega L = 2\pi f L, \quad |Z| = \sqrt{R^2 + X_L^2}, \quad I_{rms} = \frac{V_s}{|Z|}, \quad I_{max} = \sqrt{2} I_{rms}$$
3. **最大磁通量**：
   $$\Phi_{max} = \frac{N I_{max}}{\mathcal{R}_c} = \frac{L I_{max}}{N}$$

---

### ✏️ 步驟式詳細數學推導

#### 🔹 (一) 計算電感值 $L$
1. 鐵心導磁係數與磁阻：
   $$\mu = \mu_r \mu_0 = 950 \times (4\pi \times 10^{-7}) = 1.1938 \times 10^{-3}\text{ H/m}$$
   $$\mathcal{R}_c = \frac{0.32\text{ m}}{(1.1938 \times 10^{-3}\text{ H/m}) \times (2 \times 10^{-3}\text{ m}^2)} = \frac{0.32}{2.3876 \times 10^{-6}} = \mathbf{134026.4\text{ A}\cdot\text{t/Wb}}$$
2. 電感值：
   $$\mathbf{L = \frac{N^2}{\mathcal{R}_c} = \frac{70^2}{134026.4} = \frac{4900}{134026.4} = \mathbf{0.03656\text{ H} = 36.56\text{ mH}}}$$

#### 🔹 (二) 計算鐵心中磁通量的最大值 $\Phi_{max}$
1. 電感感抗與總阻抗：
   $$X_L = 2\pi \times 60 \times 0.03656 = \mathbf{13.783\ \Omega}$$
   $$|Z| = \sqrt{60^2 + 13.783^2} = \sqrt{3600 + 190.0} = \sqrt{3790.0} = \mathbf{61.563\ \Omega}$$
2. 迴路電流有效值與峰值：
   $$I_{rms} = \frac{220\text{ V}}{61.563\ \Omega} = \mathbf{3.5736\text{ A}}$$
   $$I_{max} = \sqrt{2} \times 3.5736\text{ A} = \mathbf{5.0538\text{ A}}$$
3. 最大磁通量 $\Phi_{max}$：
   $$\mathbf{\Phi_{max} = \frac{N I_{max}}{\mathcal{R}_c} = \frac{70 \times 5.0538}{134026.4} = \mathbf{2.6396 \times 10^{-3}\text{ Wb} = 2.64\text{ mWb}}}$$

---

### 🎯 第一題 滿分關鍵與結論
* **電感值**：$L = \mathbf{36.56\text{ mH}}$
* **最大磁通量**：$\Phi_{max} = \mathbf{2.64\text{ mWb}}$

## 二、5000 kVA 變壓器等效電路與電壓調整率（20 分）

### 📌 題目與已知條件
一部 $5000\text{ kVA}、230\text{ kV} / 13.8\text{ kV}$ 的單相變壓器：
* 銘牌上標示電阻標么值為 $1\%$（$R_{eq,pu} = 0.01\text{ pu}$），電抗標么值為 $5\%$（$X_{eq,pu} = 0.05\text{ pu}$）。
* 在低壓側作開路試驗（Open-Circuit Test）所量測到的數據為：
  $$V_{oc} = 13.8\text{ kV}, \quad I_{oc} = 21.1\text{ A}, \quad P_{oc} = 90.8\text{ kW}$$

**試求**：
* **(一)** 繪出此變壓器參照至低壓側的等效電路圖，並求出所有的參數值。（12 分）
* **(二)** 若低壓側電壓為 $13.8\text{ kV}$，供應 $4000\text{ kW}$，功率因數 0.8 落後的負載時，計算此變壓器的電壓調整率 $\text{VR}$。（8 分）

---

### 💡 核心考點與破題關鍵
1. **低壓側基準阻抗**：
   $$Z_{base,LV} = \frac{V_{LV}^2}{S_{base}} = \frac{(13.8\text{ kV})^2}{5000\text{ kVA}} = \frac{190.44 \times 10^6}{5 \times 10^6} = 38.088\ \Omega$$
2. **參照低壓側串聯等效阻抗**：
   $$R_{eq,LV} = R_{eq,pu} \times Z_{base,LV} = 0.01 \times 38.088 = 0.38088\ \Omega$$
   $$X_{eq,LV} = X_{eq,pu} \times Z_{base,LV} = 0.05 \times 38.088 = 1.9044\ \Omega$$
3. **低壓側激磁並聯參數**：
   $$R_c = \frac{V_{oc}^2}{P_{oc}}, \quad S_{oc} = V_{oc} I_{oc}, \quad Q_{oc} = \sqrt{S_{oc}^2 - P_{oc}^2}, \quad X_m = \frac{V_{oc}^2}{Q_{oc}}$$
4. **電壓調整率（Voltage Regulation）**：
   - 負載功率 $4000\text{ kW}$，$\text{PF} = 0.8 \implies S = \frac{4000}{0.8} = 5000\text{ kVA}$（剛好為額定滿載 $1.0\text{ pu}$！）。

---

### ✏️ 步驟式詳細數學推導

#### 🔹 (一) 參照至低壓側等效電路參數
1. **串聯等效電阻與電抗**：
   - 基準阻抗：$Z_{base,LV} = \frac{13800^2}{5000000} = \mathbf{38.088\ \Omega}$
   - 串聯等效電阻：$\mathbf{R_{eq} = 0.01 \times 38.088 = \mathbf{0.3809\ \Omega}}$
   - 串聯等效電抗：$\mathbf{X_{eq} = 0.05 \times 38.088 = \mathbf{1.9044\ \Omega}}$
2. **並聯激磁支路參數（由低壓側 OC 試驗求得）**：
   - 鐵損電阻：
     $$\mathbf{R_c = \frac{V_{oc}^2}{P_{oc}} = \frac{(13800\text{ V})^2}{90800\text{ W}} = \frac{190.44 \times 10^6}{90800} = \mathbf{2097.36\ \Omega}}$$
   - 視在功率與虛功率：
     $$S_{oc} = 13800\text{ V} \times 21.1\text{ A} = 291180\text{ VA} = 291.18\text{ kVA}$$
     $$Q_{oc} = \sqrt{S_{oc}^2 - P_{oc}^2} = \sqrt{291.18^2 - 90.8^2} = \sqrt{84785.8 - 8244.6} = \sqrt{76541.2} = 276.66\text{ kVAR}$$
   - 激磁電抗：
     $$\mathbf{X_m = \frac{V_{oc}^2}{Q_{oc}} = \frac{190.44 \times 10^6\text{ V}^2}{276660\text{ VAR}} = \mathbf{688.39\ \Omega}}$$

#### 🔹 (二) 計算電壓調整率 $\text{VR}$
1. **負載電流**：
   $$I_L = \frac{4000\text{ kW}}{13.8\text{ kV} \times 0.8} = \frac{4000}{11.04} = \mathbf{362.32\text{ A}} \quad (\text{剛好等於額定電流 } I_{rated} = \frac{5000}{13.8} = 362.32\text{ A})$$
2. **精確一次側折算電壓 $V_1'$**：
   $$\mathbf{V}_1' = V_2 + \mathbf{I}_L (R_{eq} + jX_{eq}) = 13800\angle 0^\circ + (362.32\angle -36.87^\circ)(0.3809 + j1.9044)$$
   $$I_L (R_{eq}\cos\theta + X_{eq}\sin\theta) = 362.32 \times (0.3809 \times 0.8 + 1.9044 \times 0.6) = 362.32 \times (0.3047 + 1.1426) = \mathbf{524.4\text{ V}}$$
   $$I_L (X_{eq}\cos\theta - R_{eq}\sin\theta) = 362.32 \times (1.9044 \times 0.8 - 0.3809 \times 0.6) = 362.32 \times (1.5235 - 0.2285) = \mathbf{469.2\text{ V}}$$
   $$V_1' = \sqrt{(13800 + 524.4)^2 + 469.2^2} = \sqrt{14324.4^2 + 469.2^2} = \sqrt{205188535 + 220149} = \mathbf{14332.1\text{ V}}$$
3. **電壓調整率**：
   $$\mathbf{VR = \frac{V_1' - V_2}{V_2} \times 100\% = \frac{14332.1 - 13800}{13800} \times 100\% = \frac{532.1}{13800} \times 100\% = \mathbf{3.86\%}}$$
   *(利用標么值近似式：$\text{VR} \approx R_{pu}\cos\theta + X_{pu}\sin\theta = 0.01(0.8) + 0.05(0.6) = 0.008 + 0.030 = \mathbf{3.80\%}$)*

---

### 🎯 第二題 滿分關鍵與結論
* **等效電路參數（低壓側）**：$R_{eq} = \mathbf{0.3809\ \Omega}, \ X_{eq} = \mathbf{1.9044\ \Omega}, \ R_c = \mathbf{2097.4\ \Omega}, \ X_m = \mathbf{688.4\ \Omega}$
* **電壓調整率**：$\text{VR} = \mathbf{3.86\%}$（近似值 $3.80\%$）

## 三、三相同步電動機相量與超前功因激磁電流（20 分）

### 📌 題目與已知條件
額定 $25\text{ hp}、208\text{ V}、60\text{ Hz}、\text{Y}$ 接之三相同步電動機：
* 每相同步電抗 $X_s = 1.6\ \Omega$，一切損失均可忽略。
* 工作在某一負載下，調整其激磁電流為 $2.7\text{ A}$ 時，電動機從電源汲取 $50\text{ A}$ 的電流，功率因數恰為 $1.0$。
* **(一)** 求此操作條件下，每相內部生成電壓 $\mathbf{E}_A$ 之大小及轉矩角 $\delta$。（10 分）
* **(二)** 若機械負載不變，欲使此電動機運轉於功率因數 0.8 超前，求新的激磁電流值。（10 分）

---

### 💡 核心考點與破題關鍵
1. **單位功因（$\text{PF} = 1.0$）相量關係**：
   $$V_\phi = \frac{208}{\sqrt{3}} \approx 120.091\text{ V}, \quad \mathbf{E}_{A1} = V_\phi - jX_s \mathbf{I}_{a1} = 120.091 - j(1.6 \times 50) = 120.091 - j80\text{ V}$$
2. **負載功率不變與超前功因運轉**：
   - 實功率恆定：$P = 3 V_\phi I_{a1} \cos\theta_1 = 3 V_\phi I_{a2} \cos\theta_2 \implies I_{a2} = \frac{I_{a1} \cos\theta_1}{\cos\theta_2} = \frac{50}{0.8} = 62.5\text{ A}$。
   - 超前功因電流相量：$\mathbf{I}_{a2} = 62.5\angle +36.87^\circ = 50 + j37.5\text{ A}$。
   - 新內生電壓：$\mathbf{E}_{A2} = V_\phi - jX_s \mathbf{I}_{a2}$。
3. **激磁電流正比於內生電壓大小（線性磁化假設）**：
   $$\frac{I_{f2}}{I_{f1}} = \frac{|\mathbf{E}_{A2}|}{|\mathbf{E}_{A1}|}$$

---

### ✏️ 步驟式詳細數學推導

#### 🔹 (一) 求解原始狀態之 $\mathbf{E}_A$ 與轉矩角 $\delta$
1. 每相端電壓：
   $$V_\phi = \frac{208}{\sqrt{3}} = 120.091\text{ V}$$
2. 內生電壓相量（$\mathbf{I}_{a1} = 50\angle 0^\circ\text{ A}$）：
   $$\mathbf{E}_{A1} = 120.091 - j(1.6 \times 50) = \mathbf{120.091 - j80.0\text{ V}}$$
   $$|\mathbf{E}_{A1}| = \sqrt{120.091^2 + 80.0^2} = \sqrt{14421.85 + 6400} = \sqrt{20821.85} = \mathbf{144.30\text{ V/相}}$$
3. 轉矩角 $\delta_1$：
   $$\mathbf{\delta_1 = \tan^{-1}\left( \frac{-80.0}{120.091} \right) = \mathbf{-33.69^\circ}}$$

#### 🔹 (二) 機械負載不變，$\text{PF} = 0.8\text{ 超前}$ 之新激磁電流
1. 新電樞電流：
   $$I_{a2} = \frac{P}{3 V_\phi \cos\theta_2} = \frac{3 \times 120.091 \times 50 \times 1.0}{3 \times 120.091 \times 0.8} = \frac{50}{0.8} = \mathbf{62.5\text{ A}}$$
   $$\mathbf{I}_{a2} = 62.5\angle +36.87^\circ = 62.5(0.8 + j0.6) = \mathbf{50.0 + j37.5\text{ A}}$$
2. 新內生電壓 $\mathbf{E}_{A2}$：
   $$\mathbf{E}_{A2} = V_\phi - jX_s \mathbf{I}_{a2} = 120.091 - j1.6 \times (50.0 + j37.5) = 120.091 - j80.0 + 60.0$$
   $$\mathbf{E}_{A2} = \mathbf{180.091 - j80.0\text{ V}}$$
   $$|\mathbf{E}_{A2}| = \sqrt{180.091^2 + 80.0^2} = \sqrt{32432.8 + 6400} = \sqrt{38832.8} = \mathbf{197.06\text{ V/相}}$$
3. 計算新激磁電流 $I_{f2}$：
   $$\mathbf{I_{f2} = I_{f1} \times \frac{|\mathbf{E}_{A2}|}{|\mathbf{E}_{A1}|} = 2.7\text{ A} \times \frac{197.06\text{ V}}{144.30\text{ V}} = 2.7 \times 1.3656 = \mathbf{3.687\text{ A} \approx 3.69\text{ A}}}$$

---

### 🎯 第三題 滿分關鍵與結論
* **(一) 原始運轉**：$E_A = \mathbf{144.30\text{ V/相}}, \ \delta = \mathbf{-33.69^\circ}$
* **(二) 超前運轉激磁電流**：$I_{f2} = \mathbf{3.69\text{ A}}$（內生電壓增至 $197.06\text{ V}$）

## 四、三相感應馬達並聯電容器降啟動電流設計（20 分）

### 📌 題目與已知條件
額定 $35\text{ hp}、380\text{ V}、60\text{ Hz}、\text{Y}$ 接之三相感應電動機：
* 以 $380\text{ V}$ 全壓啟動時，啟動電流 $I_{st} = 330\text{ A}$，功率因數 $PF_{st} = 0.51\text{ 落後}$。
* 若欲降低此電動機之啟動電源線電流至 $200\text{ A}$（落後），於啟動時並聯一組 $\Delta$ 接的電容器如圖二所示。

**試求**：計算每相電容 $C_\Delta$ 之值。（20 分）

---

### 💡 核心考點與破題關鍵
1. **馬達啟動電流相量分解**：
   - 阻抗角 $\theta_{st} = \cos^{-1}(0.51) = 59.336^\circ \implies \sin\theta_{st} = 0.86017$。
   - 馬達啟動電流：$\mathbf{I}_{motor} = 330(0.51 - j0.86017) = \mathbf{168.30 - j283.86\text{ A}}$。
2. **並聯電容器補償無效電流**：
   - 電容器線電流為純超前無效電流：$\mathbf{I}_{C,line} = +j I_{C,line}$。
   - 電源側總線電流：$\mathbf{I}_{total} = 168.30 + j(-283.86 + I_{C,line})$。
   - 總線電流大小限制為 $200\text{ A}$：
     $$\sqrt{168.30^2 + (-283.86 + I_{C,line})^2} = 200$$
3. **$\Delta$ 接電容器電容量計算**：
   $$I_{C,phase} = \frac{I_{C,line}}{\sqrt{3}}, \quad I_{C,phase} = \frac{V_L}{X_{C\Delta}} = V_L \cdot (2\pi f C_\Delta) \implies C_\Delta = \frac{I_{C,line}}{\sqrt{3} \omega V_L}$$

---

### ✏️ 步驟式詳細數學推導
1. **求解所需電容器組總線電流 $I_{C,line}$**：
   $$168.30^2 + (-283.86 + I_{C,line})^2 = 200^2 = 40000$$
   $$28324.89 + (-283.86 + I_{C,line})^2 = 40000$$
   $$(-283.86 + I_{C,line})^2 = 40000 - 28324.89 = 11675.11$$
   $$-283.86 + I_{C,line} = -\sqrt{11675.11} = -108.051\text{ A} \quad (\text{因總電流仍為落後})$$
   $$\mathbf{I_{C,line} = 283.86 - 108.051 = \mathbf{175.81\text{ A}}}$$
2. **計算 $\Delta$ 接單相電容量 $C_\Delta$**：
   $$\mathbf{C_\Delta = \frac{I_{C,line}}{\sqrt{3} \times (2\pi \times 60) \times V_L} = \frac{175.81\text{ A}}{\sqrt{3} \times 376.991 \times 380\text{ V}} = \frac{175.81}{248107.5} = \mathbf{7.086 \times 10^{-4}\text{ F} = \mathbf{708.6\ \mu\text{F}}}}$$

---

### 🎯 第四題 滿分關鍵與結論
* **電容器提供之無效線電流**：$I_{C,line} = \mathbf{175.81\text{ A}}$
* **每相 $\Delta$ 接電容量**：$\mathbf{C_\Delta = 708.6\ \mu\text{F}}$

## 五、直流並激電動機磁化曲線與電樞反應去磁（20 分）

### 📌 題目與已知條件
額定 $50\text{ 馬力}、250\text{ V}、1200\text{ rpm}$ 的直流並激電動機（DC shunt motor）：
* 電樞電阻 $R_a = 0.12\ \Omega$，可調式場電阻 $R_f = 50\ \Omega$。
* 無載轉速 $n_0 = 1200\text{ rpm}$，無載時電樞電流為零。
* 並激磁場繞組每極為 $N_f = 1000\text{ 匝}$。
* 電樞反應在輸入電流 $I_L = 150\text{ A}$ 時產生 $1500\text{ 安-匝}$（$\text{A}\cdot\text{t}$）的去磁磁動勢。
* 此電動機在固定轉速 $1200\text{ rpm}$ 時的磁化曲線如圖四所示（$I_f = 3.5\text{ A}$ 時 $E_a \approx 200\text{ V}$）。

**試求**：考慮磁飽和及電樞反應，計算輸入電流 $I_L = 150\text{ A}$ 時，電動機之有效磁場電流 $I_{f,eff}$、轉速 $n$ 及轉矩 $T$。（20 分）

---

### 💡 核心考點與破題關鍵
1. **分激場電流與電樞電流**：
   $$I_f = \frac{V_t}{R_f} = \frac{250\text{ V}}{50\ \Omega} = 5.0\text{ A}, \quad I_a = I_L - I_f = 150 - 5.0 = 145.0\text{ A}$$
2. **有效磁場電流（考慮電樞反應去磁）**：
   $$\mathcal{F}_{net} = N_f I_f - \mathcal{F}_{ar} = 1000 \times 5.0 - 1500 = 3500\text{ A}\cdot\text{t} \implies I_{f,eff} = \frac{\mathcal{F}_{net}}{N_f} = \frac{3500}{1000} = 3.5\text{ A}$$
3. **查磁化曲線求 $1200\text{ rpm}$ 下之基準反電動勢 $E_{a0}$ 並求實際轉速**：
   $$n = 1200 \times \frac{E_a}{E_{a0}}$$

### ✏️ 步驟式詳細數學推導
1. **計算實際電樞反電動勢 $E_a$**：
   $$\mathbf{E_a = V_t - I_a R_a = 250 - 145.0 \times 0.12 = 250 - 17.4 = \mathbf{232.6\text{ V}}}$$
2. **計算有效磁場電流 $I_{f,eff}$**：
   - 場電流：$I_f = \frac{250}{50} = 5.0\text{ A}$
   - 淨磁動勢：$\mathcal{F}_{net} = 1000(5.0) - 1500 = 3500\text{ A}\cdot\text{t}$
   - **有效磁場電流**：
     $$\mathbf{I_{f,eff} = \frac{3500\text{ A}\cdot\text{t}}{1000\text{ 匝}} = \mathbf{3.50\text{ A}}}$$
3. **由圖四磁化曲線查得 $1200\text{ rpm}$ 下之內生電壓**：
   - 當 $I_f = 3.5\text{ A}$ 時，查圖四磁化曲線對應電壓 $E_{a0} = \mathbf{200.0\text{ V}}$。
4. **計算負載轉速 $n$**：
   $$\mathbf{n = n_0 \times \frac{E_a}{E_{a0}} = 1200\text{ rpm} \times \frac{232.6\text{ V}}{200.0\text{ V}} = \mathbf{1395.6\text{ rpm} \approx 1396\text{ rpm}}}$$
5. **計算電磁轉矩 $T$**：
   - 機械角速度：$\omega = \frac{2\pi \times 1395.6}{60} = \mathbf{146.147\text{ rad/s}}$
   - 電磁功率：$P_{dev} = E_a I_a = 232.6\text{ V} \times 145.0\text{ A} = \mathbf{33727\text{ W}}$
   - 輸出轉矩：
     $$\mathbf{T = \frac{P_{dev}}{\omega} = \frac{33727\text{ W}}{146.147\text{ rad/s}} = \mathbf{230.77\text{ N}\cdot\text{m}}}$$

> ⚠️ **電機機械 核心防坑與閱卷踩雷提醒**：
> 1. **變壓器阻抗折合**：低壓側折合至高壓側乘以變比平方 $a^2$；自耦變壓器共用繞組電流為高低壓側電流之差值。
> 2. **感應機最大轉矩**：最大轉矩 $T_{max}$ 與轉子電阻 $R_2$ 無關，但產生最大轉矩之轉差率 $s_{max}$ 與 $R_2$ 成正比。
> 3. **同步機相量計算**：同步電動機 $\mathbf{E}_f = \mathbf{V}_\phi - \mathbf{I}_a \mathbf{Z}_s$；同步發電機 $\mathbf{E}_f = \mathbf{V}_\phi + \mathbf{I}_a \mathbf{Z}_s$。
