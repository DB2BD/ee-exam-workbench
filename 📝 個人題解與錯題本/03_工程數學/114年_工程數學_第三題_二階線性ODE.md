# 📌 114 年 工程數學 — 第三題（二階常係數齊次線性 ODE 初始值問題）

> **題目出處**：[[依考科分類/03_工程數學#三-求解以下初始值問題之常微分方程式]]  
> **關聯核心考點**：[[01_常微分方程ODE與尤拉柯西方程]]

---

## 💡 核心解題思維（SOP）
1. 觀察為二階常係數齊次線性常微分方程式：$y'' + 4y' + 4y = 0$。
2. 列寫特徵方程式 $\lambda^2 + 4\lambda + 4 = 0$ 求解特徵根。
3. 判斷為**重根情況**，通解為 $y(t) = (c_1 + c_2 t) e^{\lambda t}$。
4. 代入初始條件 $y(0) = 1$ 與 $y'(0) = 3$ 求解常數 $c_1, c_2$。

---

## ✍️ 詳細推導過程
### 步驟 1：求解特徵根
$$\lambda^2 + 4\lambda + 4 = (\lambda + 2)^2 = 0 \implies \lambda_{1,2} = -2 \quad (\text{二重實根})$$

### 步驟 2：寫出齊次通解
$$y(t) = (c_1 + c_2 t) e^{-2t}$$

### 步驟 3：對 $t$ 微分求一階導數 $y'(t)$
$$y'(t) = c_2 e^{-2t} - 2(c_1 + c_2 t) e^{-2t} = [c_2 - 2c_1 - 2c_2 t] e^{-2t}$$

### 步驟 4：代入初始條件
- $y(0) = c_1 = 1$
- $y'(0) = c_2 - 2c_1 = 3 \implies c_2 - 2(1) = 3 \implies c_2 = 5$

### 步驟 5：寫出特解
$$y(t) = (1 + 5t) e^{-2t}$$
