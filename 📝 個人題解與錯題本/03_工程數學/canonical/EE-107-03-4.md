# 107 年第 4 題｜分段函數傅立葉級數

題目函數以 \(2\pi\) 為週期，且
\[
f(x)=
\begin{cases}
0,&-\pi<x<0,\\
\sin x,&0\le x<\pi.
\end{cases}
\]
採用 \(f\sim a_0/2+\sum_{n\ge1}(a_n\cos nx+b_n\sin nx)\) 的慣例。因函數只在 \((0,\pi)\) 非零，
\[
a_0=\frac1\pi\int_0^\pi\sin x\,dx=\frac2\pi,
\qquad
b_n=\frac1\pi\int_0^\pi\sin x\sin(nx)\,dx
=\begin{cases}\frac12,&n=1,\\0,&n\ne1.
\end{cases}
\]
再由 \(sin x\cos nx=\tfrac12[\sin((n+1)x)-\sin((n-1)x)]\)，得
\[
a_n=\frac1\pi\int_0^\pi\sin x\cos(nx)\,dx
=\begin{cases}
-\dfrac{2}{\pi(n^2-1)},&n\text{ 為偶數},\\
0,&n\text{ 為奇數}.
\end{cases}
\]
因此
\[
\boxed{
f(x)=\frac1\pi+\frac12\sin x
-\frac2\pi\sum_{k=1}^{\infty}\frac{\cos(2kx)}{4k^2-1}}
\]
（在跳躍點取左右極限平均值）。代回係數積分可得 \(a_0=2/\pi\)、(b_1=1/2)，其餘如上，與週期延拓一致。
