## 一、電阻組合電路 $\Delta-\text{Y}$ 轉換與電源總功率（25 分）

### 📌 題目與已知條件
考慮如圖(一)之電阻組合電路：
* 直流獨立電壓源 $E = 120\text{ V}$。
* 串聯電阻 $R_s = 5\text{ k}\Omega$。
* 橋式網路包含：左上 $6\text{ k}\Omega$、右上 $18\text{ k}\Omega$、中間橫向 $12\text{ k}\Omega$、左下 $4\text{ k}\Omega$、右下 $6\text{ k}\Omega$。

**試求**：直流電源端（$120\text{ V}$）所產生的總功率值。（25 分）

---

### 💡 核心考點與破題關鍵
1. **不平衡橋式電路 $\Delta \to \text{Y}$ 阻抗轉換**：
   - 頂部三角形 $\Delta$（由 $6\text{ k}\Omega, 18\text{ k}\Omega, 12\text{ k}\Omega$ 組成）：
     $$\sum R_\Delta = 6\text{ k}\Omega + 18\text{ k}\Omega + 12\text{ k}\Omega = 36\text{ k}\Omega$$
     $$R_T = \frac{6 \times 18}{36} = 3\text{ k}\Omega, \quad R_L = \frac{6 \times 12}{36} = 2\text{ k}\Omega, \quad R_R = \frac{18 \times 12}{36} = 6\text{ k}\Omega$$
2. **中性點向下串並聯化簡**：
   - 左支路：$R_L + 4\text{ k}\Omega = 2 + 4 = 6\text{ k}\Omega$
   - 右支路：$R_R + 6\text{ k}\Omega = 6 + 6 = 12\text{ k}\Omega$
   - 兩支路並聯：$R_p = 6\text{ k}\Omega \parallel 12\text{ k}\Omega = \frac{6 \times 12}{6 + 12} = 4\text{ k}\Omega$
   - 橋式網路等效電阻：$R_{bridge} = R_T + R_p = 3 + 4 = 7\text{ k}\Omega$
3. **電源總負載與產生功率**：
   $$R_{eq} = 5\text{ k}\Omega + R_{bridge} = 5 + 7 = 12\text{ k}\Omega \implies P = \frac{E^2}{R_{eq}}$$

---

### ✏️ 步驟式詳細數學推導
1. **$\Delta \to \text{Y}$ 轉換**：
   $$\mathbf{R_T = \frac{6\text{ k}\Omega \times 18\text{ k}\Omega}{36\text{ k}\Omega} = \mathbf{3\text{ k}\Omega}}$$
   $$\mathbf{R_L = \frac{6\text{ k}\Omega \times 12\text{ k}\Omega}{36\text{ k}\Omega} = \mathbf{2\text{ k}\Omega}}$$
   $$\mathbf{R_R = \frac{18\text{ k}\Omega \times 12\text{ k}\Omega}{36\text{ k}\Omega} = \mathbf{6\text{ k}\Omega}}$$
2. **計算橋式網路等效阻抗 $R_{bridge}$**：
   $$\mathbf{R_{bridge} = R_T + [(R_L + 4\text{ k}\Omega) \parallel (R_R + 6\text{ k}\Omega)]}$$
   $$\mathbf{R_{bridge} = 3\text{ k}\Omega + [6\text{ k}\Omega \parallel 12\text{ k}\Omega] = 3\text{ k}\Omega + 4\text{ k}\Omega = \mathbf{7\text{ k}\Omega}}$$
3. **計算電源端總等效電阻與輸出功率**：
   $$\mathbf{R_{total} = R_s + R_{bridge} = 5\text{ k}\Omega + 7\text{ k}\Omega = \mathbf{12\text{ k}\Omega = 12000\ \Omega}}$$
   - 電源端總電流：
     $$I_{total} = \frac{E}{R_{total}} = \frac{120\text{ V}}{12000\ \Omega} = \mathbf{10\text{ mA} = 0.01\text{ A}}$$
   - 電源產生之總功率：
     $$\mathbf{P = E \times I_{total} = \frac{E^2}{R_{total}} = \frac{120^2}{12000} = \frac{14400}{12000} = \mathbf{1.20\text{ W}}}$$

---

### 🎯 第一題 滿分關鍵與結論
* **總等效電阻**：$R_{total} = \mathbf{12\text{ k}\Omega}$
* **電源產生總功率**：$P = \mathbf{1.20\text{ W}}$

## 二、交流互感電路相量與負載平均功率（25 分）

### 📌 題目與已知條件
交流電路如圖(二)所示：
* 電源電壓 $v_g(t) = 660\cos(5000t)\text{ V}$（角頻率 $\omega = 5000\text{ rad/s}$）。
* 一次側電阻 $R_1 = 34\ \Omega$，一次側電感 $L_1 = 10\text{ mH}$（同名端在上方）。
* 二次側電感 $L_2 = 20\text{ mH}$（同名端在下方），互感 $M = 8\text{ mH}$。
* 二次側負載電阻 $R_L = 100\ \Omega$。

**試求**：輸送到 $100\ \Omega$ 電阻之平均功率。（25 分）

---

### 💡 核心考點與破題關鍵
1. **各感抗計算（$\omega = 5000\text{ rad/s}$）**：
   $$\omega L_1 = 5000 \times 10 \times 10^{-3} = 50\ \Omega, \quad \omega L_2 = 5000 \times 20 \times 10^{-3} = 100\ \Omega, \quad \omega M = 5000 \times 8 \times 10^{-3} = 40\ \Omega$$
2. **反映阻抗法（Reflected Impedance）**：
   - 二次側總阻抗：$\mathbf{Z}_{22} = R_L + j\omega L_2 = 100 + j100\ \Omega$
   - 反映阻抗：$\mathbf{Z}_r = \frac{(\omega M)^2}{\mathbf{Z}_{22}} = \frac{40^2}{100 + j100} = 8 - j8\ \Omega$
3. **負載平均功率**：$P_L = I_{2,rms}^2 R_L = \frac{1}{2} I_{2,peak}^2 R_L$。

---

### ✏️ 步驟式詳細數學推導
1. **一次側等效輸入阻抗 $\mathbf{Z}_{in}$**：
   $$\mathbf{Z}_r = \frac{1600}{100 + j100} = \frac{1600(100 - j100)}{100^2 + 100^2} = \frac{160000 - j160000}{20000} = \mathbf{8 - j8\ \Omega}$$
   $$\mathbf{Z}_{in} = R_1 + j\omega L_1 + \mathbf{Z}_r = 34 + j50 + (8 - j8) = \mathbf{42 + j42\ \Omega} = \mathbf{42\sqrt{2}\angle 45^\circ\ \Omega \approx 59.40\angle 45^\circ\ \Omega}$$
2. **求解一次側電流 $\mathbf{I}_1$（峰值相量）**：
   $$\mathbf{I}_1 = \frac{\mathbf{V}_g}{\mathbf{Z}_{in}} = \frac{660\angle 0^\circ}{42\sqrt{2}\angle 45^\circ} = \frac{660}{59.397}\angle -45^\circ = \mathbf{11.112\angle -45^\circ\text{ A}}$$
3. **求解二次側電流 $\mathbf{I}_2$（峰值相量）**：
   $$|\mathbf{I}_2| = \frac{\omega M \cdot |\mathbf{I}_1|}{|\mathbf{Z}_{22}|} = \frac{40 \times 11.1118}{\sqrt{100^2 + 100^2}} = \frac{444.47}{100\sqrt{2}} = \mathbf{3.1427\text{ A}}$$
   - 電流有效值：$I_{2,rms} = \frac{3.1427}{\sqrt{2}} = \mathbf{2.2222\text{ A}}$
4. **計算 $100\ \Omega$ 負載電阻之平均功率**：
   $$\mathbf{P_L = I_{2,rms}^2 \times R_L = (2.2222\text{ A})^2 \times 100\ \Omega = 4.9383 \times 100 = \mathbf{493.83\text{ W}}}$$

---

### 🎯 第二題 滿分關鍵與結論
* **一次側電流**：$I_{1,rms} = \mathbf{7.857\text{ A}}$（峰值 $11.11\text{ A}$）
* **二次側電流**：$I_{2,rms} = \mathbf{2.222\text{ A}}$（峰值 $3.143\text{ A}$）
* **負載平均功率**：$P_L = \mathbf{493.83\text{ W}}$

## 三、含相依源（CCVS）電路之諾頓等效（25 分）

### 📌 題目與已知條件
考慮如圖(三)之電路：
* 電阻 $R_1 = R_2 = R_3 = 10\ \Omega$。
* 流控電壓源（CCVS）之轉換電阻 $r = 5\ \Omega$，受控電壓源極性為左負右正（$- \ +$），數值為 $r i_x = 5 i_x$。
* 施加直流電壓 $v_s = 8\text{ V}$。控制電流 $i_x$ 為流經 $R_1$ 之電流。

**試求**：繪出由負載 $R_L$ 端所看到的諾頓（Norton）等效電路。（25 分）

---

### 💡 核心考點與破題關鍵
1. **開路電壓 $V_{oc}$（戴維寧電壓）**：
   - 令 $R_L$ 斷開，設節點 1 電壓為 $v_1$，開路端點電壓為 $v_2 = V_{oc}$。
   - $i_x = \frac{v_s - v_1}{R_1} = \frac{8 - v_1}{10}$。
   - $v_2 = v_1 + 5 i_x = v_1 + 0.5(8 - v_1) = 0.5 v_1 + 4$。
   - 在節點 1 列 KCL 求解 $v_1$ 與 $V_{oc}$。
2. **短路電流 $I_{sc}$（諾頓電流 $I_N$）**：
   - 將 $R_L$ 兩端短路（$v_2 = 0$），求解流出短路端之電流 $I_{sc}$。
3. **諾頓等效電阻**：$R_N = \frac{V_{oc}}{I_{sc}}$。

---

### ✏️ 步驟式詳細數學推導

#### 🔹 (1) 求解開路電壓 $V_{oc}$
1. 斷開 $R_L$ 時，流過 $R_3$ 之電流等於流經 CCVS 之電流：
   $$i_{CCVS} = \frac{v_2}{R_3} = \frac{v_2}{10}$$
2. 節點 1 之 KCL：
   $$i_x = \frac{v_1}{R_2} + i_{CCVS} \implies \frac{8 - v_1}{10} = \frac{v_1}{10} + \frac{v_2}{10}$$
   $$8 - v_1 = v_1 + v_2 \implies 2 v_1 + v_2 = 8$$
3. 代入 CCVS 關係式 $v_2 = 0.5 v_1 + 4$：
   $$2 v_1 + (0.5 v_1 + 4) = 8 \implies 2.5 v_1 = 4 \implies \mathbf{v_1 = 1.6\text{ V}}$$
   $$\mathbf{V_{oc} = v_2 = 0.5(1.6) + 4 = \mathbf{4.8\text{ V}}}$$
   $$i_x = \frac{8 - 1.6}{10} = 0.64\text{ A}$$

#### 🔹 (2) 求解短路電流 $I_{sc}$（$I_N$）
1. 將負載端短路 $\implies v_2 = 0\text{ V}$。
2. 由 $v_2 = v_1 + 5 i_x = 0 \implies v_1 + 5 \left(\frac{8 - v_1}{10}\right) = 0$：
   $$v_1 + 4 - 0.5 v_1 = 0 \implies 0.5 v_1 = -4 \implies \mathbf{v_1 = -8\text{ V}}$$
3. 控制電流：
   $$i_x = \frac{8 - (-8)}{10} = \frac{16}{10} = \mathbf{1.6\text{ A}}$$
4. 短路電流（等於流經 CCVS 之電流，因 $R_3$ 兩端跨壓為 0，電流為 0）：
   $$\mathbf{I_{sc} = i_x - \frac{v_1}{R_2} = 1.6\text{ A} - \left(\frac{-8\text{ V}}{10\ \Omega}\right) = 1.6 + 0.8 = \mathbf{2.4\text{ A}}}$$

#### 🔹 (3) 求解諾頓等效電阻 $R_N$
$$\mathbf{R_N = \frac{V_{oc}}{I_{sc}} = \frac{4.8\text{ V}}{2.4\text{ A}} = \mathbf{2.0\ \Omega}}$$

---

### 🎯 第三題 滿分關鍵與結論
* **諾頓等效電流源**：$I_N = \mathbf{2.4\text{ A}}$（方向朝向負載端流出）
* **諾頓等效並聯電阻**：$R_N = \mathbf{2.0\ \Omega}$
* **（等效戴維寧參數）**：$V_{th} = 4.8\text{ V}, R_{th} = 2.0\ \Omega$

## 四、二階並聯 RLC 電路過阻尼暫態響應（25 分）

### 📌 題目與已知條件
考慮如圖(四)之電路：
* 激勵電流源：左側向上 $-3u(t)\text{ A}$，右側向下 $3u(t)\text{ A}$。
* 並聯元件：電感 $L = 0.2\text{ H}$，電容 $C = 20\text{ mF} = 0.02\text{ F}$，電阻 $R = 0.5\ \Omega$。
* 初值條件：電容與電感之初始值均為 0（$v(0^-) = 0\text{ V}, i(0^-) = 0\text{ A}$）。

**試求**：分別求其電感電流 $i(t)$ 與電容電壓 $v(t)$（$t > 0$）。（25 分）

---

### 💡 核心考點與破題關鍵
1. **並聯節點總激勵電流**：
   - 注入並聯上節點之總電流：$i_s(t) = -3u(t) - 3u(t) = -6u(t)\text{ A}$。
2. **二階並聯 RLC 特徵參數**：
   $$\alpha = \frac{1}{2RC} = \frac{1}{2 \times 0.5 \times 0.02} = 50\text{ rad/s}$$
   $$\omega_0^2 = \frac{1}{LC} = \frac{1}{0.2 \times 0.02} = 250 \implies \omega_0 = \sqrt{250} \approx 15.811\text{ rad/s}$$
   - 因 $\alpha = 50 > \omega_0 = 15.811 \implies$ **過阻尼響應（Overdamped）**。
3. **特徵根**：
   $$s_{1,2} = -\alpha \pm \sqrt{\alpha^2 - \omega_0^2} = -50 \pm \sqrt{2500 - 250} = -50 \pm \sqrt{2250} \approx -50 \pm 47.434$$
   $$s_1 = -2.566\text{ s}^{-1}, \quad s_2 = -97.434\text{ s}^{-1}$$

---

### ✏️ 步驟式詳細數學推導
1. **穩態特解（$t \to \infty$）**：
   - 直流穩態下電感視為短路，電容視為開路：
     $$\mathbf{i(\infty) = -6\text{ A}, \quad v(\infty) = 0\text{ V}}$$
2. **通解結構（以電感電流 $i(t)$ 為主變數）**：
   $$i(t) = i(\infty) + A_1 e^{s_1 t} + A_2 e^{s_2 t} = -6 + A_1 e^{-2.566 t} + A_2 e^{-97.434 t}$$
3. **初始條件代入求係數**：
   - 初值 $i(0^+) = i(0^-) = 0$：
     $$0 = -6 + A_1 + A_2 \implies A_1 + A_2 = 6$$
   - 初值電壓 $v(0^+) = v(0^-) = 0\text{ V}$：
     $$v(0^+) = L \left.\frac{di}{dt}\right|_{t=0^+} = 0 \implies s_1 A_1 + s_2 A_2 = 0 \implies -2.566 A_1 - 97.434 A_2 = 0$$
     $$A_1 = -\frac{s_2}{s_1} A_2 = -\frac{-97.434}{-2.566} A_2 = -37.97 A_2$$
   - 解聯立方程：
     - $37.97 A_2 + A_2 = 6 \implies -36.97 A_2 = 6 \implies \mathbf{A_2 \approx -0.1623}$
     $$\mathbf{A_1 = 6 - (-0.1623) \approx 6.1623}$$
4. **電感電流 $i(t)$ 表達式**：
   $$\mathbf{i(t) = \left[ -6 + 6.1623 e^{-2.566 t} - 0.1623 e^{-97.434 t} \right] u(t)\text{ A}}$$
5. **電容電壓 $v(t) = L \frac{di}{dt}$**：
   $$v(t) = 0.2 \times \left[ 6.1623(-2.566) e^{-2.566 t} - 0.1623(-97.434) e^{-97.434 t} \right]$$
   $$v(t) = 0.2 \times \left[ -15.812 e^{-2.566 t} + 15.814 e^{-97.434 t} \right]$$
   $$\mathbf{v(t) = \left[ -3.162 e^{-2.566 t} + 3.163 e^{-97.434 t} \right] u(t)\text{ V} = \mathbf{3.162 \left( e^{-97.434 t} - e^{-2.566 t} \right) u(t)\text{ V}}}$$

---

> [!WARNING]
> ⚠️ **電路學 核心防坑與閱卷踩雷提醒**：
> 1. **複數功率共軛**：$\mathbf{S} = \mathbf{V}\mathbf{I}^* = P + jQ$，電流 $\mathbf{I}$ 務必取共軛，電感性負載 $Q > 0$（落後），電容性負載 $Q < 0$（超前）。
> 2. **三相功率計算**：三相總功率公式 $P = \sqrt{3}V_L I_L \cos\theta = 3V_\phi I_\phi \cos\theta$，代入線電壓時必有 $\sqrt{3}$。
> 3. **一階暫態連續性**：電感電流 $i_L(0^+) = i_L(0^-)$ 與電容電壓 $v_C(0^+) = v_C(0^-)$ 不可突變。

---


### 🎯 第四題 滿分關鍵與結論
* **電感電流**：$i(t) = \mathbf{\left[ -6 + 6.162 e^{-2.566 t} - 0.162 e^{-97.434 t} \right] u(t)\text{ A}}$
* **電容電壓**：$v(t) = \mathbf{3.162 \left( e^{-97.434 t} - e^{-2.566 t} \right) u(t)\text{ V}}$
