# 111 年電路學逐題詳解

> 本檔四題均以考選部官方 PDF、逐題裁切及電路圖裁切為準。相量採峰值表示；電流若算得負值，代表實際方向與題圖箭頭相反。

## 一、串並聯等效與電流控制電流源

**題目重述：**依官方電路圖 (a) 與等效電路圖 (b)，判斷圓形與菱形電源種類；計算 `v_1`、`i_2`、`i_a`、`i_b`，以及 `R_a`、`R_b`、`v_a`、`i_1`。

原題與電路圖：[官方原題裁切](../../../依考科分類/🏛️_國考同級參考題庫/01_電路學/images/questions/GK_111年_電路學_Q01.png)、[電路圖 (a)](../../../依考科分類/🏛️_國考同級參考題庫/01_電路學/images/figures/GK_111年_電路學_Q01_figure-01.png)、[等效電路圖 (b)](../../../依考科分類/🏛️_國考同級參考題庫/01_電路學/images/figures/GK_111年_電路學_Q01_figure-02.png)。

### （一）電源種類

圓形且標示固定 `6 V`、`+`、`−` 的元件是**獨立電壓源**。菱形且內有電流箭頭、大小為 `2i_a` 的元件是**電流控制電流源**（CCCS），亦即受控電流源。

### （二）求 `v_1`、`i_2`、`i_a`、`i_b`

先做不跨越受控源的串並聯化簡：

```text
5 Ω || 20 Ω = 4 Ω
R_a = 4 Ω + 8 Ω = 12 Ω
12 Ω || 24 Ω = 8 Ω
R_b = 2 Ω + 8 Ω = 10 Ω
```

令受控源上端節點電壓為 `V`，並沿題圖箭頭定義 `i_a`。左側支路給出

```text
i_a = (6 − V)/12，亦即 V = 6 − 12i_a。
```

在 `V` 節點套用 KCL；由左側流入的 `i_a`，等於向下的受控源電流 `2i_a` 加上流往右側等效電阻的電流 `V/10`：

```text
i_a = 2i_a + V/10
V = −10i_a。
```

聯立 `V=6−12i_a` 與 `V=−10i_a`，得

```text
i_a = 3 A，V = −30 V。
```

`5 Ω || 20 Ω` 的等效電阻為 `4 Ω`，其左正右負電壓即

```text
v_1 = 4i_a = 12 V。
```

令 `2 Ω` 右端、`12 Ω` 與 `24 Ω` 上端的節點電壓為 `V_c`。它是 `2 Ω` 與 `8 Ω` 的分壓節點，因此

```text
V_c = [8/(2+8)]V = −24 V。
```

題圖的 `i_2` 是流入 `24 Ω` 支路的電流，故

```text
i_2 = V_c/24 = −1 A。
```

右側整個等效支路的題示順時針參考電流為 `V/R_b=−30/10=−3 A`；底線上的 `i_b` 也以順時針回流方向為正，所以

```text
i_b = −3 A。
```

負號表示 `i_2` 與 `i_b` 的實際方向均和題圖箭頭相反。

### （三）求 `R_a`、`R_b`、`v_a`、`i_1`

由前述等效化簡：

```text
R_a = 12 Ω，R_b = 10 Ω。
```

`v_a` 為 `R_a` 左正右負的壓降，而 `i_1` 是流入 `R_b` 的題示電流：

```text
v_a = 6 − V = 36 V
i_1 = V/R_b = −3 A。
```

**答案：**`v_1=12 V`、`i_2=−1 A`、`i_a=3 A`、`i_b=−3 A`；`R_a=12 Ω`、`R_b=10 Ω`、`v_a=36 V`、`i_1=−3 A`。

**獨立驗算：**代回原電路，在 `V_c=−24 V` 節點有 `(V_c−V)/2+V_c/12+V_c/24=3−2−1=0`；在 `V=−30 V` 節點有 `(V−6)/12+(V−V_c)/2+2i_a=−3−3+6=0`。兩個原始節點的 KCL 同時成立。

## 二、開關開路後的 RC 自然響應

**題目重述：**開關在 `t=0` 前已閉合很久，`t=0` 打開；由 `7.5 mA` 電流源、`80 kΩ`、`20 kΩ`、`50 kΩ` 與 `0.2 mF` 電容，求電容初始電壓、初始能量、開路後穩態電壓、時間常數、`v(t)`，以及能量降為初始值 25% 的時間。

原題與電路圖：[官方原題裁切](../../../依考科分類/🏛️_國考同級參考題庫/01_電路學/images/questions/GK_111年_電路學_Q02.png)、[電路圖裁切](../../../依考科分類/🏛️_國考同級參考題庫/01_電路學/images/figures/GK_111年_電路學_Q02_figure-01.png)。

### （一）初始電壓、初始能量與終值

`t=0` 前開關閉合很久，電容在直流穩態等效為開路。電流源上端所見電阻為

```text
80 kΩ || (20 kΩ + 50 kΩ)
= 80 kΩ || 70 kΩ
= 112/3 kΩ。
```

故左端節點電壓為

```text
V_L = 7.5 mA × (112/3 kΩ) = 280 V。
```

流經 `20 kΩ`、`50 kΩ` 串聯支路的電流為 `280/70 kΩ=4 mA`，所以

```text
v(0−) = 4 mA × 50 kΩ = 200 V。
```

電容電壓連續，故 `v(0)=v(0+)=200 V`。初始儲能為

```text
W(0) = (1/2)Cv²(0)
     = (1/2)(0.2 mF)(200²)
     = 4 J。
```

`t>0` 時開關打開，左側電流源網路與電容分離，電容只經 `50 kΩ` 放電，因此長時間後

```text
V_oc = v(∞) = 0 V。
```

### （二）時間常數

電容向外看只見 `50 kΩ`：

```text
τ = R_th C = (50 kΩ)(0.2 mF) = 10 s。
```

### （三）響應函數

代入題目提示的一階全響應公式：

```text
v(t) = V_oc + [v(0)−V_oc]e^(−t/τ)
     = 200e^(−t/10) V，t>0。
```

### （四）能量降至初始值的 25% 所需時間

因 `W=(1/2)Cv²`，所以能量比是電壓比的平方：

```text
W(t)/W(0) = [v(t)/v(0)]² = e^(−2t/10) = e^(−t/5)。
```

令 `W(t)/W(0)=0.25`：

```text
e^(−t/5) = 1/4
t = 5 ln 4 ≈ 6.93 s。
```

**答案：**`v(0)=200 V`、`W(0)=4 J`、`V_oc=0 V`、`τ=10 s`、`v(t)=200e^(−t/10) V`，能量降至 25% 需 `6.93 s`。

**獨立驗算：**在 `t=5ln4` 時，`v(t)/v(0)=e^(−t/10)=1/2`，故 `W(t)/W(0)=(1/2)²=1/4`；初值與終值也分別為 200 V 與 0 V。

## 三、含受控源交流電路的頻域節點分析

**題目重述：**對輸入 `20 cos(4t) V`、`10 Ω` 電阻、`0.1 F` 電容、`1 H` 與 `5 H` 電感，以及大小為 `2i_x` 的受控電流源，在正弦穩態下求流經電容的電流 `i_x`。

原題與電路圖：[官方原題裁切](../../../依考科分類/🏛️_國考同級參考題庫/01_電路學/images/questions/GK_111年_電路學_Q03.png)、[電路圖裁切](../../../依考科分類/🏛️_國考同級參考題庫/01_電路學/images/figures/GK_111年_電路學_Q03_figure-01.png)。

電路已在正弦輸入下運作很久，採餘弦峰值相量，`ω=4 rad/s`、`V_s=20∠0° V`。令電容上端與右側節點相量分別為 `V_a`、`V_b`，則

```text
Z_1H = jωL = j4 Ω
Z_5H = j20 Ω
I_x = jωCV_a = j(4)(0.1)V_a = j0.4V_a。
```

在 `V_a`、`V_b` 兩節點寫 KCL：

```text
(V_a−20)/10 + j0.4V_a + (V_a−V_b)/(j4) = 0
(V_b−V_a)/(j4) + V_b/(j20) − 2I_x = 0。
```

聯立可得

```text
V_a = (2880+j8880)/1513 V
    ≈ 1.9035+j5.8691 V

V_b = (−5280−j16280)/1513 V
    ≈ −3.4898−j10.7601 V。
```

所以電容電流相量為

```text
I_x = j0.4V_a
    = (−3552+j1152)/1513 A
    = 2.468∠162.03° A。
```

回到時域：

```text
i_x(t) = 2.468 cos(4t+162.03°) A。
```

**獨立驗算：**由解得節點電壓另算三個支路電流，`I_R=(20−V_a)/10=1.80965−j0.58691 A`、`I_C=I_x=−2.34765+j0.76140 A`、`I_1H=(V_a−V_b)/(j4)=4.15730−j1.34831 A`，可見 `I_R−I_C−I_1H=0`。右節點代入 `(V_b−V_a)/(j4)+V_b/(j20)−2I_x` 亦精確為 0，兩個節點皆通過獨立 KCL 殘差檢查。

## 四、三種一階主動濾波器

**題目重述：**對官方圖示的三個 OPA 加 RC 選頻網路，分別求輸入 `V_i` 到輸出 `V_o` 的轉移函數與截止／轉折頻率，並判斷 (a)、(b)、(c) 分別屬於何種濾波器及其判斷原因。

原題與電路圖：[官方原題裁切](../../../依考科分類/🏛️_國考同級參考題庫/01_電路學/images/questions/GK_111年_電路學_Q04.png)、[電路 (a)](../../../依考科分類/🏛️_國考同級參考題庫/01_電路學/images/figures/GK_111年_電路學_Q04_figure-01.png)、[電路 (b)](../../../依考科分類/🏛️_國考同級參考題庫/01_電路學/images/figures/GK_111年_電路學_Q04_figure-02.png)、[電路 (c)](../../../依考科分類/🏛️_國考同級參考題庫/01_電路學/images/figures/GK_111年_電路學_Q04_figure-03.png)。

先令非反相放大器的回授係數與有限開迴路增益閉迴路增益為

```text
β = R_2/(R_1+R_2)
K_A = A/(1+Aβ)。
```

理想 OPA 極限 `A→∞` 時，`K_A→1/β=1+R_1/R_2`。

### （a）低通濾波器

`+` 端前的串聯 `R`、並聯 `C` 是一階低通：

```text
V_+/V_i = 1/(1+sRC)。
```

故

```text
H_a(s) = V_o/V_i
       = K_A/(1+sRC)
       ≈ (1+R_1/R_2)/(1+sRC)。
```

其低頻增益為 `K_A`、高頻趨近 0，故為**一階低通濾波器**。相對通帶的 `−3 dB` 截止角頻率與截止頻率為

```text
ω_c = 1/(RC)，f_c = 1/(2πRC)。
```

### （b）高通濾波器

`+` 端前的串聯 `C`、並聯 `R` 是一階高通：

```text
V_+/V_i = sRC/(1+sRC)。
```

故

```text
H_b(s) = K_A sRC/(1+sRC)
       ≈ (1+R_1/R_2)sRC/(1+sRC)。
```

其直流增益為 0、高頻增益趨近 `K_A`，故為**一階高通濾波器**，且

```text
ω_c = 1/(RC)，f_c = 1/(2πRC)。
```

### （c）全通濾波器與圖面穩定性註記

兩個相等的 `R_1` 連到 `+` 端且 OPA 輸入不取電流，因此

```text
V_+ = (V_i+V_o)/2。
```

下方 `R-C` 低通節點為

```text
V_- = V_i/(1+sRC)。
```

使用圖中標示的有限增益模型 `V_o=A(V_+−V_−)`：

```text
V_o = A[(V_i+V_o)/2 − V_i/(1+sRC)]

H_c(s) = [A/(A−2)](1−sRC)/(1+sRC)。
```

若採命題通常使用的理想 OPA 代數極限 `A→∞`：

```text
H_c(s) = (1−sRC)/(1+sRC)。
```

在理想模型下 `|H_c(jω)|=1` 對所有頻率成立，因此它是**一階全通濾波器**，只改變相位：

```text
∠H_c(jω) = −2 tan⁻¹(ωRC)。
```

嚴格而言，全通濾波器的幅度沒有 `−3 dB` 截止頻率；若題目把 RC 的轉折頻率也稱為截止頻率，則

```text
ω_0 = 1/(RC)，f_0 = 1/(2πRC)，
```

且此時相位為 `−90°`。

**圖面穩定性註記：**官方圖 (c) 把輸出經 `R_1` 接回 OPA 的 `+` 端，屬正回授。上式是依題圖與理想／定增益代數模型所得的命題預期全通結果；真實 OPA 含內部極點與飽和限制，這個正回授接法不保證穩定線性工作，工程上常見的穩定全通實作會將加總回授節點接至反相端、RC 節點接至非反相端。

**獨立驗算：**`H_a(0)=K_A`、`H_a(∞)=0`，符合低通；`H_b(0)=0`、`H_b(∞)=K_A`，符合高通；理想 `H_c(0)=1`、`H_c(∞)=−1`，且 `|(1−jωRC)/(1+jωRC)|=1`，符合全通的幅頻與相位極限。
