## 一、差動串聯磁路之磁通密度與磁場儲能計算（20 分）

### 📌 題目與已知條件
圖一所示之磁路：
* 鐵心平均長度 $l_c = 45\text{ cm} = 0.45\text{ m}$，截面積 $A_c = 15\text{ cm}^2 = 15 \times 10^{-4}\text{ m}^2 = 1.5 \times 10^{-3}\text{ m}^2$。
* 相對導磁係數 $\mu_r = 3300$，真空導磁係數 $\mu_0 = 4\pi \times 10^{-7}\text{ H/m}$。
* 左柱繞組匝數 $N_1 = 100\text{ 匝}$，右柱繞組匝數 $N_2 = 85\text{ 匝}$。
* 兩繞組串聯通以直流電流 $I = 550\text{ mA} = 0.55\text{ A}$。忽略漏磁效應。

**試求**：計算鐵心中的磁通密度 $B$ 及磁場儲能 $W_m$。（20 分）

```
         ┌─────────────────────────┐  lc = 45 cm
         │         鐵  心          │
       I ├───┐                 ┌───┤
    ───> │N1 │ 100匝     85匝  │N2 │
    + E1 ├───┘                 └───┤
    ───  │                         │
    -    └─────────────────────────┘
```

---

### 💡 核心考點與破題關鍵
1. **安培右手定則判定繞向與磁動勢極性**：
   - 電流 $I$ 由電源 $(+)$ 端進入左柱 $N_1$ 繞組上方正面往右繞，由右手定則 thumb 向上 $\implies$ 在左柱建立**向上（順時針方向）**之磁動勢 $\mathcal{F}_1 = N_1 I$。
   - $N_1$ 底部引出線連接至右柱 $N_2$ 上方，電流由右柱外側進入正面往左繞，由右手定則 thumb 向上 $\implies$ 在右柱建立**向上（逆時針方向）**之磁動勢 $\mathcal{F}_2 = N_2 I$。
   - 兩繞組在共用磁路環路中互相抵消，構成**差動反向串聯（Subtractive Connection）**：
     $$\mathcal{F}_{net} = \mathcal{F}_1 - \mathcal{F}_2 = (N_1 - N_2) I$$
2. **磁路歐姆定律與磁通密度**：
   $$\mathcal{R}_c = \frac{l_c}{\mu_r \mu_0 A_c}, \quad \Phi = \frac{\mathcal{F}_{net}}{\mathcal{R}_c}, \quad B = \frac{\Phi}{A_c} = \mu H = \mu \frac{\mathcal{F}_{net}}{l_c}$$
3. **磁場儲能公式**：
   $$W_m = \frac{1}{2} \mathcal{F}_{net} \Phi = \frac{1}{2} \frac{B^2}{\mu} \times V_{core}$$

---

### ✏️ 步驟式詳細數學推導

#### 步驟 1：計算鐵心導磁率與磁阻 $\mathcal{R}_c$
* 鐵心導磁率：
  $$\mu = \mu_r \mu_0 = 3300 \times (4\pi \times 10^{-7}) = 4.1469 \times 10^{-3}\text{ H/m}$$
* 鐵心磁阻：
  $$\mathbf{\mathcal{R}_c = \frac{l_c}{\mu A_c} = \frac{0.45\text{ m}}{(4.1469 \times 10^{-3}\text{ H/m}) \times (1.5 \times 10^{-3}\text{ m}^2)} = \frac{0.45}{6.22035 \times 10^{-6}} = \mathbf{72343.16\text{ A}\cdot\text{t/Wb}}}$$

#### 步驟 2：計算淨磁動勢 $\mathcal{F}_{net}$
* $N_1 = 100, N_2 = 85, I = 0.55\text{ A}$：
  $$\mathbf{\mathcal{F}_{net} = (N_1 - N_2) I = (100 - 85) \times 0.55\text{ A} = 15 \times 0.55 = \mathbf{8.25\text{ A}\cdot\text{t}}}$$

#### 步驟 3：計算磁通量 $\Phi$ 與磁通密度 $B$
* 鐵心總磁通：
  $$\Phi = \frac{\mathcal{F}_{net}}{\mathcal{R}_c} = \frac{8.25\text{ A}\cdot\text{t}}{72343.16\text{ A}\cdot\text{t/Wb}} = \mathbf{1.1404 \times 10^{-4}\text{ Wb} = 0.11404\text{ mWb}}$$
* 鐵心磁通密度：
  $$\mathbf{B = \frac{\Phi}{A_c} = \frac{1.1404 \times 10^{-4}\text{ Wb}}{1.5 \times 10^{-3}\text{ m}^2} = \mathbf{0.07603\text{ T} \approx 0.076\text{ T}}}$$
  *(亦可由磁場強度驗算：$H = \frac{\mathcal{F}_{net}}{l_c} = \frac{8.25}{0.45} = 18.333\text{ A/m} \implies B = \mu H = (4.1469 \times 10^{-3}) \times 18.333 = \mathbf{0.07603\text{ T}}$)*

#### 步驟 4：計算鐵心中的磁場儲能 $W_m$
* 依磁動勢與磁通乘積公式：
  $$\mathbf{W_m = \frac{1}{2} \mathcal{F}_{net} \Phi = \frac{1}{2} \times 8.25\text{ A}\cdot\text{t} \times (1.1404 \times 10^{-4}\text{ Wb}) = \mathbf{4.704 \times 10^{-4}\text{ J} = 0.4704\text{ mJ}}}$$
* *（依體積能量密度驗算：$V = A_c l_c = 6.75 \times 10^{-4}\text{ m}^3，W_m = \frac{B^2}{2\mu} V = \frac{0.07603^2}{2 \times 4.1469 \times 10^{-3}} \times 6.75 \times 10^{-4} = 0.4704\text{ mJ}$，完全相符！）*

> [!NOTE] 💡 **同向串聯（Additive Connection）備註**：
> 若視兩繞組同向加動串聯，則 $\mathcal{F}_{add} = (100 + 85) \times 0.55 = 101.75\text{ A}\cdot\text{t}$，對應磁通密度為 $B = \mathbf{0.9377\text{ T}}$，儲能為 $W_m = \mathbf{71.56\text{ mJ}}$。依圖一右手定則繞向明確為差動抵消（$N_1 - N_2 = 15$ 匝）。

---

### 🎯 第一題 滿分關鍵與結論
* **鐵心磁通密度**：$\mathbf{B = 0.07603\text{ T} \approx 0.076\text{ T}}$
* **磁場總儲能**：$\mathbf{W_m = 4.704 \times 10^{-4}\text{ J} = 0.4704\text{ mJ}}$

## 二、雙繞組變壓器改接單相與三相 V-V 自耦變壓器容量（20 分）

### 📌 題目與已知條件
一部 $60\text{ Hz}、220/160\text{ V}、30\text{ kVA}$ 雙繞組單相變壓器，改接成自耦變壓器，從 $380\text{ V}$ 電源供應 $220\text{ V}$ 單相負載（降壓型自耦變壓器）。
* **(一)** 繪出此自耦變壓器之電路圖，標註變壓器繞組的極性及電壓值。（5 分）
* **(二)** 計算此自耦變壓器之 $\text{kVA}$ 容量。（5 分）
* **(三)** 欲使用兩部上述的自耦變壓器，連接成一個三相變壓器組，從三相 $380\text{ V}$ 電源供應三相 $220\text{ V}$ 之負載。試繪出此三相變壓器組的連接電路圖，標註極性及電壓值。（5 分）
* **(四)** 計算此三相變壓器組的 $\text{kVA}$ 容量。（5 分）

---

### 💡 核心考點與破題關鍵
1. **單相降壓自耦變壓器接法**：
   - 高壓端（$380\text{ V}$）由 $160\text{ V}$ 繞組（串聯繞組 Series Winding）與 $220\text{ V}$ 繞組（公共繞組 Common Winding）同極性串聯構成（$160 + 220 = 380\text{ V}$）。
   - 低壓端（$220\text{ V}$）取公共繞組兩端。
   - 串聯繞組允許之額定電流 $I_{se} = \frac{30\text{ kVA}}{160\text{ V}} = 187.5\text{ A}$。
   - 單相自耦變壓器額定容量：
     $$S_{auto,1\phi} = V_H \times I_{se} = 380\text{ V} \times 187.5\text{ A} = 71.25\text{ kVA}$$
2. **三相開 \Delta（V-V）自耦變壓器組**：
   - 兩台單相自耦變壓器連接為 V-V 接線，供應三相對稱負載。
   - 三相 V-V 容量為單台容量的 $\sqrt{3}$ 倍：
     $$S_{3\phi,VV} = \sqrt{3} \times S_{auto,1\phi} = \sqrt{3} \times 71.25\text{ kVA} \approx 123.41\text{ kVA}$$

---

### ✏️ 步驟式詳細數學推導

#### 🔹 (一) 單相自耦變壓器電路圖
* **電路圖結構**：
  ```
  380V 電源端 (H1) ───●───[ 160V 串聯繞組 (•) ]───●─── (X1) 220V 負載端
                                                  │
                                          [ 220V 公共繞組 (•) ]
                                                  │
  380V 電源端 (H2) ───────────────────────────────┴─── (X2) 220V 負載端
  ```
* **極性標註**：160V 繞組與 220V 繞組之同名端（•）串接相加，使總高壓為 $160 + 220 = 380\text{ V}$。

#### 🔹 (二) 單相自耦變壓器 $\text{kVA}$ 容量
* 原雙繞組各側額定電流：
  $$I_{160V} = \frac{30\text{ kVA}}{160\text{ V}} = \mathbf{187.5\text{ A}}, \quad I_{220V} = \frac{30\text{ kVA}}{220\text{ V}} = \mathbf{136.36\text{ A}}$$
* 串聯繞組電流限制高壓端輸入電流 $I_H = 187.5\text{ A}$：
  $$\mathbf{S_{auto,1\phi} = V_H \times I_H = 380\text{ V} \times 187.5\text{ A} = \mathbf{71250\text{ VA} = 71.25\text{ kVA}}}$$
  *(亦可由低壓端驗證：$I_L = I_{160V} + I_{220V} = 187.5 + 136.36 = 323.86\text{ A} \implies S = 220 \times 323.86 = 71.25\text{ kVA}$)*

#### 🔹 (三) 三相 V-V 自耦變壓器組連接電路圖
* **連接架構**：使用兩部自耦變壓器 $T_A$ 與 $T_B$，將輸入端分別接至三相 $380\text{ V}$ 電源的 A-B 相與 B-C 相，公共點接至 B 相，輸出端引出三相 $220\text{ V}$（a, b, c）：
  ```
  電源 A (380V) ───●─[ 160V ]─●── a (220V 負載)
                              │
                           [ 220V ]
                              │
  電源 B ─────────────────────●── b
                              │
                           [ 220V ]
                              │
  電源 C (380V) ───●─[ 160V ]─●── c (220V 負載)
  ```

#### 🔹 (四) 三相變壓器組之 $\text{kVA}$ 容量
* 兩台變壓器以開 \Delta（V-V）方式運轉時，其三相輸出容量為：
  $$\mathbf{S_{3\phi,VV} = \sqrt{3} \times S_{auto,1\phi} = \sqrt{3} \times 71.25\text{ kVA} = \mathbf{123.41\text{ kVA}}}$$

---

### 🎯 第二題 滿分關鍵與結論
* **單相自耦變壓器容量**：$\mathbf{S_{auto,1\phi} = 71.25\text{ kVA}}$
* **三相 V-V 自耦變壓器組容量**：$\mathbf{S_{3\phi,VV} = 123.41\text{ kVA}}$

## 三、八極三相同步電動機相量與電壓下降運轉特性（20 分）

### 📌 題目與已知條件
一部 $380\text{ V}、60\text{ Hz}、15\text{ kW}$、八極、$\text{Y}$ 接之三相同步電動機：
* 每相同步電抗 $X_s = 5.80\ \Omega$，電樞電阻 $R_a = 0$，鐵損及機械損均忽略。
* **(一)** 工作於額定電壓並輸出額定機械功率 $15\text{ kW}$，功率因數 $\text{PF} = 0.8\text{ 落後}$。繪出每相等效電路圖，計算電樞電流 $I_a$、每相激勵電勢 $E_a$ 及轉矩角 $\delta$。（10 分）
* **(二)** 若供電電壓下降 10\%成為 $342\text{ V}$，激磁電流（$E_a$ 大小不變）及機械輸出功率 $15\text{ kW}$ 保持不變，計算轉矩角 $\delta$、電樞電流 $I_a$ 及功率因數。（10 分）

---

### 💡 核心考點與破題關鍵
1. **同步電動機每相方程式**：
   $$\mathbf{V}_\phi = \frac{V_{LL}}{\sqrt{3}}, \quad \mathbf{E}_a = \mathbf{V}_\phi - jX_s \mathbf{I}_a$$
2. **落後功因（Lagging PF）在電動機中的意義**：
   - 電動機由電網吸取落後無效功率（欠激磁狀態），電流相角為負值：$\mathbf{I}_a = I_a \angle -\theta$（$\theta = \cos^{-1} 0.8 \approx 36.87^\circ$）。
3. **三相實功率與轉矩角關係**：
   $$P = 3 \frac{V_\phi E_a}{X_s} \sin|\delta| \implies \sin|\delta| = \frac{P \cdot X_s}{3 V_\phi E_a}$$

---

### ✏️ 步驟式詳細數學推導

#### 🔹 (一) 額定電壓 $380\text{ V}$ 下運轉（$\text{PF} = 0.8\text{ 落後}$）
1. 每相端電壓：
   $$V_\phi = \frac{380}{\sqrt{3}} \approx 219.393\text{ V}$$
2. 電樞電流大小與相量：
   $$\mathbf{I_a = \frac{P}{\sqrt{3} V_L \cos\theta} = \frac{15000}{\sqrt{3} \times 380 \times 0.8} = \frac{15000}{526.543} = \mathbf{28.487\text{ A}}}$$
   $$\mathbf{I}_a = 28.487\angle -36.87^\circ = 28.487(0.8 - j0.6) = \mathbf{22.790 - j17.092\text{ A}}$$
3. 每相激勵電勢 $\mathbf{E}_a$：
   $$\mathbf{E}_a = \mathbf{V}_\phi - jX_s \mathbf{I}_a = 219.393 - j5.80 \times (22.790 - j17.092)$$
   $$\mathbf{E}_a = 219.393 - (j132.182 + 99.134) = \mathbf{120.259 - j132.182\text{ V}}$$
   |\mathbf{E}_a| = \sqrt{120.259^2 + (-132.182)^2} = \sqrt{14462.2 + 17472.1} = \sqrt{31934.3} = \mathbf{178.70\text{ V/相}}
4. 轉矩角 $\delta$：
   $$\mathbf{\delta = \tan^{-1}\left( \frac{-132.182}{120.259} \right) = \mathbf{-47.71^\circ}}$$
   *(負號代表電動機模式，內生電壓落後於端電壓)*

#### 🔹 (二) 端電壓下降 10\%成為 $342\text{ V}$
1. 新的每相端電壓：
   $$V_{\phi2} = \frac{342}{\sqrt{3}} \approx 197.454\text{ V}$$
2. 激磁電流不變 $\implies |\mathbf{E}_a| = 178.70\text{ V}$ 不變；機械功率 $P = 15000\text{ W}$ 不變：
   $$P = \frac{3 V_{\phi2} E_a}{X_s} \sin|\delta_2| \implies \sin|\delta_2| = \frac{15000 \times 5.80}{3 \times 197.454 \times 178.70} = \frac{87000}{105856.4} = 0.82187$$
   $$|\delta_2| = \sin^{-1}(0.82187) = 55.27^\circ \implies \mathbf{\delta_2 = -55.27^\circ}$$
3. 新電樞電流與功率因數：
   $$\mathbf{E}_{a2} = 178.70\angle -55.27^\circ = 178.70(\cos 55.27^\circ - j\sin 55.27^\circ) = 101.805 - j146.853\text{ V}$$
   $$\mathbf{I}_{a2} = \frac{\mathbf{V}_{\phi2} - \mathbf{E}_{a2}}{jX_s} = \frac{197.454 - (101.805 - j146.853)}{j5.80} = \frac{95.649 + j146.853}{j5.80}$$
   $$\mathbf{I}_{a2} = \frac{146.853}{5.80} - j\frac{95.649}{5.80} = \mathbf{25.320 - j16.491\text{ A}}$$
   $$|\mathbf{I}_{a2}| = \sqrt{25.320^2 + (-16.491)^2} = \sqrt{641.10 + 271.95} = \sqrt{913.05} = \mathbf{30.22\text{ A}}$$
   $$\theta_2 = \tan^{-1}\left( \frac{-16.491}{25.320} \right) = -33.08^\circ \implies \mathbf{\text{PF}_2 = \cos(-33.08^\circ) = \mathbf{0.8379\text{ 落後}}}$$

---

### 🎯 第三題 滿分關鍵與結論
* **(一) 額定運轉**：$I_a = \mathbf{28.49\text{ A}}, \ E_a = \mathbf{178.70\text{ V/相}}, \ \delta = \mathbf{-47.71^\circ}$
* **(二) 電壓下降 10\%**：$\delta_2 = \mathbf{-55.27^\circ}, \ I_{a2} = \mathbf{30.22\text{ A}}, \ \text{PF}_2 = \mathbf{0.8379\text{ 落後}}$

## 四、永磁式直流電動機額定負載運轉轉速與轉矩（20 分）

### 📌 題目與已知條件
額定 $3\text{ 馬力}$（$1\text{ hp} = 746\text{ W} \implies 3\text{ hp} = 2238\text{ W}$）、$180\text{ V}$ 之永磁式直流電動機（PMDC）：
* 電樞電阻 $R_a = 2.01\ \Omega$。
* 無載時轉速 $n_{nl} = 4200\text{ rpm}$。
* 機械損失、鐵損及無載電樞電流均可忽略。
* 當此電動機以直流 $180\text{ V}$ 供電，輸出額定機械功率 $2238\text{ W}$ 時：

**試求**：
* **(一)** 繪出等效電路圖，計算電樞反電壓 $E_a$ 及電樞電流 $I_a$。（10 分）
* **(二)** 計算此時之轉速 $n$（$\text{rpm}$）及轉矩 $T$（$\text{N}\cdot\text{m}$）。（10 分）

---

### 💡 核心考點與破題關鍵
1. **無載常數推導**：
   - 忽略無載損耗與無載電流時，$E_{a,nl} = V_t = 180\text{ V}$。
   - 反電動勢常數：$K_e = \frac{E_a}{n} = \frac{180\text{ V}}{4200\text{ rpm}} = \frac{3}{70} \approx 0.042857\text{ V/rpm}$。
2. **負載功率平衡一元二次方程式**：
   $$P_{out} = P_{em} = E_a I_a = (V_t - I_a R_a) I_a \implies R_a I_a^2 - V_t I_a + P_{out} = 0$$

---

### ✏️ 步驟式詳細數學推導

#### 🔹 (一) 等效電路與電樞電壓、電流
* **等效電路**：
  ```
  + ───[ Ra = 2.01 Ω ]───( Ia ──> )───[ + (Ea) - ]─── -
     Vt = 180V 直流電源                轉子反電動勢
  ```
* **解電樞電流 $I_a$**：
  2. $01 I_a^2 - 180 I_a + 2238 = 0$
  $$I_a = \frac{180 - \sqrt{180^2 - 4(2.01)(2238)}}{2(2.01)} = \frac{180 - \sqrt{32400 - 17993.52}}{4.02} = \frac{180 - 120.027}{4.02} = \mathbf{14.919\text{ A}}$$
* **電樞反電壓 $E_a$**：
  $$\mathbf{E_a = V_t - I_a R_a = 180 - (14.919 \times 2.01) = 180 - 29.987 = \mathbf{150.01\text{ V}}}$$
  *(驗算功率：$E_a I_a = 150.013 \times 14.919 = 2238.0\text{ W}$，精確無誤！)*

#### 🔹 (二) 轉速 $n$ 與輸出轉矩 $T$
* **負載轉速 $n$**：
  $$\mathbf{n = \frac{E_a}{K_e} = \frac{150.013\text{ V}}{0.042857\text{ V/rpm}} = 150.013 \times \frac{70}{3} = \mathbf{3500.3\text{ rpm}}}$$
* **旋轉角速度 $\omega$ 與轉矩 $T$**：
  $$\omega = \frac{2\pi \times n}{60} = \frac{2\pi \times 3500.3}{60} = \mathbf{366.55\text{ rad/s}}$$
  $$\mathbf{T = \frac{P_{out}}{\omega} = \frac{2238\text{ W}}{366.55\text{ rad/s}} = \mathbf{6.106\text{ N}\cdot\text{m}}}$$

**二次方程的分支核對與穩定性**：功率平衡另有數學根 $I_a=74.6336$ A、$E_a=29.9865$ V、$n=699.685$ rpm、$T=30.5442$ N·m。以 $K_t=K_e=0.4092556$ SI 單位計算
\[
\left.\frac{\mathrm d(T_e-T_L)}{\mathrm d\omega}\right|_*=-\frac{K_eK_t}{R_a}+\frac{P_{out}}{\omega_*^2},
\]
低電流根為 $-0.066672$、高電流根為 $+0.333539$；只有斜率為負的 $14.9187$ A／3500.315 rpm 根是穩定額定連續運轉解。

---

### 🎯 第四題 滿分關鍵與結論
* **(一) 電樞電流與電壓**：$I_a = \mathbf{14.92\text{ A}}, \ E_a = \mathbf{150.01\text{ V}}$
* **(二) 轉速與轉矩**：$n = \mathbf{3500.3\text{ rpm}}, \ T = \mathbf{6.106\text{ N}\cdot\text{m}}$

## 五、六極鼠籠式感應電動機啟動電抗器設計（20 分）

### 📌 題目與已知條件
額定 $60\text{ Hz}、208\text{ V}（\text{Y}\text{ 接}）、30\text{ 馬力}$ 之三相六極鼠籠式感應電動機：
* 定子側每相參數：$R_1 = 0.10\ \Omega, R_2 = 0.07\ \Omega, X_1 = X_2 = 0.21\ \Omega, X_m = 10\ \Omega$。
* **(一)** 若不使用啟動電抗器（$X_{st} = 0$，SW 閉合），在額定電壓下啟動，計算啟動電流 $I_{start}$ 與啟動轉矩 $T_{start}$。（10 分）
* **(二)** 若欲抑制啟動電流為原來的 $\frac{1}{\sqrt{3}}$ 倍，計算啟動電抗 $X_{st}$ 之值及使用此啟動電抗時的啟動轉矩。（10 分）

---

### 💡 核心考點與破題關鍵
1. **啟動時轉差率 $s = 1$**：
   - 轉子支路阻抗：$Z_{rotor} = \frac{R_2}{1} + jX_2 = 0.07 + j0.21\ \Omega$。
   - 轉子與激磁電抗 $jX_m$ 之並聯等效阻抗 $Z_p$。
   - 總啟動輸入阻抗 $Z_{start} = (R_1 + jX_1) + Z_p$。
2. **感應機啟動轉矩**：
   $$T_{start} = \frac{3 (I_2')^2 R_2}{\omega_s}, \quad \omega_s = \frac{2\pi \times 1200}{60} = 125.664\text{ rad/s}$$
3. **啟動電抗器串聯降流與轉矩比例平方定律**：
   - 當電流降低為原來的 $\frac{1}{\sqrt{3}}$ 倍，轉矩與電流平方成正比，啟動轉矩降為原本的 $\left(\frac{1}{\sqrt{3}}\right)^2 = \frac{1}{3}$！

---

### ✏️ 步驟式詳細數學推導

#### 🔹 (一) 全電壓直接啟動（$X_{st} = 0$）
1. 每相輸入相電壓：
   $$V_1 = \frac{208}{\sqrt{3}} \approx 120.091\text{ V}$$
2. 轉子與激磁並聯阻抗：
   $$Z_p = \frac{(j10)(0.07 + j0.21)}{0.07 + j10.21} = \frac{-2.10 + j0.70}{0.07 + j10.21} = \mathbf{0.06692 + j0.20606\ \Omega}$$
3. 總輸入阻抗：
   $$Z_{start} = (0.10 + j0.21) + (0.06692 + j0.20606) = \mathbf{0.16692 + j0.41606\ \Omega}$$
   $$|Z_{start}| = \sqrt{0.16692^2 + 0.41606^2} = \sqrt{0.02786 + 0.17311} = \mathbf{0.44845\ \Omega}$$
4. 啟動電流：
   $$\mathbf{I_{start} = \frac{V_1}{|Z_{start}|} = \frac{120.091}{0.44845} = \mathbf{267.79\text{ A}}}$$
5. 轉子電流與啟動轉矩：
   $$I_2' = I_{start} \times \left| \frac{j10}{0.07 + j10.21} \right| = 267.79 \times \frac{10}{10.2102} = \mathbf{262.28\text{ A}}$$
   $$\mathbf{T_{start} = \frac{3 (I_2')^2 R_2}{\omega_s} = \frac{3 \times (262.275)^2 \times 0.07}{125.664} = \mathbf{114.95\text{ N}\cdot\text{m}}}$$

#### 🔹 (二) 串接啟動電抗器 $X_{st}$
1. 目標啟動電流降為 $\frac{1}{\sqrt{3}}$：
   $$I_{start}' = \frac{I_{start}}{\sqrt{3}} \implies |Z_{start}'| = \sqrt{3} |Z_{start}| = \sqrt{3} \times 0.44845 = \mathbf{0.77674\ \Omega}$$
2. 計算所需總電抗與 $X_{st}$：
   $$R_{total} = 0.16692\ \Omega \implies X_{total}' = \sqrt{|Z_{start}'|^2 - R_{total}^2} = \sqrt{0.77674^2 - 0.16692^2} = \mathbf{0.75860\ \Omega}$$
   $$\mathbf{X_{st} = X_{total}' - X_{total} = 0.75860 - 0.41606 = \mathbf{0.3425\ \Omega}}$$
3. 串接 $X_{st}$ 後之啟動轉矩：
   $$\mathbf{T_{start}' = \left(\frac{1}{\sqrt{3}}\right)^2 \times T_{start} = \frac{1}{3} \times 114.95\text{ N}\cdot\text{m} = \mathbf{38.32\text{ N}\cdot\text{m}}}$$

> ⚠️ **電機機械 核心防坑與閱卷踩雷提醒**：
> 1. **變壓器阻抗折合**：低壓側折合至高壓側乘以變比平方 $a^2$；自耦變壓器共用繞組電流為高低壓側電流之差值。
> 2. **感應機最大轉矩**：最大轉矩 $T_{max}$ 與轉子電阻 $R_2$ 無關，但產生最大轉矩之轉差率 $s_{max}$ 與 $R_2$ 成正比。
> 3. **同步機相量計算**：同步電動機 $\mathbf{E}_f = \mathbf{V}_\phi - \mathbf{I}_a \mathbf{Z}_s$；同步發電機 $\mathbf{E}_f = \mathbf{V}_\phi + \mathbf{I}_a \mathbf{Z}_s$。
