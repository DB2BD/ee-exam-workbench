# 發版紀錄 v1.3.2

日期：2026-10-05

## 修正

- 核心時段「三題對照」改為同時顯示母題、同型、變式三張原題圖，並標示角色；母題取自同章的第一輪核心時段（`CORE-07`～`12` 對 `CORE-01`～`06`，`CORE-19`～`24` 對 `CORE-13`～`18`）。
- 11/12 考前確認與 11/13 停筆日：即使有未完成的任務也不再自動開啟做題視窗，卡片說明該任務不再繼續。
- 知識回想到期日與備份檔名改用本地日期（台灣時間午夜換日，不再是早上 8 點）。
- 全新使用者尚未設定「已在紙本做過前面的任務？」時，不顯示自動刪減清單，改為提示先設定起點。

## 文件

- 修正 141 條失效的相對連結：六科題庫彙編的官方 PDF 連結（132 條）與兩份國考同級題解的圖片路徑（9 條）。連結檢查剩 1 筆為公式括號誤判，不是連結。

## 清理

- 移除 5 個無引用的函式與約 50 個已下架功能的 CSS 規則（舊複習頁、1／3／5 評分條、計算機指南等）。
- 移除 `scripts/legacy_migrations/`（141 個一次性遷移腳本，已無任何程式或流程使用）。
- 更新瀏覽器端到端測試腳本 `scripts/qa_browser.cjs`，對應目前的隨機練習與作答結果卡。
