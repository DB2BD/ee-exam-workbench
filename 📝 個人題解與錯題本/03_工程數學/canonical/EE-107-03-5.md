# 107 年第 5 題｜抽取損壞保險絲

損壞率 (p=5/20=1/4)。放回抽取時 (X\sim\operatorname{Binomial}(3,1/4))：
[
P(X=x)=\binom3x(1/4)^x(3/4)^{3-x},quad P(X=1)=\boxed{27/64}.
]
不放回時為超幾何分布：
[
P(X=x)=\frac{\binom5x\binom{15}{3-x}}{\binom{20}{3}},quad
P(X=1)=\frac{5\binom{15}{2}}{\binom{20}{3}}=\boxed{35/76}.
]
兩式的支持集皆為 (x=0,1,2,3)（不放回另受 (x\le5) 與 (3-x\le15) 限制）。
