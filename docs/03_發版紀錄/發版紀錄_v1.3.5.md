# 發版紀錄 v1.3.5

日期：2026-10-06

## 防呆：不可逆動作都要按兩下

- 模考「交卷」改為二段確認：第一下按鈕變成「確定交卷？會顯示全部答案」並出現「取消」，4 秒未確認自動復原。
- 閉卷階段的「停筆，開始核對」在剩餘超過 5 分鐘時要按兩下，提示會寫出還剩幾分鐘；剩 5 分鐘內或時間到則直接進入核對。
- 「放棄本次」改為頁尾最右側的低強調按鈕，按一下顯示「確定放棄？會清掉這次進度」，3 秒未確認自動復原。
- 題解視窗按 Esc：焦點在輸入框時不處理；停靠的作答結果卡有未存的標記或加註時，第一次 Esc 只收合卡片、不關閉視窗。

## 不丟進度

- 模考評分狀態（年度、科目、階段、本次 mockId）存入本機 `EE_EXAM_MOCK_SESSION_V1`，重新整理、分頁被回收或手機休眠後重開，會接續到尚未評分的題目，mockId 不變，紀錄不會變成「未評完」。
- 評分階段不再顯示每題的第一輪時間帽。

## 少按幾下

- 模考總結直接提供「下一份：MOCK114-0N／BLIND108-0N」主按鈕（依排程找第一份未完成的卷），12 份都完成時顯示「已完成」；「換一份試卷」降為次要；同列加「下載備份」。
- 核對階段處理完最後一題時，標題改為「全部記錄完成，按「完成核對」結束」，並自動捲到、聚焦「完成核對」按鈕。
- 「今天的任務」視窗打開時焦點放在主按鈕；按 Esc 等同「先離開」，只關閉視窗、不改任務狀態。

## 備份提醒

- 首頁新增一行提醒：有紀錄但從未備份顯示「還沒備份過」，距上次備份滿 3 天顯示「已 N 天沒備份」，附「下載備份」與「明天再說」（延後到隔天）。狀態存於 `EE_EXAM_BACKUP_NUDGE_V1`，不納入備份檔。
- 新增全域 `backupDownloadNow()`，與備份／還原視窗的匯出相同。

## 開發與部署

- `npm run check:fast`（組建＋語法檢查＋測試，可 `-- -k 關鍵字` 篩選）；`npm run check` 不再順帶複製 `_site`，改由 `npm run stage` 單獨執行；`npm run qa` ＝ check → stage → qa:browser。
- `scripts/run_all_tests.py` 支援 `-k`、`--file`、`--jobs`，預設依 CPU 數平行跑各測試檔，全套約 156 秒 → 56 秒；`scripts/run_verify_scripts.py` 的逐題驗證改為平行執行。
- GitHub Actions：pip 快取、移除未使用的 poppler 安裝步驟；只改 `docs/**`、`*.md`、`reports/**` 不再觸發部署。
- 刪除已無作用的 `sw.js`（頁面載入時本來就會解除所有 Service Worker 註冊，該段程式保留）。
- 測試改以 stdin 把 JS 原始碼餵給 node（原本當命令列參數，Linux 單一參數上限 128 KB，CI 於 `sm2Store.js` 增長後失敗）；CI 補回 `pdftotext`（`scripts/build_year_readmes.py` 需要）。
- 新增 `scripts/qa_guards.cjs`：以無頭 Chromium 走過上述 13 個情境，併入 `npm run qa:browser`。
