## 一、考前 3 大黃金模式設定（開機必檢查）

```text
+-------------------------------------------------------------+
|  DEG                CPLX                                    |
|                       [ 0. ]                                |
+-------------------------------------------------------------+
```

1. **角度制確認（`DEG`）**：
   - 螢幕上方必須顯示 **`DEG`**（度數制）。
   - 若顯示 `RAD`（弧度）或 `GRAD`（百分度），請連續按 **`DRG`** 鍵切換直到出現 **`DEG`**。
2. **進入複數模式（`CPLX`）**：
   - 按 **`2ndF`** ➔ **`CPLX`**。
   - 螢幕上方亮起 **`CPLX`** 標誌即表示已進入複數模式。
3. **清除歸零（`ON/C`）**：
   - 計算新題目時，建議按兩次 **`ON/C`** 清除舊暫存器。

## 三、3 大經典相量轉換實戰按法（逐鍵示範）

### 1. 直角座標 ➔ 極座標（$a+bj \longrightarrow r\angle\theta$）

> **範例**：將阻抗 $\mathbf{Z} = 3 + j4\ \Omega$ 轉為極座標 $5\angle 53.13^\circ\ \Omega$。

```text
步驟 1：輸入實部 3            ➔ 按 [ 3 ]
步驟 2：輸入加號與虛部 4      ➔ 按 [ + ] [ 4 ]
步驟 3：標記為虛數            ➔ 按 [2ndF] [ i ] (或 [b] 鍵)
步驟 4：執行轉極座標          ➔ 按 [2ndF] [ →rθ ]
         👉 螢幕立即顯示幅值：[ 5.0000 ]
步驟 5：查看相角              ➔ 按 [2ndF] [ b ]
         👉 螢幕立即顯示角度：[ 53.1301 ]
步驟 6：切回幅值              ➔ 按 [2ndF] [ a ] ➔ 顯示 [ 5.0000 ]
```

---

### 2. 極座標 ➔ 直角座標（$r\angle\theta \longrightarrow a+bj$）

> **範例**：將電壓相量 $\mathbf{V} = 100\angle 30^\circ\text{ V}$ 轉為直角座標 $86.60 + j50.00\text{ V}$。

```text
步驟 1：輸入幅值 100          ➔ 按 [ 100 ]
步驟 2：啟動角度符號          ➔ 按 [2ndF] [ ∠ ]
步驟 3：輸入相角 30           ➔ 按 [ 30 ]
步驟 4：執行轉直角座標        ➔ 按 [2ndF] [ →xy ]
         👉 螢幕立即顯示實部：[ 86.6025 ]
步驟 5：查看虛部              ➔ 按 [2ndF] [ b ]
         👉 螢幕立即顯示虛部：[ 50.0000 ]
```

---

### 3. 免開根號求向量幅值（$\sqrt{A^2 + B^2}$ 神技）

> **範例**：發電機電壓 $\mathbf{E}_f = 4860.19 + j1399.60\text{ V}$，求 $|\mathbf{E}_f| = \sqrt{4860.19^2 + 1399.60^2}$。

```text
傳統老方法：按 [ ( ] [ 4860.19 ] [ x² ] [ + ] [ 1399.60 ] [ x² ] [ ) ] [ √ ] ➔ 耗時 15 秒且易按錯！

🚀 fx-127 秒殺法（3 秒完成）：
步驟 1：按 [ 4860.19 ] [ + ] [ 1399.60 ] [2ndF] [ i ]
步驟 2：按 [2ndF] [ →rθ ]
         👉 螢幕秒出大小：[ 5057.73 ]！
```

## 四、電力系統與電路學 4 大典型考題秒殺 SOP

### 1. 對稱成分法：旋轉相量 $a$ 運算（$a = 1\angle 120^\circ$）
* **算式**：$a \times \mathbf{I}_b = (1\angle 120^\circ) \times (-6.92) = 6.92\angle 300^\circ$
* **按鍵**：`6.92` ➔ `2ndF` `∠` ➔ `300` ➔ `2ndF` `→xy` ➔ 實部顯示 **`3.46`**，按 `2ndF` `b` 虛部顯示 **`-5.9929`**。

### 2. 並聯阻抗相加（倒數和法）
* **算式**：$\mathbf{Z}_{eq} = \frac{1}{\frac{1}{\mathbf{Z}_1} + \frac{1}{\mathbf{Z}_2}}$
* **按鍵建議**：在 CPLX 模式下，直接利用 `1/x`（倒數鍵）進行分步累積，避免括號層數過深。

### 3. 三相交流功率計算（$S = \sqrt{3} V_L I_L^*$）
* **視在功率**：幅值直乘 $\sqrt{3} \times V_L \times I_L$。
* **功因角**：由 $\theta = \cos^{-1}(\text{PF})$，直接按 `0.8` ➔ `2ndF` `cos⁻¹` ➔ 秒出 `36.87°`。

## 五、考場防呆與避坑指南

1. **避免在 CPLX 模式下按倒退鍵（Backspace）**：
   - 部分批次的晶片在複數模式下若使用倒退修正位元，可能導致內部暫存器數值異常。**若按錯，直接按 `ON/C` 重新輸入整組數值最穩當！**
2. **負號鍵請按 `+/-` 而非減號 `-`**：
   - 輸入負角度（如 $-30^\circ$）時，請按 `30` ➔ `+/-`，避免計算機誤判為減法運算。
3. **兩組電池防護**：
   - 考前務必更換全新的鈕扣電池（LR44 / G13），避免考場上液晶螢幕因電壓不足變淡！
