# 🇦🇺 Australian Job & Visa Radar Pipeline Skill

## 1. Overview
This skill guides any agent on how to update and maintain the Australian Heavy Electrical Job Radar system in compliance with `SPEC_澳洲重電求職戰情室架構規格書.md`.

## 2. Invariants
- **Never edit `au-job-radar-data.js` directly.** It is auto-generated by `scripts/au_job_radar_crawler.py`.
- **Always preserve the 6 sections** in `scripts/au_job_radar_crawler.py`.
- **Always use `build_links()`** to construct multi-platform search links (Seek, LinkedIn with verified geoId `101902409`/`101471505`, Indeed AU, Google Jobs with `&ibp=htl;jobs`, and official career portals).
- **Never include former employer names (e.g. CTCI / 中鼎).** Keep all job summaries and market analytics objective and industry-standard.

## 3. Execution Commands
```bash
# 1. Regenerate database
python3 scripts/au_job_radar_crawler.py

# 2. Verify URL formatting
python3 -c "
with open('au-job-radar-data.js') as f:
    for line in f:
        if 'Url\":' in line:
            print(line.strip())
"

# 3. Test front-end locally
open australia-job-radar.html
```
