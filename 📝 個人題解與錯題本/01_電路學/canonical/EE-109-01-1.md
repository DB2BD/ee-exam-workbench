# 109 年電路學第 1 題

> ⚠️ 本檔由年度詳解分割產生；尚未完成獨立逐步重算，禁止視為已校驗答案。

## 一、三運算放大器儀表放大器轉移關係推導（25 分）

### 📌 題目與已知條件
試求下圖三運算放大器電路之輸出電壓 $v_o$ 與輸入電壓 $v_1, v_2$ 的數學關係式。（25 分）
* 第一級輸入緩衝放大級：包含兩個理想運算放大器，正向輸入端分別輸入 $v_1$（上）與 $v_2$（下），負向反饋電阻各為 $R_1$，兩反相端間連接增益設定電阻 $R_g$。
* 第二級差動放大級：包含一個差動運算放大器，輸入電阻均為 $R_2$，反饋電阻及下接地電阻均為 $R_0$。

---

### 💡 核心考點與破題關鍵
1. **理想運算放大器黃金法則**：
   - 虛短路（Virtual Short）：$v_+ = v_-$。
   - 虛斷路（Virtual Open）：輸入端電流 $i_+ = i_- = 0$。
2. **第一級差動輸出推導**：
   - 上側反相端電位為 $v_1$，下側反相端電位為 $v_2$。
   - 流經 $R_g$ 之電流：$i_g = \frac{v_1 - v_2}{R_g}$（由上往下流）。
   - 上側 OpAmp 輸出：$v_{o1} = v_1 + i_g R_1 = v_1 + \frac{R_1}{R_g}(v_1 - v_2)$。
   - 下側 OpAmp 輸出：$v_{o2} = v_2 - i_g R_1 = v_2 - \frac{R_1}{R_g}(v_1 - v_2)$。
   - 第一級差動輸出：$v_{o1} - v_{o2} = (v_1 - v_2) + \frac{2R_1}{R_g}(v_1 - v_2) = \left(1 + \frac{2R_1}{R_g}\right)(v_1 - v_2)$。
3. **第二級標準差動放大器**：
   - 差動級反相輸入接 $v_{o1}$，同相輸入接 $v_{o2}$。
   - 輸出電壓：$v_o = \frac{R_0}{R_2}(v_{o2} - v_{o1}) = \frac{R_0}{R_2}\left(1 + \frac{2R_1}{R_g}\right)(v_2 - v_1)$。

---

### ✏️ 步驟式詳細數學推導
1. **第一級輸入緩衝級節點分析**：
   - 設上側 OpAmp 輸出為 $v_{o1}$，下側 OpAmp 輸出為 $v_{o2}$。
   - 由虛短路性質，上側反相端電壓為 $v_1$，下側反相端電壓為 $v_2$。
   - 因 OpAmp 輸入端不吸入電流，流經上側反饋電阻 $R_1$、增益電阻 $R_g$ 與下側反饋電阻 $R_1$ 之電流為同一串聯電流 $i$：
     $$i = \frac{v_1 - v_2}{R_g}$$
   - 上側輸出電壓：
     $$v_{o1} = v_1 + R_1 i = v_1 + \frac{R_1}{R_g}(v_1 - v_2)$$
   - 下側輸出電壓：
     $$v_{o2} = v_2 - R_1 i = v_2 - \frac{R_1}{R_g}(v_1 - v_2)$$
   - 兩輸出端差模電壓：
     $$\mathbf{v_{o2} - v_{o1} = (v_2 - v_1) - \frac{2R_1}{R_g}(v_1 - v_2) = \left(1 + \frac{2R_1}{R_g}\right)(v_2 - v_1)}$$
2. **第二級差動放大級節點分析**：
   - 差動 OpAmp 同相端電位 $v_+$（由 $v_{o2}$ 經分壓電路）：
     $$v_+ = v_{o2} \cdot \frac{R_0}{R_2 + R_0}$$
   - 由虛短路 $v_- = v_+$，在反相端列 KCL：
     $$\frac{v_{o1} - v_-}{R_2} = \frac{v_- - v_o}{R_0} \implies \frac{v_{o1}}{R_2} + \frac{v_o}{R_0} = v_- \left(\frac{1}{R_2} + \frac{1}{R_0}\right) = v_+ \cdot \frac{R_2 + R_0}{R_2 R_0}$$
     $$\frac{v_{o1}}{R_2} + \frac{v_o}{R_0} = \left(v_{o2} \frac{R_0}{R_2 + R_0}\right) \frac{R_2 + R_0}{R_2 R_0} = \frac{v_{o2}}{R_2}$$
     $$\frac{v_o}{R_0} = \frac{v_{o2} - v_{o1}}{R_2} \implies \mathbf{v_o = \frac{R_0}{R_2} (v_{o2} - v_{o1})}$$
3. **整合第一級與第二級推導總輸出公式**：
   $$\mathbf{v_o = \frac{R_0}{R_2} \left(1 + \frac{2R_1}{R_g}\right) (v_2 - v_1) = -\frac{R_0}{R_2} \left(1 + \frac{2R_1}{R_g}\right) (v_1 - v_2)}$$

---

### 🎯 第一題 滿分關鍵與結論
* **輸出與輸入電壓數學關係式**：
  $$\mathbf{v_o = \frac{R_0}{R_2}\left(1 + \frac{2R_1}{R_g}\right)(v_2 - v_1)}$$
