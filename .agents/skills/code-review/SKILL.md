# Code Review Skill (by Matt Pocock)

Performs comprehensive dual-axis evaluation of changed code.

## 🎯 Evaluation Dimensions

1. **Axis 1 - Specification & Business Logic Alignment**:
   - Does the implementation fully solve the requested requirements?
   - Are edge cases and failure modes gracefully handled?
2. **Axis 2 - Engineering Rigor & Code Quality**:
   - KaTeX / LaTeX formula correctness and escaping.
   - Performance, memory leaks, and unnecessary complexity.
   - Code readability, naming conventions, and modularity.
3. **Actionable Feedback**:
   - Deliver clear line-by-line diffs and explicit recommendations.
