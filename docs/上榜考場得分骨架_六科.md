# 電機工程技師上榜｜六科考場得分骨架

> 這不是另一份筆記，也不是官方配分表。它只固定每題應留下的閱卷證據：先定義、再列式、再代入、最後寫單位與結論。沒有官方逐步配分時，不替每一步捏造分數。

完整整卷另套用 [考場 120 分鐘得分節奏](./上榜考場120分鐘得分節奏.md)，先讓每題留下可閱卷證據，再處理最可能補回的配分。

## 每題共同骨架

拿到題目後依序留下五層證據；不必回填專案，也不需把骨架抄成長篇文字。

1. **定義**：寫已知、所求、參考方向／正負號、必要假設與適用條件。
2. **起手式**：先寫控制方程、定理或等效模型，再代數字；不要只放計算機結果。
3. **中間量**：保留閱卷者能追蹤的關鍵轉換，例如初值、標么基準、相電壓、工作區或積分係數。
4. **結論**：框出題目要求的量，附單位、方向、相角、時間範圍或條件分支。
5. **快驗**：用回代、守恆、量綱、極端情況或第二種表示法檢查；驗算不取代正文列式。

若題幹缺參數或存在多根，先寫假設，再給條件解；不要把慣例冒充題目已知。可直接套用 [10 題條件題安全作答卡](./上榜精確解答邊界_條件題處理.md)。

## 01 電路學

起手順序：

1. 畫等效電路，標電壓極性、電流方向、同名端與開關前後狀態。
2. 暫態題先寫 \(i_L(0^-)=i_L(0^+)\)、\(v_C(0^-)=v_C(0^+)\)；交流題先聲明峰值或 RMS 相量。
3. 寫 KCL／KVL、元件式或狀態方程，再解未知量；二階題必須有兩個獨立初始條件。
4. 末行寫參考方向、單位及適用時間；負值要解釋為與原假設方向相反。

核對範本：[RLC 暫態 `EE-114-01-3`](../📝%20個人題解與錯題本/01_電路學/canonical/EE-114-01-3.md)｜[互感耦合 `EE-112-01-2`](../📝%20個人題解與錯題本/01_電路學/canonical/EE-112-01-2.md)

## 02 電子學（含電力電子）

起手順序：

1. 標元件端點、電壓極性、電流方向與候選工作狀態。
2. 寫清楚採用的元件模型與區域條件，例如理想二極體、截止／導通、連續或不連續導通。
3. 依每個狀態畫等效電路並列 KCL／KVL；求完後回查偏壓、電流方向或工作區是否自洽。
4. 週期切換題寫成完整分段函數，並明示切換瞬間的連續量與時間區間。

核對範本：[半波整流 EE-110-02-3](../📝%20個人題解與錯題本/02_電子學_含電力電子/canonical/EE-110-02-3.md)｜[反相降升壓 EE-112-02-3](../📝%20個人題解與錯題本/02_電子學_含電力電子/canonical/EE-112-02-3.md)

## 03 工程數學

起手順序：

1. 先寫所用定理、轉換或分布成立的條件與積分範圍。
2. 變數代換必須保留 Jacobian／微分係數；機率題先驗證正規化與支持集。
3. 複變題列極點、輪廓方向、留數公式及弧積分消失理由；線性代數題保留關鍵消去或特徵條件。
4. 末行回答題目要求的函數、區間、機率或數值，不只停在中間積分式。

核對範本：[聯合機率 `EE-113-03-6`](../📝%20個人題解與錯題本/03_工程數學/canonical/EE-113-03-6.md)｜[留數積分 `EE-113-03-3`](../📝%20個人題解與錯題本/03_工程數學/canonical/EE-113-03-3.md)

## 04 電機機械

起手順序：

1. 先判斷 Y／Δ、發電機／電動機、轉差與功率正方向；線量與相量不可直接混用。
2. 畫每相等效電路或寫反電勢式，列出必要的線相轉換、同步轉速與角速度。
3. 功率依「輸入 → 銅損／鐵損／機械損 → 電磁轉換 → 輸出」逐層寫；轉矩要說明是電磁轉矩或軸轉矩。
4. 使用磁化曲線或試驗資料時，明示轉速、基準與內插假設；末行附功率因數超前／落後或轉矩方向。

核對範本：[直流機磁化曲線 `EE-112-04-5`](../📝%20個人題解與錯題本/04_電機機械/canonical/EE-112-04-5.md)｜[同步發電機 `EE-114-04-4`](../📝%20個人題解與錯題本/04_電機機械/canonical/EE-114-04-4.md)

## 05 電力系統

起手順序：

1. 先列共同基準、匯流排類型、淨注入正負號與已知／未知狀態量。
2. 畫單線圖、序網路或 \(Y_{\text{bus}}\) 關係，再寫潮流、故障或搖擺方程；不要直接跳數值。
3. 遇到無效功率或容量限制，先檢查是否超限，再明示 PV→PQ、飽和或其他條件切換。
4. 末行分清匯流排注入、發電機輸出與負載；附 pu／MW／Mvar、方向及採用頻率。

核對範本：[PV 超限潮流 `EE-114-05-2`](../📝%20個人題解與錯題本/05_電力系統/canonical/EE-114-05-2.md)｜[搖擺方程 `EE-114-05-5`](../📝%20個人題解與錯題本/05_電力系統/canonical/EE-114-05-5.md)

## 06 工業配電

起手順序：

1. 畫故障點或負載點所見的單線等效，寫共同 \(S_b\)、各層 \(V_b\) 與設備額定值。
2. 電抗、短路容量與百分阻抗全部換到同一基準後，才做串並聯；保留每條支路來源。
3. 分清短路電流、短路容量、設備額定遮斷能力與允許壓降，不能用其中一個量代替另一個。
4. 末行標三相／單相、線電壓／相電壓、RMS／峰值與安全裕度；缺少功因或效率時先條件化。

核對範本：[短路容量 `EE-113-06-4`](../📝%20個人題解與錯題本/06_工業配電/canonical/EE-113-06-4.md)｜[壓降抑制 `EE-110-06-4`](../📝%20個人題解與錯題本/06_工業配電/canonical/EE-110-06-4.md)

## 停筆前 30 秒

- 題目每一小題都有明確落點，沒有只算未答。
- 最終量有單位、方向／相角、有效時間或條件。
- 使用的假設寫在結果之前，而不是事後補一句。
- 圖、公式與最後數值的正負方向一致。
- 不因最後數字漂亮就刪掉必要列式；閱卷者必須看得見得分證據。
