# 112 年電路學逐題詳解

> 本檔以考選部官方 PDF、逐題裁切與電路圖裁切為準。官方 PDF 的 SHA-256 為
> `b4193f5840550ee012eb0022e2631022012ce912661ae40b82b6642f041167ac`。
> 四題數值均經另一種計算或功率守恆核對。

## 一、三相理想變壓器

### 題目辨識

原題與接線圖：[官方原題裁切](../../../依考科分類/🏛️_國考同級參考題庫/01_電路學/images/questions/GK_112年_電路學_Q01.png)、[電路圖裁切](../../../依考科分類/🏛️_國考同級參考題庫/01_電路學/images/figures/GK_112年_電路學_Q01_figure-01.png)。

一次側與二次側的三個繞組都首尾相接成閉合三角形，三條線分別接在三個頂點，因此接法為：

```text
Δ－Δ（三角形－三角形）連接
```

圖示一次側線電壓為 `V_LP=2.4 kV`，每相匝數比為：

```text
a = N_P/N_S = 4/1
```

負載實功率為 120 kW、功率因數為 0.8 落後，所以三相視在功率大小為：

```text
|S_3φ| = P/pf = 120/0.8 = 150 kVA
```

### 相電壓

三角形接法的相電壓等於線電壓：

```text
V_PP = V_LP = 2400 V
V_PS = V_PP/a = 2400/4 = 600 V
V_LS = V_PS = 600 V
```

其中下標第一碼 `L/P` 表示線量或相量，第二碼 `P/S` 表示一次側或二次側。

### 四個電流

二次側每相視在功率為 `150/3=50 kVA`，故二次側相電流：

```text
I_PS = |S_3φ|/(3V_PS)
     = 150000/(3×600)
     = 83.333 A
```

理想變壓器的電流比與匝數比互為倒數：

```text
I_PP = I_PS/a
     = 83.333/4
     = 20.833 A
```

三角形接法的線電流大小為相電流的 `√3` 倍，因此：

```text
I_LP = √3 I_PP = √3×20.833 = 36.084 A
I_LS = √3 I_PS = √3×83.333 = 144.338 A
```

功率因數角為 `φ=cos⁻¹(0.8)=36.87°`。各繞組相電流落後其對應相電壓 36.87°；由於題圖沒有標出同名端與相序，本題列出不受相序選擇影響的電流有效值。

### 答案

```text
接法：Δ－Δ
I_LP = 36.08 A
I_LS = 144.34 A
I_PP = 20.83 A
I_PS = 83.33 A
```

### 獨立驗算

由一次側與二次側分別計算實功率：

```text
P_P = 3V_PP I_PP pf
    = 3×2400×20.833×0.8
    = 120 kW

P_S = 3V_PS I_PS pf
    = 3×600×83.333×0.8
    = 120 kW
```

兩側功率相等，且 `I_LP/I_LS=1/4`，同時符合能量守恆與 4：1 匝數比。

## 二、電阻最大功率

### 題目辨識

原題與電路圖：[官方原題裁切](../../../依考科分類/🏛️_國考同級參考題庫/01_電路學/images/questions/GK_112年_電路學_Q02.png)、[電路圖裁切](../../../依考科分類/🏛️_國考同級參考題庫/01_電路學/images/figures/GK_112年_電路學_Q02_figure-01.png)。

令 40 V 電源左端節點為 `L`、右端為 `N`，取 `V_N=0`，由圖示極性得 `V_L=40 V`。負載 `R` 上、下端分別記為 `T`、`B`。

### 戴維寧電壓

先將負載開路。上支路的 80 Ω 與 20 Ω 串聯，下支路的 10 Ω 與 90 Ω 串聯，兩支路都跨接在 40 V 電源兩端：

```text
I_top = 40/(80+20) = 0.4 A
V_T = 40 - 80×0.4 = 8 V

I_bottom = 40/(10+90) = 0.4 A
V_B = 40 - 10×0.4 = 36 V
```

若以負載上端對下端為正：

```text
V_th = V_T - V_B = 8 - 36 = -28 V
|V_th| = 28 V
```

負號只表示實際開路電壓的正端在負載下端；最大功率計算使用其平方。

### 戴維寧電阻

將獨立 40 V 電壓源設為零，也就是以短路取代。此時電源左右兩端成為同一節點：

```text
R_T = 80 || 20 = 16 Ω
R_B = 10 || 90 = 9 Ω
R_th = R_T + R_B = 16+9 = 25 Ω
```

因此最大功率傳輸條件與最大功率為：

```text
R = R_th = 25 Ω
P_R,max = |V_th|²/(4R_th)
        = 28²/(4×25)
        = 7.84 W
```

### 答案

```text
R 的最佳值 = 25 Ω
R 可取得的最大功率 = 7.84 W
```

### 獨立驗算

不使用戴維寧定理，直接對接上任意 `R` 後的 `T`、`B` 兩節點列 KCL，可解得：

```text
V_T = (8R+648)/(R+25)
V_B = (36R+648)/(R+25)
V_T-V_B = -28R/(R+25)
```

因此：

```text
P_R(R) = (V_T-V_B)²/R
       = 784R/(R+25)²

dP_R/dR = 784(25-R)/(R+25)³
```

`R=25 Ω` 為唯一正值極大點，代回得到 `P_R=7.84 W`，與戴維寧法一致。

## 三、端子 a-b 等效電阻

### 題目辨識

原題與電路圖：[官方原題裁切](../../../依考科分類/🏛️_國考同級參考題庫/01_電路學/images/questions/GK_112年_電路學_Q03.png)、[電路圖裁切](../../../依考科分類/🏛️_國考同級參考題庫/01_電路學/images/figures/GK_112年_電路學_Q03_figure-01.png)。

端子 `a` 的 33 Ω 與端子 `b` 的 40 Ω 都是全電路必經元件，故可先求它們右側兩節點 `T`、`B` 間的內部等效電阻，最後再串聯 73 Ω。

圖中右側垂直的 40 Ω 與 20 Ω 中間沒有其他分支，可先合併為 `60 Ω`。取 `B` 為 0 V，從 `T` 注入 1 A 測試電流。未知節點為 `V_T,V_C,V_D,V_E`，KCL 為：

```text
(V_T-V_C)/10 + (V_T-V_D)/50 = 1

(V_C-V_T)/10 + V_C/10
  + (V_C-V_D)/40 + (V_C-V_E)/60 = 0

(V_D-V_T)/50 + (V_D-V_C)/40
  + (V_D-V_E)/60 = 0

V_E/30 + (V_E-V_C)/60
  + (V_E-V_D)/60 = 0
```

聯立解得：

```text
V_T = 461/27 V
V_C = 76/9 V
V_D = 92/9 V
V_E = 14/3 V
```

因測試電流為 1 A：

```text
R_TB = V_T/1 A = 461/27 Ω
```

加回兩端串聯電阻：

```text
R_ab = 33 + 461/27 + 40
     = 2432/27 Ω
     ≈ 90.074 Ω
```

### 答案

```text
R_ab = 2432/27 Ω ≈ 90.07 Ω
```

### 獨立驗算

把上述節點電壓代回每一個內部電阻，以 `P=(ΔV)²/R` 加總，可得內部七個電阻總耗功恰為：

```text
P_internal = 461/27 W
```

兩個端點串聯電阻皆流過 1 A，耗功合計 `33+40=73 W`。故整體測試功率：

```text
P_total = 461/27 + 73
        = 2432/27 W
```

對 1 A 測試源，`R_eq=P/I²=2432/27 Ω`，與節點電壓法相同。

## 四、端子 a-b 等效阻抗

### 題目辨識

原題與電路圖：[官方原題裁切](../../../依考科分類/🏛️_國考同級參考題庫/01_電路學/images/questions/GK_112年_電路學_Q04.png)、[電路圖裁切](../../../依考科分類/🏛️_國考同級參考題庫/01_電路學/images/figures/GK_112年_電路學_Q04_figure-01.png)。

此網路含跨接 `a` 與最右節點的 `-j4 Ω` 支路，不能當成單純梯形網路由右向左逐段串並聯。以下以測試源節點法直接求輸入阻抗。

令 `b` 為參考地，沿中間水平支路由左至右依序將節點記為 `v_0=v_a,v_1,v_2,v_3`。在 `a` 注入 1 A。各支路導納為：

```text
1/(j6)   = -j/6
1/(j8)   = -j/8
1/(j12)  = -j/12
1/(-j6)  =  j/6
1/(-j4)  =  j/4
```

KCL 的節點導納矩陣為：

```text
┌ 1/4+j/12   -1/4          0          -j/4     ┐ ┌v₀┐   ┌1┐
│ -1/4       1/4+j/24     -j/6         0       │ │v₁│ = │0│
│ 0          -j/6          1/2+j/24   -1/2     │ │v₂│   │0│
└ -j/4        0            -1/2        1/2+j/6 ┘ └v₃┘   └0┘
```

解得 1 A 測試電流下的輸入節點電壓：

```text
v₀ = 203400/307429 + j(435768/307429) V
   ≈ 0.661616 + j1.417459 V
```

所以：

```text
Z_ab = v₀/(1 A)
     = 0.661616 + j1.417459 Ω
     ≈ 1.56427∠64.9786° Ω
```

### 答案

```text
Z_ab ≈ 0.6616 + j1.4175 Ω
     ≈ 1.5643∠64.98° Ω
```

### 獨立驗算

改以 `V_a=1 V` 驅動同一網路，消去其餘三個節點後得到輸入導納：

```text
Y_ab = 2825/10448 - j(18157/31344) S
     ≈ 0.2703867 - j0.5792815 S
```

其倒數為：

```text
1/Y_ab = 0.661616 + j1.417459 Ω
```

此外，1 V 測試下兩個實電阻的支路電流分別為：

```text
I_4Ω = 245/2612 - j(295/1306) A
I_2Ω = -615/5224 + j(215/5224) A
```

實電阻總耗功為：

```text
4|I_4Ω|² + 2|I_2Ω|²
= 2825/10448 W
= Re{Y_ab}×1²
```

輸入實功率與電阻耗功完全一致；虛部也由 `1/Y_ab` 反算一致，故數值與符號均通過功率平衡核對。
