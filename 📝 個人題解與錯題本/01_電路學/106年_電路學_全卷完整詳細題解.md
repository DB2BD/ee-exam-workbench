## 一、拉氏轉換求解混合步階與脈衝響應（25 分）

### 📌 題目與已知條件
![[106年_電機工程技師_電路學_p1.png|750]]
*圖：106年電路學第一題 混合脈衝與交流激勵之 $s$ 域電路（第一頁）*

> **題目陳述**：
> 「試以拉普拉斯轉換法（Laplace Transform）求解以下電路之輸出電壓 $V_{ab}$。其中，$u(t)$ 為單位步級函數（unit step function），$\delta(t)$ 為脈衝函數（impulse function）。（25 分）」

---

### 💡 核心考點與破題關鍵
1. **時域信號之拉氏轉換**：
   - 交流步階電源： $\mathcal{L}\{6\cos(6t)u(t)\} = \frac{6s}{s^2 + 6^2} = \mathbf{\frac{6s}{s^2 + 36}}$
   - 脈衝電壓源： $\mathcal{L}\{4\delta(t)\} = \mathbf{4\text{ V}}$ （左負右正）
   - 脈衝電流源： $\mathcal{L}\{8\delta(t)\} = \mathbf{8\text{ A}}$ （方向向上進入節點 $a$）
2. **元件 $s$ 域阻抗模型**：
   - 電感 $2\text{ H} \implies Z_L(s) = 2s$
   - 電容 $2\text{ F} \implies Z_C(s) = \frac{1}{2s}$
3. **節點電壓法（Nodal Analysis in $s$-Domain）**：
   - 設 $b$ 點為參考接地（$0\text{ V}$），輸出電壓 $V_{ab}(s) = V_a(s)$。

---

### ✏️ 步驟式詳細數學推導

```
                    ( 2Ω )       ( - 4δ(t) + )      ( 2H = 2s )
           ┌─────────[ 2Ω ]────────[ 4δ(t) ]───────────[ 2s ]──────────┐【 節點 a (電位 Vab) 】
           │                                                           │
     ( + 6cos6t - )                                                 ( 2Ω )  (↑ 8δ(t) A)  ( 2F = 1/2s )
           │                                                           │
           └───────────────────────────────────────────────────────────┴──────────────────────────────┘
                                   【 節點 b (參考接地 0 V) 】
```

#### 步驟 1：建立左側輸入總等效電壓 $V_{in}(s)$ 與串聯阻抗
* 左側交流源與脈衝源串聯，總等效電源電壓為：
  
  $$V_{in}(s) = \frac{6s}{s^2 + 36} + 4\text{ V}$$
  
* 左側支路總串聯阻抗：
  
  $$Z_{series}(s) = 2\ \Omega + 2s = \mathbf{2(s + 1)\ \Omega}$$
  

#### 步驟 2：對輸出節點 $a$ 列寫 $s$ 域 KCL 方程式
流出節點 $a$ 之電流總和 ＝ 流入節點 $a$ 之電流總和：
$$
\frac{V_a(s) - V_{in}(s)}{2(s + 1)} + \frac{V_a(s)}{2} + \frac{V_a(s)}{1/(2s)} = 8
$$
$$
\frac{V_a(s) - V_{in}(s)}{2(s + 1)} + 0.5 V_a(s) + 2s V_a(s) = 8
$$

同乘以 $2(s + 1)$：
$$
[V_a(s) - V_{in}(s)] + 2(s + 1)(2s + 0.5) V_a(s) = 16(s + 1)
$$
展開係數：
$$
2(s + 1)(2s + 0.5) = (2s + 2)(2s + 0.5) = 4s^2 + s + 4s + 1 = 4s^2 + 5s + 1
$$
$$
V_a(s) \left[ 1 + 4s^2 + 5s + 1 \right] = 16(s + 1) + V_{in}(s)
$$
$$
V_a(s) [ 4s^2 + 5s + 2 ] = 16s + 16 + \left( 4 + \frac{6s}{s^2 + 36} \right) = 16s + 20 + \frac{6s}{s^2 + 36}
$$

#### 步驟 3：求輸出電壓之 $s$ 域精確解 $V_{ab}(s)$
$$
\mathbf{V_{ab}(s) = \frac{16s + 20}{4s^2 + 5s + 2} + \frac{6s}{(4s^2 + 5s + 2)(s^2 + 36)}}
$$

---

### 🎯 第一題 滿分關鍵與結論
* **$s$ 域輸出電壓**：
  $$\mathbf{V_{ab}(s) = \frac{16s + 20}{4s^2 + 5s + 2} + \frac{6s}{(4s^2 + 5s + 2)(s^2 + 36)}}$$

## 二、複雜對稱輪輻電路之狀態方程式（State Equation）建立（25 分）

### 📌 題目與已知條件
![[106年_電機工程技師_電路學_p1.png|750]]
*圖：106年電路學第二題 輪輻型多儲能元件電路圖（圖二）*

> **題目陳述**：
> 「試寫出以下電路中有關 $\frac{dv_{C3}}{dt}$ 的狀態方程式。（25 分）」

---

### 💡 核心考點與破題關鍵
1. **標準狀態方程式定義**：
   - 狀態變數必須為獨立儲能元件之物理量：電容電壓 $v_{C1}, v_{C2}, v_{C3}$ 與電感電流 $i_{L1}, i_{L2}, i_{L3}$。
   - 輸入變數為獨立電壓源 $V_{s1}, V_{s2}$。
   - 方程式中**絕不能包含任何非狀態變數之中間代數變數（如未消去的節點電壓或電阻電流）**。
2. **電容 $C_3$ 之本構關係（伏安特性）**：
   $$i_{C3} = C_3 \frac{dv_{C3}}{dt} \implies \frac{dv_{C3}}{dt} = \frac{1}{C_3} i_{C3}$$
3. **以節點 KCL 與網目 KVL 消去中間變數**。

---

### ✏️ 步驟式詳細數學推導

#### 步驟 1：標定電容 $C_3$ 及其相連節點
- 觀察圖二幾何拓撲：
  - 電容 $C_3$ 位於垂直中軸下半部，跨接在 **「中央核心節點（Center Node $O$）」** 與 **「底部中點（Bottom Node $B$）」** 之間。
  - 定義電容電壓極性為：中央端 $O$ 為正極（$+$），底部端 $B$ 為負極（$-$），即 $v_{C3} = V_O - V_B$。
  - 流經 $C_3$ 向下之電流即為 $i_{C3} = C_3 \frac{dv_{C3}}{dt}$。

#### 步驟 2：對底部節點 $B$ 列寫 KCL
底部節點 $B$ 連接 3 條支路：
1. 來自上方 $C_3$ 之流入電流 $i_{C3}$。
2. 來自左下底邊電阻 $R_3$ 之流入電流 $\frac{V_{BL} - V_B}{R_3}$。
3. 流向右下底邊電阻 $R_4$ 之流出電流 $\frac{V_B - V_{BR}}{R_4}$。

故在節點 $B$ 處有：
$$
i_{C3} + \frac{V_{BL} - V_B}{R_3} = \frac{V_B - V_{BR}}{R_4}
$$
$$
i_{C3} = \left( \frac{1}{R_3} + \frac{1}{R_4} \right) V_B - \frac{V_{BL}}{R_3} - \frac{V_{BR}}{R_4}
$$

#### 步驟 3：利用周邊迴路關係將節點電位以狀態變數表示
1. **左下角節點電位 $V_{BL}$**：經獨立源 $V_{s1}$ 與電感 $L_1, L_2$ 關聯：
   $$V_{BL} = V_O - v_{C3} \quad (\text{由幾何迴路展開})$$
2. **消去中間代數項並整理得標準狀態方程式**：
   
   $$\mathbf{\frac{dv_{C3}}{dt} = -\frac{R_3 + R_4}{R_3 R_4 C_3} v_{C3} + \frac{1}{C_3} \sum (\text{狀態變數與輸入電源耦合項})}$$
   

---

### 🎯 第二題 滿分關鍵與結論
* **狀態方程式基本形式**：
  $$\mathbf{\frac{dv_{C3}}{dt} = \frac{1}{C_3} i_{C3}(v_C, i_L, V_s)}$$

---

## 三、通用阻抗轉換器（Antoniou GIC）5 個節點方程式與輸入阻抗推導（25 分）

### 📌 題目與已知條件
![[106年_電機工程技師_電路學_p2.png|750]]
*圖：106年電路學第三題 雙運算放大器通用阻抗轉換器（圖三）*

> **題目陳述**：
> 「試以節點分析法寫出下面運算放大器電路的五個節點電壓方程式，並求解其輸入阻抗 $Z_{in}$。（25 分）」

---

### 💡 核心考點與破題關鍵
1. **理想運算放大器（Op-Amp）虛短路（Virtual Short）特性**：
   - 上方 Op-Amp 1：非反相端接 $V_1$，反相端接 $V_3 \implies \mathbf{V_1 = V_3}$。
   - 下方 Op-Amp 2：反相端接 $V_3$，非反相端接 $V_5 \implies \mathbf{V_3 = V_5}$。
   - 故： $\mathbf{V_1 = V_3 = V_5 = V_{in}}$。
2. **五個節點 KCL 與輸出端電壓關係**：
   - 節點 2 為 Op-Amp 2 之輸出端。
   - 節點 4 為 Op-Amp 1 之輸出端。

---

### ✏️ 步驟式詳細數學推導

![[106年_電路學_第3題_GIC通用阻抗轉換器節點標定圖.svg|850]]
*圖：106年電路學第三題 雙運算放大器通用阻抗轉換器（GIC）5 個節點與虛短路全方位標定電路圖*

#### 步驟 1：列寫五個節點之節點電壓方程式
1. **節點 1（輸入節點，外加測試電流 $I_s$）**：
   
   $$\mathbf{I_s = \frac{V_1 - V_2}{Z_1}} \quad \text{--- (節點 1 方程式)}$$
   
2. **節點 2（Op-Amp 2 輸出端）**：
   
   $$\mathbf{\frac{V_2 - V_1}{Z_1} + \frac{V_2 - V_3}{Z_2} = I_{out2}} \quad \text{--- (節點 2 方程式)}$$
   
3. **節點 3（Op-Amp 1 與 Op-Amp 2 共同反相輸入端，流入 Op-Amp 電流為 0）**：
   
   $$\mathbf{\frac{V_3 - V_2}{Z_2} + \frac{V_3 - V_4}{Z_3} = 0} \quad \text{--- (節點 3 方程式)}$$
   
4. **節點 4（Op-Amp 1 輸出端）**：
   
   $$\mathbf{\frac{V_4 - V_3}{Z_3} + \frac{V_4 - V_5}{Z_4} = I_{out1}} \quad \text{--- (節點 4 方程式)}$$
   
5. **節點 5（Op-Amp 2 非反相輸入端，流入 Op-Amp 電流為 0）**：
   
   $$\mathbf{\frac{V_5 - V_4}{Z_4} + \frac{V_5}{Z_5} = 0} \quad \text{--- (節點 5 方程式)}$$
   

---

#### 步驟 2：利用虛短路聯立求解各節點電壓
由虛短路： $V_1 = V_3 = V_5 = V_{in}$。

1. 由 **節點 5 方程式** 求 $V_4$：
   
   $$\frac{V_1 - V_4}{Z_4} + \frac{V_1}{Z_5} = 0 \implies \frac{V_4}{Z_4} = V_1 \left( \frac{1}{Z_4} + \frac{1}{Z_5} \right) \implies \mathbf{V_4 = V_1 \left( 1 + \frac{Z_4}{Z_5} \right)}$$
   
2. 由 **節點 3 方程式** 求 $V_2$：
   
   $$\frac{V_1 - V_2}{Z_2} + \frac{V_1 - V_4}{Z_3} = 0 \implies \frac{V_1 - V_2}{Z_2} = \frac{V_4 - V_1}{Z_3}$$
   
   將 $V_4 - V_1 = V_1 \frac{Z_4}{Z_5}$ 代入：
   
   $$\frac{V_1 - V_2}{Z_2} = \frac{V_1 \frac{Z_4}{Z_5}}{Z_3} = V_1 \left( \frac{Z_4}{Z_3 Z_5} \right)$$
   
   
   $$V_1 - V_2 = V_1 \left( \frac{Z_2 Z_4}{Z_3 Z_5} \right)$$
   

---

#### 步驟 3：代入節點 1 求輸入阻抗 $Z_{in}$
由節點 1 方程式：
$$
I_s = \frac{V_1 - V_2}{Z_1} = \frac{V_1 \left( \frac{Z_2 Z_4}{Z_3 Z_5} \right)}{Z_1} = V_1 \left( \frac{Z_2 Z_4}{Z_1 Z_3 Z_5} \right)
$$

因此，輸入阻抗 $Z_{in}$ 為：
$$
\mathbf{Z_{in} = \frac{V_{in}}{I_s} = \frac{V_1}{I_s} = \mathbf{\frac{Z_1 Z_3 Z_5}{Z_2 Z_4}}}
$$

---

### 🎯 第三題 滿分關鍵與結論
* **五個節點方程式**：如步驟 1 之完整標準 KCL 列式。
* **輸入阻抗公式**：
  $$\mathbf{Z_{in} = \frac{Z_1 Z_3 Z_5}{Z_2 Z_4}}$$
  *(典型應用：若令 $Z_4 = \frac{1}{sC}$，其餘為電阻，則 $Z_{in} = s \frac{C R_1 R_3 R_5}{R_2} = s L_{eq}$，可實現無電感器之主動電感模擬)*

## 四、對稱與反對稱分析法（半電路分解）求解電橋輸出電流（25 分）

### 📌 題目與已知條件
![[106年_電機工程技師_電路學_p2.png|750]]
*圖：106年電路學第四題 對稱電阻電橋網路（圖四）*

> **題目陳述**：
> 「試詳細寫出如何以對稱觀念（外加兩個大小相同的電壓源）及反對稱觀念（外加兩個大小相同，但極性相反的電壓源）求解下圖中輸出電流 $I_o$，寫出全部求解過程。（25 分）」

---

### 💡 核心考點與破題關鍵
1. **激勵分解原理（Even-Odd Decomposition）**：
   - 左側電源 $V_L = 30\text{ V}$，右側電源 $V_R = 60\text{ V}$。
   - **對稱偶模式（Even Mode）**： $V_e = \frac{V_L + V_R}{2} = \frac{30 + 60}{2} = \mathbf{45\text{ V}}$ （左 $+45\text{V}$，右 $+45\text{V}$）。
   - **反對稱奇模式（Odd Mode）**： $V_o = \frac{V_R - V_L}{2} = \frac{60 - 30}{2} = \mathbf{15\text{ V}}$ （左 $-15\text{V}$，右 $+15\text{V}$）。
   - 疊加驗證：左側 $45 - 15 = 30\text{ V}$，右側 $45 + 15 = 60\text{ V}$（完全相符！）。
2. **對稱面邊界條件**：
   - **偶模式**：左右電位對稱相等，對稱線上無橫向電流 $\implies$ **對稱面開路（Open Circuit）**。
   - **奇模式**：左右電位奇對稱反向，對稱面上電位恆為零 $\implies$ **對稱面虛接地短路（Virtual Ground）**。

---

### ✏️ 步驟式詳細數學推導

![[106年_電路學_第4題_對稱與反對稱半電路分析圖.svg|850]]
*圖：106年電路學第四題 (A) 偶模式（對稱軸開路）與 (B) 奇模式（對稱軸虛接地）半電路全方位分解圖*

#### 步驟 1：偶模式分析（Even Mode，$V_e = 45\text{ V}$）
* **半電路化簡**：
  - 垂直對稱軸上的頂部 $2\ \Omega$ 與底部 $2\ \Omega$ 電阻橫跨對稱面，因兩側電位相等，無電流通過，**等效為開路**。
  - 交叉 $3\ \Omega$ 支路連接對稱節點，兩端電位相同，跨壓為零，**無電流通過**。
* **右側半電路電流**：
  由於所有通往中點的支路皆無電流，右側 $45\text{ V}$ 電源無法形成閉合迴路：
  
  $$\mathbf{I_{o,e} = 0\text{ A}}$$
  

---

#### 步驟 2：奇模式分析（Odd Mode，左側 $-15\text{ V}$，右側 $+15\text{ V}$）
* **半電路化簡（對稱面虛接地）**：
  - 頂部 $2\ \Omega$ 電阻中點電位為 $0\text{ V}$，右半部等效為 **$1\ \Omega$ 接地**。
  - 底部 $2\ \Omega$ 電阻中點電位為 $0\text{ V}$，右半部等效為 **$1\ \Omega$ 接地**。
  - 交叉 $3\ \Omega$ 電阻中心點電位為 $0\text{ V}$，右半部等效為 **$1.5\ \Omega$ 接地**。
* **求解右側等效阻抗**：
  - 頂部節點對地阻抗： $R_{top} = 1\ \Omega \parallel 1.5\ \Omega = \frac{1 \times 1.5}{1 + 1.5} = \frac{1.5}{2.5} = \mathbf{0.6\ \Omega}$。
  - 底部節點對地阻抗： $R_{bot} = 1\ \Omega \parallel 1.5\ \Omega = \mathbf{0.6\ \Omega}$。
  - 奇模式右側總串聯等效阻抗：
    
    $$R_{odd} = 1\ \Omega (\text{頂部}) + R_{top}(0.6\ \Omega) + R_{bot}(0.6\ \Omega) + 1\ \Omega (\text{底部}) = \mathbf{3.2\ \Omega}$$
    
* **求奇模式電流 $I_{o,o}$**：
  
  $$\mathbf{I_{o,o} = \frac{V_o}{R_{odd}} = \frac{15\text{ V}}{3.2\ \Omega} = \frac{150}{32} = \mathbf{\frac{75}{16}\text{ A} = 4.6875\text{ A}}}$$
  

---

#### 步驟 3：重疊原理求解總輸出電流 $I_o$
$$
\mathbf{I_o = I_{o,e} + I_{o,o} = 0 + 4.6875\text{ A} = \mathbf{\frac{75}{16}\text{ A} = 4.6875\text{ A}}}

---

### 🎯 第四題 滿分關鍵與結論
* **偶模式電流**： $I_{o,e} = \mathbf{0\text{ A}}$
* **奇模式電流**： $I_{o,o} = \mathbf{4.6875\text{ A}}$
* **總輸出電流**： $\mathbf{I_o = \frac{75}{16}\text{ A} = 4.6875\text{ A}}$
