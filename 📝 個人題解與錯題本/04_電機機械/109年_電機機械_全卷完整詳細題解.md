## 一、50 kVA 變壓器磁化電流與漏磁電抗（20 分）

### 📌 題目與已知條件
有一具 $50\text{ kVA}、2400:240\text{ V}、60\text{ Hz}$ 雙繞組變壓器：
* 主線圈（一次側）匝數 $N_P = 1000\text{ 匝}$，副線圈（二次側）匝數 $N_S = 100\text{ 匝}$。
* 鐵心之導磁係數為接近無限大（$\mu_c \to \infty \implies \mathcal{R}_M = 0$）。
* 主、副線圈繞組之電阻值皆為 0（$R_P = R_S = 0$）。
* 變壓器於額定操作時之鐵損（Core Loss）$P_{core} = 500\text{ W}$。
* 主線圈繞組之漏磁路徑磁阻 $\mathcal{R}_P = 4 \times 10^8\text{ A}\cdot\text{t/Wb}$。
* 副線圈繞組之漏磁路徑磁阻 $\mathcal{R}_S = 5 \times 10^6\text{ A}\cdot\text{t/Wb}$。

**試求**：
* **(一)** 此變壓器之磁化電流 $I_\phi$（請以主線圈繞組側為參考邊，即 refer to primary side）。（10 分）
* **(二)** 此變壓器之主線圈繞組漏磁電抗（Leakage Reactance）$X_P$。（10 分）

---

### 💡 核心考點與破題關鍵
1. **激磁電流組成與無限大導磁率鐵心**：
   - 激磁支路由激磁電阻 $R_c$ 與激磁電抗 $X_m$ 並聯組成。
   - 鐵心導磁率無限大 $\implies$ 主磁阻 $\mathcal{R}_M = 0 \implies$ 激磁電感 $L_m = \frac{N_P^2}{\mathcal{R}_M} \to \infty \implies X_m \to \infty$，無效磁化分量 $I_m = 0$。
   - 激磁電流全為供給鐵損之核心損耗電流：$I_\phi = I_c = \frac{V_P}{R_c}$，其中 $R_c = \frac{V_P^2}{P_{core}}$。
2. **漏電感與漏電抗公式**：
   $$L_P = \frac{N_P^2}{\mathcal{R}_P}, \quad X_P = \omega L_P = 2\pi f L_P$$

---

### ✏️ 步驟式詳細數學推導

#### 🔹 (一) 計算主線圈側磁化電流 $I_\phi$
1. 鐵損等效電阻 $R_c$（接於一次側額定電壓 $V_P = 2400\text{ V}$）：
   $$\mathbf{R_c = \frac{V_P^2}{P_{core}} = \frac{(2400\text{ V})^2}{500\text{ W}} = \frac{5760000}{500} = \mathbf{11520\ \Omega = 11.52\text{ k}\Omega}}$$
2. 磁化電流（激磁電流）：
   $$\mathbf{I_\phi = I_c = \frac{V_P}{R_c} = \frac{2400\text{ V}}{11520\ \Omega} = \mathbf{\frac{5}{24}\text{ A} \approx 0.2083\text{ A}}}$$

#### 🔹 (二) 計算主線圈繞組漏磁電抗 $X_P$
1. 主線圈漏電感 $L_P$：
   $$\mathbf{L_P = \frac{N_P^2}{\mathcal{R}_P} = \frac{(1000)^2}{4 \times 10^8\text{ A}\cdot\text{t/Wb}} = \frac{10^6}{4 \times 10^8} = \mathbf{2.5 \times 10^{-3}\text{ H} = 2.5\text{ mH}}}$$
2. 主線圈漏磁電抗 $X_P$（$f = 60\text{ Hz}$）：
   $$\mathbf{X_P = \omega L_P = 2\pi \times 60 \times (2.5 \times 10^{-3}\text{ H}) = 0.3\pi\ \Omega \approx 0.9425\ \Omega}$$

---

### 🎯 第一題 滿分關鍵與結論
* **(一) 磁化電流**：$I_\phi = \mathbf{0.2083\text{ A}}$（$\frac{5}{24}\text{ A}$）
* **(二) 主線圈漏磁電抗**：$X_P = \mathbf{0.9425\ \Omega}$（$L_P = \mathbf{2.5\text{ mH}}$）

## 二、他激直流發電機與電動機雙模式運轉（25 分）

### 📌 題目與已知條件
一具固定激磁的他激（separately excited）直流機，電樞電阻 $R_a = 0.02\ \Omega$：
* 當以發電機模式、轉速為 $3000\text{ rpm}$ 運轉時，得其開路端電壓為 $125\text{ V}$。
* **(一)** 提高此發電機之轉速為 $4000\text{ rpm}$。此時若輸出功率為 $21.5\text{ kW}$，求其輸出端電壓 $V_t$。（8 分）
* **(二)** 將此直流機改以馬達模式運轉，機械負載功率為 $21.5\text{ kW}$，此時改以端電壓輸入為 $213\text{ V}$，求此時之電樞電流 $I_a$。（8 分）
* **(三)** 此時馬達之輸出轉矩為何？（9 分）

---

### 💡 核心考點與破題關鍵
1. **反電動勢常數**：
   $$E_a = K_e n \implies K_e = \frac{125\text{ V}}{3000\text{ rpm}} = \frac{1}{24}\text{ V/rpm} \approx 0.041667\text{ V/rpm}$$
2. **發電機模式功率方程式**：
   $$E_a(4000) = 4000 \times \frac{1}{24} = 166.667\text{ V}, \quad P_{out} = V_t I_a = (E_a - I_a R_a) I_a = 21500\text{ W}$$
3. **電動機模式功率方程式**：
   $$P_{mech} = E_a I_a = (V_t - I_a R_a) I_a = 21500\text{ W}$$
4. **輸出轉矩**：$T = \frac{P_{mech}}{\omega_m} = \frac{P_{mech}}{2\pi n / 60}$。

---

### ✏️ 步驟式詳細數學推導

#### 🔹 (一) 發電機模式（$4000\text{ rpm}, P_{out} = 21.5\text{ kW}$）
1. 內生電壓：
   $$E_a = 4000 \times \frac{1}{24} = \frac{500}{3} \approx \mathbf{166.667\text{ V}}$$
2. 解輸出端電壓與電流：
   $$P_{out} = V_t I_a = (166.667 - 0.02 I_a) I_a = 21500$$
   $$0.02 I_a^2 - 166.667 I_a + 21500 = 0$$
   $$I_a = \frac{166.667 - \sqrt{(166.667)^2 - 4(0.02)(21500)}}{2(0.02)} = \frac{166.667 - \sqrt{27777.8 - 1720}}{0.04} = \frac{166.667 - 161.424}{0.04} = \mathbf{131.06\text{ A}}$$
3. 輸出端電壓：
   $$\mathbf{V_t = E_a - I_a R_a = 166.667 - 131.06 \times 0.02 = 166.667 - 2.621 = \mathbf{164.05\text{ V}}}$$
   * （驗算：$V_t I_a = 164.046 \times 131.061 = 21500\text{ W}$）

#### 🔹 (二) 電動機模式（$V_t = 213\text{ V}, P_{mech} = 21.5\text{ kW}$）
1. 解電樞電流 $I_a$：
   $$P_{mech} = E_a I_a = (213 - 0.02 I_a) I_a = 21500$$
   $$0.02 I_a^2 - 213 I_a + 21500 = 0$$
   $$I_a = \frac{213 - \sqrt{213^2 - 4(0.02)(21500)}}{0.04} = \frac{213 - \sqrt{45369 - 1720}}{0.04} = \frac{213 - 208.923}{0.04} = \mathbf{101.91\text{ A}}$$
2. 此時反電動勢：
   $$E_a = 213 - 101.91 \times 0.02 = \mathbf{210.96\text{ V}}$$

#### 🔹 (三) 計算馬達之輸出轉矩 $T$
1. 馬達轉速：
   $$n = \frac{E_a}{K_e} = 210.96 \times 24 = \mathbf{5063.08\text{ rpm}}$$
2. 機械角速度：
   $$\omega_m = \frac{2\pi \times 5063.08}{60} = \mathbf{530.207\text{ rad/s}}$$
3. 輸出轉矩：
   $$\mathbf{T = \frac{P_{mech}}{\omega_m} = \frac{21500\text{ W}}{530.207\text{ rad/s}} = \mathbf{40.55\text{ N}\cdot\text{m}}}$$

---

### 🎯 第二題 滿分關鍵與結論
* **(一) 發電機端電壓**：$V_t = \mathbf{164.05\text{ V}}$（$I_a = 131.06\text{ A}$）
* **(二) 馬達電樞電流**：$I_a = \mathbf{101.91\text{ A}}$（$E_a = 210.96\text{ V}$）
* **(三) 馬達輸出轉矩**：$T = \mathbf{40.55\text{ N}\cdot\text{m}}$（轉速 $n = 5063\text{ rpm}$）

## 三、六極三相感應馬達起始轉矩與負載轉矩（20 分）

### 📌 題目與已知條件
一部三相、$\text{Y}$ 接、$220\text{ V}、60\text{ Hz}、7.5\text{ kW}$、六極感應馬達：
* 定子及轉子繞組參數（每相）：$R_1 = 0.3\ \Omega, X_1 = 0.5\ \Omega, R_2 = 0.2\ \Omega, X_2 = 0.4\ \Omega$。
* 不計鐵心效應及激磁阻抗。

**試求**：
* **(一)** 此感應馬達之起始轉矩（Starting Torque）$T_{start}$。（10 分）
* **(二)** 當此感應馬達以每分鐘 $1188\text{ rpm}$ 穩態運轉時，其負載轉矩 $T_{load}$ 為若干牛頓・米（$\text{N}\cdot\text{m}$）？（10 分）

---

### 💡 核心考點與破題關鍵
1. **同步轉速與角速度**：
   $$n_s = \frac{120 \times 60}{6} = 1200\text{ rpm} \implies \omega_s = \frac{2\pi \times 1200}{60} = 40\pi \approx 125.664\text{ rad/s}$$
2. **每相輸入相電壓**：$V_1 = \frac{220}{\sqrt{3}} \approx 127.017\text{ V}$。
3. **電磁轉矩公式**：
   $$T = \frac{3 I_2^2 (R_2/s)}{\omega_s}, \quad I_2 = \frac{V_1}{\sqrt{(R_1 + R_2/s)^2 + (X_1 + X_2)^2}}$$

---

### ✏️ 步驟式詳細數學推導

#### 🔹 (一) 計算起始轉矩 $T_{start}$（$s = 1$）
1. 啟動總阻抗與電流：
   $$Z_{start} = (0.3 + 0.2) + j(0.5 + 0.4) = 0.5 + j0.9\ \Omega$$
   $$|Z_{start}| = \sqrt{0.5^2 + 0.9^2} = \sqrt{0.25 + 0.81} = \sqrt{1.06} = \mathbf{1.02956\ \Omega}$$
   $$I_{start} = \frac{127.017\text{ V}}{1.02956\ \Omega} = \mathbf{123.37\text{ A}}$$
2. 起始轉矩：
   $$\mathbf{T_{start} = \frac{3 \times I_{start}^2 \times R_2}{\omega_s} = \frac{3 \times (123.37\text{ A})^2 \times 0.2\ \Omega}{125.664\text{ rad/s}} = \frac{9132.1}{125.664} = \mathbf{72.67\text{ N}\cdot\text{m}}}$$

#### 🔹 (二) 計算 $1188\text{ rpm}$ 穩態運轉之負載轉矩
1. 轉差率 $s$：
   $$\mathbf{s = \frac{1200 - 1188}{1200} = \frac{12}{1200} = \mathbf{0.01\ (1\%)}}$$
2. 轉子等效負載電阻與電流：
   $$\frac{R_2}{s} = \frac{0.2}{0.01} = \mathbf{20.0\ \Omega}$$
   $$Z_{load} = (0.3 + 20.0) + j0.9 = 20.3 + j0.9\ \Omega \implies |Z_{load}| = \sqrt{20.3^2 + 0.9^2} = \sqrt{412.90} = \mathbf{20.320\ \Omega}$$
   $$I_2 = \frac{127.017\text{ V}}{20.320\ \Omega} = \mathbf{6.2508\text{ A}}$$
3. 穩態負載轉矩：
   $$\mathbf{T_{load} = \frac{3 \times I_2^2 \times (R_2/s)}{\omega_s} = \frac{3 \times (6.2508)^2 \times 20.0}{125.664} = \frac{2344.36}{125.664} = \mathbf{18.66\text{ N}\cdot\text{m}}}$$

---

### 🎯 第三題 滿分關鍵與結論
* **(一) 起始轉矩**：$T_{start} = \mathbf{72.67\text{ N}\cdot\text{m}}$
* **(二) $1188\text{ rpm}$ 負載轉矩**：$T_{load} = \mathbf{18.66\text{ N}\cdot\text{m}}$

## 四、三相定子繞組合成磁動勢旋轉向量推導（15 分）

### 📌 題目與已知條件
三相電機定子繞組 $a、b、c$ 相軸各相差 $120^\circ$，三相電流時間函數為：
$$i_a(t) = I \cos\omega_e t, \quad i_b(t) = I \cos(\omega_e t - 120^\circ), \quad i_c(t) = I \cos(\omega_e t - 240^\circ)$$
其中角頻率 $\omega_e = 100\pi\text{ rad/s}$。令三相繞組匝數皆為 $N$。

**試求**：
* **(一)** 根據三個相軸空間關係，畫出時間 $t=0$ 時三相電流所產生的磁動勢（$\mathcal{F} = N \times i$）向量和。（5 分）
* **(二)** 當時間 $\omega_e t = \frac{\pi}{3} = 60^\circ$ 時，畫出三相電流所產生的磁動勢向量和。（5 分）
* **(三)** 此旋轉磁動勢之旋轉頻率為多少 $\text{Hz}$？（5 分）

---

### 💡 核心考點與破題關鍵
1. **空間相軸定義**：
   - $\vec{a}$ 軸：$0^\circ$（水平向右）
   - $\vec{b}$ 軸：$120^\circ$（逆時針）
   - $\vec{c}$ 軸：$240^\circ$（或 $-120^\circ$）
2. **合成磁動勢恆等式**：
   $$\vec{\mathcal{F}}_{total}(t) = \mathcal{F}_a \angle 0^\circ + \mathcal{F}_b \angle 120^\circ + \mathcal{F}_c \angle 240^\circ = \frac{3}{2} N I \angle \omega_e t$$
3. **旋轉頻率**：$f = \frac{\omega_e}{2\pi}$。

---

### ✏️ 步驟式詳細數學推導
1. **(一) $t=0$ 時之磁動勢向量和**：
   - 各相電流：
     $$i_a(0) = I \cos 0^\circ = I, \quad i_b(0) = I \cos(-120^\circ) = -0.5 I, \quad i_c(0) = I \cos(-240^\circ) = -0.5 I$$
   - 合成空間向量：
     $$\vec{\mathcal{F}}_{total}(0) = (N I)\angle 0^\circ + (-0.5 N I)\angle 120^\circ + (-0.5 N I)\angle 240^\circ$$
     $$= N I - 0.5 N I (-0.5 + j\frac{\sqrt{3}}{2}) - 0.5 N I (-0.5 - j\frac{\sqrt{3}}{2}) = N I (1 + 0.25 + 0.25) = \mathbf{1.5 N I \angle 0^\circ}$$
   - **結論**：大小為 $\mathbf{1.5 N I}$，方向指向 **$a$ 軸正方向（$0^\circ$）**。
2. **(二) $\omega_e t = 60^\circ$ 時之磁動勢向量和**：
   - 各相電流：
     $$i_a = I \cos 60^\circ = 0.5 I, \quad i_b = I \cos(-60^\circ) = 0.5 I, \quad i_c = I \cos(-180^\circ) = -I$$
   - 合成空間向量：
     $$\vec{\mathcal{F}}_{total}(60^\circ) = (0.5 N I)\angle 0^\circ + (0.5 N I)\angle 120^\circ + (-N I)\angle 240^\circ$$
     $$= N I [ 0.5 + 0.5(-0.5 + j\frac{\sqrt{3}}{2}) - (-0.5 - j\frac{\sqrt{3}}{2}) ] = N I [ 0.5 - 0.25 + 0.5 + j(\frac{\sqrt{3}}{4} + \frac{\sqrt{3}}{2}) ]$$
     $$= N I [ 0.75 + j 0.75\sqrt{3} ] = 1.5 N I (\frac{1}{2} + j\frac{\sqrt{3}}{2}) = \mathbf{1.5 N I \angle 60^\circ}$$
   - **結論**：大小維持 $\mathbf{1.5 N I}$ 不變，空間方向逆時針旋轉至 **$60^\circ$ 方向**。
3. **(三) 旋轉頻率**：
   $$\mathbf{f = \frac{\omega_e}{2\pi} = \frac{100\pi\text{ rad/s}}{2\pi} = \mathbf{50\text{ Hz}}}$$

---

### 🎯 第四題 滿分關鍵與結論
* **(一) $t=0$ 磁動勢向量和**：$\vec{\mathcal{F}} = \mathbf{1.5 N I \angle 0^\circ}$（沿 $a$ 相軸）
* **(二) $\omega_e t = 60^\circ$ 磁動勢向量和**：$\vec{\mathcal{F}} = \mathbf{1.5 N I \angle 60^\circ}$
* **(三) 旋轉頻率**：$f = \mathbf{50\text{ Hz}}$

## 五、可變磁阻電磁系統電感 $L(\theta)$ 與電磁扭力（20 分）

### 📌 題目與已知條件
如圖五之電磁系統：
* 線圈總匝數 $N = 120\text{ 匝}$。
* 氣隙寬度 $g = 3\text{ mm} = 3 \times 10^{-3}\text{ m}$。
* 整個鐵心（含轉子）厚度（軸向深度）$h = 1.8\text{ cm} = 0.018\text{ m}$。
* 轉子半徑長度 $r_1 = 2.5\text{ cm} = 0.025\text{ m}$。
* 空氣導磁率 $\mu_0 = 4\pi \times 10^{-7}\text{ H/m}$，鐵心相對導磁率為無限大。

**試求**：
* **(一)** 當轉子角度為 $\theta$（弧度）時，計算本電磁系統之電感值 $L(\theta)$。（10 分）
* **(二)** 當轉子角度為 $\theta = 30^\circ$，輸入電流為 $i = 20\text{ A}$ 時，求此系統所產生之電磁扭力 $T$。（10 分）

---

### 💡 核心考點與破題關鍵
1. **重疊氣隙磁路分析**：
   - 磁通由定子穿過氣隙進入轉子，再由另一端氣隙回到定子（共串聯兩個氣隙，每個長度為 $g$）。
   - 重疊氣隙截面積隨轉角 $\theta$（$\text{rad}$）呈線性變化：
     $$A_g(\theta) = h \times (r_1 \theta)$$
2. **總氣隙磁阻與電感函數**：
   $$\mathcal{R}_g(\theta) = \frac{2g}{\mu_0 A_g(\theta)} = \frac{2g}{\mu_0 h r_1 \theta} \implies L(\theta) = \frac{N^2}{\mathcal{R}_g(\theta)} = \frac{N^2 \mu_0 h r_1 \theta}{2g}$$
3. **電磁扭力公式**：
   $$T = \frac{1}{2} i^2 \frac{dL(\theta)}{d\theta}$$

---

### ✏️ 步驟式詳細數學推導

#### 🔹 (一) 推導電感值函數 $L(\theta)$
1. 每一氣隙截面積：$A_g = h \cdot (r_1 \theta)$。
2. 兩氣隙串聯總磁阻（鐵心導磁率無限大）：
   $$\mathcal{R}_{total}(\theta) = \frac{2g}{\mu_0 h r_1 \theta}$$
3. 電感函數：
   $$\mathbf{L(\theta) = \frac{N^2}{\mathcal{R}_{total}(\theta)} = \frac{N^2 \mu_0 h r_1}{2g} \cdot \theta}$$
4. 代入具體參數值（$\theta$ 單位為 $\text{rad}$）：
   $$\frac{dL}{d\theta} = \frac{(120)^2 \times (4\pi \times 10^{-7}\text{ H/m}) \times (0.018\text{ m}) \times (0.025\text{ m})}{2 \times (3 \times 10^{-3}\text{ m})}$$
   $$\frac{dL}{d\theta} = \frac{14400 \times (4\pi \times 10^{-7}) \times 4.5 \times 10^{-4}}{6 \times 10^{-3}} = \frac{8.1430 \times 10^{-6}}{6 \times 10^{-3}} = \mathbf{1.3572 \times 10^{-3}\text{ H/rad} = 1.3572\text{ mH/rad}}$$
   $$\mathbf{L(\theta) = 1.3572 \times 10^{-3} \theta\text{ H} = \mathbf{1.3572 \theta\text{ mH}} \quad (\theta\text{ in rad})}$$

#### 🔹 (二) 計算 $\theta = 30^\circ, i = 20\text{ A}$ 時之電磁扭力
1. 角度轉換與電感值：
   $$\theta = 30^\circ = \frac{\pi}{6}\text{ rad} \approx 0.5236\text{ rad}$$
   $$L(30^\circ) = (1.3572\text{ mH/rad}) \times \frac{\pi}{6} = \mathbf{0.7106\text{ mH}}$$
2. 電磁扭力計算：
   $$\mathbf{T = \frac{1}{2} i^2 \frac{dL}{d\theta} = \frac{1}{2} \times (20\text{ A})^2 \times (1.3572 \times 10^{-3}\text{ H/rad})}$$
   $$\mathbf{T = \frac{1}{2} \times 400 \times (1.3572 \times 10^{-3}) = 200 \times 1.3572 \times 10^{-3} = \mathbf{0.2714\text{ N}\cdot\text{m}}}$$

> ⚠️ **電機機械 核心防坑與閱卷踩雷提醒**：
> 1. **變壓器阻抗折合**：低壓側折合至高壓側乘以變比平方 $a^2$；自耦變壓器共用繞組電流為高低壓側電流之差值。

> 3. **同步機相量計算**：同步電動機 $\mathbf{E}_f = \mathbf{V}_\phi - \mathbf{I}_a \mathbf{Z}_s$；同步發電機 $\mathbf{E}_f = \mathbf{V}_\phi + \mathbf{I}_a \mathbf{Z}_s$。
