# 發版紀錄 v1.5.0（2026-10-18）

## 改了什麼

- P0 共 144 題詳解改寫（六科穩拿題型錨章，加上使用者標記的 △／× 題；01:18、02:22、03:25、04:30、05:20、06:29，含 6 題金標準範例）：
  - 「考場標準作答」開頭新增「解題邏輯」段落，先說明整題的解法與理由。
  - 每個子題新增「邏輯」行，交代該小題為何這樣做。
  - 共用的中間量獨立成步驟，不在各小題重複推導。
  - 得分推導逐行不跳步，數字皆有出處。
- 數值規則統一：
  - 最終答案框內取兩位小數（題幹指定位數者優先）。
  - 四捨五入過的中間值至少保留 4 位有效數字，每一行照字面即可驗算。
  - 不使用 6.76×10⁻¹ 這類寫法。
- 新增教科書風格 SVG 圖解，共 168 張。App 內以內嵌 SVG 顯示，字型與 KaTeX 一致。
- 每一批改寫皆由獨立審查代理抽審，退回項目已修正。
- 唯一的答案更正（使用者決定）：EE-111-04-4（二）118.60 A 改為 118.59 A（原本是兩次進位造成）。

## 沒改什麼

其餘答案值、稽核狀態、驗算腳本、日程與畫面功能。P1／P2 題目尚未改寫，留待後續版本。
