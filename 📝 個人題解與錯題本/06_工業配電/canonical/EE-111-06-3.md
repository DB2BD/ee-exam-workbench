# 111 年第 3 題｜待獨立校驗

## 官方題目（逐題裁切）

一工廠以汽電共生發電機供應電力其單線圖如下圖所示，已知各項設備
參數如下：
發電機：$25\text{ MW}，22.8\text{ kV}$，次暫態電抗Xd"=12\%，
電動機：$6000\text{ kW}，3.3\text{ kV}$，次暫態電抗Xd"=15\%，暫態電抗Xd'=25\%，
變壓器：$25\text{ MVA}，22.8\text{ kV} / 3.3\text{ kV}$，$X_T = 8\%$，
假設該系統在F點發生短路故障，MVA基準值為$25\text{ MVA}$，kV基準值為
$22.8\text{ kV} / 3.3\text{ kV}$，試求(一)故障點F之次暫態故障電流A，（10分）(二)斷路器
A點之次暫態故障電流A。（10分）
