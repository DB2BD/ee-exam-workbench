# 發版紀錄 v1.7.0（2026-10-23）

新增「破題訓練」，專練看到題目後的下筆速度；經驗值改為獎勵練弱章、複習和進步。

破題訓練是**選用功能**，全部放在 `src/features/breakdownDrill/`；刪除該資料夾即可移除（步驟見資料夾內 README）。

## 改了什麼

### 1. 破題訓練

- 首頁新增第三個主要入口「破題訓練 8 題」。
- 每題只顯示題目截圖、科目與年份，倒數 2 分鐘：
  1. 從同科四個章節選出這題的題型；
  2. 選填「第一步」（公式或要畫的圖）；
  3. 翻答案後看正確題型、核心公式和該題詳解的「解題邏輯」，自評起手方向對不對。
- 一輪結束顯示題型命中、起手式命中、本輪 EXP 和要再練的題。
- 抽題：
  - 先排到期要再練的題，最多半輪；錯的隔天再出，連續答對依序隔 3、7、14 天。
  - 再補新題，掌握度低於 0.5 的章節優先；六科交錯，相鄰兩題不同科。
- 尚未完成的模考／盲測卷（例如 108 年盲測）整卷不出題，其他排程保留題也不出，避免先看到題目。
- 中途離開可「繼續上一輪」；首頁顯示今天到期題數與近 7 天命中率。
- 資料：產生器 `src/features/breakdownDrill/build.py` → `data.generated.js`（323 題的章節與解題邏輯）。
- 首頁入口按鈕與面板由功能本身加入，首頁版面原始碼不變。

### 2. 選用功能架構

- `scripts/build_workbench.py` 自動載入 `src/features/*/feature.json` 列出的檔案，排在核心之後、`main.js` 之前。
- `npm run check` 改呼叫 `scripts/build_features.py`，執行各功能自己的 `build.py`。
- 核心新增三個通用掛勾，本身不提到任何功能：
  - `registerBackupExtension`（`sm2Store.js`）：功能可在備份加自己的欄位；
  - `registerHomeStatusExpSource`（`homeStatus.js`）：功能可貢獻經驗值與學習日；
  - `ee:data-merged` 事件（`cloudSync.js`）：雲端合併後通知功能重繪；同時刷新狀態視窗。
- 測試確認核心檔案不含破題訓練的名稱。已實測移除資料夾後建置，`run_all_tests` 與 `qa:browser` 全過。

### 3. 經驗值與稱號（只加不減）

- 結果卡：一律 20 EXP（舊規則依得分 10～20），舊版自評紀錄仍 5。
- 弱章加成：該卡章節在這張卡之前的掌握度低於 0.5 時 +10；以當時的歷史計算，之後章節變強也不會扣回。
- 到期複習存的結果卡 +5。
- 模考或盲測某科分數超過該科之前最佳模考時，每多 1 分 +5。
- 破題訓練每題 +5，題型選對再 +5（由功能註冊，移除功能即不計）。
- Lv25 稱號「榜上技師」需同時達到預估總分及格線（360）；未達到時顯示「準技師」。
- 升級曲線不變。以 10/20 備份計算：由 Lv16（5,806 EXP）變為 Lv19「系統調度員」（7,505 EXP）。

### 4. 備份與雲端同步

- 破題訓練向備份註冊選填欄位 `breakdownDrill`（只含作答紀錄，不含進行中的一輪）。
- 合併匯入：依紀錄 id 聯集；取代匯入：以備份為準。舊版備份沒有此欄位時，不動本機的破題紀錄。
- 雲端同步沿用合併，兩台裝置的破題紀錄會聯集。新鍵 `EE_EXAM_BREAKDOWN_DRILL_V1`。
