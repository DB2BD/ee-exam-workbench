# 發版紀錄 v1.3.9

日期：2026-10-13

主題：成績分頁新增「日程進度」區，把今日任務卡那一行「落後約 N 小時」背後的明細列出來：哪幾項落後、原排哪天、下一個關卡還差多少。

## 這版改了什麼

- **成績分頁「日程進度」**：位於「合計」之前；成績紀錄為空時也會顯示（日程與作答紀錄無關）。內容與今日任務卡取自同一份 `todayTaskPacing` 計算，不另算：
  - 狀態行：沿用今日任務卡的「落後約／照日程／超前約」文字。
  - 落後項目：每列「代碼｜標題｜原排日期（M/D）｜剩餘時數」；超過 8 列只列前 8 列，其餘收在「另有 N 項」展開。
  - 下一關卡：一行「下一關卡 M/D 名稱：剩 N 項，需 X 小時／可用 Y 小時」；做不完的關卡沿用既有警示色。
  - 已自動刪減：「代碼｜標題｜時數」清單，預設收合。
  - 照日程且無刪減時，只顯示狀態行與下一關卡。
- 純函式 `scoreboardPaceModel`、`scoreboardPaceHtml_`（`src/components/scoreboard.js`），樣式 `.sb-pace*`（`src/styles/components.css`），390 px 無水平捲動。

## 這版沒改什麼

- `pacing.js`、今日任務卡、其他分頁、備份 schema（2.1.0）與 localStorage 鍵，沒有新增畫面提示文字（只有標題與上列欄位）。
- 缺少 `todayTaskPacing` 或 `DAILY_SCHEDULE` 時整區省略，不影響只載入成績看板的環境。

## 風險與已知限制

- 剛開始、尚未標記任何完成項目時，今日任務卡會隱藏落後行，這一區仍照實列出（資料遺失時正好用來看出異常）。
- 落後列的小時數以「尚需時數」計；已開始的任務只計剩餘階段，與今日任務卡的落後小時一致。
