## 一、三相變壓器 Δ-Δ 故障改 V-V 接線容量（20 分）

### 📌 題目與已知條件
某用電戶擁有三台相同之單相變壓器，每台額定 $66\text{ kVA}, 6600\text{ V} / 220\text{ V}, 60\text{ Hz}$，原連接為 $\Delta-\Delta$ 接線供應三相平衡負載。若其中一台變壓器故障拆除，將剩餘兩台改為開角 $\text{V}-\text{V}$ 接線。

* **(一)** 求改為 $\text{V}-\text{V}$ 接線後之三相總輸出容量 $S_V$（$\text{kVA}$）與原 $\Delta-\Delta$ 容量之比值。（10 分）
* **(二)** 求 $\text{V}-\text{V}$ 接線之變壓器設備利用率（Utilization Factor）為何？（10 分）

---

### ✏️ 步驟式詳細數學推導
1. **$\text{V}-\text{V}$ 接線容量**：
   原 $\Delta-\Delta$ 容量：$S_\Delta = 3 \times 66 = \mathbf{198\text{ kVA}}$。
   改為 $\text{V}-\text{V}$ 接線後：
   $$\mathbf{S_V = \sqrt{3} \times S_{1\phi} = \sqrt{3} \times 66\text{ kVA} \approx \mathbf{114.315\text{ kVA}}}$$
   容量比值：
   $$\mathbf{\frac{S_V}{S_\Delta} = \frac{\sqrt{3} \times 66}{3 \times 66} = \frac{\sqrt{3}}{3} = \frac{1}{\sqrt{3}} \approx \mathbf{57.74\%}}$$
2. **設備利用率（Utilization Factor）**：
   兩台變壓器安裝之名牌總容量為 $2 \times 66 = 132\text{ kVA}$。
   $$\mathbf{\text{利用率} = \frac{S_V}{2 \times S_{1\phi}} = \frac{\sqrt{3} \times 66}{2 \times 66} = \frac{\sqrt{3}}{2} \approx \mathbf{86.60\%}}$$

---

### 🎯 第一題 滿分關鍵與結論
- **$\text{V}-\text{V}$ 總輸出容量**：$S_V = \mathbf{114.32\text{ kVA}}$（為原容量之 $\mathbf{57.74\%}$）
- **設備利用率**：$\mathbf{86.60\%}$（$\frac{\sqrt{3}}{2}$）

## 二、直流串激電動機反電動勢與轉矩特性（20 分）

### 📌 題目與已知條件
某起重機直流串激電動機，額定電壓 $V_t = 240\text{ V}$，電樞與串激場總電阻 $R_a + R_s = 0.4\ \Omega$。
在兩種不同吊掛運轉狀況下，電樞內反電動勢分別為 $E_{a1} = 40\text{ V}$ 與 $E_{a2} = 48\text{ V}$。假設磁路不飽和（磁通 $\Phi \propto I_a$）。

* **(一)** 計算此兩種運轉狀況下之電樞電流與電磁轉矩之比值。（10 分）
* **(二)** 計算此兩種運轉狀況下之轉子轉速比值 $n_2 / n_1$。（10 分）

---

### ✏️ 步驟式詳細數學推導
1. **電樞電流計算**：
   $$I_{a1} = \frac{V_t - E_{a1}}{R_a + R_s} = \frac{240 - 40}{0.4} = \frac{200}{0.4} = \mathbf{500.0\text{ A}}$$
   $$I_{a2} = \frac{V_t - E_{a2}}{R_a + R_s} = \frac{240 - 48}{0.4} = \frac{192}{0.4} = \mathbf{480.0\text{ A}}$$
   轉矩比（因 $\Phi \propto I_a \implies T \propto I_a^2$）：
   $$\mathbf{\frac{T_2}{T_1} = \left(\frac{I_{a2}}{I_{a1}} \right)^2 = \left( \frac{480}{500} \right)^2 = (0.96)^2 = \mathbf{0.9216\ (92.16\%)}}$$
2. **轉速比計算**：
   因 $E_a = K \Phi n \propto I_a n \implies n \propto \frac{E_a}{I_a}$：
   $$\mathbf{\frac{n_2}{n_1} = \left(\frac{E_{a2}}{E_{a1}} \right) \times \left(\frac{I_{a1}}{I_{a2}} \right) = \left( \frac{48}{40} \right) \times \left( \frac{500}{480} \right) = 1.20 \times 1.0417 = \mathbf{1.25}}$$
   （狀況二之轉速為狀況一之 $1.25$ 倍）

---

### 🎯 第二題 滿分關鍵與結論
- **電流與轉矩比**：$I_{a1} = 500\text{ A}, I_{a2} = 480\text{ A} \implies \frac{T_2}{T_1} = \mathbf{0.9216}$
- **轉速比**：$\frac{n_2}{n_1} = \mathbf{1.25}$

## 三、感應電動機戴維寧等效與轉矩計算（20 分）

### 📌 題目與已知條件
一部三相、4 極、$60\text{ Hz}$、$\text{Y}$ 接感應電動機，額定 $380\text{ V}, 1755\text{ rpm}$。
定子側單相戴維寧等效參數：$V_{TH} = 210\text{ V}, Z_{TH} = (0.2 + j4.0)\ \Omega$，轉子等效阻抗 $Z_R = \left(\frac{0.8}{s} + j4.0 \right)\ \Omega$。

* **(一)** 計算轉差率 $s = 5\%$ 時之轉子轉速 $n$ 與感應轉矩 $T_{ind}$。（10 分）
* **(二)** 計算產生最大轉矩時之轉差率 $s_{max}$ 與最大電磁轉矩 $T_{max}$。（10 分）

---

### ✏️ 步驟式詳細數學推導
1. **$s = 0.05$ 時之轉速與轉矩**：
   $$n_s = \frac{120 \times 60}{4} = 1800\text{ rpm} \implies \mathbf{n} = (1 - 0.05) \times 1800  = \mathbf{1710\text{ rpm}}$$
   $$\omega_s = \frac{2\pi \times 1800}{60} = 188.50\text{ rad/s}$$
   轉子支路電阻：$\frac{R_2'}{s} = \frac{0.8}{0.05} = 16.0\ \Omega$。
   總迴路阻抗：$Z_{tot} = (0.2 + 16.0) + j(4.0 + 4.0) = 16.2 + j8.0\ \Omega \implies |Z_{tot}| = \sqrt{16.2^2 + 8.0^2} = 18.068\ \Omega$。
   轉子電流：$I_2' = \frac{V_{TH}}{|Z_{tot}|} = \frac{210}{18.068} = 11.623\text{ A}$。
   $$\mathbf{T_{ind} = \frac{3 (I_2')^2 (R_2'/s)}{\omega_s} = \frac{3 \times (11.623)^2 \times 16.0}{188.50} = \frac{6484.5}{188.50} = \mathbf{34.40\text{ N}\cdot\text{m}}}$$
2. **最大轉矩特性**：
   $$\mathbf{s_{max} = \frac{R_2'}{\sqrt{R_{TH}^2 + (X_{TH} + X_2')^2}} = \frac{0.8}{\sqrt{0.2^2 + (4.0 + 4.0)^2}} = \frac{0.8}{\sqrt{0.04 + 64}} = \frac{0.8}{8.0025} \approx \mathbf{0.100\ (10.0\%)}}$$
   $$\mathbf{T_{max} = \frac{3 V_{TH}^2}{2\omega_s [R_{TH} + \sqrt{R_{TH}^2 + (X_{TH} + X_2')^2}]} = \frac{3 \times 210^2}{2 \times 188.50 \times (0.2 + 8.0025)} = \frac{132300}{377 \times 8.2025} = \mathbf{42.78\text{ N}\cdot\text{m}}}$$

---

### 🎯 第三題 滿分關鍵與結論
- **$s=5\%$ 轉速與轉矩**：$n = \mathbf{1710\text{ rpm}}, T_{ind} = \mathbf{34.40\text{ N}\cdot\text{m}}$
- **最大轉矩與轉差**：$s_{max} = \mathbf{10.0\%}, T_{max} = \mathbf{42.78\text{ N}\cdot\text{m}}$

## 四、同步發電機短路特性與電壓調整率（20 分）

### 📌 題目與已知條件
- 三相 6 極、$\text{Y}$ 接同步發電機，額定容量 $S_{rated} = 100\text{ kVA}$，線電壓 $V_L = 480\text{ V}, 60\text{ Hz}$。
- 電樞電阻 $R_a = 0.05\ \Omega/\text{相}$，同步電抗 $X_s = 1.2\ \Omega/\text{相}$。滿載功率因數 $\text{PF} = 0.8\text{ 落後}$。

* **(一)** 計算額定滿載時之每相激磁電壓 $E_f$ 與功率角 $\delta$。（10 分）
* **(二)** 計算此發電機之電壓調整率 $\text{VR}$。（10 分）

---

### ✏️ 步驟式詳細數學推導
1. **相電壓與滿載電流**：
   $$V_\phi = \frac{480}{\sqrt{3}} \approx 277.13\text{ V}, \quad I_a = \frac{100 \times 10^3}{\sqrt{3} \times 480} = 120.28ngle -36.87^\circ\text{ A} = (96.22 - j72.17)\text{ A}$$
2. **激磁電壓 $\mathbf{E}_f$**：
   $$\mathbf{E}_f = 277.13 + (96.22 - j72.17)(0.05 + j1.2) = 277.13 + (4.81 + 86.60) + j(115.46 - 3.61)$$
   $$\mathbf{E}_f = 368.54 + j111.85\text{ V}$$
   $$|\mathbf{E}_f| = \sqrt{368.54^2 + 111.85^2} = \mathbf{385.14\text{ V/相}}$$
   $$\mathbf{\delta = \tan^{-1}\left( \frac{111.85}{368.54} \right) = \mathbf{16.88^\circ}}$$
3. **電壓調整率 $\text{VR}$**：
   $$\mathbf{VR = \frac{|\mathbf{E}_f| - V_\phi}{V_\phi} \times 100\% = \frac{385.14 - 277.13}{277.13} \times 100\% = \mathbf{38.97\%}}$$

---

### 🎯 第四題 滿分關鍵與結論
- **每相激磁電壓**：$E_f = \mathbf{385.14\text{ V/相}}$（線電壓 $667.1\text{ V}$）
- **功角**：$\delta = \mathbf{16.88^\circ}$
- **電壓調整率**：$\text{VR} = \mathbf{38.97\%}$

> 1. **變壓器阻抗折合**：低壓側折合至高壓側乘以變比平方 $a^2$；自耦變壓器共用繞組電流為高低壓側電流之差值。

> 3. **同步機相量計算**：同步電動機 $\mathbf{E}_f = \mathbf{V}_\phi - \mathbf{I}_a \mathbf{Z}_s$；同步發電機 $\mathbf{E}_f = \mathbf{V}_\phi + \mathbf{I}_a \mathbf{Z}_s$。

## 五、變頻器 V/f 恆定控制感應電動機原理（20 分）

* **(一) 為何在基頻以下調速需維持 $V/f = \text{常數}$？（10 分）**
  - 由法拉第定律：$V \approx E = 4.44 f N \Phi_m \implies \Phi_m \propto \frac{V}{f}$。
  - **維持磁通恆定**：若僅降頻而不降壓，磁通 $\Phi_m$ 會劇增導致鐵心嚴重磁飽和、激磁電流飆升過熱燒毀；若降壓太多則轉矩不足。維持 $V/f$ 恆定可確保電機具有**恆轉矩（Constant Torque）調速特性**。
* **(二) 基頻以上運轉時之控制策略為何？（10 分）**
  - **弱磁控制（Field Weakening / Constant Power Region）**：因端電壓受限於絕緣額定值不能再升高，故維持電壓 $V = V_{rated}$ 不變，僅提高頻率 $f$。
  - 此時磁通 $\Phi_m \propto 1/f$ 隨頻率反比減弱，輸出能力轉為**恆功率（Constant Power）特性**，最大可用轉矩隨頻率平方反比下降（$T_{max} \propto 1/f^2$）。
