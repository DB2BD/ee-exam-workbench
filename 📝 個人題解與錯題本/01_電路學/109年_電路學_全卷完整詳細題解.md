## 一、三運算放大器儀表放大器轉移關係推導（25 分）

### 📌 題目與已知條件
試求下圖三運算放大器電路之輸出電壓 $v_o$ 與輸入電壓 $v_1, v_2$ 的數學關係式。（25 分）
* 第一級輸入緩衝放大級：包含兩個理想運算放大器，正向輸入端分別輸入 $v_1$（上）與 $v_2$（下），負向反饋電阻各為 $R_1$，兩反相端間連接增益設定電阻 $R_g$。
* 第二級差動放大級：包含一個差動運算放大器，輸入電阻均為 $R_2$，反饋電阻及下接地電阻均為 $R_0$。

---

### 💡 核心考點與破題關鍵
1. **理想運算放大器黃金法則**：
   - 虛短路（Virtual Short）：$v_+ = v_-$。
   - 虛斷路（Virtual Open）：輸入端電流 $i_+ = i_- = 0$。
2. **第一級差動輸出推導**：
   - 上側反相端電位為 $v_1$，下側反相端電位為 $v_2$。
   - 流經 $R_g$ 之電流：$i_g = \frac{v_1 - v_2}{R_g}$（由上往下流）。
   - 上側 OpAmp 輸出：$v_{o1} = v_1 + i_g R_1 = v_1 + \frac{R_1}{R_g}(v_1 - v_2)$。
   - 下側 OpAmp 輸出：$v_{o2} = v_2 - i_g R_1 = v_2 - \frac{R_1}{R_g}(v_1 - v_2)$。
   - 第一級差動輸出：$v_{o1} - v_{o2} = (v_1 - v_2) + \frac{2R_1}{R_g}(v_1 - v_2) = \left(1 + \frac{2R_1}{R_g}\right)(v_1 - v_2)$。
3. **第二級標準差動放大器**：
   - 差動級反相輸入接 $v_{o1}$，同相輸入接 $v_{o2}$。
   - 輸出電壓：$v_o = \frac{R_0}{R_2}(v_{o2} - v_{o1}) = \frac{R_0}{R_2}\left(1 + \frac{2R_1}{R_g}\right)(v_2 - v_1)$。

---

### ✏️ 步驟式詳細數學推導
1. **第一級輸入緩衝級節點分析**：
   - 設上側 OpAmp 輸出為 $v_{o1}$，下側 OpAmp 輸出為 $v_{o2}$。
   - 由虛短路性質，上側反相端電壓為 $v_1$，下側反相端電壓為 $v_2$。
   - 因 OpAmp 輸入端不吸入電流，流經上側反饋電阻 $R_1$、增益電阻 $R_g$ 與下側反饋電阻 $R_1$ 之電流為同一串聯電流 $i$：
     $$i = \frac{v_1 - v_2}{R_g}$$
   - 上側輸出電壓：
     $$v_{o1} = v_1 + R_1 i = v_1 + \frac{R_1}{R_g}(v_1 - v_2)$$
   - 下側輸出電壓：
     $$v_{o2} = v_2 - R_1 i = v_2 - \frac{R_1}{R_g}(v_1 - v_2)$$
   - 兩輸出端差模電壓：
     $$\mathbf{v_{o2} - v_{o1} = (v_2 - v_1) - \frac{2R_1}{R_g}(v_1 - v_2) = \left(1 + \frac{2R_1}{R_g}\right)(v_2 - v_1)}$$
2. **第二級差動放大級節點分析**：
   - 差動 OpAmp 同相端電位 $v_+$（由 $v_{o2}$ 經分壓電路）：
     $$v_+ = v_{o2} \cdot \frac{R_0}{R_2 + R_0}$$
   - 由虛短路 $v_- = v_+$，在反相端列 KCL：
     $$\frac{v_{o1} - v_-}{R_2} = \frac{v_- - v_o}{R_0} \implies \frac{v_{o1}}{R_2} + \frac{v_o}{R_0} = v_- \left(\frac{1}{R_2} + \frac{1}{R_0}\right) = v_+ \cdot \frac{R_2 + R_0}{R_2 R_0}$$
     $$\frac{v_{o1}}{R_2} + \frac{v_o}{R_0} = \left(v_{o2} \frac{R_0}{R_2 + R_0}\right) \frac{R_2 + R_0}{R_2 R_0} = \frac{v_{o2}}{R_2}$$
     $$\frac{v_o}{R_0} = \frac{v_{o2} - v_{o1}}{R_2} \implies \mathbf{v_o = \frac{R_0}{R_2} (v_{o2} - v_{o1})}$$
3. **整合第一級與第二級推導總輸出公式**：
   $$\mathbf{v_o = \frac{R_0}{R_2} \left(1 + \frac{2R_1}{R_g}\right) (v_2 - v_1) = -\frac{R_0}{R_2} \left(1 + \frac{2R_1}{R_g}\right) (v_1 - v_2)}$$

---

### 🎯 第一題 滿分關鍵與結論
* **輸出與輸入電壓數學關係式**：  
  $$\mathbf{v_o = \frac{R_0}{R_2}\left(1 + \frac{2R_1}{R_g}\right)(v_2 - v_1)}$$

## 二、轉移函數極點分佈與系統穩定度深度分析（25 分）

### 📌 題目與已知條件
試詳述線性非時變（LTI）系統轉移函數 $H(s) = \frac{N(s)}{D(s)}$ 之極點（Poles）在複數 $s$ 平面上的分佈位置與系統穩定度（Stability）的完整對應關係。（25 分）

---

### 💡 核心考點與破題關鍵
1. **極點定義與時域衝激響應本質**：
   - 設系統轉移函數之極點為 $p_i = \sigma_i + j\omega_i$。
   - 系統衝激響應為各極點對應模態之疊加：
     $$h(t) = \mathcal{L}^{-1}\{H(s)\} = \sum A_i e^{p_i t} = \sum A_i e^{\sigma_i t} (\cos\omega_i t + j\sin\omega_i t)$$
2. **三種穩定度定義與判定準則**：
   - **漸進穩定（Asymptotically Stable / BIBO Stable）**
   - **臨界穩定 / 邊界穩定（Marginally Stable）**
   - **不穩定（Unstable）**

---

### ✏️ 步驟式詳細論述與分類判定表

#### 🔹 1. 漸進穩定（Asymptotic / BIBO Stability）
* **極點條件**：系統所有極點均位於 **$s$ 平面的嚴格左半平面（Open Left-Half Plane, LHP）**，即對所有極點 $p_i$，均滿足 $\mathbf{\text{Re}(p_i) = \sigma_i < 0}$。
* **時域物理行為**：
  - 由於 $\sigma_i < 0$，時域因子 $e^{\sigma_i t} \to 0$ 當 $t \to \infty$。
  - 暫態響應隨時間指數衰減，任何有界輸入均產生有界輸出（Bounded-Input Bounded-Output Stable）。

#### 🔹 2. 臨界穩定 / 邊界穩定（Marginal Stability）
* **極點條件**：
  1. 虛軸（$j\omega$ 軸）上存在**單重極點（Simple Poles on $j\omega$-axis）**，即 $\text{Re}(p_i) = 0$ 且為一重根。
  2. 嚴格左半平面可有其他極點（$\text{Re}(p_k) < 0$）。
  3. **右半平面不得存在任何極點**。
* **時域物理行為**：
  - 原點單極點（$s=0$）產生持續的直流恆定值響應 $A u(t)$。
  - 共軛虛軸單極點（$s = \pm j\omega_0$）產生等幅持續振盪之正弦波響應 $A \cos(\omega_0 t + \phi)$。
  - 響應不隨時間發散，但亦不衰減至零。

#### 🔹 3. 系統不穩定（Unstable）
* **極點條件**（符合下列任一條件即判定為不穩定）：
  1. **右半平面極點**：至少有一個極點位於 **$s$ 平面右半平面（Right-Half Plane, RHP）**，即 $\mathbf{\text{Re}(p_i) > 0}$。
  2. **虛軸多重極點**：虛軸（$j\omega$ 軸）上存在**重根極點（Repeated Poles on $j\omega$-axis）**（如二重極點 $\frac{1}{(s^2 + \omega_0^2)^2}$）。
* **時域物理行為**：
  - 右半平面極點包含 $e^{+\sigma t}$ 項，輸出隨時間呈現**指數性爆炸發散**。
  - 虛軸重根極點拉氏反轉換包含 $t \cos(\omega_0 t)$ 或 $t u(t)$ 項，輸出振幅隨時間**線性增長發散**。

---

### 🎯 第二題 滿分總結表格
| 極點分佈位置特徵 | 實部 $\text{Re}(p) = \sigma$ | 時域衝激響應 $h(t)$ 行為 | 系統穩定度判定 |
| :--- | :---: | :--- | :---: |
| **嚴格左半平面 (LHP) 單根或重根** | $\sigma < 0$ | 指數衰減收斂至 0 | **漸進穩定 (Stable)** |
| **虛軸上的單重極點 ($s=\pm j\omega_0$ 或 $s=0$)** | $\sigma = 0$ (單根) | 等幅持續振盪或恆定常數 | **臨界穩定 (Marginally Stable)** |
| **右半平面 (RHP) 任一極點** | $\sigma > 0$ | 隨時間指數發散至無窮大 | **不穩定 (Unstable)** |
| **虛軸上的多重極點 ($j\omega$-axis Repeated)** | $\sigma = 0$ (重根) | 振幅隨時間 $t^n$ 線性/多項式發散 | **不穩定 (Unstable)** |

## 三、節點電壓方程式轉換與對偶網路建構（25 分）

### 📌 題目與已知條件
試寫出下圖電路之節點電壓方程式，將其轉換為對偶方程式後，繪出其對偶網路（Dual Network）。（25 分）
* 原電路拓撲：包含 4 個外部節點 $V_1, V_2, V_3, V_4$ 及中心參考接地點（第 0 節點）。
* 支路元件連接：
  - 節點 1 與接地：$1\ \Omega$ 電阻；節點 4 至 1：$1\text{ A}$ 電流源；節點 1 至 2：$2\text{ V}$ 電壓源（$+ \ -$）。
  - 節點 2 與接地：$2\ \Omega$ 電阻；節點 2 至 3：$3\text{ A}$ 電流源。
  - 節點 3 與接地：$3\ \Omega$ 電阻；節點 4 至 3：$4\text{ V}$ 電壓源（$- \ +$）。
  - 節點 4 與接地：$4\ \Omega$ 電阻。

---

### 💡 核心考點與破題關鍵
1. **超節點（Supernode）列寫 KCL**：
   - 節點 1 與 2 間跨接 $2\text{ V}$ 電壓源 $\implies V_1 - V_2 = 2\text{ V}$（組成超節點 A）。
   - 節點 3 與 4 間跨接 $4\text{ V}$ 電壓源 $\implies V_3 - V_4 = 4\text{ V}$（組成超節點 B）。
2. **對偶轉換映射法則（Dual Mapping）**：
   - 節點電壓 $V_k \longleftrightarrow$ 網目電流 $I_k'$
   - 電阻/電導 $G = \frac{1}{R} \longleftrightarrow$ 電阻 $R' = G$
   - 獨立電流源 $I_s \longleftrightarrow$ 獨立電壓源 $V_s' = I_s$
   - 獨立電壓源 $V_s \longleftrightarrow$ 獨立電流源 $I_s' = V_s$
   - 節點 KCL $\longleftrightarrow$ 網目 KVL

---

### ✏️ 步驟式詳細數學推導

#### 🔹 (1) 列寫原電路節點電壓方程式
1. **電壓源約束方程式**：
   $$V_1 - V_2 = 2$$
   $$V_3 - V_4 = 4$$
2. **超節點 1-2（Supernode 1-2）之 KCL 方程式**：
   $$\frac{V_1}{1} + \frac{V_2}{2} - 1\text{ A} + 3\text{ A} = 0 \implies \mathbf{V_1 + 0.5 V_2 = -2}$$
3. **超節點 3-4（Supernode 3-4）之 KCL 方程式**：
   $$\frac{V_3}{3} + \frac{V_4}{4} - 3\text{ A} + 1\text{ A} = 0 \implies \mathbf{\frac{1}{3} V_3 + \frac{1}{4} V_4 = 2}$$

#### 🔹 (2) 建立對偶網目電流方程式（Dual Mesh Equations）
依對偶映射法則，將節點電壓 $V_k$ 替換為網目電流 $i_k'$，電壓約束轉為電流約束，KCL 轉為 KVL：
1. **網目電流約束方程式（對偶於電壓源）**：
   $$\mathbf{i_1' - i_2' = 2\text{ A}}$$
   $$\mathbf{i_3' - i_4' = 4\text{ A}}$$
2. **超網目 1-2（Supermesh 1-2）之 KVL 方程式**：
   $$\mathbf{1 \cdot i_1' + 0.5 \cdot i_2' = -2\text{ V} \implies 1 i_1' + 0.5 i_2' + 2 = 0}$$
3. **超網目 3-4（Supermesh 3-4）之 KVL 方程式**：
   $$\mathbf{\frac{1}{3} i_3' + \frac{1}{4} i_4' = 2\text{ V}}$$

#### 🔹 (3) 對偶網路拓撲架構繪製說明
* **網目與元件對應**：
  - 網目 1 與 2 之間串接 $2\text{ A}$ 獨立電流源。
  - 網目 3 與 4 之間串接 $4\text{ A}$ 獨立電流源。
  - 網目 1 包含 $1\ \Omega$ 電阻與 $-2\text{ V}$ 電壓源。
  - 網目 2 包含 $0.5\ \Omega$ 電阻。
  - 網目 3 包含 $\frac{1}{3}\ \Omega$ 電阻與 $2\text{ V}$ 電壓源。
  - 網目 4 包含 $\frac{1}{4}\ \Omega$ 電阻。

---

### 🎯 第三題 滿分關鍵與結論
* **節點電壓方程式**：  
  $$\begin{cases} V_1 - V_2 = 2 \\ V_3 - V_4 = 4 \\ V_1 + 0.5 V_2 = -2 \\ \frac{1}{3} V_3 + \frac{1}{4} V_4 = 2 \end{cases}$$
* **對偶網目方程式**：  
  $$\begin{cases} i_1' - i_2' = 2 \\ i_3' - i_4' = 4 \\ 1 i_1' + 0.5 i_2' = -2 \\ \frac{1}{3} i_3' + \frac{1}{4} i_4' = 2 \end{cases}$$

## 四、時域脈衝與步階激勵二階暫態全響應求解（25 分）

### 📌 題目與已知條件
電路包含：
* 步階電壓源 $10u(t)\text{ V}$。
* 脈衝電流源 $6\delta(t)\text{ A}$（與 $C_1 = 1\text{ F}, R_1 = 1\ \Omega$ 並聯）。
* 脈衝電壓源 $4\delta(t)\text{ V}$（串聯於底線迴路）。
* 輸出負載支路包含 $R_2 = 1\ \Omega, L_2 = 1\text{ H}$ 串聯，端電壓為 $v_2(t)$。
* 初值狀態：在 $t = 0^-$ 時儲能均為 0。

**試求**：以時域分析法求解 $t > 0$ 時之輸出電壓響應 $v_2(t)$。（25 分）

---

### 💡 核心考點與破題關鍵
1. **脈衝函數衝擊下的狀態變數初值突變（$t = 0^-$ 到 $t = 0^+$）**：
   - 脈衝電流源 $6\delta(t)$ 對電容 $C_1 = 1\text{ F}$ 充電：
     $$v_C(0^+) = \frac{1}{C_1} \int_{0^-}^{0^+} 6\delta(t) dt = \frac{6}{1} = \mathbf{6\text{ V}}$$
   - 脈衝電壓源 $4\delta(t)$ 對電感 $L_2 = 1\text{ H}$ 激勵：
     $$i_L(0^+) = \frac{1}{L_2} \int_{0^-}^{0^+} 4\delta(t) dt = \frac{4}{1} = \mathbf{4\text{ A}}$$
2. **$t > 0$ 電路特徵方程式**：
   - 迴路總電阻 $R = R_1 + R_2 = 1 + 1 = 2\ \Omega$。
   - 二階串聯 RLC 特徵方程：
     $$s^2 + \frac{R}{L} s + \frac{1}{LC} = s^2 + 2s + 2 = 0 \implies s_{1,2} = -1 \pm j1$$
     （$\alpha = 1\text{ s}^{-1}, \omega_d = 1\text{ rad/s}$，欠阻尼響應）。
3. **直流穩態值（$t \to \infty$）**：
   - 電容視為開路，電感視為短路：
     $$i_L(\infty) = 0, \quad v_C(\infty) = 10\text{ V}, \quad v_2(\infty) = R_2 i_L(\infty) + 0 = \mathbf{0\text{ V}} \text{ (或依端點定義 } v_2(\infty) = 10\text{ V})$$

---

### ✏️ 步驟式詳細數學推導
1. **$t = 0^+$ 初值確定**：
   $$v_C(0^+) = 6\text{ V}, \quad i_L(0^+) = 4\text{ A}$$
   $$v_2(0^+) = v_{in}(0^+) - v_C(0^+) = 10 - 6 = \mathbf{4\text{ V}}$$
2. **求解電感電流 $i_L(t)$**：
   - 穩態電流：$i_L(\infty) = 0$。
   - 欠阻尼通解形式：
     $$i_L(t) = e^{-t} [B_1 \cos t + B_2 \sin t]$$
   - 代入 $i_L(0^+) = 4 \implies B_1 = 4$。
   - 由 $\left.L_2 \frac{di_L}{dt}\right|_{0^+} = v_{L2}(0^+) = v_2(0^+) - R_2 i_L(0^+) = 4 - (1)(4) = 0$：
     $$\left.\frac{di_L}{dt}\right|_{0^+} = -B_1 + B_2 = 0 \implies B_2 = B_1 = 4$$
     $$\mathbf{i_L(t) = 4 e^{-t} (\cos t + \sin t)\text{ A}}$$
3. **求解輸出電壓 $v_2(t) = R_2 i_L(t) + L_2 \frac{di_L}{dt}$**：
   $$\frac{di_L}{dt} = 4 e^{-t} (-\sin t + \cos t) - 4 e^{-t} (\cos t + \sin t) = -8 e^{-t} \sin t$$
   $$\mathbf{v_2(t) = (1) [4 e^{-t}(\cos t + \sin t)] + (1) [-8 e^{-t}\sin t] = \mathbf{4 e^{-t} (\cos t - \sin t) u(t)\text{ V}}}$$

---

> [!WARNING]
> ⚠️ **電路學 核心防坑與閱卷踩雷提醒**：
> 1. **複數功率共軛**：$\mathbf{S} = \mathbf{V}\mathbf{I}^* = P + jQ$，電流 $\mathbf{I}$ 務必取共軛，電感性負載 $Q > 0$（落後），電容性負載 $Q < 0$（超前）。
> 2. **三相功率計算**：三相總功率公式 $P = \sqrt{3}V_L I_L \cos	heta = 3V_\phi I_\phi \cos	heta$，代入線電壓時必有 $\sqrt{3}$。
> 3. **一階暫態連續性**：電感電流 $i_L(0^+) = i_L(0^-)$ 與電容電壓 $v_C(0^+) = v_C(0^-)$ 不可突變。
