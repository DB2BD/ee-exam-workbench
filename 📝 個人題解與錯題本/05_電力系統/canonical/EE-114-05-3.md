# 114 年電力系統第 3 題：經濟調度
忽略損失時，最適條件是增量成本相等：
\[
\frac{dC_1}{dP_1}=6+0.008P_1=6.8+0.004P_2=\frac{dC_2}{dP_2},\qquad P_1+P_2=550.
\]
解得 \(P_1=250\,\mathrm{MW}\)、\(P_2=300\,\mathrm{MW}\)，共同增量成本為 \(8\,\$/\mathrm{MWh}\)。二階導數皆為正，故為最小燃料成本解。
