## 固定使用方式

1. 只開官方原卷，依卷首計算器規範閉卷作答 120 分鐘；時間到立即停筆。
2. 再開完整題解，在自己的答案紙標出完整證據 `○`、部分證據 `△`、空白或錯起手 `×`。
3. 選最高配分的 `△／×` 題，關閉題解後重寫一次；錯因與分數不需回填專案。
4. `verified` 只代表題解通過專案題級查核，不代表使用者已掌握，也不等於官方逐步配分。
