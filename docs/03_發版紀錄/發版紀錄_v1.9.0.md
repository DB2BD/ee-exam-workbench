323 題詳解改成答案卷寫法：拿掉「解題邏輯」段落與各小題的「邏輯」標籤，前提寫進步驟裡。

## 改了什麼

### 1. 詳解內容（323 題）

- 刪除「考場標準作答」開頭的 `**解題邏輯**` 段落，以及各小題開頭的 `**邏輯**：` 行。這些文字大多在預告下面算式本來就寫的事。
- 算式沒交代的前提、條件、選根或選分支，例如忽略電阻、取低功角根、匯流排類型、峰值或有效值的讀法，改寫成一句普通的話，放進用到的步驟。用語為「設…」「取…（因…）」「由…得」，不加粗體標籤。
- 步驟標題、算式、代入、數值與框選答案都不動。驗算、失分點與已知與所求也不動。
- 合計刪去約 1,500 行。

### 2. 破題訓練

翻答案後原本顯示「解題邏輯」，改為「解題路線」：列出該題詳解的步驟標題，例如「導納矩陣與潮流方程 → 指定淨注入 → （一）功角與發電機虛功率 → （二）超限判斷與一次 N-R」。

### 3. 檢查規則

- `lint_canonical_notes.py`：
  - 改為預設禁止「解題邏輯」「邏輯」兩種標籤（錯誤碼 `logic-label`）；
  - compact 題仍限總配分 ≤ 5 分。
  - 旗標 `--require-logic` 保留為 `--answer-style` 的別名。
- 移除 `data/solution-logic-registry.json` 與 `scripts/update_solution_logic_registry.py`：規則改為對全部題目生效，不再需要登記表。
- `audit_solution_depth.py`：移除 `no-logic` 旗標。
