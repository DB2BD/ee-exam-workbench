## 一、比流器（CT）激磁特性與負擔（Burden）誤差分析（20 分）

### 📌 題目與已知條件
多比例比流器額定 $100 / 5\text{ A}$（變流比 $\text{CTR} = 20$），二次側內阻 $Z' = 0.082\ \Omega$。連接過電流電驛（動作值 $8\text{ A}$）。誤差定義為 $\text{Error}\% = \frac{I_e}{I_e + I'} \times 100\%$。
* **(一)** 當負擔 $Z_B = 0.8\ \Omega$ 時，求比流器誤差，並判斷是否能偵測到一次側 $200\text{ A}$ 故障電流。（10 分）
* **(二)** 當負擔 $Z_B = 3.0\ \Omega$ 時，重算誤差與偵測能力。（10 分）

---

### 💡 核心考點與破題關鍵
1. **理想二次電流**：$I_{ideal} = \frac{I_{fault}}{\text{CTR}} = \frac{200\text{ A}}{20} = 10\text{ A}$。
2. **激磁電壓**：$E' = I' \times (Z' + Z_B)$。
3. **查激磁特性曲線（Excitation Curve）**：由 $E'$ 查出激磁電流 $I_e$，二次實際電流 $I' = I_{ideal} - I_e$。
4. **動作判準**：若二次實際電流 $I' \ge 8\text{ A}$ 則電驛動作（可偵測）。

---

### ✏️ 步驟式詳細數學推導
1. **(一) 負擔 $Z_B = 0.8\ \Omega$**：
   - 總二次阻抗：$Z_{total} = Z' + Z_B = 0.082 + 0.8 = 0.882\ \Omega$。
   - 二次感應電壓：$E' \approx 10\text{ A} \times 0.882\ \Omega = 8.82\text{ V}$。
   - 查激磁曲線，在 $8.82\text{ V}$ 下處於線性段（未飽和），$I_e \approx 0.2\text{ A}$。
   - 比流器誤差：
     $$\mathbf{\text{Error}\% = \frac{0.2}{10} \times 100\% = 2.0\%}$$
   - 電驛二次電流：$I' = 10 - 0.2 = 9.8\text{ A} > 8\text{ A} \implies$ **可正確偵測並動作！**
2. **(二) 負擔 $Z_B = 3.0\ \Omega$**：
   - 總二次阻抗：$Z_{total} = 0.082 + 3.0 = 3.082\ \Omega$。
   - 二次感應電壓：$E' \approx 10\text{ A} \times 3.082\ \Omega = 30.82\text{ V}$。
   - 查激磁曲線，進入膝點飽和區，激磁電流激增至 $I_e \approx 2.5\text{ A}$。
   - 比流器誤差：
     $$\mathbf{\text{Error}\% = \frac{2.5}{10} \times 100\% = 25.0\%}$$
   - 電驛二次電流：$I' = 10 - 2.5 = 7.5\text{ A} < 8\text{ A} \implies$ **電驛拒動，無法偵測！**

---

### 🎯 第一題 滿分關鍵與結論
- **$Z_B = 0.8\ \Omega$**：誤差 $\mathbf{2.0\%}$，電驛電流 $9.8\text{ A}$，**能成功偵測**。
- **$Z_B = 3.0\ \Omega$**：誤差 $\mathbf{25.0\%}$，電驛電流 $7.5\text{ A}$，**無法偵測（飽和拒動）**。

## 二、大型同步馬達全壓啟動電壓變動率計算（20 分）

### 📌 題目與已知條件
特高壓用戶 $69\text{ kV}$ 受電，短路容量 $S_{sc} = 500\text{ MVA}$。主變 $5000\text{ kVA}, 69\text{ kV} / 3.3\text{ kV}, Z = 5\%$。同步馬達 $3.3\text{ kV}, 3000\text{ kW}$，啟動電流為 5 倍額定電流，全壓啟動且功因為 0（純感性）。基準值 $S_b = 5000\text{ kVA} = 5\text{ MVA}$。
試求：
* **(一)** 變壓器二次側（$3.3\text{ kV}$ 匯流排）之電壓變動率。（10 分）
* **(二)** $69\text{ kV}$ 責任分界點之電壓變動率。（10 分）

---

### 💡 核心考點與破題關鍵
1. **各元件標么阻抗（$S_b = 5\text{ MVA}$）**：
   - 系統：$X_{sys} = \frac{5}{500} = 0.01\text{ pu}$
   - 主變：$X_{Tr} = 0.05\text{ pu}$
2. **馬達啟動容量標么值**：
   - 額定容量（設 $\text{PF} \approx 0.9$ 或按額定計算）：$S_{start} = 5 \times S_{motor} = 5 \times 3.33 = 16.67\text{ MVA} \implies X_{motor,start} = \frac{S_b}{S_{start}} = \frac{5}{16.67} = 0.30\text{ pu}$
3. **電壓降分壓公式**：
   $$\Delta V\% = \frac{X_{source}}{X_{source} + X_{motor,start}} \times 100\%$$

---

### ✏️ 步驟式詳細數學推導
1. **(一) 變壓器二次側電壓變動率**：
   - 上游總阻抗：$X_{up} = X_{sys} + X_{Tr} = 0.01 + 0.05 = 0.06\text{ pu}$。
   $$\mathbf{\Delta V_{3.3kV} = \frac{0.06}{0.06 + 0.30} \times 100\% = \frac{0.06}{0.36} \times 100\% = 16.67\%}$$
2. **(二) $69\text{ kV}$ 側電壓變動率**：
   - $69\text{ kV}$ 處上游阻抗僅為系統阻抗 $X_{sys} = 0.01\text{ pu}$：
   $$\mathbf{\Delta V_{69kV} = \frac{0.01}{0.01 + 0.05 + 0.30} \times 100\% = \frac{0.01}{0.36} \times 100\% = 2.78\%}$$

---

### 🎯 第二題 滿分關鍵與結論
- **$3.3\text{ kV}$ 側電壓變動率**：$\Delta V = \mathbf{16.67\%}$
- **$69\text{ kV}$ 側電壓變動率**：$\Delta V = \mathbf{2.78\%}$

## 三、汽電共生短路電流與斷路器容量計算（20 分）

### 📌 題目與已知條件
汽電共生系統，$S_b = 25\text{ MVA}$：
- 發電機：$25\text{ MW}, 22.8\text{ kV}, X_d'' = 12\%$
- 變壓器：$25\text{ MVA}, 22.8\text{ kV} / 3.3\text{ kV}, X_T = 8\%$
- 大型馬達：$6000\text{ kW}, 3.3\text{ kV}, X_d'' = 15\%$
在低壓側 F 點發生三相短路，求：
* **(一)** 故障點 F 之次暫態短路電流（A）。（10 分）
* **(二)** 斷路器 A 點之次暫態電流（A）。（10 分）

---

### 💡 核心考點與破題關鍵
1. **短路電流來源**：發電機經變壓器注入電流 ＋ 馬達反饋倒灌電流。
2. **阻抗換算與標么短路電流**：$I_{sc,pu} = \frac{1.0}{X_{th}}$。

---

### ✏️ 步驟式詳細數學推導
1. **換算標么電抗（$S_b = 25\text{ MVA}$）**：
   - 發電機：$X_{G} = 0.12\text{ pu}$
   - 變壓器：$X_T = 0.08\text{ pu}$
   - 發電機側支路總抗：$X_1 = X_G + X_T = 0.12 + 0.08 = 0.20\text{ pu}$
   - 馬達側電抗（$S_m \approx 6.67\text{ MVA}$）：$X_m = 0.15 \times \frac{25}{6.67} = 0.5625\text{ pu}$
   - 總等效戴維寧電抗：
     $$X_{th} = X_1 \parallel X_m = \frac{0.20 \times 0.5625}{0.20 + 0.5625} = \frac{0.1125}{0.7625} = 0.1475\text{ pu}$$
2. **計算故障點 F 次暫態短路電流**：
   - $3.3\text{ kV}$ 基準電流：
     $$I_b = \frac{25 \times 10^6}{\sqrt{3} \times 3.3 \times 10^3} = 4373.87\text{ A}$$
   - 故障點短路電流：
     $$\mathbf{I_{sc,F} = \frac{1.0}{0.1475} \times 4373.87 = 6.778 \times 4373.87 = 29646\text{ A} = 29.65\text{ kA}}$$
3. **計算斷路器 A 之次暫態電流**：
   - 僅含發電機經變壓器提供之短路分量：
     $$\mathbf{I_{A} = \frac{1.0}{X_1} \times I_b = \frac{1.0}{0.20} \times 4373.87 = 5.0 \times 4373.87 = 21869\text{ A} = 21.87\text{ kA}}$$

---

### 🎯 第三題 滿分關鍵與結論
- **故障點 F 次暫態短路電流**：$I_{sc,F} = \mathbf{29.65\text{ kA}}$
- **斷路器 A 次暫態短路電流**：$I_A = \mathbf{21.87\text{ kA}}$

## 四、多台連續運轉動力設備配線與保護設計（20 分）

### 📌 題目與已知條件
三相三線 $220\text{ V}$ 動力負載：$20\text{ HP}$ 電焊機、$20\text{ HP}$ 壓縮機、$10\text{ HP}$ 冷氣機、$8\text{ HP}$ 車床。均連續運轉，$\text{PF} = 0.85$ 落後，啟動階級 B，保護設備最大額定為額定電流 1.8 倍。金屬管配線。設計各分路與幹線導線線徑及過電流保護規格。

---

### 💡 核心考點與破題關鍵
1. **各電動機額定電流（三相 $220\text{ V}$）**：
   - $20\text{ HP}: I_{FLC} \approx 54\text{ A}$
   - $10\text{ HP}: I_{FLC} \approx 28\text{ A}$
   - $8\text{ HP}: I_{FLC} \approx 22\text{ A}$
2. **分路導線安培容量**：$I_w \ge 1.25 \times I_{FLC}$。
3. **共同幹線導線安培容量**：$I_{w,main} \ge 1.25 \times I_{FLC,max} + \sum I_{FLC,others}$。

---

### ✏️ 步驟式詳細數學推導
1. **幹線導線載流量與選定**：
   $$I_{w,main} = 1.25 \times 54 + 54 + 28 + 22 = 67.5 + 104 = 171.5\text{ A}$$
   $\implies$ 選用 **$80\text{ mm}^2$ 銅導線**（安全載流量 $190\text{ A}$）。
2. **幹線保護規格**：
   $$I_{CB,main} \le (1.8 \times 54) + 54 + 28 + 22 = 97.2 + 104 = 201.2\text{ A}$$
   $\implies$ 選用標準品 **$200\text{ AT} / 225\text{ AF}$**。

---

### 🎯 第四題 滿分關鍵與結論
- **共同幹線導線**：**$80\text{ mm}^2$ 銅導線**
- **幹線斷路器保護**：**$200\text{ AT} / 225\text{ AF}$**

## 五、特高壓主變中性點電阻接地設計與驗證（20 分）

### 📌 題目與已知條件
煉油廠 $161\text{ kV}$ 受電，系統短路容量 $10000\text{ MVA}$。主變 $100\text{ MVA}, 161\text{ kV} / 33\text{ kV}, Z = 12\%$。二次側以 $18\ \Omega$ 電阻器接地。低電阻接地規範要求電阻器額定電流落在二次側三相短路電流之 $5\% \sim 20\%$ 範圍內。
試求：
* **(一)** 接地電阻器之額定電壓與額定電流。（10 分）
* **(二)** 驗證該電阻器是否符合低電阻接地規範要求。（10 分）

---

### 💡 核心考點與破題關鍵
1. **接地電阻器額定電壓**：承受最高單相對地相電壓 $V_n = \frac{V_L}{\sqrt{3}} = \frac{33\text{ kV}}{\sqrt{3}} = 19.05\text{ kV}$。
2. **額定接地電流**：$I_n = \frac{V_n}{R_n} = \frac{19.05\text{ kV}}{18\ \Omega} = 1058.5\text{ A}$。
3. **二次側三相短路電流**：$I_{sc,3\phi} = \frac{S_{sc,sec}}{\sqrt{3} V_L}$。

---

### ✏️ 步驟式詳細數學推導
1. **(一) 計算電阻器規格**：
   - 額定電壓：$\mathbf{V_n = \frac{33\text{ kV}}{\sqrt{3}} = 19.05\text{ kV}}$
   - 額定電流：$\mathbf{I_n = \frac{19053\text{ V}}{18\ \Omega} = 1058.5\text{ A}}$（通常選定 $1000\text{ A} \sim 1060\text{ A}$，容許 $10\text{ 秒}$ 耐受）。
2. **(二) 驗證低電阻接地標準（$5\% \sim 20\%$）**：
   - 換算總標么阻抗（$S_b = 100\text{ MVA}$）：
     $$X_{sys} = \frac{100}{10000} = 0.01\text{ pu}, \quad X_{Tr} = 0.12\text{ pu} \implies X_{total} = 0.13\text{ pu}$$
   - 二次側三相短路容量：
     $$S_{sc} = \frac{100\text{ MVA}}{0.13} = 769.23\text{ MVA}$$
   - 二次側三相短路電流：
     $$I_{sc,3\phi} = \frac{769.23 \times 10^6}{\sqrt{3} \times 33 \times 10^3} = 13458\text{ A}$$
   - 接地電流佔比：
     $$\text{比率} = \frac{I_n}{I_{sc,3\phi}} = \frac{1058.5\text{ A}}{13458\text{ A}} \times 100\% = \mathbf{7.865\%}$$
   - 因 $5\% \le 7.865\% \le 20\%$，**完全符合低電阻接地規範要求！**

---

### 🎯 第五題 滿分關鍵與結論
- **電阻器額定**：電壓 $\mathbf{19.05\text{ kV}}$，電流 $\mathbf{1058.5\text{ A}}$（阻值 $18\ \Omega$）
- **規範驗證**：接地電流佔短路電流 **$7.865\%$**，落在 $5\%\sim 20\%$ 規定區間內，**完全符合**。
