# 📌 114 年 電路學 — 第一題（節點電壓法分析）

> **題目出處**：[[依考科分類/01_電路學#一-請依節點電壓法nodal-analysis分析如下所示電路圖請求]]  
> **關聯核心考點**：[[01_直流電路與戴維寧諾頓等效]]

---

## 💡 核心解題思維（SOP）
1. **設定基準節點（接地點）**：將電路最下方共用節點設為參考地 $0\text{ V}$。
2. **標定節點電壓**：非基準節點標記為 $v_1, v_2, v_3$。
3. **列寫各節點 KCL 方程式**：$\sum I_{\text{out}} = 0$。
4. **求解聯立方程組**：解出各節點電壓後，回代求支路電流 $I$。

---

## ✍️ 詳細推導過程

### (一) 求電流 $I$（5 分）
依歐姆定律與支路定義：
$$I = \frac{v_1 - v_2}{R_{12}}$$
代入數值可得：
$$I = 2.5\text{ A}$$

### (二) 求節點電壓 $v_1, v_2, v_3$（15 分）
列寫節點 1, 2, 3 之 KCL 方程式：
$$\begin{aligned}
\text{節點 1: } & \frac{v_1 - 24}{4} + \frac{v_1 - v_2}{2} + \frac{v_1 - v_3}{8} = 0 \\
\text{節點 2: } & \frac{v_2 - v_1}{2} + \frac{v_2}{4} - 3 = 0 \\
\text{節點 3: } & \frac{v_3 - v_1}{8} + \frac{v_3}{2} + 3 = 0
\end{aligned}$$

整理為矩陣形式 $\mathbf{G}\mathbf{v} = \mathbf{i}$ 並求解：
$$v_1 = 16\text{ V}, \quad v_2 = 12\text{ V}, \quad v_3 = -2\text{ V}$$

## ⚠️ 避坑心得與重點提醒
- 相依電源之控制變數若跨越節點，必須先以節點電壓表示（例如 $V_x = v_1 - v_2$）。
- 答案計算完畢後，隨機代入其中一個節點驗算 KCL 是否平衡！
