# 發版紀錄 v1.0.7

日期：2026-09-12

## 本版內容

本版依照既有 `v1.0.x` 公開里程碑規則，收錄架構清理、每日練習查找效能改善與可重跑 QA 工作流。

### 清理與效能

- 移除已被正式測試取代的兩個過時檢查入口，並刪除每日練習查找後不再使用的包裝函式。
- 每日練習只在目前考科資料集查找，避免重複轉換另一考科的 482 題資料。
- 加入查找微基準與一鍵 QA 指令，保留結果等價性斷言。
- CI 直接使用語法檢查器的退出碼，避免以文字輸出判斷成功。

### QA 與工作樹流程

- 加入 `npm run check`，串接建置、309 項測試、HTML／JavaScript 語法、482 題切片／連結、圖片資產及 Pages staging 檢核。
- 加入桌機／手機 PE／GK 瀏覽器端到端測試，驗證三題、四段蓋牌、完成後前進、重載保存與詳解內容。
- 加入 `docs/QA_WORKFLOW.md`，供後續模型與工作樹重現驗證。

## 驗證結果

- 完整題庫 QA：309 項測試通過。
- PE／GK 題目、圖片、PDF 連結與切片：482/482 通過。
- 瀏覽器 QA：PE／GK × 1440/390px 四組通過。
- 每日查找微基準：10 次完整查找約由 1,213 ms 降至 85 ms；482 題結果等價。
- `git diff --check`：通過。

## 已知限制

- 外部 URL 可達性不在離線 QA 範圍內。
- 工作樹中的其他未提交使用者變更不屬於本版，未被合併或覆蓋。

## 版次依據

既有 `v1.0.0`～`v1.0.6` 均以公開功能、資料或文件里程碑遞增一個 `v1.0.x` 版次。本版延續該慣例，將 `v1.0.6` 後完成並通過完整 QA 的架構清理與驗證工具更新標記為 `v1.0.7`。
