# 發版紀錄 v1.8.5（2026-10-25）

首頁、成績頁與練習視窗的人性化調整：重點更好找、數字不重複、手機的返回鍵不會把工作台關掉。

## 改了什麼

### 首頁
- **任務卡**：
  - 標題在前，例如「108 年電路學計時演練 · 180 分鐘」；任務代碼（BLIND108-01）改成旁邊的小標籤。
  - 「今天還有」也改成名稱在前、代碼放括號。
- **狀態列**：
  - 拆成兩行：進度與關卡一行，「落後約 N 小時」獨立一行。落後用警示色，超前用主色。
  - 到期複習題數只留在「到期複習」卡上，寫成「到期複習 15 題／今天的份量（共 95 題到期）」，不再在三個地方重複。
- **自動刪減提示**：改名為「今天先跳過：…（有空再做）」，從橘色警示框改成中性灰框。成績頁的同名區塊改為「先跳過（有空再做）」。
- **頂部摘要**：拿掉到期題數；任務改顯示名稱，不顯示代碼。
- **手機版**：
  - 像素場景縮成細條。
  - 在「今天」分頁隱藏頂部摘要，因為下方任務卡已經寫了同樣的內容。
  - 「下一個任務＋開始」整張卡都在第一屏內。

### 成績頁
- 亮色模式下的警示字（零分風險、差 N 分到 60、最可能拖垮平均的科目）改用新的 `--warn-ink` 色。對比由 2.9～3.3 提高到 ≥ 4.5。

### 練習視窗
- 標題列顯示「第 N／M 題」，手機上也看得到。
- 手機上的學習狀態按鈕保留文字（例如「● 需二刷」），不再只有一個圓點。
- 題目圖載入前顯示佔位色塊；開啟「減少動態效果」時不播動畫。

### 返回鍵與無障礙
- 切換分頁、開啟練習視窗都會留下瀏覽紀錄。
- 按返回鍵或滑動返回時，會先關閉練習視窗，再回到上一個分頁，不會直接離開工作台。
- 主要分頁改為 `<nav>`，目前分頁加上 `aria-current="page"`。

## 沒改什麼

題解內容、排程與評分規則、資料格式、備份格式。

## 驗證

- `npm run check` 全過（1217 tests）。新增 `tests/test_humane_ui.py`，檢查：
  - 配速行的語氣；
  - 練習進度文字；
  - 兩種主題下警示字的對比；
  - 目前分頁標記與返回鍵的接線。
- `npm run qa:browser` 全過（31 項）。新增「返回鍵 390px」情境：
  - 返回會先關練習視窗，再從成績回到今天，不會離開工作台；
  - 視窗關閉後立刻重開同一個流程時，只需要按一次返回。
- 亮色、暗色模式下，今天與成績頁的文字對比全部 ≥ 4.5。
- 公式渲染閘門：0 錯誤。
