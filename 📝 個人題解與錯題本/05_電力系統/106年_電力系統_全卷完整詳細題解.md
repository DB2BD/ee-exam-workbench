## 一、161 kV 短距離輸電線路電壓調整率與傳輸效率（25 分）

### 📌 題目與已知條件
- 額定線電壓 $V_L = 161\text{ kV}$，長度 $l = 40\text{ km}$。
- 每相阻抗：$R = 0.15 \times 40 = 6.0\ \Omega，X_L = 2\pi(60)(1.3\times 10^{-3})(40) = 19.6035\ \Omega \implies Z = 6.0 + j19.6035\ \Omega$。
- 負載：$S_R = 300\text{ MVA}, \text{PF} = 0.8\text{ 滯後}$，受電端電壓 $V_{R,LL} = 161\text{ kV}$。

* **(一)** 試求送電端之相電壓與線電壓。（7 分）
* **(二)** 試求送電端之三相實功率 $P_S$ 與虛功率 $Q_S$。（6 分）
* **(三)** 試求線路之電壓調整率 $\text{VR}$。（6 分）
* **(四)** 試求傳輸線之傳輸效率 $\eta$。（6 分）

---

### ✏️ 步驟式詳細數學推導
1. **受電端相量**：
   $$V_R = \frac{161\text{ kV}}{\sqrt{3}} \approx 92.953\angle 0^\circ\text{ kV}$$
   $$\mathbf{I}_R = \frac{300\times 10^6}{\sqrt{3}\times 161\times 10^3}\angle -36.87^\circ = 1075.76\angle -36.87^\circ\text{ A} = (860.61 - j645.46)\text{ A}$$
2. **送電端電壓 $\mathbf{V}_S$**：
   $$\mathbf{V}_S = 92953 + (860.61 - j645.46)(6.0 + j19.6035) = 110770 + j12998\text{ V} = \mathbf{111.53\angle 6.69^\circ\text{ kV}}$$
   $$V_{S,LL} = \sqrt{3} \times 111.53\text{ kV} = \mathbf{193.18\text{ kV}}$$
3. **三相損耗與傳輸效率**：
   $$P_{loss} = 3 I_R^2 R = 3 \times (1075.76)^2 \times 6.0 = \mathbf{20.83\text{ MW}}$$
   $$P_S = 300(0.8) + 20.83 = 240.0 + 20.83 = \mathbf{260.83\text{ MW}}$$
   $$\eta = \frac{240.0}{260.83} \times 100\% = \mathbf{92.01\%}$$
4. **電壓調整率**：
   $$\text{VR} = \frac{111.53 - 92.953}{92.953} \times 100\% = \mathbf{19.98\%}$$

---

### 🎯 第一題 滿分關鍵與結論
- **送電端線電壓**：$V_{S,LL} = \mathbf{193.18\text{ kV}}$
- **送電端實功**：$P_S = \mathbf{260.83\text{ MW}}$
- **電壓調整率**：$\text{VR} = \mathbf{19.98\%}$
- **傳輸效率**：$\eta = \mathbf{92.01\%}$

## 二、三匯流排阻抗矩陣三相短路故障電壓與電流（25 分）

### 📌 題目與已知條件
![[106年_電機工程技師_電力系統_第2題_阻抗單線圖.png|750]]
*圖：106年電力系統第二題 三匯流排電力系統阻抗單線圖*

- 基準容量 $100\text{ MVA}$，無載額定電壓 $V_f = 1.0\angle 0^\circ\text{ pu}$。
- 匯流排 1 發生三相短路接地，接地阻抗 $Z_f = j0.11\text{ pu}$。
- $\mathbf{Z}_{bus}$ 元素：$Z_{11} = j0.14\text{ pu}, Z_{31} = j0.06\text{ pu}$。

* **(一)** 試求匯流排 3 之故障期間電壓 $V_3$。（9 分）
* **(二)** 試求匯流排 1 之故障電流 $I_f$。（8 分）
* **(三)** 試求匯流排 1 之故障點電壓 $V_1$。（8 分）

---

### ✏️ 步驟式詳細數學推導
1. **故障電流 $I_f$**：
   $$I_f = \frac{V_f}{Z_{11} + Z_f} = \frac{1.0}{j0.14 + j0.11} = \frac{1.0}{j0.25} = \mathbf{-j4.000\text{ pu}} = \mathbf{4.000\angle -90^\circ\text{ pu}}$$
2. **故障點端電壓 $V_1$**：
   $$V_1 = I_f Z_f = (-j4.0)(j0.11) = \mathbf{0.440\text{ pu}}$$
3. **匯流排 3 電壓 $V_3$**：
   $$V_3 = 1.0 - Z_{31} I_f = 1.0 - (j0.06)(-j4.0) = 1.0 - 0.24 = \mathbf{0.760\text{ pu}}$$

---

### 🎯 第二題 滿分關鍵與結論
- **故障電流**：$I_f = \mathbf{4.000\angle -90^\circ\text{ pu}}$
- **Bus 1 電壓**：$V_1 = \mathbf{0.440\text{ pu}}$
- **Bus 3 電壓**：$V_3 = \mathbf{0.760\text{ pu}}$

## 三、三匯流排電力潮流導納矩陣與潮流方程式（25 分）

### 📌 題目與已知條件
- **Bus 1**：Slack bus，$V_1=1\angle0^\circ$ pu。
- **Bus 2**：PV bus，$P_2=1$ pu、$|V_2|=1$ pu。
- **Bus 3**：PQ bus，$S_{L3}=1+j0.9$ pu，因此 $P_3=-1$ pu、$Q_3=-0.9$ pu。
- 由承上題官方圖讀取線路電抗：$x_{12}=j0.8$、$x_{13}=j0.4$、$x_{23}=j0.4$ pu。

**試求**：$Y_{bus}$、Bus 1 實功輸出 $P_1$ 及 2–3 線路無效功率流向。（25 分）

### ✏️ 步驟式詳細數學推導

各線路導納為 $-j1.25,-j2.5,-j2.5$ pu，故
\[
\boxed{Y_{bus}=\begin{bmatrix}-j3.75&j1.25&j2.50\\j1.25&-j3.75&j2.50\\j2.50&j2.50&-j5.00\end{bmatrix}\ \mathrm{pu}}.
\]

令 $V_2=e^{j\delta_2}$、$V_3=V_3e^{j\delta_3}$，PV/PQ 方程為
\[
\frac{V_2}{0.8}\sin\delta_2+\frac{V_2V_3}{0.4}\sin(\delta_2-\delta_3)=1,
\]
\[
\frac{V_3}{0.4}\sin\delta_3+\frac{V_3V_2}{0.4}\sin(\delta_3-\delta_2)=-1,
\]
\[
\frac{2V_3^2}{0.4}-\frac{V_3}{0.4}\cos\delta_3-\frac{V_3V_2}{0.4}\cos(\delta_3-\delta_2)=-0.9.
\]

通常 Newton 高電壓解為 $\delta_2=13.929834^\circ$、$\delta_3=-10.091837^\circ$、$|V_3|=0.686920978$ pu；回代得 $P_1=0$ pu。線路 2→3
\[
S_{23}=V_2\overline{\frac{V_2-V_3}{j0.4}}=0.699083+j0.931430\ \mathrm{pu},
\]
故無效功率由 **Bus 2 流向 Bus 3**。

同一方程另有低電壓解 $|V_3|=0.396731$ pu（$\delta_2=17.298689^\circ,\delta_3=-22.009128^\circ$），其 $S_{23}=0.628309+j1.732570$ pu；因題目未指定初值／穩定分支，完整 canonical 記錄保留此非唯一性並將本題標為人工複核。

## 四、單相變壓器差動電驛 CT 匝比設定與動作原理（25 分）

### 📌 題目與已知條件
![[106年_電機工程技師_電力系統_第4題_差動電驛保護圖.png|750]]
*圖：106年電力系統第四題 單相雙繞組變壓器差動電驛保護電路圖*

主變壓器匝比 $N_1 / N_2$，兩側 CT 變比為 $1/n_1, 1/n_2$。

**試求**：差動電流 $I'$ 之表示式、CT 匝比匹配條件及正常運轉時之 $I'$。（25 分）

---

> [!WARNING]
> ⚠️ **電力系統 核心防坑與閱卷踩雷提醒**：
> 1. **對稱成分故障計算**：單相接地 (SLG) 故障電流為 $I_f = 3I_{a1} = \frac{3V_f}{Z_1 + Z_2 + Z_0 + 3Z_n}$，千萬不可漏乘 3 倍！
> 2. **旋轉相量符號**：$a^2 - a = -j\sqrt{3}$，而 $a - a^2 = +j\sqrt{3}$，正負序相量展開切勿混淆。
> 3. **等面積準則**：計算擺動極限角 $(\pi - \delta_0 - \delta_1)$ 時，分母角度嚴格必須使用**弧度 (Radian)** 代入！

---


### ✏️ 完整標準推導
1. **差動電流公式**：
   $$I' = \mathbf{\frac{I_1}{n_1} - \frac{I_2}{n_2}}$$
2. **匝比匹配條件**：
   由理想變壓器電流守恆 $\frac{I_1}{I_2} = \frac{N_2}{N_1}$，為使正常時 $I' = 0$：
   $$\mathbf{\frac{n_1}{n_2} = \frac{N_2}{N_1} \iff n_1 N_1 = n_2 N_2}$$
3. **正常運轉差動電流**：$I_{\text{normal}}' = \mathbf{0\text{ A}}$。
