## 一、$\Delta-\Delta$ 變壓器開 $\Delta$（V-V）接線緊急供電分析（20 分）

### 📌 題目與已知條件
三台容量相同為 $50\text{ kVA}$，高低壓側電壓 $3300\text{ V} / 220\text{ V}$ 之單相變壓器以 $\Delta-\Delta$ 接線供應三相負載。假設其中一台變壓器因故障隔離，試求：
* **(一)** 請繪圖說明如何改用開 \Delta（V-V）接線方式進行緊急供電。（10 分）
* **(二)** 改接後可供應之最大三相平衡負載容量為多少？改接後之容量利用率與輸出過載能力為何？（10 分）

---

### 💡 核心考點與破題關鍵
1. **$\Delta-\Delta \to \text{V-V}$ 故障應急原理**：
   - 移除一台故障變壓器後，剩餘兩台變壓器仍能維持對稱三相線電壓（藉由基爾霍夫電壓定律 $\mathbf{V}_{ca} = -(\mathbf{V}_{ab} + \mathbf{V}_{bc})$）。
2. **V-V 接線容量公式**：
   - 三台 $\Delta-\Delta$ 總容量：$S_{\Delta} = 3 S_{1\phi} = 3 \times 50 = 150\text{ kVA}$
   - 兩台 V-V 總容量：$S_V = \sqrt{3} S_{1\phi} = \sqrt{3} \times 50\text{ kVA} \approx 86.60\text{ kVA}$
3. **容量比與利用率（指標必考）**：
- **容量比（Capacity Ratio）**： $\frac{S_V}{S_\Delta} = \frac{\sqrt{3} S_{1\phi}}{3 S_{1\phi}} = \frac{1}{\sqrt{3}} \approx 57.7\%$
- **利用率（Utilization Factor）**： $\frac{S_V}{2 S_{1\phi}} = \frac{\sqrt{3} S_{1\phi}}{2 S_{1\phi}} = \frac{\sqrt{3}}{2} \approx 86.6\%$

---

### ✏️ 步驟式詳細數學推導
1. **V-V 接線接線圖與相量原理說明**：
   - 將原 $\Delta-\Delta$ 接線中故障之一相完全拆除（開路）。
   - 保留兩台變壓器分別接於 A-B 相與 B-C 相。
   - 二次側輸出線電壓維持為三相對稱：
     $$\mathbf{V}_{ab} = V_L \angle 0^\circ, \quad \mathbf{V}_{bc} = V_L \angle -120^\circ$$
     $$\mathbf{V}_{ca} = -(\mathbf{V}_{ab} + \mathbf{V}_{bc}) = V_L \angle 120^\circ$$
2. **計算最大可供應負載容量 $S_V$**：
   - 每台單相變壓器額定容量 $S_{1\phi} = 50\text{ kVA}$。
   - 線路額定電流 $I_L = I_{1\phi, rated} = \frac{50\text{ kVA}}{220\text{ V}} = 227.27\text{ A}$。
   - 最大可供應之三相平衡容量：
     $$\mathbf{S_V = \sqrt{3} V_L I_L = \sqrt{3} \times S_{1\phi} = \sqrt{3} \times 50\text{ kVA} = 86.60\text{ kVA}}$$
3. **指標計算**：
   - 供應能力相較原 $\Delta-\Delta$ 降至：$\frac{86.60}{150} = 57.7\%$
   - 兩台變壓器之設備利用率為：$\frac{86.60}{2 \times 50} = 86.6\%$

---

### 🎯 第一題 滿分關鍵與結論
- **改接後最大容量**：$S_V = \mathbf{86.60\text{ kVA}}$
- **容量比**：$\mathbf{57.7\%}$；**設備利用率**：$\mathbf{86.6\%}$

## 二、電弧爐壓降與電壓閃爍變動率（$\Delta V_{10}$）計算（20 分）

### 📌 題目與已知條件
鋼鐵廠啟用 50 噸電弧爐，系統短路容量 $S_{sc} = 2000\text{ MVA}$（於 $69\text{ kV}$ 變電所），線路阻抗 $Z_L = j0.01\text{ pu}$。主變壓器容量 $25\text{ MVA}, Z_{MTr} = j0.06\text{ pu}$；爐用變壓器容量 $25\text{ MVA}, Z_{FTr} = j0.05\text{ pu}$；電弧爐及其配線等效阻抗 $Z_F = j0.4\text{ pu}$（基準容量均為 $S_b = 25\text{ MVA}$）。
試求：
* **(一)** 電極短路與電極斷弧時，主變壓器二次側匯流排之百分壓降值。（10 分）
* **(二)** 主變壓器二次側所產生之閃爍電壓變動率 $\Delta V$。（10 分）

---

### 💡 核心考點與破題關鍵
1. **系統電源阻抗標么值轉換**：
   $$X_{sys} = \frac{S_b}{S_{sc}} = \frac{25\text{ MVA}}{2000\text{ MVA}} = 0.0125\text{ pu}$$
2. **總阻抗與分壓定理**：
   - 匯流排上游總阻抗：$X_{up} = X_{sys} + X_L + X_{MTr} = 0.0125 + 0.01 + 0.06 = 0.0825\text{ pu}$
   - 匯流排下游總阻抗：$X_{down} = X_{FTr} + X_F$
3. **電壓閃爍變動率公式**：
   $$\Delta V\% = \frac{V_{斷弧} - V_{短路}}{V_{額定}} \times 100\%$$

---

### ✏️ 步驟式詳細數學推導
1. **上游各部分標么電抗匯總**：
   - 系統電源：$X_{sys} = \frac{25}{2000} = 0.0125\text{ pu}$
   - 線路：$X_L = 0.01\text{ pu}$
   - 主變：$X_{MTr} = 0.06\text{ pu}$
   - 上游總電抗：$X_{up} = 0.0125 + 0.01 + 0.06 = 0.0825\text{ pu}$
2. **電弧爐運轉狀態分析**：
   - **狀態 A：電極斷弧（開路，無負載電流）**：
     $$I = 0 \implies V_{二次側} = 1.0\text{ pu} \implies \text{壓降 } \Delta V_{斷弧} = \mathbf{0\%}$$
   - **狀態 B：電極短路（$Z_F = 0$）**：
     - 下游電抗僅剩爐用變壓器 $X_{down} = X_{FTr} = 0.05\text{ pu}$。
     - 總迴路電抗：$X_{total} = X_{up} + X_{down} = 0.0825 + 0.05 = 0.1325\text{ pu}$。
     - 短路電流：$I_{sc,arc} = \frac{1.0}{0.1325} = 7.547\text{ pu}$。
     - 主變二次側電壓：
       $$V_{二次側} = 1.0 - I_{sc,arc} \times X_{up} = 1.0 - (7.547 \times 0.0825) = 1.0 - 0.6226 = 0.3774\text{ pu}$$
     - 百分壓降值：
       $$\mathbf{\Delta V_{短路}\% = (1.0 - 0.3774) \times 100\% = 62.26\%}$$
   - **狀態 C：正常運轉（含電弧爐阻抗 $Z_F = j0.4\text{ pu}$）**：
     - 下游總電抗：$X_{down} = 0.05 + 0.4 = 0.45\text{ pu}$。
     - 總迴路電抗：$X_{total} = 0.0825 + 0.45 = 0.5325\text{ pu}$。
     - 運轉電流：$I_{run} = \frac{1.0}{0.5325} = 1.878\text{ pu}$。
     - 正常運轉主變二次側壓降：
       $$\Delta V_{run}\% = I_{run} \times X_{up} \times 100\% = 1.878 \times 0.0825 \times 100\% = 15.49\%$$
3. **計算主變二次側之電壓閃爍變動率 $\Delta V$**：
   - 根據短路至斷弧之最大電壓變動幅度：
     $$\mathbf{\Delta V = \frac{X_{up}}{X_{up} + X_{FTr}} \times 100\% = \frac{0.0825}{0.0825 + 0.05} \times 100\% = \frac{0.0825}{0.1325} \times 100\% = 62.26\%}$$

---

### 🎯 第二題 滿分關鍵與結論
- **斷弧時百分壓降**：$\mathbf{0\%}$（電壓維持 $1.0\text{ pu}$）
- **短路時百分壓降**：$\mathbf{62.26\%}$（電壓跌至 $0.3774\text{ pu}$）
- **電壓閃爍變動率**：$\Delta V = \mathbf{62.26\%}$

## 三、汽電共生系統發電機短路電流與容量計算（20 分）

### 📌 題目與已知條件
石化廠汽電共生系統含兩部並聯發電機：
- 發電機 1：$50\text{ MW}$, X_{d1}'' = 25\%
- 發電機 2：$30\text{ MW}$, X_{d2}'' = 25\%
經由一台 $100\text{ MVA}, 22\text{ kV} / 69\text{ kV}, X_{Tr} = 10\%$ 之升壓變壓器輸出。故障前高壓側電壓為 $65\text{ kV}$。以變壓器容量 $S_b = 100\text{ MVA}$ 為基準值。試求：
* **(一)** 變壓器 $69\text{ kV}$ 側三相短路電流標么值（$\text{pu}$）。（10 分）
* **(二)** 各發電機之次暫態短路電流實際值（$\text{A}$）。（10 分）

---

### 💡 核心考點與破題關鍵
1. **發電機電抗基準值換算（換算至 $S_b = 100\text{ MVA}$）**：
   $$X_{new} = X_{old} \times \left(\frac{S_{b,new}}{S_{b,old}}\right) \times \left(\frac{V_{b,old}}{V_{b,new}}\right)^2$$
2. **發電機並聯等效電抗**：
   $$X_{G,eq} = X_{G1,pu} \parallel X_{G2,pu}$$
3. **故障前電壓標么值**：
   $$V_f = \frac{65\text{ kV}}{69\text{ kV}} = 0.942\text{ pu}$$

---

### ✏️ 步驟式詳細數學推導
1. **將各元件電抗換算至 $S_b = 100\text{ MVA}$ 基準**：
   - 假設發電機額定功率因數為 0.8，則容量分別為 $S_{G1} = \frac{50}{0.8} = 62.5\text{ MVA}$，若題目以 MW 即容量計，則：
     $$X_{G1} = 0.25 \times \frac{100}{50} = 0.50\text{ pu}$$
     $$X_{G2} = 0.25 \times \frac{100}{30} = 0.8333\text{ pu}$$
   - 發電機並聯等效次暫態電抗：
     $$X_{G,eq} = \frac{0.50 \times 0.8333}{0.50 + 0.8333} = \frac{0.4167}{1.3333} = 0.3125\text{ pu}$$
   - 加上變壓器電抗 $X_{Tr} = 0.10\text{ pu}$：
     $$X_{total} = X_{G,eq} + X_{Tr} = 0.3125 + 0.10 = 0.4125\text{ pu}$$
2. **計算變壓器 $69\text{ kV}$ 側三相短路電流標么值**：
   - 故障點初始電壓 $V_f = \frac{65}{69} = 0.9420\text{ pu}$。
   $$\mathbf{I_{sc,pu} = \frac{V_f}{X_{total}} = \frac{0.9420}{0.4125} = 2.2836\text{ pu}}$$
3. **計算各發電機之次暫態短路電流實際值（A）**：
   - $22\text{ kV}$ 側基準電流：
     $$I_{b,22kV} = \frac{S_b}{\sqrt{3} V_b} = \frac{100 \times 10^6}{\sqrt{3} \times 22 \times 10^3} = 2624.3\text{ A}$$
   - 短路總電流在 $22\text{ kV}$ 側：
     $$I_{sc,total} = I_{sc,pu} \times I_{b,22kV} = 2.2836 \times 2624.3 = 5992.9\text{ A}$$
   - 發電機分流（按導納比反比於電抗分配）：
     $$\mathbf{I_{G1} = I_{sc,total} \times \frac{X_{G2}}{X_{G1} + X_{G2}} = 5992.9 \times \frac{0.8333}{0.50 + 0.8333} = 5992.9 \times 0.625 = 3745.6\text{ A}}$$
     $$\mathbf{I_{G2} = I_{sc,total} \times \frac{X_{G1}}{X_{G1} + X_{G2}} = 5992.9 \times 0.375 = 2247.3\text{ A}}$$

---

### 🎯 第三題 滿分關鍵與結論
- **$69\text{ kV}$ 側短路電流標么值**：$I_{sc} = \mathbf{2.284\text{ pu}}$
- **發電機 1 次暫態短路電流**：$I_{G1} = \mathbf{3745.6\text{ A}}$
- **發電機 2 次暫態短路電流**：$I_{G2} = \mathbf{2247.3\text{ A}}$

## 四、電動機配線設計與 Y-$\Delta$ 降壓啟動（20 分）

### 📌 題目與已知條件
鋁材料加工廠擬裝設三相 $220\text{ V}$ 電動機兩台：$20\text{ HP}$ 一台（起動階級 E，起動容量 $4.5 \sim 4.99\text{ kVA/HP}$）與 $10\text{ HP}$ 一台。採 PVC 配管施工。
* **(一)** 繪圖說明如何以 Y-\Delta 起動器降低起動電流及其原理。（10 分）
* **(二)** 設計兩台電動機之線路，註明分路/幹線線徑及過電流保護斷路器之 AT 額定值。（10 分）

---

### 💡 核心考點與破題關鍵
1. **Y-\Delta 降壓啟動原理**：
   - 啟動時定子繞組接成 Y 接，每相承受相電壓 $V_\phi = \frac{V_L}{\sqrt{3}}$。
   - 啟動相電流降為全壓 \Delta 運轉之 $\frac{1}{\sqrt{3}}$，線電流降為全壓啟動之 $\frac{1}{3}$（$33.3\%$），啟動轉矩亦降為 $\frac{1}{3}$。
2. **電動機額定電流查表/公式**（三相 $220\text{ V}$ 經驗值）：
   - $20\text{ HP}$ 滿載額定電流：$I_{FLC,1} \approx 54\text{ A}$
   - $10\text{ HP}$ 滿載額定電流：$I_{FLC,2} \approx 28\text{ A}$
3. **導線安培容量與過電流保護規範（屋內線路裝置規則）**：
   - **分路導線**：$I_w \ge 1.25 \times I_{FLC}$
   - **幹線導線**：$I_{w,main} \ge 1.25 \times I_{FLC,max} + \sum I_{FLC,others}$
   - **無熔線斷路器（NFB/MCCB）保護**：
     - 分路保護：$I_{CB} \le 2.5 \times I_{FLC}$（一般非時延斷路器）
     - 幹線保護：$I_{CB,main} \le I_{CB,max} + \sum I_{FLC,others}$

---

### ✏️ 步驟式詳細數學推導
1. **$20\text{ HP}$ 電動機分路設計**：
   - 滿載電流 $I_{n1} = 54\text{ A}$。
   - 分路導線最小載流容量：$I_{w1} = 1.25 \times 54 = 67.5\text{ A} \implies$ 選用 **$22\text{ mm}^2$ PVC 絕緣銅線**（安全載流量 $80\text{ A}$）。
   - 分路斷路器 AT 值：$I_{CB1} = 2.5 \times 54 = 135\text{ A} \implies$ 標準品選用 **$125\text{ AT} \sim 150\text{ AT}$**（框架 $225\text{ AF}$）。
2. **$10\text{ HP}$ 電動機分路設計**：
   - 滿載電流 $I_{n2} = 28\text{ A}$。
   - 分路導線最小載流容量：$I_{w2} = 1.25 \times 28 = 35\text{ A} \implies$ 選用 **$8\text{ mm}^2$ PVC 絕緣銅線**（安全載流量 $40\text{ A}$）。
   - 分路斷路器 AT 值：$I_{CB2} = 2.5 \times 28 = 70\text{ A} \implies$ 標準品選用 **$75\text{ AT}$**（框架 $100\text{ AF}$）。
3. **共同幹線設計**：
   - 幹線導線最小載流容量：
     $$\mathbf{I_{w,main} = 1.25 \times 54 + 28 = 67.5 + 28 = 95.5\text{ A}}$$
     $\implies$ 選用 **$38\text{ mm}^2$ PVC 絕緣銅線**（安全載流量 $115\text{ A}$）。
   - 幹線斷路器保護 AT 值：
     $$\mathbf{I_{CB,main} \le 125\text{ A} + 28\text{ A} = 153\text{ A}}$$
     $\implies$ 選用標準容量 **$150\text{ AT}$**（框架 $225\text{ AF}$）。

---

### 🎯 第四題 滿分關鍵與結論
| 項目 | $20\text{ HP}$ 分路 | $10\text{ HP}$ 分路 | 共同幹線 |
| :--- | :---: | :---: | :---: |
| **導線規格** | **$22\text{ mm}^2$ PVC** | **$8\text{ mm}^2$ PVC** | **$38\text{ mm}^2$ PVC** |
| **斷路器保護** | **$125\text{ AT} / 225\text{ AF}$** | **$75\text{ AT} / 100\text{ AF}$** | **$150\text{ AT} / 225\text{ AF}$** |

## 五、自動功因調整器（APFR）電容器組投切控制（20 分）

### 📌 題目與已知條件
加工廠負載特性：
- 經常性負載：$P_1 = 200\text{ kW}, \text{PF}_1 = 0.85$ 落後（1 ~ 24 時全天運轉）。
- 新增負載：$P_2 = 100\text{ kW}, \text{PF}_2 = 0.70$ 落後（8 ~ 17 時運轉）。
目標功率因數提升至 $\text{PF} \ge 0.95$ 落後。現裝設每組 $50\text{ kvar}$ 共 6 組電容器盤結合 APFR 調控。
* **(一)** 求各時段（輕載時段與重載時段）理論需補償之無效功率 $Q_c$。（10 分）
* **(二)** 求各時段 APFR 實際投入之電容器組數、總補償容量及補償後之實際功率因數。（10 分）

---

### 💡 核心考點與破題關鍵
1. **補償容量計算公式**：$Q_c = P(\tan\theta_{old} - \tan\theta_{target})$
   - $\theta_{target} = \arccos(0.95) = 18.19^\circ \implies \tan\theta_{target} = 0.3287$
2. **階梯式電容器離散投切原則**：以 $50\text{ kvar}$ 為單位整數倍投切，確保補償後不發生過補償（Over-compensation / 領先功因）。

---

### ✏️ 步驟式詳細數學推導
1. **時段一：輕載時段（1 ~ 8 時及 17 ~ 24 時，共 15 小時）**：
   - 僅經常性負載運轉：$P = 200\text{ kW}, \text{PF}_1 = 0.85 \implies \tan\theta_1 = \tan(\arccos 0.85) = 0.6197$。
   - 原始無效功率：$Q_1 = 200 \times 0.6197 = 123.95\text{ kvar}$。
   - 理論所需補償容量：
     $$Q_{c1} = 200 \times (0.6197 - 0.3287) = 200 \times 0.2910 = \mathbf{58.21\text{ kvar}}$$
   - **實際投入決策**：
     - 若投 1 組（$50\text{ kvar}$）：殘餘無效功率 $Q' = 123.95 - 50 = 73.95\text{ kvar} \implies \text{PF}' = \cos(\arctan(73.95/200)) = \cos(20.29^\circ) = \mathbf{0.938}$
     - 若投 2 組（$100\text{ kvar}$）：殘餘無效功率 $Q' = 123.95 - 100 = 23.95\text{ kvar} \implies \text{PF}' = \cos(\arctan(23.95/200)) = \cos(6.83^\circ) = \mathbf{0.993} \ge 0.95$
     - **APFR 投入 2 組（$100\text{ kvar}$），實際功率因數為 $0.993$ 落後**。
2. **時段二：重載時段（8 ~ 17 時，共 9 小時）**：
   - 總實功率：$P_{total} = 200 + 100 = 300\text{ kW}$。
   - 新增負載無效功率：$Q_2 = 100 \times \tan(\arccos 0.70) = 100 \times 1.0202 = 102.02\text{ kvar}$。
   - 總無效功率：$Q_{total} = 123.95 + 102.02 = 225.97\text{ kvar}$。
   - 綜合原始功因：$\tan\theta_{orig} = \frac{225.97}{300} = 0.7532 \implies \text{PF}_{orig} = 0.799$。
   - 理論所需補償容量：
     $$Q_{c2} = 300 \times (0.7532 - 0.3287) = 300 \times 0.4245 = \mathbf{127.35\text{ kvar}}$$
   - **實際投入決策**：
     - 若投 3 組（$150\text{ kvar}$）：殘餘無效功率 $Q' = 225.97 - 150 = 75.97\text{ kvar} \implies \tan\theta' = \frac{75.97}{300} = 0.2532 \implies \mathbf{\text{PF}' = 0.969} \ge 0.95$。
     - **APFR 投入 3 組（$150\text{ kvar}$），實際功率因數為 $0.969$ 落後**。
