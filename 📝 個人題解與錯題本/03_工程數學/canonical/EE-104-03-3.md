# 104 年第 3 題｜主值積分

官方裁切題目為
\[
I=\operatorname{PV}\int_{-\infty}^{\infty}\frac{3x+2}{x(x-4)(x^2+9)}\,dx.
\]
因 (x=0,4) 在實軸上，普通廣義積分不存在，留數法的正確解讀是 Cauchy 主值。部分分式為
\[
\frac{3x+2}{x(x-4)(x^2+9)}=-\frac1{18x}+\frac7{50(x-4)}-\frac{19x+126}{225(x^2+9)}.
\]
對稱主值下，(operatorname{PV}int 1/x,dx=operatorname{PV}int 1/(x-4),dx=0)。剩餘兩項中奇函數 (x/(x^2+9)) 主值為零，而
\[
\int_{-\infty}^{\infty}\frac{dx}{x^2+9}=\frac\pi3.
\]
因此
\[
\boxed{I=-\frac{14\pi}{225}}.
\]
若題目未採主值慣例，應明確註記積分因實軸極點而發散；上式是考試留數題所使用的主值答案。
