# 上榜精確解答邊界：15 題條件題安全作答卡

> 目的是拿到可講清楚的步驟分，不是把題幹沒給的條件偷補成「唯一正解」。這些題不進入預設核心路徑，也不需要回填任何紀錄。

## 固定作答規則

1. 先寫題幹可唯一確定的式子與數值。
2. 再用一句「若採……假設」先寫假設，才代入數值。
3. 把結果明標為條件解，不當成唯一答案背誦。
4. 有兩個都能回代的分支時，主答寫工程上通常採用的分支，緊接一句說明另一分支為何未被題幹排除。
