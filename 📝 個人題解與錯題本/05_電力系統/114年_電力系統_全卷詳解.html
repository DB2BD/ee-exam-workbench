一、交流負載相量與複數功率計算 20 分

【題目】 端電壓 \(v(t) = \sqrt{2} \times 100 \cos(\omega t + \alpha)\text{ V}\)，相量為 \(100\angle\alpha\)；電流 \(i(t) = \sqrt{2} I_{rms} \cos(\omega t + 60^\circ)\text{ A}\)，相量為 \(I_{rms}\angle 60^\circ\)。負載實功率 \(P = 500\sqrt{3}\text{ W}\)，虛功率 \(Q = 500\text{ Var}\)，求 \(I_{rms}\) 及 \(\alpha\)。

💡 破題關鍵： 複數功率 \(\mathbf{S} = P + jQ = \mathbf{V}\mathbf{I}^* = |\mathbf{V}|I_{rms}\angle(\theta_v - \theta_i)\)。
$$|\mathbf{S}| = \sqrt{P^2 + Q^2} = \sqrt{(500\sqrt{3})^2 + 500^2} = 1000\text{ VA}$$ $$\theta = \tan^{-1}\left(\frac{Q}{P}\right) = \tan^{-1}\left(\frac{500}{500\sqrt{3}}\right) = 30^\circ$$ $$\mathbf{S} = (100\angle\alpha)(I_{rms}\angle -60^\circ) = 100 I_{rms}\angle(\alpha - 60^\circ) = 1000\angle 30^\circ$$
🎯 滿分結論：
• \(100 I_{rms} = 1000 \implies \mathbf{I_{rms} = 10\text{ A}}\)
• \(\alpha - 60^\circ = 30^\circ \implies \mathbf{\alpha = 90^\circ}\)
二、二匯流排電力潮流與 Newton-Raphson 疊代 20 分

【題目】 系統基準 \(S_{base} = 100\text{ MVA}\)。匯流排 1 為 Slack Bus (\(\mathbf{V}_1 = 1.0\angle 0^\circ\text{ pu}\))。匯流排 2 有 \(P_{g2} = 100\text{ MW}\) 發電機與 \(250\text{ MW} + j100\text{ Mvar}\) 負載，線路導納 \(y_{12} = -j10\text{ pu}\)。

(一) 求 \(\delta_2\) 與 \(Q_{g2}\)：

標么值：\(P_{2,sch} = (100 - 250)/100 = -1.5\text{ pu}\)
\(P_2 = |V_2||V_1| B_{21}\sin\delta_2 = 10\sin\delta_2 = -1.5 \implies \sin\delta_2 = -0.15\)
\(\mathbf{\delta_2 = -0.15057\text{ rad} = -8.627^\circ}\)
\(Q_2 = -10(1)(1)\cos(-8.627^\circ) - (1)^2(-10) = -9.8869 + 10 = 0.1131\text{ pu}\)
\(Q_{g2} = Q_2 + Q_{d2} = 0.1131 + 1.0 = 1.1131\text{ pu} = \mathbf{111.31\text{ Mvar}}\)

(二) Q 極限判斷與 Newton-Raphson 疊代：

• \(Q_{g2} = 111.31\text{ Mvar} > 100\text{ Mvar}\)（超出上限！）$\implies$ 轉為 PQ Bus，鎖定 \(Q_{g2} = 1.0\text{ pu}\)，\(Q_{2,sch} = 0.0\text{ pu}\)。
• 初值 \(\delta_2^{(0)}=0, |V_2|^{(0)}=1.0\)，不平衡量 \(\Delta P_2 = -1.5, \Delta Q_2 = 0.0\)。
• 雅可比矩陣 \(\mathbf{J}^{(0)} = \begin{bmatrix} 10 & 0 \\ 0 & 10 \end{bmatrix}\)
• 修正量：\(\Delta\delta_2 = -0.15\text{ rad}, \Delta |V_2| = 0.0\)
• 一次疊代後結果：\(\mathbf{\delta_2^{(1)} = -0.15\text{ rad} = -8.594^\circ, \quad |V_2|^{(1)} = 1.0\text{ pu}}\)
三、二發電機最佳經濟調度 20 分

【題目】 成本函數 \(C_1 = 400 + 6.0 P_1 + 0.004 P_1^2\)，\(C_2 = 400 + 6.8 P_2 + 0.002 P_2^2\)，總需求 \(P_D = 550\text{ MW}\)，求各廠最佳出力。

💡 破題關鍵： 等微增成本準則 \(\lambda = \frac{dC_1}{dP_1} = \frac{dC_2}{dP_2}\)。
$$\text{IC}_1 = 6.0 + 0.008 P_1 = \lambda \implies P_1 = 125\lambda - 750$$ $$\text{IC}_2 = 6.8 + 0.004 P_2 = \lambda \implies P_2 = 250\lambda - 1700$$ $$P_1 + P_2 = 375\lambda - 2450 = 550 \implies 375\lambda = 3000 \implies \mathbf{\lambda = 8.0\text{ \$/MWh}}$$
🎯 滿分結論：
• \(P_1 = 125(8.0) - 750 = \mathbf{250\text{ MW}}\)
• \(P_2 = 250(8.0) - 1700 = \mathbf{300\text{ MW}}\)
四、戴維寧等效三相短路故障分析 20 分

【題目】 匯流排 1 發生三相短路，故障阻抗 \(Z_f = j0.0125\text{ pu}\)。左側發電機 \(j0.1\) 串聯變壓器 \(j0.4\)；右側發電機 \(j0.1\) 串聯線路 \(j0.2\)。

(一) 故障點阻抗與故障電流：
• 戴維寧等效阻抗：\(Z_{th1} = (j0.5) \parallel (j0.3) = \mathbf{j0.1875\text{ pu}}\)
• 總故障阻抗：\(Z_{\text{total}} = j0.1875 + j0.0125 = j0.20\text{ pu}\)
• 故障電流：\(I_f = \frac{1.0}{j0.20} = \mathbf{-j5.0\text{ pu} = 5.0\angle -90^\circ\text{ pu}}\)
(二) 故障期間電壓與電流：
• \(V_1 = I_f \times Z_f = (-j5.0)(j0.0125) = \mathbf{0.0625\text{ pu}}\)
• 支路電流：\(I_{31} = \frac{1.0 - 0.0625}{j0.5} = \mathbf{-j1.875\text{ pu}}, \quad I_{21} = \frac{1.0 - 0.0625}{j0.3} = \mathbf{-j3.125\text{ pu}}\)
• 匯流排電壓：\(V_3 = 1.0 - (-j1.875)(j0.1) = \mathbf{0.8125\text{ pu}}, \quad V_2 = 1.0 - (-j3.125)(j0.1) = \mathbf{0.6875\text{ pu}}\)
五、發電機轉子加速度與同步轉速計算 20 分

【題目】 2 極，\(60\text{ Hz}\) 發電機，額定 \(250\text{ MVA}\)，\(H = 4.32\text{ s}\)，穩態出力 \(P_m = 60\text{ MW} = 0.24\text{ pu}\)。負載突切（\(P_e = 0\)），求轉子加速度與 12 週期後轉速。

💡 搖擺方程式推導：
• 加速功率：\(P_a = P_m - P_e = 0.24 - 0 = 0.24\text{ pu}\)
• 角加速度：\(\alpha = \frac{P_a \cdot \omega_s}{2H} = \frac{0.24 \times 120\pi}{2 \times 4.32} = \mathbf{\frac{10\pi}{3}\text{ rad/s}^2 \approx 10.472\text{ rad/s}^2 = 600^\circ/\text{s}^2}\)
🎯 12 週期末轉速計算：
• 時間 \(\Delta t = 12 / 60 = 0.2\text{ s}\)
• 轉速加速度：\(a_{\text{rpm}} = \left(\frac{10\pi}{3}\right) \times \frac{60}{2\pi} = 100\text{ rpm/s}\)
• 轉速增加量：\(\Delta N = 100 \times 0.2 = 20\text{ rpm}\)
• 終點轉速：\(N = N_s + \Delta N = 3600 + 20 = \mathbf{3620\text{ rpm}}\)
