## 五、考慮輸電線損失之兩電廠最佳經濟調度方程式（20 分）

### 📌 題目與已知條件
二座發電廠具有相同燃料成本函數：
$$C_i = \beta P_{Gi} + \gamma P_{Gi}^2 \quad (\text{\$/h}), \quad i=1, 2$$
其中 $\beta = 6\ \text{\$/MWh}, \ \gamma = 5 \times 10^{-3}\ \text{\$/MW}^2\text{h}$（成本函數 $C_i = 6 P_{Gi} + 0.005 P_{Gi}^2$）。
輸電線損失方程式為：
$$P_L = B_{11} P_{G1}^2 + B_{22} P_{G2}^2$$
其中 $B_{11} = 0.5 \times 10^{-3}\text{ MW}^{-1}, \ B_{22} = 0.2 \times 10^{-3}\text{ MW}^{-1}$。總負載需求 $P_D = 600\text{ MW}$。

**試求**：請將各數值代入列出，求 $P_{G1}、P_{G2}$ 最佳調度值之協調方程式（Coordination Equations）及功率平衡約束方程式。（20 分）

---

### 💡 核心考點與破題關鍵
1. **增量成本（Incremental Cost, $\text{IC}_i$）**：
   $$\text{IC}_i = \frac{dC_i}{dP_{Gi}} = \beta + 2\gamma P_{Gi} = 6 + 2(5 \times 10^{-3}) P_{Gi} = 6 + 0.010 P_{Gi}$$
2. **增量傳輸損失（Incremental Transmission Loss, $\text{ITL}_i$）**：
   $$\text{ITL}_i = \frac{\partial P_L}{\partial P_{Gi}} = 2 B_{ii} P_{Gi}$$
3. **拉格朗日協調方程式（Lagrangian Coordination Equations）**：
   $$L_i \times \text{IC}_i = \lambda \iff \frac{\text{IC}_i}{1 - \text{ITL}_i} = \lambda$$
   其中 $L_i = \frac{1}{1 - \frac{\partial P_L}{\partial P_{Gi}}}$ 為懲罰因數（Penalty Factor）。

---

### ✏️ 步驟式詳細數學推導
1. **計算各電廠之增量燃料成本**：
   $$\text{IC}_1 = \frac{dC_1}{dP_{G1}} = 6 + 2(5 \times 10^{-3}) P_{G1} = \mathbf{6 + 0.010 P_{G1}}\quad (\text{\$/MWh})$$
   $$\text{IC}_2 = \frac{dC_2}{dP_{G2}} = 6 + 2(5 \times 10^{-3}) P_{G2} = \mathbf{6 + 0.010 P_{G2}}\quad (\text{\$/MWh})$$
2. **計算各電廠之增量傳輸線損失（ITL）**：
   $$\frac{\partial P_L}{\partial P_{G1}} = 2 B_{11} P_{G1} = 2(0.5 \times 10^{-3}) P_{G1} = \mathbf{0.001 P_{G1}} = 10^{-3} P_{G1}$$
   $$\frac{\partial P_L}{\partial P_{G2}} = 2 B_{22} P_{G2} = 2(0.2 \times 10^{-3}) P_{G2} = \mathbf{0.0004 P_{G2}} = 0.4 \times 10^{-3} P_{G2}$$
3. **建立懲罰因數 $L_1, L_2$**：
   $$L_1 = \frac{1}{1 - \frac{\partial P_L}{\partial P_{G1}}} = \frac{1}{1 - 0.001 P_{G1}}$$
   $$L_2 = \frac{1}{1 - \frac{\partial P_L}{\partial P_{G2}}} = \frac{1}{1 - 0.0004 P_{G2}}$$
4. **代入列出最佳經濟調度協調方程式**：
   $$\mathbf{\frac{6 + 0.010 P_{G1}}{1 - 0.001 P_{G1}} = \frac{6 + 0.010 P_{G2}}{1 - 0.0004 P_{G2}} = \lambda}$$
5. **功率平衡約束方程式**：
   $$P_{G1} + P_{G2} = P_D + P_L$$
   $$\mathbf{P_{G1} + P_{G2} = 600 + 0.5 \times 10^{-3} P_{G1}^2 + 0.2 \times 10^{-3} P_{G2}^2}$$
   $$\mathbf{P_{G1} + P_{G2} = 600 + 0.0005 P_{G1}^2 + 0.0002 P_{G2}^2}$$
6. **數值收斂精確求解（加分補充）**：
   - 聯立非線性疊代求解可得精確最佳工作點：
     $$\mathbf{\lambda = 11.8877\ \text{\$/MWh}}$$
     $$\mathbf{P_{G1} = 269.00\text{ MW}}, \quad \mathbf{P_{G2} = 399.03\text{ MW}}$$
     $$\mathbf{P_L = 0.0005(269.00)^2 + 0.0002(399.03)^2 = 36.18 + 31.84 = 68.02\text{ MW}}$$
     驗證：$P_{G1} + P_{G2} = 269.00 + 399.03 = 668.03\text{ MW} = 600\text{ MW} + 68.02\text{ MW} = P_D + P_L$（完全平衡！）

---

### 🎯 第五題 滿分關鍵與結論
* **最佳經濟調度協調方程式**：
  $$\mathbf{\frac{6 + 0.01 P_{G1}}{1 - 0.001 P_{G1}} = \frac{6 + 0.01 P_{G2}}{1 - 0.0004 P_{G2}} = \lambda}$$
* **功率平衡限制方程式**：
  $$\mathbf{P_{G1} + P_{G2} = 600 + (0.0005 P_{G1}^2 + 0.0002 P_{G2}^2)}$$
* **最佳發電配置數值**：$P_{G1} = \mathbf{269.00\text{ MW}}, \ P_{G2} = \mathbf{399.03\text{ MW}}, \ \lambda = \mathbf{11.89\ \text{\$/MWh}}$
