# 111 年第 3 題｜待獨立校驗

## 官方題目（逐題裁切）

一部具有H = 6.0 MJ/MVA 的發電機，經由一純電抗網路傳送1.0 標么
的實功率到一個無限匯流排，可以被傳送的最大實功率為2.5 標么，當
三相短路故障發生在發電機輸出端時，發電機的輸出實功率降為零，在
故障清除後，系統再度恢復到原來的網路狀態。試求臨界清除角及臨界
清除時間。（25 分）
